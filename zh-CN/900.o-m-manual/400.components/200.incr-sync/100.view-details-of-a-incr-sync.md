# 查看 Incr-Sync 组件的详情

OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版运维监控模块的 Incr-Sync 页面提供 Incr-Sync 组件的常见运维操作，以便运维人员监控 Incr-Sync 的运行状态，遇到故障或问题时可以快速排查。

## 操作步骤

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.layout.constants.OMMonitoring">运维监控</UI-TERM>** **>** **<UI-TERM key="oms-community.Audit.constants.Component">组件</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.Audit.constants.Component">组件</UI-TERM>** 页面，单击 **<UI-TERM>Incr-Sync</UI-TERM>** 页签。

4. 在 **<UI-TERM>Incr-Sync</UI-TERM>** 页面，通过搜索 Incr-Sync 名称、机器 IP、任务名称等信息，或通过筛选状态进行精确查询，查找目标 Incr-Sync 组件。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>OMS 社区版不支持在 <strong>Incr-Sync</strong> 页面进行模糊查询。</p>
    </main>

5. 查看 Incr-Sync 组件的基本信息。

   | **参数** |  **<UI-TERM key="oms-community.pages.SystemParam.Description">描述</UI-TERM>**    |
   |--------|----|
   | 名称     | Incr-Sync 组件的名称。鼠标悬停至 Incr-Sync 名称，并单击复制图标，即可复制 Incr-Sync 名称。  |
   | 地域     | 您可以在地域列进行筛选，查看目标地域下的 Incr-Sync 信息。    |
   | 任务名称      | Incr-Sync 组件所关联的数据迁移或数据同步任务的名称。单击后，您可以直接跳转至该任务的详情页面。|
   | 任务类型     | 包括 **<UI-TERM key="oms-community.src.constants.DataMigration">数据迁移</UI-TERM>** 和 **<UI-TERM key="oms-community.components.CustomizedTable.DataSynchronization">数据同步</UI-TERM>**。         |
   | 类型         | 数据迁移任务的迁移类型、数据同步任务的同步类型。|
   | RPS    | 服务器每秒处理的事务数，用于衡量系统吞吐量。               |
   | 延时（s）  | “当前时间 - 当前写入至目标端记录的最小变更时间”得到的时间差即 Incr-Sync 组件的延迟时间。该时间计算存在轮询，轮询时间请参考括号内多少秒前更新的时间。   |
   | 延时刷新时刻 | 显示距离上次任务延时更新的时间间隔。|
   | 状态     | Incr-Sync 组件的状态，包括 **<UI-TERM key="oms-community.Operator.constants.Running">运行中</UI-TERM>**、**<UI-TERM key="oms-community.Migration.constants.Stopped">已停止</UI-TERM>** 和 **<UI-TERM key="oms-community.Operation.Overview.constants.Exception">异常</UI-TERM>**。  |
   | 操作     | <ul><li>处于 **<UI-TERM key="oms-community.Migration.constants.Running">运行中</UI-TERM>** 状态的 Incr-Sync 组件，您可以进行 **<UI-TERM key="oms-community.Overview.constants.Pause">暂停</UI-TERM>**、**<UI-TERM key="oms-community.Operator.Checker.DisableUpdateBtn.Update">更新</UI-TERM>** 和 **<UI-TERM key="oms-community.Operation.Machine.ViewLogs">查看日志</UI-TERM>** 操作。<li>处于 **<UI-TERM key="oms-community.Migration.constants.Stopped">已停止</UI-TERM>** 和 **<UI-TERM key="oms-community.Operation.constants.Exception">异常</UI-TERM>** 状态的 Incr-Sync 组件，您可以进行 **<UI-TERM key="oms-community.Audit.constants.Start">启动</UI-TERM>**、**<UI-TERM key="oms-community.Operation.Machine.Update">更新</UI-TERM>**、**<UI-TERM key="oms-community.EndpointPublic.constants.Delete">删除</UI-TERM>**、**<UI-TERM key="oms-community.components.PreCheck.PreCheckRes.Migration">迁移</UI-TERM>** 和 **<UI-TERM key="oms-community.components.Operator.openLog.ViewLogs">查看日志</UI-TERM>** 操作。                               |
