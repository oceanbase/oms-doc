# 删除 Incr-Sync 组件

本文为您介绍如何删除 Incr-Sync 组件，以节约运行资源。

## 使用限制

* OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版支持删除处于 **<UI-TERM key="oms-community.Operation.Overview.constants.Stopped">已停止</UI-TERM>** 或 **<UI-TERM key="oms-community.Migration.constants.Exception">异常</UI-TERM>** 状态的 Incr-Sync 组件。

* 不能删除正在运行或正在接入的任务对应的 Incr-Sync 组件。

* 如果数据迁移或数据同步任务报错，您需要重新创建任务。请删除任务和 Incr-Sync 组件，再创建新的任务。

## 前提条件

请先停止需要删除的 Incr-Sync 组件，详情请参见 [启动和暂停 Incr-Sync 组件](../200.incr-sync/200.start-and-pause-a-incr-sync.md)。

## 操作步骤

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.Welcome.constants.OMMonitoring">运维监控</UI-TERM>** **\>** **<UI-TERM key="oms-community.Audit.constants.Component">组件</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.Operation.OperationComponent.Component">组件</UI-TERM>** 页面，单击 **Incr-Sync** 页签。

4. 在 **Incr-Sync** 页面，通过 Incr-Sync 名称、机器 IP 或任务名称进行筛选，查找目标 Incr-Sync 组件。

   您可以在地域列进行筛选，删除目标地域下的 Incr-Sync 组件。

5. 在目标 Incr-Sync 对应的 **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.Operation">操作</UI-TERM>** 列单击 **<UI-TERM key="oms-community.project.cloudweb.MoreOperations">更多操作</UI-TERM>** > **<UI-TERM key="oms-community.components.BanchView.Delete">删除</UI-TERM>**。

6. 在对话框中输入 **delete**，并单击 **<UI-TERM key="oms-community.pages.EndpointPublic.Add">确定</UI-TERM>**。
