# 更新 Incr-Sync 组件

OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版支持查看和更新指定 Incr-Sync 组件的配置。更新配置时，默认显示该 Incr-Sync 组件的现存配置。您可以直接查看配置信息，也可以对配置进行修改。

## 使用限制

* OMS 社区版支持更新处于 **<UI-TERM key="oms-community.Operator.constants.Running">运行中</UI-TERM>**、**<UI-TERM key="oms-community.Operator.constants.Stopped">已停止</UI-TERM>** 和 **<UI-TERM key="oms-community.Operator.constants.Exception">异常</UI-TERM>** 状态的 Incr-Sync 组件的配置。

* 更新 Incr-Sync 组件的配置后，系统会重启 Incr-Sync 组件以生效配置的变更，请谨慎操作。

  遇到数据迁移/数据同步任务失败的问题时，请先检查该任务的配置。例如，源端和目标端的基本信息及用户权限等。

## 适用场景

通常更新 Incr-Sync 组件的配置适用于以下场景：

* 因为配置信息出错，导致数据迁移/数据同步任务失败。

* 数据迁移/数据同步任务调优。

## 进入更新配置对话框

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.OMMonitoring">运维监控</UI-TERM>** **>** **<UI-TERM key="oms-community.Audit.constants.Component">组件</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.Operation.OperationComponent.Component">组件</UI-TERM>** 页面，单击 **<UI-TERM>Incr-Sync</UI-TERM>** 页签。

4. 在 **<UI-TERM>Incr-Sync</UI-TERM>** 页面，通过 Incr-Sync 组件的名称、IP 地址或任务的名称进行筛选，查找目标 Incr-Sync 组件。

   您可以在地域列进行筛选，更新目标地域下的 Incr-Sync 组件。

5. 单击目标 Incr-Sync 组件对应 **<UI-TERM key="oms-community.pages.Audit.Operation">操作</UI-TERM>** 列的 **<UI-TERM key="oms-community.IncrSync.New.Update">更新</UI-TERM>**。

6. 在 **<UI-TERM key="oms-community.Operator.Connector.useConnectorAction.UpdateConfigurations">更新配置</UI-TERM>** 对话框，根据实际情况选择在 **<UI-TERM>配置列表</UI-TERM>** 或 **<UI-TERM>配置详情</UI-TERM>** 页签新增或更新配置。参数详情请参见 [组件参数说明](../../../900.o-m-manual/400.components/500.component-parameters/100.coordinator.md) 模块的内容。

## 在配置列表页签新增或更新配置

### 新增配置

1. 进入 **<UI-TERM key="oms-community.Operator.Connector.useConnectorAction.UpdateConfigurations">更新配置</UI-TERM>** 对话框的 **<UI-TERM>配置列表</UI-TERM>** 页签。

2. 单击页面下方的 **<UI-TERM>+ 添加</UI-TERM>**。

3. 在第一列输入需要添加的参数名称，在第二列输入该新增参数的取值。

4. 添加完成后，在 **<UI-TERM>配置列表</UI-TERM>** 页签，单击 **<UI-TERM key="oms-community.components.ImportTransferObj.Determine">确定</UI-TERM>**。

   如果您需要删除参数，单击目标参数取值右侧的删除图标即可。

### 更新配置

1. 进入 **<UI-TERM key="oms-community.Operator.Connector.useConnectorAction.UpdateConfigurations">更新配置</UI-TERM>** 对话框的 **<UI-TERM>配置列表</UI-TERM>** 页签。

2. 找到需要修改的目标参数，在第二列输入该目标参数新的的取值。

   如果您需要删除参数，单击目标参数取值右侧的删除图标即可。您还可以根据实际需要，修改 **<UI-TERM>并发速度</UI-TERM>**。

3. 修改完成后，在 **<UI-TERM>配置列表</UI-TERM>** 页签，单击 **<UI-TERM key="oms-community.components.ImportTransferObj.Determine">确定</UI-TERM>**。

## 在配置详情页签新增或更新配置

### 新增配置

1. 在 **<UI-TERM key="oms-community.Operator.Checker.useCheckerAction.UpdateConfigurations">更新配置</UI-TERM>** 对话框，单击 **<UI-TERM>配置详情</UI-TERM>** 页签。

2. 根据实际情况，鼠标悬停至 `condition`、`coordinator`、`sink` 或 `source` 参数旁边的空白处，单击添加图标。

3. 输入需要添加的 **Key Name**，单击对号。

4. 在 **<UI-TERM key="oms-community.Operator.JDBCWriter.useJDBCWriterAction.UpdateConfigurations">更新配置</UI-TERM>** 对话框，找到新增的 Key Name，其默认值为 NULL。

5. 鼠标悬停至新增参数，单击显示的编辑图标。修改参数值后，单击确认图标。

6. 在 **<UI-TERM>配置详情</UI-TERM>** 页签，单击 **<UI-TERM key="oms-community.Operator.JDBCWriter.useJDBCWriterAction.Start">确定</UI-TERM>**。

### 更新配置

1. 在 **<UI-TERM key="oms-community.Operator.Store.useStoreAction.UpdateConfigurations">更新配置</UI-TERM>** 对话框，单击 **<UI-TERM>配置详情</UI-TERM>** 页签。

2. 鼠标悬停至目标配置，单击显示的编辑图标。

3. 在文本框中输入修改后的参数后，单击确认图标。

   绿色的对号表示更新数值，红色的叉号表示取消修改。

4. 修改完成后，在 **<UI-TERM>配置详情</UI-TERM>** 页签，单击 **<UI-TERM key="oms-community.components.ImportTransferObj.Determine">确定</UI-TERM>**。
