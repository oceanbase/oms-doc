# 启动和暂停 Incr-Sync 组件

OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版的监控运维模块支持对 Incr-Sync 组件进行停止或启动等运维操作。您可以停止 Incr-Sync 组件的运行，并在修复问题后进行自动或手动启动。

## 使用限制

* OMS 社区版支持启动处于 **<UI-TERM key="oms-community.Operator.constants.Stopped">已停止</UI-TERM>** 和 **<UI-TERM key="oms-community.Notification.Setting.AlarmChannel.Exception">异常</UI-TERM>** 状态的 Incr-Sync 组件。

* OMS 社区版支持暂停处于 **<UI-TERM key="oms-community.ModifyRecordTable.constants.Running">运行中</UI-TERM>** 状态的 Incr-Sync 组件。

## 启动 Incr-Sync 组件

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.layout.constants.OMMonitoring">运维监控</UI-TERM>** **>** **<UI-TERM key="oms-community.Operation.OperationComponent.Component">组件</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Components">组件</UI-TERM>** 页面，单击 **<UI-TERM>Incr-Sync</UI-TERM>** 页签。

4. 在 **<UI-TERM>Incr-Sync</UI-TERM>** 页面，通过 Incr-Sync 名称、机器 IP 或任务名称进行筛选，查找未运行的目标 Incr-Sync 组件。

   您可以在地域列进行筛选，启动目标地域下未运行的 Incr-Sync 组件。

5. 单击目标 Incr-Sync 对应 **<UI-TERM key="oms-community.components.MonitorDrawer.Operation">操作</UI-TERM>** 列的 **<UI-TERM key="oms-community.Detail.components.StartConnectorModal.Start">启动</UI-TERM>**。

6. 在弹出对话框中确认 **<UI-TERM key="oms-community.components.ResetPassword.ResetUserPassword.OperationObject">操作对象</UI-TERM>** 和 **<UI-TERM key="oms-community.Detail.components.StartConnectorModal.PullBack">是否重置同步位点</UI-TERM>** 后，单击 **<UI-TERM key="oms-community.components.SyncObjectForm.Determine">确定</UI-TERM>**。

## 暂停 Incr-Sync 组件

发现 Incr-Sync 组件出现延时较高等运行异常状态时，建议及时停止 Incr-Sync，修复问题。

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.layout.constants.OMMonitoring">运维监控</UI-TERM>** **>** **<UI-TERM key="oms-community.Operation.OperationComponent.Component">组件</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Components">组件</UI-TERM>** 页面，单击 **<UI-TERM>Incr-Sync</UI-TERM>** 页签。

4. 在 **<UI-TERM>Incr-Sync</UI-TERM>** 页面，您可以通过 Incr-Sync 名称、机器 IP 或任务名称进行筛选，查找运行中的目标 Incr-Sync 组件。

   您可以在地域列进行筛选，暂停目标地域下的 Incr-Sync 组件。

5. 单击目标 Incr-Sync 对应 **<UI-TERM key="oms-community.components.ProjectLabel.LabelManager.Operation">操作</UI-TERM>** 列的 **<UI-TERM key="oms-community.Overview.constants.Pause">暂停</UI-TERM>**。

6. 单击对话框中的 **<UI-TERM key="oms-community.components.ProjectLabel.LabelManager.Determine">确定</UI-TERM>**。
