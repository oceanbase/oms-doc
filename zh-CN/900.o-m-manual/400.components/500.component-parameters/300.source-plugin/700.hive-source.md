# HiveSource

OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版 4.2.8-CE 及之后版本支持迁移 Hive 数据库的数据至 OceanBase 社区版，本文为您介绍 HiveSource 相关参数。

`source.json` 配置文件如下：

```Json
    {
        "boosterClass":"com.oceanbase.oms.connector.source.hive.OmsHiveRunner",
        "clients":[
            {
                "clientId":"np_6cm31nfy1d28",
                "instance":"jdbc:hive2://sqaoxxxxxxx:10000/default",
                "username":"hadoop",
                "password":" ",
                "hiveconf":{
                            "HADOOP_USER_NAME":"hadoop",
                            "oms.kerberos.principal":"",
                            "oms.kerberos.keytab.file":"",
                            //spark 才需要
                        "hive.metastore.uris":"thrift://sqaoxxxxxxx:9083"
                        },
        "fileconf":{
            "hive-site.xml":"hive-site.xml 文件内容，base64 编码"
        }
            }
        ],
    //您可以自定义读取 Hive 的 SQL 语句。此处的 select 字段顺序必须和目标端 OceanBase 社区版中的表字段顺序一致，并且数量一致。
    "hivesql":[
        {
        "table":"schema.table_name",
        "sql":"select f1,f2 from schema.table_name where f1='xx'"
        }
    ],
    "addjars": [
            "/data/1/hadoop/oms-hive-jdbc-handler.jar","/data/1/hive/lib/hive-jdbc-handler-2.3.9.jar","/data/1/hive/lib/commons-dbcp-1.4.jar","/data/1/hive/lib/commons-pool-1.5.4.jar"
        ],
    "jar":"connector-hive.jar:connector-dataflow.jar",
        "dbVersion":"1.2.0-cdh5.15.2",
        "timezone":"+08:00",
        "taskResume":"false",
        "type":"HIVE_SOURCE",
    "sliceWorkerNum":"4",
    "dbType":"HIVE"
    }
```

|    参数   |   描述   |
|-----------------|------------------|
| hiveconf | hiveconf 中的配置可以使用在 Hive 命令行中使用 SET 语句设置的配置参数。|
| hivesql | 该参数适用于需要自定义查询 Hive 表 SQL 语句的情况。从 Hive 向 OceanBase 社区版写入数据时，OMS 社区版会使用 OceanBase 社区版目标表中的所有字段名和顺序来组装查询 Hive 表的 SQL 语句。如果存在以下两种情况，则需要您自定义查询 Hive SQL，并且自定义 SQL 的 SELECT 字段顺序必须和目标端 OceanBase 社区版中的字段顺序保持一致。<ul><li>Hive 表的字段名称和目标端 OceanBase 社区版中的字段名称不一致。<li>目标端 OceanBase 社区版中的字段在 Hive 表中不存在。该情况可以使用常量替换字段应该出现的位置。</ul>
| addjars | 该参数用于添加外表相关的 JAR 包，包括 Hive Server2 本地模式和 HTTP 模式。<ul><li>Hive Server2 本地模式：JAR 复制到 Hive Server2 服务器的特定目录，此处直接配置 JAR 目录。<li>HTTP 模式：对于 Hive 支持 HTTP 方式添加 JAR 包的情况，您可以直接使用 OMS 社区版的 HTTP 服务添加 JAR 包（http://{OMS_IP}:{OMS_PORT}/jars/oms-hive-jdbc-handler.jar）。<main id="notice" type='notice'><h4>注意</h4><p>oms-hive-jdbc-handler.jar 为必填项。对于部分 Hive，还需要添加 Hive 自带的 JAR 包：hive-jdbc-handler-x.x.x.jar,commons-dbcp-x.x.jar,commons-pool-x.x.x.jar。</p></main></ul>|
| sliceWorkerNum | 该参数用于控制读取 Hive 表的并发，表示同时有几张 Hive 表在进行读写。默认值为 4。|
