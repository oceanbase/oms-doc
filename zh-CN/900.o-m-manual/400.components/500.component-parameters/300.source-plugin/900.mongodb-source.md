# MongoDBSource

OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版 V4.2.10-CE 及之后版本支持迁移 MongoDB 数据库的数据至 OceanBase 社区版，本文为您介绍 MongoDBSource 相关参数。

|    参数  |   描述   |
|--------------|--------------|
| retainId | 是否保留 MongoDB 的 `_id` 字段。BOOLEAN 类型，默认值为 `true`。|
| mongoIdName | MongoDB `_id` 字段映射到 OceanBase 社区版的 ID 字段名称。STRING 类型，默认值为 `_id`。|
| docAsField | 是否将整个 document 作为 OceanBase 社区版的一个字段。BOOLEAN 类型，默认值为 `false`。<br>设置 docAsField 为 `true` 时，默认迁移 `_id` 字段，同时需要指定 `mongoIdName`。|
| docFieldName | 整个 document 作为 OceanBase 社区版字段的字段名称，STRING 类型。|
| enableSplitVector | 是否使用 splitVector 命令切片。BOOLEAN 类型，默认值为 `true`。<br>如果设置为 `false`，则使用 skip 进行切片。|
| tlsProvider  | 仅 MongoDB Source 支持。当 MongoDB 数据库仅启用 tls1.3 时，需要配置为 `CONSCRYPT`（目前仅支持 `CONSCRYPT`）。|
