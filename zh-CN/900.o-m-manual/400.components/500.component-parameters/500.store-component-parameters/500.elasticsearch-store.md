# ElasticSearch Store

|  参数  |  是否必填 | 默认值 | 描述  |
|--------------|-------------|--------------|------------|
| es.host | 是 | 无 | ElasticSearch 连接地址。例如，`<http://10.10.10.1:9200>`。|
| es.port | 是 | 无 | ElasticSearch 端口。|
| es.username | 否 | 无 | ElasticSearch 用户名。|
| es.password | 否 | 无 | ElasticSearch 密码。|
| es.pullThreadPoolSize | 否 | 16 | CCR 拉取线程池大小，所有索引 Shard 共用。|
| es.whitelist | 是 | 无 | 白名单，使用竖线（\|）分割的通配符表达。通配符仅支持 `*.*`、`dbName.*` 或 `dbName.tableName` 格式。|
| es.blacklist | 否 | 无 | 黑名单，使用竖线（\|）分割的通配符表达。通配符仅支持 `*.*`、`dbName.*` 或 `dbName.tableName` 格式。|
| es.usePluginApi | 是 | true | 是否使用插件模式（在 ElasticSearch 中安装 OMS 的插件）。 |
| es.startFromCurrentMaxSeqNo | 是 | false | 是否从最大的 seqno 开始，默认从最小的开始。 |
| es.retentionLeaseEnabled | 是 | true | 是否开启租约。不开启可能会丢失数据；开启后，ElasticSearch 服务端会保留一段时间的数据，过期的租约由 ES 服务端参数 `index.soft_deletes.retention_lease.period` 控制失效时间。 |
| es.retentionLeaseRenewIntervalSeconds | 是 | 30 | 续租时间间隔。 |
| es.skipOnHistoryGap | 是 | false | 碰到 seqno 漏洞的是否跳过，默认不跳过报错。 |
| es.retentionLeaseRemoveOnStop | 是 | false | store 退出是否删除租约，默认不删除，过期的租约由 ES 服务端参数 `index.soft_deletes.retention_lease.period` 控制失效时间。 |
