# MongoDB Store

| 参数 | 是否必填 | 默认值 | 描述 |
|-----------|------------|------------|----------|
| mongodb.host | 是 | 无 | MongoDB 数据库的 IP 地址。|
| mongodb.port | 是 | 无 | MongoDB 数据库的端口。|
| mongodb.username | 否 | 无 | MongoDB 数据库的用户名。|
| mongodb.password | 否 | 无 | MongoDB 数据库的密码。|
| mongodb.authDatabase | 否 | 无 | 认证数据库。|
| mongodb.tlsCAFile | 否 | 无 | CA 证书路径。|
| mongodb.tlsCertificateKeyFile | 否 | 无 | 客户端证书路径。|
| mongodb.tlsCertificateKeyFilePassword | 否 | 无 | 客户端证书文件的密码。|
| mongodb.tlsAllowInvalidHostnames | 否 | 无 | 是否忽略主机名验证。|
| mongodb.whitelist | 是 | 无 | 白名单，使用竖线（\|）分割的通配符表达。通配符仅支持 `*.*`、`dbName.*` 或 `dbName.tableName` 格式。|
| mongodb.blacklist |  否 | 无 | 黑名单，使用竖线（\|）分割的通配符表达。通配符仅支持 `*.*`、`dbName.*` 或 `dbName.tableName` 格式。|
