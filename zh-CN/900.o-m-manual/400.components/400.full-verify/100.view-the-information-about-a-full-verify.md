# 查看 Full-Verification 组件的详情

OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版运维监控模块的 Full-Verification 页面可以查看 Full-Verification 的名称、任务名称、任务类型和状态等基本信息，便于运维人员判断 Full-Verification 的运行状态。

## 操作步骤

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.Welcome.constants.OMMonitoring">运维监控</UI-TERM>** **>** **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Components">组件</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Components">组件</UI-TERM>** 页面，单击 **<UI-TERM>Full-Verification</UI-TERM>** 页签。

4. 在 **<UI-TERM>Full-Verification</UI-TERM>** 页面，查看目标 Full-Verification 组件的信息。

   您可以通过搜索 Full-Verification 名称、迁移任务的名称或机器 IP 等信息，或通过筛选状态进行精确查询，也可以通过任务的名称进行模糊查询，查找目标 Full-Import 组件。

5. 查看目标 Full-Verification 的基本信息。

   | **参数** | **<UI-TERM key="oms-community.pages.SystemParam.Description">描述</UI-TERM>**  |
   |--------|------------|
   | 名称     | Full-Verification 的名称。鼠标悬停至 Full-Verification 名称，并单击复制图标，即可复制 Full-Verification 名称。  |
   | 地域     | 您可以在地域列进行筛选，查看目标地域下的 Full-Verification 信息。           |
   | 任务名称 | Full-Verification 组件所关联的数据迁移任务的名称。单击后，您可以直接跳转至该任务的详情页面。            |
   | 任务类型   | Full-Verification 组件对应的任务类型。              |
   | 状态     | Full-Verification 组件的状态，包括 **<UI-TERM key="oms-community.src.constants.Running">运行中</UI-TERM>**、**<UI-TERM key="oms-community.Sync.constants.Completed">已完成</UI-TERM>**、**<UI-TERM key="oms-community.Migration.constants.Exception">异常</UI-TERM>** 和 **<UI-TERM key="oms-community.Operator.constants.Stopped">已停止</UI-TERM>**。|
   | 操作     | <ul><li>处于 **<UI-TERM key="oms-community.src.constants.Running">运行中</UI-TERM>** 状态的 Full-Verification 组件，您可以进行 **<UI-TERM key="oms-community.Overview.constants.Pause">暂停</UI-TERM>**、**<UI-TERM key="oms-community.IncrSync.New.Update">更新</UI-TERM>** 和 **<UI-TERM key="oms-community.Operation.Machine.ViewLogs">查看日志</UI-TERM>** 操作。  <li> 处于 **<UI-TERM key="oms-community.Operator.constants.Stopped">已停止</UI-TERM>** 或 **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.Exception">异常</UI-TERM>** 状态的 Full-Verification 组件，您可以进行 **<UI-TERM key="oms-community.Operator.constants.Rerun">重跑</UI-TERM>**、**<UI-TERM key="oms-community.Operation.constants.Recovery">恢复</UI-TERM>**、**<UI-TERM key="oms-community.Operation.Machine.Update">更新</UI-TERM>**、**<UI-TERM key="oms-community.Operator.constants.Destruction">删除</UI-TERM>** 和 **<UI-TERM key="oms-community.components.Operator.openLog.ViewLogs">查看日志</UI-TERM>** 操作。  <li>处于 **<UI-TERM key="oms-community.Overview.constants.Completed">已完成</UI-TERM>** 状态的 Full-Verification 组件，您可以进行 **<UI-TERM key="oms-community.Operator.constants.Destruction">删除</UI-TERM>** 和 **<UI-TERM key="oms-community.Operation.Machine.ViewLogs">查看日志</UI-TERM>** 操作。    |
