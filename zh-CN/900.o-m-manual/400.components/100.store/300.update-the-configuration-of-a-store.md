# 更新 Store 组件

OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版提供指定 Store 组件配置的查看和更新功能。更新配置时，默认显示该 Store 组件的现存配置。您可以直接查看配置信息，也可以对配置进行修改。

## 背景信息

新增或更新的 Store 组件会默认更新至 topic 中，后续的 Store 组件启动均使用更新后的参数。

例如，更新前数据迁移任务有 N 个 Store 组件（N\>=1），用户选择其中 1 个 Store 组件进行更新，则更新的执行逻辑如下，且其它 N-1 个 Store 组件的配置不变。

1. 更新该 Store 组件的配置。

2. 更新 Store 组件对应 Subtopic 的配置。

## 使用限制

* OMS 社区版支持更新处于 **<UI-TERM key="oms-community.Operation.Overview.constants.Running">运行中</UI-TERM>**、**<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.Stopped">已停止</UI-TERM>**、**<UI-TERM key="oms-community.Migration.constants.Exception">异常</UI-TERM>** 和 **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.UnexpectedExit">非预期退出</UI-TERM>** 状态的 Store 组件的配置。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>更新 Store 组件的配置通常用于调优或应急场景，请勿随意修改。</p>
  </main>

* 如果新的配置有误，可能会导致 Store 组件运行异常、对应的数据迁移或数据同步任务失败。如果您有强烈需求，请联系 OMS 技术支持人员。

* 更新 Store 组件的配置后，系统会暂停并重启 Store 组件以生效配置的变更，请谨慎操作。

## 进入更新配置对话框

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏中单击 **<UI-TERM key="oms-community.SystemParam.contants.OMMonitoring">运维监控</UI-TERM>** **>** **<UI-TERM key="oms-community.Audit.constants.Component">组件</UI-TERM>**，默认进入 **<UI-TERM>Store</UI-TERM>** 页面。

3. 在 **<UI-TERM>Store</UI-TERM>** 页面，单击目标 Store 组件后的 **<UI-TERM key="oms-community.Operation.constants.Update">更新</UI-TERM>**，默认进入 **<UI-TERM key="oms-community.Operator.Connector.useConnectorAction.UpdateConfigurations">更新配置</UI-TERM>** 对话框的 **<UI-TERM>配置列表</UI-TERM>** 页签。

   您可以在地域列进行筛选，更新目标地域下的 Store 组件。

4. 在 **<UI-TERM key="oms-community.Operator.Connector.useConnectorAction.UpdateConfigurations">更新配置</UI-TERM>** 对话框，根据实际情况选择在 **<UI-TERM>配置列表</UI-TERM>** 或 **<UI-TERM>配置详情</UI-TERM>** 页签新增或更新配置。参数详情请参见 [Store 组件参数说明](../../400.components/500.component-parameters/500.store-component-parameters/300.mysql-store.md)。

## 在配置列表页签新增或更新配置

### 新增配置

1. 进入 **<UI-TERM key="oms-community.Operator.Connector.useConnectorAction.UpdateConfigurations">更新配置</UI-TERM>** 对话框的 **<UI-TERM>配置列表</UI-TERM>** 页签。

2. 单击页面下方的 **<UI-TERM>+ 添加</UI-TERM>**。

3. 在第一列输入需要添加的参数名称，在第二列输入该新增参数的取值。

4. 添加完成后，在 **<UI-TERM>配置列表</UI-TERM>** 页签，单击 **<UI-TERM key="oms-community.components.ImportTransferObj.Determine">确定</UI-TERM>**。

   如果您需要删除参数，单击目标参数取值右侧的删除图标即可。

### 更新配置

1. 进入 **<UI-TERM key="oms-community.Operator.Connector.useConnectorAction.UpdateConfigurations">更新配置</UI-TERM>** 对话框的 **<UI-TERM>配置列表</UI-TERM>** 页签。

2. 找到需要修改的目标参数，在第二列输入该目标参数新的的取值。

   如果您需要删除参数，单击目标参数取值右侧的删除图标即可。您还可以根据实际需要，修改 **<UI-TERM>增量记录保存时间</UI-TERM>**。

3. 修改完成后，在 **<UI-TERM>配置列表</UI-TERM>** 页签，单击 **<UI-TERM key="oms-community.components.ImportTransferObj.Determine">确定</UI-TERM>**。

## 在配置详情页签新增或更新配置

### 新增配置

1. 在 **<UI-TERM key="oms-community.components.UpdateCompCfgDrawer.UpdateCompCfgDrawer.UpdateConfigurations">更新配置</UI-TERM>** 对话框，单击 **<UI-TERM>配置详情</UI-TERM>** 页签。

2. 鼠标悬停至 root 参数旁边的空白处，单击添加图标。

3. 输入需要添加的 **Key Name**，单击对号。

4. 在 **<UI-TERM key="oms-community.Operator.Checker.useCheckerAction.UpdateConfigurations">更新配置</UI-TERM>** 对话框，找到新增的 Key Name，其默认值为 NULL。

5. 鼠标悬停至新增参数，单击显示的编辑图标。修改参数值后，单击确认图标。

6. 添加完成后，在 **<UI-TERM>配置详情</UI-TERM>** 页签，单击 **<UI-TERM key="oms-community.components.ImportTransferObj.Determine">确定</UI-TERM>**。

### 更新配置

1. 在 **<UI-TERM key="oms-community.components.UpdateCompCfgDrawer.UpdateCompCfgDrawer.UpdateConfigurations">更新配置</UI-TERM>** 对话框，单击 **<UI-TERM>配置详情</UI-TERM>** 页签。

2. 鼠标悬停至目标配置，单击显示的编辑图标。

3. 在文本框中输入修改后的参数后，单击确认图标。

    绿色的对号表示更新数值，红色的叉号表示取消修改。

4. 修改完成后，在 **<UI-TERM>配置详情</UI-TERM>** 页签，单击 **<UI-TERM key="oms-community.components.ImportTransferObj.Determine">确定</UI-TERM>**。
