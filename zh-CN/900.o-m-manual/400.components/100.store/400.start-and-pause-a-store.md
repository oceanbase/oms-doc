# 启动和暂停 Store 组件

当数据同步任务对应的 Store 组件运行异常时，您可以暂停 Store 组件，处理问题后再次启动。您也可以在运行发生故障时，停止并重新启动 Store 组件。

## 启动 Store 组件

OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版支持启动处于 **<UI-TERM key="oms-community.Migration.constants.Stopped">已停止</UI-TERM>**、**<UI-TERM key="oms-community.Notification.Setting.AlarmChannel.Exception">异常</UI-TERM>** 和 **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.UnexpectedExit">非预期退出</UI-TERM>** 状态的 Store 组件。

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.SystemParam.contants.OMMonitoring">运维监控</UI-TERM>** **>** **<UI-TERM key="oms-community.Operation.OperationComponent.Component">组件</UI-TERM>**，默认进入 **Store** 页面。

3. 在 **</UI-TERM>Store</UI-TERM>** 页面，单击目标 Store 后的 **<UI-TERM key="oms-community.constants.dist.Start">启动</UI-TERM>**，该 Store 需要是 **<UI-TERM key="oms-community.Migration.constants.Exception">异常</UI-TERM>** 或 **<UI-TERM key="oms-community.Operation.constants.Stopped">已停止</UI-TERM>** 的状态。

    您可以在地域列进行筛选，启动目标地域下未运行的 Store。

4. 单击对话框中的 **<UI-TERM key="oms-community.components.ETL.ETLFormDrawer.Determine">确定</UI-TERM>**。

## 暂停 Store 组件

OMS 社区版支持暂停处于 **<UI-TERM key="oms-community.src.constants.Running">运行中</UI-TERM>** 状态的 Store 组件。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>暂停 Store 后，可能会导致数据同步任务和数据迁移任务中断，请谨慎操作。</p>
  </main>

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.SystemParam.contants.OMMonitoring">运维监控</UI-TERM>** **>** **<UI-TERM>Store</UI-TERM>**，默认进入 **<UI-TERM>Store</UI-TERM>** 页面。

3. 在 **<UI-TERM>Store</UI-TERM>** 页面，单击目标 Store 后的 **<UI-TERM key="oms-community.Operation.constants.Pause">暂停</UI-TERM>**。

   您可以在地域列进行筛选，暂停目标地域下处于 **<UI-TERM key="oms-community.src.constants.Running">运行中</UI-TERM>** 状态的 Store 组件。

4. 单击对话框中的 **<UI-TERM key="oms-community.Migration.New.Confirmation">确定</UI-TERM>**。
