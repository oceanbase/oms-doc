# 查看 Store 组件的详情

OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版运维监控模块的 Store 页面可以查看 Store 的名称、类型、延时和状态等基本信息，便于运维人员判断 Store 的运行状态。

## 操作步骤

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏中单击 **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.OMMonitoring">运维监控</UI-TERM>** **>** **<UI-TERM key="oms-community.Audit.constants.Component">组件</UI-TERM>**，默认进入 **<UI-TERM>Store</UI-TERM>** 页面。

3. 在 **<UI-TERM>Store</UI-TERM>** 页面，查看目标 Store 的基本信息。

   您也可以通过搜索 Store 名称、Topic、Subtopic 或任务 ID 等信息，进行精确查询。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>Store 页面不支持进行模糊查询。</p>
    </main>

   |   **参数**   | **<UI-TERM key="oms-community.pages.SystemParam.Description">描述</UI-TERM>**                                                                                   |
   |------------|----------------|
   | 名称         | Store 的名称。  |
   | 地域         |<ul><li>如果是单地域部署，**<UI-TERM>Store</UI-TERM>** 右侧会显示地域信息，将不再显示该列。   <li> 如果是多地域部署，您可以在地域列进行筛选，查看目标地域下的 Store 信息。</ul>    |
   | 任务名称      | Store 组件所关联的数据迁移或数据同步任务的名称。单击后，您可以直接跳转至该任务的详情页面。|
   | 类型         | 数据库源端的类型。   |
   | RPS        | 服务器每秒处理的事务数，用于衡量系统吞吐量。   |
   | 延时         | “当前时间 - Store 抓取变更记录的时间”得到的时间差即 Store 组件的延迟时间。该时间计算存在轮询，通常为 10~30 秒。     |
   | 状态         | Store 组件的状态，包括 **<UI-TERM key="oms-community.Sync.constants.YunXingZhong">运行中</UI-TERM>**、**<UI-TERM key="oms-community.Operation.constants.Exception">异常</UI-TERM>** 和 **<UI-TERM key="oms-community.Operator.constants.Stopped">已停止</UI-TERM>**。  |
   | 起始位点  |  Store 组件中保存一连串的 LogRecord（事务日志记录），每个 LogRecord 对应一个 event time（该记录在数据库中的变更时间或所属事务的提交时间）。起始位点指当前 Store 组件中，所有 LogRecord 的 event time 的最小值。   |
   | 当前位点  | 当前 Store 组件中，所有 LogRecord 的 event time 的最大值。   |
   | 连接数        | Store 数据处理流程中，下游的个数。   |
   | 操作   |  <ul><li>处于 **<UI-TERM key="oms-community.Operator.constants.Running">运行中</UI-TERM>** 状态的 Store 组件，您可以进行 **<UI-TERM key="oms-community.Overview.constants.Pause">暂停</UI-TERM>**、**<UI-TERM key="oms-community.Operation.constants.Update">更新</UI-TERM>** 和 **<UI-TERM key="oms-community.components.SyncSwitch.DbObjectTable.ViewLogs">查看日志</UI-TERM>** 操作。<li>处于 **<UI-TERM key="oms-community.Operation.constants.Stopped">已停止</UI-TERM>**、**<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.Exception">异常</UI-TERM>** 或 **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.UnexpectedExit">非预期退出</UI-TERM>** 状态的 Store 组件，您可以进行 **<UI-TERM key="oms-community.JDBCWriter.New.Start">启动</UI-TERM>**、**<UI-TERM key="oms-community.Connector.New.Update">更新</UI-TERM>**、**<UI-TERM key="oms-community.OperationComponent.Connector.Delete">删除</UI-TERM>** 和 **<UI-TERM key="oms-community.Operator.constants.ViewLogs">查看日志</UI-TERM>** 操作。</ul>|

4. 您也可以单击目标 Store 后的 **<UI-TERM key="oms-community.components.Operator.openLog.ViewLogs">查看日志</UI-TERM>**，查看该 Store 的具体日志，并可以进行 **下载** 和 **<UI-TERM key="oms-community.Endpoint.constants.Copy">复制</UI-TERM>** 操作。
