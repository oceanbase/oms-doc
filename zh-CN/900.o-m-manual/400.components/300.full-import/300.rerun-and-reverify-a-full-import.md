# 重跑和恢复 Full-Import 组件

OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版运维监控模块支持重跑和恢复 Full-Import 组件。

## 使用限制

OMS 社区版支持重跑和恢复处于 **<UI-TERM key="oms-community.Migration.constants.Exception">异常</UI-TERM>** 和 **<UI-TERM key="oms-community.Operation.Overview.constants.Stopped">已停止</UI-TERM>** 状态的 Full-Import 组件。

## 重跑 Full-Import 组件

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.OMMonitoring">运维监控</UI-TERM>** **\>** **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Components">组件</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.Operation.OperationComponent.Component">组件</UI-TERM>** 页面，单击 **Full-Import** 页签。

4. 在 **Full-Import** 页面，通过 Full-Import 名称、机器 IP 进行精确查询，也可以通过任务的名称或 ID 进行模糊查询，查找目标 Full-Import 组件。

   您可以在地域列进行筛选，启动目标地域下的 Full-Import 组件。

5. 单击目标 Full-Import 对应 **<UI-TERM key="oms-community.migration.new.components.communityForm.createPlatform.action">操作</UI-TERM>** 列的 **<UI-TERM key="oms-community.Migration.constants.Rerun">重跑</UI-TERM>**。

6. 在对话框中确认 **<UI-TERM key="oms-community.components.ResetPassword.ResetUserPassword.OperationObject">操作对象</UI-TERM>** 后，单击 **<UI-TERM key="oms-community.Operator.JDBCWriter.useJDBCWriterAction.Update">确定</UI-TERM>**。

## 恢复 Full-Import 组件

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.layout.constants.OMMonitoring">运维监控</UI-TERM>** **\>** **<UI-TERM key="oms-community.Operation.OperationComponent.Component">组件</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.Audit.constants.Component">组件</UI-TERM>** 页面，单击 **Full-Import** 页签。

4. 在 **Full-Import** 页面，您可以通过 Full-Import 名称、机器 IP 进行精确查询，也可以通过任务的名称或 ID 进行模糊查询，查找目标 Full-Import 组件。

   您可以在地域列进行筛选，暂停目标地域下的 Full-Import 组件。

5. 单击目标 Full-Import 对应 **<UI-TERM key="oms-community.pages.EndpointPublic.Operation">操作</UI-TERM>** 列的 **<UI-TERM key="oms-community.Operation.constants.Recovery">恢复</UI-TERM>**。

6. 在对话框中确认 **<UI-TERM key="oms-community.Operation.constants.OperationObject">操作对象</UI-TERM>** 后，单击 **<UI-TERM key="oms-community.Operator.Connector.StartConnectorModal.StartConfirm">确定</UI-TERM>**。
