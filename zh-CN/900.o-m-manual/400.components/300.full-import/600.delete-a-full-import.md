# 删除 Full-Import 组件

本文为您介绍如何删除 Full-Import 组件，以节约运行资源。

## 使用限制

OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版支持删除处于 **<UI-TERM key="oms-community.Migration.constants.Stopped">已停止</UI-TERM>**、**<UI-TERM key="oms-community.Notification.Setting.AlarmChannel.Exception">异常</UI-TERM>** 或 **<UI-TERM key="oms-community.Operator.constants.Finished">已完成</UI-TERM>** 状态的 Full-Import 组件。

## 操作步骤

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.OMMonitoring">运维监控</UI-TERM>** **>** **<UI-TERM key="oms-community.Audit.constants.Component">组件</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Components">组件</UI-TERM>** 页面，单击 **<UI-TERM>Full-Import</UI-TERM>** 页签。

4. 在 **<UI-TERM>Full-Import</UI-TERM>** 页面，您可以通过 Full-Import 名称、机器 IP 进行精确查询，也可以通过任务的名称或 ID 进行模糊查询，查找目标 Full-Import 组件。

   您可以在地域列进行筛选，删除目标地域下的 Full-Import 组件。

5. 单击目标 Full-Import 对应 **<UI-TERM key="oms-community.pages.Audit.Operation">操作</UI-TERM>** 列的 **<UI-TERM key="oms-community.Migration.Detail.MoreOperations">更多操作</UI-TERM>** > **<UI-TERM key="oms-community.Operator.constants.Destruction">删除</UI-TERM>**。

6. 在对话框中输入 delete，并单击 **<UI-TERM key="oms-community.Endpoint.New.Add">确定</UI-TERM>**。
