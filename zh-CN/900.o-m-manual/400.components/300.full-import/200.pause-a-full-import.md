# 暂停 Full-Import 组件

OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版运维监控模块支持暂停运行中的 Full-Import 组件。

## 操作步骤

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.SystemParam.contants.OMMonitoring">运维监控</UI-TERM>** **>** **<UI-TERM key="oms-community.Audit.constants.Component">组件</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.Operation.OperationComponent.Component">组件</UI-TERM>** 页面，单击 **<UI-TERM>Full-Import</UI-TERM>** 页签。

4. 在 **<UI-TERM>Full-Import</UI-TERM>** 页面，通过 Full-Import 名称、机器 IP 进行精确查询，也可以通过任务的名称或 ID 进行模糊查询，查找目标 Full-Import 组件。

   您可以在地域列进行筛选，启动目标地域下的 Full-Import 组件。

5. 单击目标 Full-Import 对应 **<UI-TERM key="oms-community.pages.Audit.Operation">操作</UI-TERM>** 列的 **<UI-TERM key="oms-community.Operation.constants.Pause">暂停</UI-TERM>**。

6. 在对话框中，单击 **<UI-TERM key="oms-community.Operator.Connector.useConnectorAction.Update">确定</UI-TERM>**。
