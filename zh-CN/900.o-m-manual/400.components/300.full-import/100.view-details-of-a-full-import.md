# 查看 Full-Import 组件的详情

全量导入组件 Full-Import 负责源库表对象中存量数据的迁移和部分增量数据的同步。OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版运维监控模块的 Full-Import 页面提供 Full-Import 组件的常见运维操作，您还可以查看 Full-Import 组件的基本信息。

## 操作步骤

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.SystemParam.contants.OMMonitoring">运维监控</UI-TERM>** **>** **<UI-TERM key="oms-community.Audit.constants.Component">组件</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Components">组件</UI-TERM>** 页面，单击 **<UI-TERM>Full-Import</UI-TERM>** 页签。

4. 在 **<UI-TERM>Full-Import</UI-TERM>** 页面，您可以通过搜索 Full-Import 名称、机器 IP 等信息，或通过筛选状态进行精确查询，也可以通过任务的名称或 ID 进行模糊查询，查找目标 Full-Import 组件。

5. 查看目标 Full-Import 的基本信息。

   | **参数** |  **<UI-TERM key="oms-community.pages.SystemParam.Description">描述</UI-TERM>**   |
   |--------|-----------------------------------|
   | 名称     | Full-Import 组件的名称。 鼠标悬停至 Full-Import 名称，并单击复制图标，即可复制 Full-Import 名称。   |
   | 任务名称      | Full-Import 组件所关联的数据迁移或数据同步任务的名称。单击后，您可以直接跳转至该任务的详情页面。 |
   | 地域     | 您可以在地域列进行筛选，查看目标地域下的 Full-Import 信息。    |
   | 任务类型     | 包括 **<UI-TERM key="oms-community.components.UserGuidance.DataMigration">数据迁移</UI-TERM>** 和 **<UI-TERM key="oms-community.SystemParam.contants.DataSynchronization">数据同步</UI-TERM>**。         |
   | 状态     | Full-Import 组件的状态，通常包括 **<UI-TERM key="oms-community.Sync.constants.YunXingZhong">运行中</UI-TERM>**、**<UI-TERM key="oms-community.Operator.constants.Stopped">已停止</UI-TERM>**、**<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.Exception">异常</UI-TERM>** 和 **<UI-TERM key="oms-community.components.SyncSwitch.DbObjectTable.Completed">已完成</UI-TERM>**。                                    |
   | 操作     | <ul><li>处于 **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.Running">运行中</UI-TERM>** 状态的 Full-Import 组件，您可以进行 **<UI-TERM key="oms-community.Operation.constants.Pause">暂停</UI-TERM>**、**<UI-TERM key="oms-community.Migration.constants.Update">更新</UI-TERM>** 和 **<UI-TERM key="oms-community.Migration.constants.ViewLogs">查看日志</UI-TERM>** 操作。 <li>处于 **<UI-TERM key="oms-community.Migration.constants.Stopped">已停止</UI-TERM>** 或 **<UI-TERM key="oms-community.Migration.constants.Exception">异常</UI-TERM>** 状态的 Full-Import 组件，您可以进行 **<UI-TERM key="oms-community.Operator.constants.Rerun">重跑</UI-TERM>**、**<UI-TERM key="oms-community.Operator.constants.Restore">恢复</UI-TERM>**、**<UI-TERM key="oms-community.Connector.New.Update">更新</UI-TERM>**、**<UI-TERM key="oms-community.Sync.constants.Delete">删除</UI-TERM>** 和 **<UI-TERM key="oms-community.components.Operator.openLog.ViewLogs">查看日志</UI-TERM>** 操作。<li>处于 **<UI-TERM key="oms-community.Operation.constants.Completed">已完成</UI-TERM>** 状态的 Full-Import 组件，您可以进行 **<UI-TERM key="oms-community.Sync.Detail.Delete">删除</UI-TERM>** 和 **<UI-TERM key="oms-community.components.Operator.openLog.ViewLogs">查看日志</UI-TERM>** 操作。</ul>                       |
