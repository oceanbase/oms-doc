# 删除机器

OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版控制台支持在运维监控 > 机器页面删除机器。删除之后，该机器将不再在控制台页面展示，OMS 社区版不再向该机器下发任务或在该机器上调度组件。

## 注意事项

* 删除机器前，请先清理该机器上的 Store、Full-Import、Incr-Sync 和 Full-Verification 等组件，释放相关任务。如果存在组件，将无法删除该机器。

* 删除操作不会删除该机器上的 OMS 社区版容器。如果您需要删除容器，请自行处理。

* 仅支持删除宕机和未知状态下的机器。

## 操作步骤

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM>运维监控</UI-TERM>** > **<UI-TERM>机器</UI-TERM>**。

3. 在目标地域的 **<UI-TERM>机器列表</UI-TERM>** 页面，找到待删除的机器。

    您也可以在右上角搜索框中输入机器 IP，搜索目标机器。

4. 单击目标机器操作列下的 **<UI-TERM>删除</UI-TERM>**。

5. 在弹出的确认对话框中，确认删除信息后单击 **<UI-TERM>确定</UI-TERM>**。
