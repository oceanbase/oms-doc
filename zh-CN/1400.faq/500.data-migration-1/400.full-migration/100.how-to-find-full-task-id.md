# 如何查询 Full-Verification 组件的名称

本文为您介绍如何通过 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版数据迁移任务查询 Full-Verification 组件的名称。

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.New.components.EndpointForm.DataMigration">数据迁移</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.SystemParam.contants.DataMigration">数据迁移</UI-TERM>** 页面，单击目标数据迁移任务的名称，进入详情页面。

4. 单击页面右上角的 **<UI-TERM key="oms-community.Sync.constants.ViewComponentMonitoring">查看组件监控</UI-TERM>**。

5. 在 **<UI-TERM key="oms-community.Migration.Detail.ViewComponentMonitoring">查看组件监控</UI-TERM>** 对话框，查看 Full-Verification 全量校验组件的 **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.ComponentId">组件 ID</UI-TERM>**。
