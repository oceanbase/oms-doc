# 如何跳过 DDL

## 背景信息

对于导致增量同步任务报错的 DDL 语句，您可以通过更新组件配置进行跳过。操作流程如下：

1. 在 `error.log` 中定位报错的 DDL 语句。

2. 在 `ddl_msg.log` 中复制 `receive ddl` 关键字冒号后面的 DDL 语句。

3. 新增或更新参数。

## 操作步骤

1. 找到源端接收的 DDL 语句。

   1. 登录 OMS 社区版控制台。

   2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.SystemParam.contants.DataMigration">数据迁移</UI-TERM>**。

   3. 在 **<UI-TERM key="oms-community.components.CustomizedTable.DataMigration">数据迁移</UI-TERM>** 页面，单击目标数据迁移任务的名称，进入详情页面。

   4. 单击页面右上角的 **<UI-TERM key="oms-community.Migration.constants.ViewComponentMonitoring">查看组件监控</UI-TERM>**。

   5. 在 **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.ViewComponentMonitoring">查看组件监控</UI-TERM>** 对话框，单击 **Incr-Sync 增量同步组件** 后的 **<UI-TERM key="oms-community.components.SyncSwitch.DbObjectTable.ViewLogs">查看日志</UI-TERM>**。

   6. 单击 `msg/ddl_msg.log` 页签，复制 `receive ddl` 关键字冒号后面的 DDL 语句，该语句是从源端接收到的。

      ![ddl-msg-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/ddl-msg-zh.png)

2. 更新 Incr-Sync 组件的配置。

   1. 进入 **<UI-TERM key="oms-community.Migration.constants.ViewComponentMonitoring">查看组件监控</UI-TERM>** 对话框。

   2. 单击 Incr-Sync 组件后的 **<UI-TERM key="oms-community.Operator.Checker.DisableUpdateBtn.Update">更新</UI-TERM>**。

   3. 在 **<UI-TERM key="oms-community.Operator.JDBCWriter.useJDBCWriterAction.UpdateConfigurations">更新配置</UI-TERM>** 对话框，鼠标悬停至 `coordinator` 参数旁边的空白处，单击添加图标。

   4. 输入需要新增的 **Key Name** 为 `skipDdl`，单击对号。

   5. 在 **<UI-TERM key="oms-community.Operator.Checker.useCheckerAction.UpdateConfigurations">更新配置</UI-TERM>** 对话框，找到新增的 Key Name，其默认值为 NULL。

   6. 鼠标悬停至新增参数，单击显示的编辑图标，修改参数值为复制的 `receive ddl` 关键字冒号后面的 DDL 语句。

      OMS 支持关键字匹配，即配置的关键字存在于接收的 DDL 语句中，即可进行匹配过滤。同时，跳过 DDL 语句的配置为 JSON 格式。

      例如，接收的 DDL 语句为：

      ```sql
      CREATE TABLE my_table (
      id INT,
      name VARCHAR(50)
      );
      ```

      `skipDdl` 参数值匹配为 `["CREATE TABLE my_table"]`。

      如果您需要跳过多个 DDL 语句，请使用 JSON 格式并通过英文逗号（,）分隔。例如，`["CREATE TABLE my_table","create table test"]`。

      <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>如果 DDL 中包含双引号，请务必添加转义符，否则会报 JSON 解析错误。<br>例如，您需要跳过的 DDL 语句为 <code>create table "student" xxx</code>，请配置 <code>skipDdl</code> 参数的值为 <code>["create table \"student\" xxx"]</code>。</p>
      </main>

   7. 在文本框中输入修改后的参数值后，单击确认图标。

   8. 在 **<UI-TERM key="oms-community.Operator.JDBCWriter.useJDBCWriterAction.UpdateConfigurations">更新配置</UI-TERM>** 对话框，单击 **<UI-TERM key="oms-community.Migration.New.Confirmation">确定</UI-TERM>**。
