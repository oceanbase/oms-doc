# 升级 OceanBase 增量 CDC 库

本文为您介绍如何通过工具或手动更新来升级 OceanBase 增量 CDC 库。

## 背景信息

OceanBase 数据库的不同版本可能需要对应的 CDC 库才能拉取到增量日志数据，OMS 社区版的 Store 组件通过加载 CDC 动态库的方式来拉取 OceanBase 数据库的增量数据。

下表为 OMS 社区版 Store 组件和 OceanBase CDC 库相关的目录 `/home/ds/lib64/reader`。

| OMS 社区版 Store 组件 OceanBase CDC 库目录  | OceanBase 数据库版本范围 |
|------------------------|-----------------------|
| ob-ce-reader | 不可升级 |
| ob-ce-4.x-reader | OceanBase 数据库 V4.0.0 及之后，V4.2.1 及之前版本 |
| ob-ce-4.2.2-reader | OceanBase 数据库 V4.2.2 及之后，V4.3.0 及之前版本 |
| ob-ce-4.3-reader | OceanBase 数据库 V4.3.x 及之后，V4.4.x 之前版本 |
| ob-ce-4.4-reader | OceaBase 数据库 V4.4.x 及之后版本 |

## 通过工具升级

1. [下载 CDC rpm 包](https://www.oceanbase.com/softwarecenter)：增量数据获取工具（OB CDC）。

    请根据实际的 OceanBase 数据库版本，单击右上角的版本号选择对应版本的 CDC 包进行下载。

    ![omsce2-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-ce/omsce2-zh.png)

2. 下载完成后，将 rpm 包传入 OMS 社区版容器，执行 CDC 更新脚本。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>更新前，请备份 <code>/home/ds/lib64/reader/ob-ce-xxx-reader</code> 中的文件。</p>
    </main>

    ```shell
    # 进入容器内部
    sudo docker exec -it [容器名] bash

    # 执行 CDC 更新脚本
    cd /root
    bash obcdc_update.sh [rpm包路径]

    # 示例
    bash obcdc_update.sh /home/ds/oceanbase-ce-cdc-4.2.1.10-110000022024112010.el7.x86_64.rpm
    ```

3. 根据工具提示进行升级。

    1. 当前更新的 cdc 版本是：4.x，是否确认？[y/n]

        此处输入 y，继续执行。此处输入 n，则退出。

    2. 开始解压 rpm 包。

    3. 开始更新 cdc。

    4. 更新成功，是否继续更新已存在 Store 的 cdc？[y/n]

        此处输入 y，继续更新已经存在 Store 组件的 cdc。此处输入 n，则结束更新。

    5. 如果选择继续更新

        请输入需要更新的 Store，用英文逗号（,）分隔，格式 store{port}。输入 all 更新全部，输入 exit 退出。例如，store7100,store7101,store7102

        * 输入 all：更新所有 /home/ds/store/store{port} 下的 cdc。

        * 输入指定的 Store：更新指定 store 目录下的 cdc。

        * 输入 exit：结束更新。

4. 如果您更新了已存在 Store 的 cdc，需要重启 Store 组件并观察位点是否推进。

## 通过手动更新升级

1. [下载 CDC rpm 包](https://www.oceanbase.com/softwarecenter)：增量数据获取工具（OB CDC）。

    请根据实际的 OceanBase 数据库版本，单击右上角的版本号选择对应版本的 CDC 包进行下载。

    ![omsce2-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-ce/omsce2-zh.png)

2. 解压 rpm 包：`rpm2cpio oceanbase-ce-cdc-x.x.x.x-xxxx.el7.x86_64.rpm|cpio -idmu --quiet`。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>OMS 社区版仅支持 <b>-el7</b>。</p>
    </main>

3. 解压后，当前目录 `./home/admin/oceanbase/lib64` 会出现下述文件。

    ```shell
    libobcdc.so.x.x.x.x
    libobcdc.so.x -> libobcdc.so.x.x.x.x
    libobcdc.so -> libobcdc.so.x
    ```

4. 进入 OMS 社区版容器，并通过 `cd` 命令进入目录 `/home/ds/lib64/reader`，根据 OceanBase 数据库的版本号进入上述表格中的 `ob-ce-xxx-reader` 目录。

5. 备份 `ob-ce-xxx-reader` 目录中的原文件。

6. 将 rpm 包解压的 `./home/admin/oceanbase/lib64` 下面的文件复制到 `ob-ce-xxx-reader` 目录中。

上述步骤完成后，新建的 Store 组件均会使用升级后的 CDC 库。如果已经存在的 Store 组件需要升级，请执行下述操作。

1. 进入 Store 组件的运行目录 `/home/ds/store/store{port}/lib64/reader`，下面的目录结构和 `/home/ds/lib64/reader` 下的目录一致。

2. 将 rpm 解压的 `./home/admin/oceanbase/lib64` 下面的文件复制到 `/home/ds/store/store{port}/lib64/reader/ob-ce-xxx-reader`。

3. 在 OMS 社区版控制台，暂停 Store 组件。详情请参见 [暂停 Store 组件](../900.o-m-manual/400.components/100.store/400.start-and-pause-a-store.md)。

4. 执行下述命令，确认 Store 进程已经停止。如果 Store 进程未停止，则可以执行 `kill -9`。
  
    ```shell
    ps -ef|grep store{port}
    ```

5. 在 OMS 社区版控制台，启动 Store 组件。
