# 配置同步对象的匹配规则

本文为您介绍同步对象匹配规则的背景信息、使用限制和配置方式。

## 背景信息

您在创建数据同步任务时，需要指定具体的同步对象。OMS 社区版提供指定对象、导入对象和匹配规则三种方式供您选择。其中匹配规则方式支持您通过编写通配规则指定需要同步的对象，并且支持配置源端及目标端的对象映射逻辑，通过简单、高效的字符串匹配能力，可以有效地降低您在待同步对象数量众多时的配置难度。同时，符合匹配规则的新增表可以通过增量 DDL 的方式自动同步至目标端。

## 使用限制

* OMS 社区版允许输入多条规则，但需要注意每条规则不能跨行且前后不允许有空格。

* 同步对象规则不允许为空，排除对象规则允许为空。

* OMS 社区版不支持在结构同步、全量同步期间进行 DDL 变更。

* 通过匹配规则的方式选择同步对象时，OMS 社区版不支持表名包含特殊字符（包括 |"'`()=;/&*?[][!] 和换行）。

## 注意事项

* 当您完成配置同步对象规则和排除对象规则后，如果源端表名在同步对象规则和排除对象规则的差集内，则相关对象可以被选择。

    <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>差集是指对于给定的两个集合，返回一个包含所有存在于第一个集合但不存在于第二个集合的元素的新集合。</p>
  </main>

* 开启同步 DDL 功能后，当您使用 DDL 语句在源端创建一张新表或者修改一张表结构时，如果对应的表名在同步对象规则和排除对象规则的差集内，则该 DDL 语句可以被 OMS 社区版同步至目标端。

## 配置匹配规则

1. 新建数据同步任务，并配置至 **选择同步对象** 步骤。

    详情请参见 [数据同步](../100.data-synchronization-overview.md) 模块相应类型的创建数据同步任务文档。

2. 在 **选择对象** 页面，选择同步对象和迁移范围。

      您可以通过 **指定对象** 和 **匹配规则** 两个入口选择同步对象，本文仅为您介绍如何配置匹配规则。

      1. 勾选 **匹配规则**。

      2. 在 **选择同步范围** 区域，输入 **同步对象规则** 和 **排除对象规则**（可选）。支持的匹配规则详情请参见 [通配符规则说明](../../600.data-migration/1600.migration-function-introduction/400.wildcard-rules.md)。

      3. 单击 **校验**。
  
      4. 在 **将对象映射至 Topic** 对话框中，选择需要的映射方式进行配置。

         * 同步 OceanBase 社区版的数据至 Kafka 时

            如果设置同步类型时未选择 **结构同步**，则仅支持选择 **已有 Topic**。如果设置同步类型时已选择 **结构同步**，支持 **新建 Topic**、**选择 Topic** 和 **批量生成 Topic** 三种映射方式，请选择一种映射方式进行 Topic 的创建或选择。

         * 同步 OceanBase 社区版的数据至 RocketMQ 时

            在 **将对象映射至 Topic** 对话框的 **已有 Topic** 下拉列表中，搜索并选中需要同步的 Topic 即可。

      5. 在 **将对象映射至 Topic** 对话框中，单击 **确定**。

      配置完成后，如果您需要查看匹配结果，请单击 **预览对象** 进行查看。您填写的通配同步对象规则和排除对象规则，会同时应用于表和视图。**匹配结果** 包括最终对象、新增对象和减少对象。

      | 对象          |       描述    |
      |--------------|---------------|
      | 最终对象 | 配置的匹配规则最终匹配的同步对象。     |
      | 新增对象 | 最终匹配结果和前一次配置的匹配结果相比，新增的同步对象。       |
      | 减少对象 | 最终匹配结果和前一次配置的匹配结果相比，减少的同步对象。          |

3. 根据提示完成后续的任务配置。
