# 更改 Topic

本文为您介绍如何使用 OceanBase 迁移服务（OceanBase Migration Service，OMS）提供的更改 Topic 功能。

## 适用场景

创建数据库至消息队列的数据同步任务时，OMS 社区版支持您在选择需要同步的 Topic 类型后，通过更改 Topic 功能重新选择 Topic 名称。

## 操作步骤

1. 新建数据同步任务，并配置至 **<UI-TERM key="oms-community.Sync.New.SelectASynchronizationObject">选择同步对象</UI-TERM>** 步骤。

    详情请参见 [数据同步](../100.data-synchronization-overview.md) 模块相应类型的创建数据同步任务文档。

2. 选择同步对象后，在 **<UI-TERM key="oms-community.SyncObjectForm.ObjectSelect.SelectSynchronizationRange">选择同步范围</UI-TERM>** 区域右侧的 **<UI-TERM key="oms-community.common.Transfer.TargetObject">目标端对象</UI-TERM>** 列表中，鼠标悬停至目标 Topic 对象。

3. 单击显示的 **<UI-TERM key="oms-community.common.TreeSearch.TargetNode.ChangeTopic">更改 Topic</UI-TERM>**。

    ![topic-rename1-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/topic-rename1-zh.png)

4. 在 **<UI-TERM key="oms-community.Transfer.sync.MapObjectsToTopics">将对象映射至 Topic</UI-TERM>** 的对话框中，更改需要同步的 Topic。

    ![topic-rename2-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/topic-rename2-zh.png)

    <main id="notice" type='explain'>
    <h4>说明</h4>
    <ul>
    <li>
    <p>同步 OceanBase 社区版的数据至 RocketMQ 时，仅支持 <b>已有 Topic</b> 的映射方式。</p>
    </li>
    <li>
    <p>同步 OceanBase 社区版的数据至 Kafka、DataHub 时，如果选择同步类型时未选择 <b>结构同步</b>，则仅支持选择 <b>已有 Topic</b>。如果选择同步类型时已选择 <b>结构同步</b>，则仅支持选择一种映射方式进行 Topic 的创建或选择。</p>
    </li>
    </main>

5. 单击 **<UI-TERM key="oms-community.biz.AccountAuthorization.Ok">确定</UI-TERM>**。

    确定后会将所选 Topic 及表合并至选中 Topic，请谨慎操作。

6. 根据提示完成后续的任务配置。
