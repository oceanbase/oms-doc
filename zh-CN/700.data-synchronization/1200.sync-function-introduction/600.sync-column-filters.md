# 列过滤

本文为您介绍如何使用 OceanBase 迁移服务（OceanBase Migration Service，OMS）提供的列过滤功能。

## 操作步骤

1. 新建数据同步任务，并配置至 **<UI-TERM key="oms-community.SyncObjectForm.ObjectSelect.SelectSynchronizationObjects">选择同步对象</UI-TERM>** 步骤。

   详情请参见 [数据同步](../100.data-synchronization-overview.md) 模块相应类型的创建数据同步任务文档。

2. 选择同步对象后，在 **<UI-TERM key="oms-community.SyncObjectForm.ObjectSelect.SelectSynchronizationRange">选择同步范围</UI-TERM>** 区域右侧的 **<UI-TERM key="oms-community.common.Transfer.TargetObject">目标端对象</UI-TERM>** 列表中，鼠标悬停至目标表对象。

3. 单击 **<UI-TERM key="oms-community.components.ViewObject.Set">设置</UI-TERM>**。

   ![column-filter-1-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/column-filter-1-zh.png)

4. 在 **<UI-TERM key="oms-community.biz.ETL.ETLFormDrawer.Set">设置</UI-TERM>** 对话框的 **<UI-TERM key="oms-community.components.ETL.ETLFormDrawer.SelectAColumn">选择列</UI-TERM>** 区域，勾选您需要同步的列。

   ![column-filter-2-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/column-filter-2-zh.png)

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>全选或不勾选任何列，OMS 社区版会同步全部列。</p>
   </main>

5. 单击 **<UI-TERM key="oms-community.pages.EndpointPublic.Confirmation">确定</UI-TERM>**。

6. 根据提示完成后续的任务配置。
