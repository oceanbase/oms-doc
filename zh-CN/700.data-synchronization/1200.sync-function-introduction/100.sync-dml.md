# DML 过滤

本文为您介绍创建数据同步任务时，DML 过滤的适用场景、使用限制和操作步骤。

## 适用场景

创建数据同步任务时，您可以对需要同步的 DML SQL 语句设置同步策略，只有符合设置条件的 SQL 语句才会被同步至目标端。该功能常用于历史表和交易明细表场景。

## 使用限制

* DML 过滤：支持 Insert、Delete 和 Update。

* DML 过滤作用范围为整个数据同步任务。

## 操作步骤

1. 新建数据同步任务，并配置至 **<UI-TERM key="oms-community.Sync.New.SelectSynchronizationType">选择同步类型</UI-TERM>** 步骤。

    详情请参见 [数据同步](../100.data-synchronization-overview.md) 模块相应类型的创建数据同步任务文档。

2. 在 **<UI-TERM key="oms-community.Sync.New.SelectSynchronizationType">选择同步类型</UI-TERM>** 页面，勾选 **<UI-TERM key="oms-community.components.SyncOption.CheckSyncKind.IncrementalSynchronization">增量同步</UI-TERM>**。

3. 同步 DML 处于默认勾选状态，再勾选需要同步的 DML 策略，则设置完成。

    ![select-type2-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/select-type2-zh.png)

4. 根据提示完成后续的任务配置。
