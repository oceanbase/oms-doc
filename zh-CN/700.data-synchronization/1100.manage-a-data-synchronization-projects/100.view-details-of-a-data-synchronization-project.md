# 查看数据同步任务的详情

启动数据同步任务后，您可以在数据同步任务的详情页面查看相应任务的基本信息、同步详情、组件监控和同步对象等信息。

## 进入详情页面

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.components.CustomizedTable.DataSynchronization">数据同步</UI-TERM>**。

3. 单击目标数据同步任务的名称，进入详情页面。

   您可以在 **<UI-TERM key="oms-community.pages.Sync.DataSynchronization">数据同步</UI-TERM>** 页面，根据标签、状态、类型和关键字等，搜索目标数据同步任务。数据同步任务的状态包括：

   * **<UI-TERM key="oms-community.components.StepsCard.StepCard.NotStarted">未启动</UI-TERM>**：表示数据同步任务尚未启动，您可以在对应的操作列中单击 **<UI-TERM key="oms-community.Migration.constants.Start">启动</UI-TERM>**。

   * **<UI-TERM key="oms-community.Sync.constants.YunXingZhong">运行中</UI-TERM>**：数据同步任务运行中，状态右侧展示了数据同步的计划和当前进度。

   * **<UI-TERM key="oms-community.Sync.constants.Modifying">修改中</UI-TERM>**：数据同步任务正在被修改同步对象。

   * **<UI-TERM key="oms-community.Migration.constants.Merging">合并中</UI-TERM>**：被修改同步对象的数据同步任务与修改同步对象任务进行合并的过程。

   * **<UI-TERM key="oms-community.Migration.constants.Paused">已暂停</UI-TERM>**：数据同步任务已被手动中止，您可以在对应的操作列中单击 **<UI-TERM key="oms-community.Operation.constants.Recovery">恢复</UI-TERM>**，从中止的子任务开始继续执行同步。

   * **<UI-TERM key="oms-community.Overview.constants.Failed">失败</UI-TERM>**：数据同步任务执行失败，状态右侧展示该任务失败的具体环节。单击数据同步任务的名称，您可以在详情页面查看具体的报错信息。

   * **<UI-TERM key="oms-community.Operation.Overview.constants.Completed">已完成</UI-TERM>**：数据同步任务已成功执行完毕，OMS 已按照您预设的同步模式将指定的数据内容同步至目标库中。

   * **<UI-TERM key="oms-community.Overview.constants.Releasing">释放中</UI-TERM>**：数据同步任务正在被释放。释放中的数据同步任务不能进行任何操作。

   * **<UI-TERM key="oms-community.src.constants.Released">已释放</UI-TERM>**：数据同步任务已经成功释放。释放后，OMS 会终止当前的同步任务。

## 查看基本信息

**<UI-TERM key="oms-community.Migration.Detail.BasicInformation">基本信息</UI-TERM>** 区域为您展示当前数据同步任务相关的基本信息。

| **参数** |                                                                                      **<UI-TERM key="oms-community.pages.SystemParam.Description">描述</UI-TERM>**                                                                                       |
|--------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID     | 数据同步任务的唯一 ID 标识。             |
| 同步类型   | 创建数据同步任务时，选择的同步类型。                                                                    |
| 告警等级   | 显示当前任务的告警等级。OMS 支持的告警级别包括 **<UI-TERM key="oms-community.components.WarnLevel.Unprotected">无保护</UI-TERM>**、**<UI-TERM key="oms-community.components.WarnLevel.HighProtection">高保护</UI-TERM>**、**<UI-TERM key="oms-community.components.WarnLevel.MediumProtection">中保护</UI-TERM>** 和 **<UI-TERM key="oms-community.components.WarnLevel.DiBaoHu">低保护</UI-TERM>**，设置的详情请参见 [告警设置](../../1000.system-management/200.alert-center/300.manage-alert-settings.md)。 |
| 创建人    | 当前数据同步任务的创建人。                          |
| 创建时间   | 当前数据同步任务的创建时间。                         |
| 增量同步起始位点 | 显示创建数据同步任务时指定的时间节点。                 |
|连接详情|单击 **<UI-TERM key="oms-community.Detail.components.MigrationInfos.ConnectionDetails">连接详情</UI-TERM>**，查看数据同步任务源端和目标端的连接信息。|

您可以进行以下操作：

* 查看组件监控

  单击页面右上角的 **<UI-TERM key="oms-community.Migration.constants.ViewComponentMonitoring">查看组件监控</UI-TERM>**，查看 Store、Incr-Sync 和 Full-Import 等组件的信息，并可以进行相关操作。
  
* 查看和修改同步对象

  单击页面右上角的 **<UI-TERM key="oms-community.Migration.hooks.useMigrationObject.ViewObjectsToBeMigrated">查看对象</UI-TERM>**，查看当前数据同步任务的同步对象列表。您还可以在数据同步任务运行过程中修改同步对象，详情请参见 [查看和修改同步对象](../1100.manage-a-data-synchronization-projects/200.view-and-modify-objects-to-be-synchronized.md)。

* 克隆数据同步任务

  单击页面右上角的 **<UI-TERM key="oms-community.project.cloudweb.MoreOperations">更多操作</UI-TERM>** \> **<UI-TERM key="oms-community.Migration.constants.Clone">克隆</UI-TERM>**，克隆当前数据同步任务。您可以在克隆过程中，根据业务需求，修改相关配置。

* 查看参数配置

  单击页面右上角的 **<UI-TERM key="oms-community.Detail.components.FullMigration.MoreOperations">更多操作</UI-TERM>** \> **<UI-TERM key="oms-community.Sync.constants.ViewParameterConfigurations">查看参数配置</UI-TERM>**，查看创建数据同步任务时的配置参数。

* 修改告警等级

  OMS 社区版支持修改数据同步任务的告警等级，详情请参见 [告警设置](../../1000.system-management/200.alert-center/300.manage-alert-settings.md)。

* 下载对象配置信息

  OMS 支持下载数据同步任务的配置信息，以批量导入的格式输出。详情请参见 [下载和导入同步对象配置](../1100.manage-a-data-synchronization-projects/400.download-and-import-the-settings-of-synchronization-objects.md)。

* 修改数据源

  OMS 社区版的 **<UI-TERM key="oms-community.Migration.constants.ModifyEndpoint">修改数据源</UI-TERM>** 功能适用于以下场景，除下述场景外，禁止使用本功能。如果强行使用，将导致数据同步任务运行异常且无法恢复。

  * 源库主备切换，数据源配置的是原主库的 IP，主备切换之后需要换成切换之后的主库 IP。

  * 数据源 IP 换域名、端口修改，数据库本身无变化。

  * 数据源用户名、密码修改。

  修改数据源的操作如下：

  1. 进入数据同步任务的详情页面。

  2. 单击页面右上角的 **<UI-TERM key="oms-community.components.ModifyRecordTable.MoreOperations">更多操作</UI-TERM>** > **<UI-TERM key="oms-community.Migration.constants.ModifyEndpoint">修改数据源</UI-TERM>**。

  3. 在 **<UI-TERM>适用场景</UI-TERM>** 对话框，确认提示信息后，单击 **<UI-TERM>确定</UI-TERM>**。

  4. 在 **<UI-TERM key="oms-community.Migration.constants.ModifyEndpoint">修改数据源</UI-TERM>** 对话框，分别选择  **<UI-TERM key="oms-community.components.MonitorDrawer.Source">源端</UI-TERM>** 和 **<UI-TERM key="oms-community.biz.EndpointSelect.Group.TargetNode">目标端</UI-TERM>** 需要的数据源。

     <main id="notice" type='notice'>
     <h4>注意</h4>
     <p>仅支持修改和当前任务数据源类型一致的数据源。</p>
     </main>

  5. 单击 **<UI-TERM key="oms-community.components.ViewObj.AddObject.Ok">确定</UI-TERM>**。

## 查看同步详情

您可以在 **<UI-TERM key="oms-community.Sync.Detail.SynchronizationDetails">同步详情</UI-TERM>** 区域查看 **<UI-TERM key="oms-community.components.SyncOption.CheckSyncKind.SchemaSynchronization">结构同步</UI-TERM>**、**同步增量日志拉取**、**<UI-TERM key="oms-community.components.SyncOption.CheckSyncKind.FullSynchronization">全量同步</UI-TERM>** 和 **<UI-TERM key="oms-community.Migration.constants.IncrementalMigration">增量同步</UI-TERM>** 等信息。

### 结构同步

结构同步实际为创建 Topic，结构同步成功后，您可以查询到新建的 Topic。

您可以在 **<UI-TERM key="oms-community.components.SyncOption.CheckSyncKind.SchemaSynchronization">结构同步</UI-TERM>** 页面，查看结构同步的状态、启动时间、结束时间、总计耗时和结构同步的进度。

### 同步增量日志拉取

您可以在 **同步增量日志拉取** 页面，查看同步增量日志拉取的状态、启动时间、结束时间、总计耗时和进度。

### 全量同步

同步源端的存量数据至目标端。您可以在 **<UI-TERM key="oms-community.components.SyncOption.CheckSyncKind.FullSynchronization">全量同步</UI-TERM>** 页面，查看全量同步的状态、启动时间、结束时间、总计耗时和全量同步的进度，以及预估总行数、已完成同步行数、RPS 和实时流量等信息。

在 **<UI-TERM key="oms-community.Migration.constants.FullSyncPerformance">全量同步性能</UI-TERM>** 区域，您可以图形化查看 **<UI-TERM key="oms-community.components.FullMigrationPerformance.constants.SourceRps">源端 RPS</UI-TERM>**、**<UI-TERM key="oms-community.components.FullMigrationPerformance.constants.TargetRps">目标端 RPS</UI-TERM>**、**<UI-TERM key="oms-community.components.FullMigrationPerformance.constants.SourceSyncTraffic">源端同步流量</UI-TERM>**、**<UI-TERM key="oms-community.components.FullMigrationPerformance.constants.DestinationSyncTraffic">目标端同步流量</UI-TERM>**、**<UI-TERM key="must.components.FullMigrationPerformance.constants.AverageReadTimeAtSource">源端平均读取时间</UI-TERM>**、**<UI-TERM key="must.components.FullMigrationPerformance.constants.AverageSlicingTimeAtSource">源端平均切片时间</UI-TERM>** 和 **<UI-TERM key="must.components.FullMigrationPerformance.constants.AverageDestinationWriteTime">目标端平均写入时间</UI-TERM>**，帮助您有效识别性能相关问题。

### 增量同步

您可以在 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.IncrementalMigration">增量同步</UI-TERM>** 页面，查看增量同步的状态、延迟时间和当前位点时间等信息，了解任务的运行状态，为您监控数据同步任务性能提供参考依据。

创建数据同步任务时，建议您设置告警级别、告警频率等信息，以便随时掌握任务运行状态。OMS 默认低等级保护，您可以根据业务需求，修改告警等级。详情请参见 [告警设置](../../1000.system-management/200.alert-center/300.manage-alert-settings.md)。

* 如果数据同步任务的增量同步延时大于配置的告警时间，增量同步步骤始终处于运行中，系统不会触发告警信息。

* 如果数据同步任务的增量同步延时小于等于配置的告警时间，增量同步步骤的状态由运行中切换为监控中。增量同步的状态变为监控中后，延时大于配置的告警时间，也不会再切换为运行中状态。

**<UI-TERM key="oms-community.Detail.components.IncrSyncMonitor.IncrementalSynchronizationPerformance">增量同步性能</UI-TERM>** 区域为您实时展示增量同步的信息。您可以在 **增量同步监控** 区域的右上角，筛选 **<UI-TERM key="oms-community.Operation.components.MetricChart.NearlyHour">近 1 小时</UI-TERM>**、**<UI-TERM key="oms-community.Detail.components.MonitorCard.LastDay">最近一天</UI-TERM>**、**<UI-TERM key="oms-community.Detail.components.IncrSyncMonitor.LastWeek">最近一周</UI-TERM>** 和自定义时间段的增量同步数据，分段和实时地查看同步性能的变化。

|  参数   |  描述  |
|---------|-------|
|  延迟   |源端增量变更被同步至目标端的滞后时间，单位为秒。|
| 同步流量 |增量同步刚启动时，流量展示可能包含全量阶段数据流量信息。|
|平均写入时间|同步数据时的平均写入时间。|
|  RPS  |   每秒写入目标端的行数。 |

* **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.StoreLogPullComponents">Store 增量拉取组件</UI-TERM>** 的信息包括 **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.ComponentId">组件 ID</UI-TERM>**、**最早拉取位点**、**当前拉取位点** 和 **<UI-TERM key="oms-community.Operation.constants.State">状态</UI-TERM>**。您可以对其进行以下操作：

    <h4>注意</h4>
    <p>此处的更新包含重启操作，请谨慎操作。</p>
