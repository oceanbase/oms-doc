# 查看和修改同步对象

本文为您介绍如何在 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版中查看和修改已配置的数据同步任务的同步对象。

## 背景信息

数据同步任务在同步过程中，满足限制条件的情况下，您可以增加或减少同步对象。每一次运行的修改行为都会被记录。当增加对象任务执行完成后，会与关联的原任务合并。合并成功后，原任务正常运行，增加对象任务会自动释放。

## 使用限制

* 数据同步任务处于 **<UI-TERM key="oms-community.src.constants.NotStarted">未启动</UI-TERM>**、**<UI-TERM key="oms-community.ModifyRecordTable.constants.Running">运行中</UI-TERM>** 或 **<UI-TERM key="oms-community.Sync.constants.Paused">已暂停</UI-TERM>** 状态时，支持增加和减少同步对象。

   <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>对于处于 <b>已暂停</b> 状态的数据同步任务，如果 <b>增量同步</b> 步骤处于 <b>已暂停</b> 状态，则不支持增加同步对象。</p>
    </main>

* 数据同步任务处于 **<UI-TERM key="oms-community.components.BatchSelect.BatchSwitch.Failed">失败</UI-TERM>** 状态时，不支持增加同步对象。

* 数据同步任务处于 **<UI-TERM key="oms-community.Sync.constants.Modifying">修改中</UI-TERM>** 或 **<UI-TERM key="oms-community.ModifyRecordTable.constants.Merging">合并中</UI-TERM>** 状态时，不支持再次修改同步对象。

* 数据同步任务的 **<UI-TERM key="oms-community.Sync.constants.IncrementalSynchronization">增量同步</UI-TERM>** 步骤处于 **<UI-TERM key="oms-community.Sync.constants.Paused">已暂停</UI-TERM>** 或 **<UI-TERM key="oms-community.components.BatchSelect.BatchSwitch.Failed">失败</UI-TERM>** 状态时，不支持增加同步对象。

* 同步 IDB 逻辑表的数据至 OceanBase 数据库 MySQL 租户和 DataHub 时，不支持减少同步对象。

## 查看同步对象

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.pages.Sync.DataSynchronization">数据同步</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.src.constants.DataSynchronization">数据同步</UI-TERM>** 页面，单击目标任务的名称，进入该任务的详情页面。

4. 单击页面右上角的 **<UI-TERM key="oms-community.Migration.hooks.useMigrationObject.ViewObjectsToBeMigrated">查看对象</UI-TERM>**，查看 **<UI-TERM key="oms-community.components.ImportTransferObj.ObjectsToBeSynchronized">同步对象</UI-TERM>** 和 **<UI-TERM key="oms-community.components.ViewObject.ModifyObjectRecords">修改对象记录</UI-TERM>**。

   * **<UI-TERM key="oms-community.Detail.components.SyncObject.SynchronizeObjects">同步对象</UI-TERM>** 页签为您展示当前任务的同步对象，您还可以单击 **<UI-TERM key="oms-community.components.ViewObject.ModifyObjects">修改对象</UI-TERM>**，进行 **<UI-TERM key="oms-community.components.ViewObj.AddObject.AddObjects">增加对象</UI-TERM>** 和 **<UI-TERM key="oms-community.Detail.components.SyncObject.ReduceObjects">减少对象</UI-TERM>** 操作。

   * **<UI-TERM key="oms-community.Migration.Detail.ModifyObjectRecords">修改对象记录</UI-TERM>** 页签为您展示所有修改对象操作的 ID、修改类型、状态和修改时间等信息。

## 增加同步对象

1. 在目标任务的详情页面，单击右上角的 **<UI-TERM key="oms-community.Sync.constants.ViewObjectsToBeSynchronized">查看对象</UI-TERM>**。

2. 在 **<UI-TERM key="oms-community.Sync.constants.ViewObjectsToBeSynchronized">查看对象</UI-TERM>** 对话框，单击 **<UI-TERM key="oms-community.Detail.components.SyncObject.ModifyObjects">修改对象</UI-TERM>** \> **<UI-TERM key="oms-community.components.ViewObj.AddObject.AddObjects">增加对象</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.Detail.components.SyncObject.AddObjects">增加对象</UI-TERM>** 对话框，在选择区域左侧选中需要同步的对象，单击 **\>**，在 **<UI-TERM key="oms-community.Transfer.sync.MapObjectsToTopics">将对象映射至 Topic</UI-TERM>** 对话框中，选择需要的映射方式进行配置。

   选择增加的同步对象后，您可以进行更改 Topic、设置行过滤等操作。

   <main id="notice" type='notice'>
    <h4>注意</h4>
    <ul>
    <li>
    <p>新增对象将默认继承原数据同步任务的全部配置选项。如果增加对象的过程中终止了操作，您需要手动删除目标库中已增加的对象。</p>
    </li>
    <li>
    <p>如果源端数据源配置了 Schema Name 或 DB Name，则仅支持增加指定 Schema Name 或 DB Name 下的同步对象。</p>
    </li>
    </ul>
   </main>

4. 选择完成后，单击 **<UI-TERM key="oms-community.Sync.New.Next">下一步</UI-TERM>**。

5. 系统会自动对增加对象执行预检查。全部检查任务均通过后，单击 **<UI-TERM key="oms-community.biz.EndpointSupplement.Save">保存</UI-TERM>**。

6. 确认无误后，在弹出框单击 **<UI-TERM key="oms-community.components.ProjectLabel.LabelManager.Determine">确定</UI-TERM>**。

   * 如果任务处于已暂停或失败状态，您可以取消后重新进行修改。修改后，请先恢复数据同步任务，才能够执行增加对象操作。

   * 如果任务处于运行中状态，单击保存后，将立即执行增加对象操作。

   增加对象操作开始执行后，会在 **<UI-TERM key="oms-community.Migration.constants.ViewObjectsToBeMigrated">查看对象</UI-TERM>** \> **<UI-TERM key="oms-community.components.ViewObject.ModifyObjectRecords">修改对象记录</UI-TERM>** 页面生成记录，您可以进入该页面查看记录的详情。增加对象记录的状态包括 **<UI-TERM key="oms-community.ModifyRecordTable.constants.PendingExecution">待执行</UI-TERM>**、**<UI-TERM key="oms-community.Operation.constants.Canceled">已取消</UI-TERM>**、**<UI-TERM key="oms-community.Sync.constants.Modifying">修改中</UI-TERM>**、**<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.Running">运行中</UI-TERM>**、**<UI-TERM key="oms-community.ModifyRecordTable.constants.Terminated">已终止</UI-TERM>**、**<UI-TERM key="oms-community.ModifyRecordTable.constants.Merging">合并中</UI-TERM>**、**<UI-TERM key="oms-community.Home.Toolbar.Success">成功</UI-TERM>** 和 **<UI-TERM key="oms-community.Home.Toolbar.Failed">失败</UI-TERM>**，不同状态的增加对象记录支持的操作，以及处于运行中状态的原任务对应的状态也不同。

   <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>原任务处于 <strong>未启动</strong> 状态时，增加对象会生成一条 <strong>成功</strong> 状态的修改记录。原任务处于 <strong>已暂停</strong> 状态时，增加对象会生成一条 <strong>待执行</strong> 状态的修改记录。</p>
   </main>

   只有原任务处于运行中的状态，增加对象记录的状态才会被推进。增加对象记录的状态推进后，原任务状态也随之更新。详情请参见下表。

   | **增加对象记录的状态** | **支持的操作**                                                    | **原任务对应的状态** |
   |---------------|--------------------------------------------------------------|------------|
   | 待执行           | 查看详情、取消                                                      | 运行中        |
   | 已取消           |  无                                                            |  运行中  |
   | 修改中           | 无                                                          | 修改中       |
   | 运行中           | 查看详情、终止                                                      | 修改中        |
   | 已终止           | 查看详情                                                         | 运行中        |
   | 合并中           | 查看详情                                                         | 合并中        |
   | 成功            | 查看详情                         | 运行中        |
   | 失败            | 查看详情、重试 <br>您还可以单击 **<UI-TERM key="oms-community.components.ModifyRecordTable.ViewReason">查看原因</UI-TERM>**，跳转至任务的详情页面，查看失败的原因。 | 修改中/合并中       |

## 减少同步对象

1. 在目标任务的详情页面，单击右上角的 **<UI-TERM key="oms-community.Migration.constants.ViewObjectsToBeMigrated">查看对象</UI-TERM>**。

2. 在 **<UI-TERM key="oms-community.Migration.constants.ViewObjectsToBeMigrated">查看对象</UI-TERM>** 对话框，单击 **<UI-TERM key="oms-community.components.ViewObject.ModifyObjects">修改对象</UI-TERM>** \> **<UI-TERM key="oms-community.ModifyRecordTable.constants.ReduceObjects">减少对象</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.components.ViewObj.DelObject.ReduceObjects">减少对象</UI-TERM>** 对话框的右侧 **<UI-TERM key="oms-community.common.Transfer.TargetObject">目标端对象</UI-TERM>** 区域，鼠标悬停至需要减少迁移的对象，单击 **<UI-TERM key="oms-community.components.ViewObj.DelObject.Remove">移除</UI-TERM>**。

   您也可以勾选复选框，选择多个需要移除的对象，单击 **<UI-TERM key="oms-community.common.TreeSearch.BatchRemoval">批量移除</UI-TERM>**，在弹出框中，单击 **<UI-TERM key="oms-community.constants.dist.Confirm">确认</UI-TERM>**。

4. 在 **<UI-TERM key="oms-community.components.Rules2destination.ReduceObjects">减少对象</UI-TERM>** 对话框，单击 **<UI-TERM key="oms-community.common.TreeSearch.TargetNode.Remove">移除</UI-TERM>**。

5. 在弹出框中确认需要移除的对象无误后，单击 **<UI-TERM key="oms-community.Detail.components.MigrationSteps.Determine">确定</UI-TERM>**。

   如果任务处于已暂停、失败或运行中状态，单击确定后，将立即执行减少对象操作。

   <main id="notice" type='notice'>
    <h4>注意</h4>
    <ul>
    <li>
    <p>对象减少后不可恢复，请谨慎操作。</p>
    </li>
    <li>
    <p>减少对象操作最终是全部成功或全部失败。</p>
    </li>
    </ul>
   </main>

   减少对象操作开始执行后，会在 **<UI-TERM key="oms-community.Detail.components.SyncObject.ViewObjectsToBeSynchronized">查看对象</UI-TERM>** \> **<UI-TERM key="oms-community.components.ViewObject.ModifyObjectRecords">修改对象记录</UI-TERM>** 页面生成记录，您可以进入该页面查看记录的详情。减少对象记录的状态包括 **<UI-TERM key="oms-community.ModifyRecordTable.constants.PendingExecution">待执行</UI-TERM>**、**<UI-TERM key="oms-community.SystemManage.Authorization.contants.Canceled">已取消</UI-TERM>**、**<UI-TERM key="oms-community.Migration.constants.Modifying">修改中</UI-TERM>**、**<UI-TERM key="oms-community.pages.Audit.Success">成功</UI-TERM>** 和 **<UI-TERM key="oms-community.Overview.constants.Failed">失败</UI-TERM>**，不同状态的修改对象记录支持的操作，以及处于运行中状态的原任务对应的状态也不同。

   | **减少对象记录的状态** | **支持的操作**                                                    | **原任务对应的状态** |
   |---------------|--------------------------------------------------------------|------------|
   | 待执行           | 查看详情、取消                                                      | 运行中        |
   | 已取消           |  无                                                            |  运行中  |
   | 修改中           | 无                                                          | 修改中       |
   | 成功            | 查看详情                         | 运行中        |
   | 失败            | 查看详情、重试 <br>您还可以单击 **<UI-TERM key="oms-community.components.ModifyRecordTable.ViewReason">查看原因</UI-TERM>**，跳转至任务的详情页面，查看失败的原因。 | 修改中      |
