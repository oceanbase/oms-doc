# 释放和删除数据同步任务

如果您不再需要维护源端和目标端的数据同步任务，可以及时暂停并释放。释放数据同步任务后，如果您确认不再需要保留该任务的相关信息，请删除数据同步任务，释放组件资源。

## 释放数据同步任务

释放数据同步任务后，OMS 社区版会终止当前任务，且该操作不可恢复，请谨慎操作。但 OMS 社区版不会删除该数据同步任务，您可以查看该任务的详细信息。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>OMS 社区版支持释放处于 <strong>已暂停</strong>、<strong>失败</strong> 和 <strong>已完成</strong> 状态的数据同步任务。</p>
</main>

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **数据同步**。

3. 在 **同步任务列表** 页面，单击目标任务后的 **释放**。

   您也可以单击任务名称进入详情页面，单击右上角的 **更多操作** \> **释放**。

4. 在对话框中，单击 **确定**。

## 删除数据同步任务

删除数据同步任务后，该任务的数据将不可恢复，请谨慎操作。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>OMS 支持删除处于 <strong>未启动</strong> 和 <strong>已释放</strong> 状态的数据同步任务。</p>
</main>

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **数据同步**。

3. 在 **同步任务列表** 页面，单击目标任务后的 **删除**。

   您也可以单击任务名称进入详情页面，单击右上角的 **删除**。

4. 在对话框中，单击 **删除**。
