# 批量操作数据同步任务

本文为您介绍如何使用 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版对数据同步任务进行批量操作。

## 背景信息

OMS 社区版支持在 **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">同步任务列表</UI-TERM>** 页面，对数据同步任务进行批量操作。不同状态的数据同步任务支持不同的批量操作。

| **数据同步任务的状态** | **支持的批量操作**        |
|---------------|--------------------|
| 未启动           | 批量启动、批量删除、批量修改告警配置 |
| 运行中           | 批量暂停、批量修改告警配置      |
| 已暂停           | 批量恢复、批量释放、批量修改告警配置 |
| 失败            | 批量恢复、批量释放、批量修改告警配置 |
| 已释放           | 批量删除               |
| 释放中           | 无                  |
| 已完成           | 批量释放               |

如果您在选择多个任务进行某项批量操作时，遇到并非所有任务都符合该项批量操作适用的场景。OMS 社区版会在弹出对话框中提示您可以进行该项批量操作的任务。

![batch-pause-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/batch-pause-zh.png)

## 进入同步任务列表页面

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.Sync.Detail.DataSynchronization">数据同步</UI-TERM>**，即可进入 **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">同步任务列表</UI-TERM>** 页面。

   您可以在该页面选择需要进行批量操作的数据同步任务，进行相关批量操作。

   ![sync-batch-operation-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/sync-batch-operation-zh.png)

## 批量暂停

OMS 社区版支持处于 **<UI-TERM key="oms-community.src.constants.Running">运行中</UI-TERM>** 状态的数据同步任务进行 **<UI-TERM key="oms-community.Migration.constants.BatchPause">批量暂停</UI-TERM>** 操作。

1. 在 **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">同步任务列表</UI-TERM>** 页面，选择需要暂停的数据同步任务。

2. 单击页面下方的 **<UI-TERM key="oms-community.Migration.constants.BatchPause">批量暂停</UI-TERM>**。

3. 在弹出对话框中，单击 **<UI-TERM key="oms-community.components.FullValidation.UpdateValidatingSqlDrawer.Determine">确定</UI-TERM>**。

   该对话框会提示您可以进行批量暂停的任务个数、任务名称和最新位点。

4. 待批量暂停成功后，页面会进行提示并告知您批量暂停成功的任务个数。

   如果有操作失败的任务，请根据页面提示进行排查。

## 批量恢复

OMS 社区版支持处于 **<UI-TERM key="oms-community.Migration.constants.Paused">已暂停</UI-TERM>** 和 **<UI-TERM key="oms-community.Operation.constants.Failed">失败</UI-TERM>** 状态的数据同步任务进行 **<UI-TERM key="oms-community.Migration.constants.BatchRecovery">批量恢复</UI-TERM>** 操作。

1. 在 **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">同步任务列表</UI-TERM>** 页面，选择需要恢复的数据同步任务。

2. 单击页面下方的 **<UI-TERM key="oms-community.Migration.constants.BatchRecovery">批量恢复</UI-TERM>**。

3. 在弹出对话框中，单击 **<UI-TERM key="oms-community.Detail.components.MigrationSteps.Determine">确定</UI-TERM>**。

   该对话框会提示您可以进行批量恢复的任务个数、任务名称和最新位点。

4. 待批量恢复成功后，页面会进行提示并告知您批量恢复成功的任务个数。

   如果有操作失败的任务，请根据页面提示进行排查。

## 批量释放

OMS 社区版支持处于 **<UI-TERM key="oms-community.Migration.constants.Paused">已暂停</UI-TERM>**、**<UI-TERM key="oms-community.Audit.Deatil.Failed">失败</UI-TERM>** 和 **<UI-TERM key="oms-community.Operator.constants.Finished">已完成</UI-TERM>** 状态的数据同步任务进行 **<UI-TERM key="oms-community.Migration.constants.BatchRelease">批量释放</UI-TERM>** 操作。

1. 在 **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">同步任务列表</UI-TERM>** 页面，选择需要释放的数据同步任务。

2. 单击页面下方的 **<UI-TERM key="oms-community.Migration.constants.BatchRelease">批量释放</UI-TERM>**。

3. 在弹出对话框中，单击 **<UI-TERM key="oms-community.components.TreeTransfer.TargetNode.Determine">确定</UI-TERM>**。

   该对话框会提示您可以进行批量释放的任务个数、任务名称和最新位点。

4. 待批量释放成功后，页面会进行提示并告知您批量释放成功的任务个数。

   如果有操作失败的任务，请根据页面提示进行排查。

1. 在 **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">同步任务列表</UI-TERM>** 页面，选择需要批量启动的数据同步任务。

2. 单击页面下方的 **<UI-TERM key="oms-community.Migration.constants.BatchStart">批量启动</UI-TERM>**。

3. 在弹出对话框中，单击 **<UI-TERM key="oms-community.biz.AccountAuthorization.Ok">确定</UI-TERM>**。

   该对话框会提示您可以进行批量启动的任务个数、任务名称和最新位点。

4. 待批量启动成功后，页面会进行提示并告知您批量操作成功的任务个数。

   如果有操作失败的任务，请根据页面提示进行排查。

## 批量删除

OMS 社区版支持处于 **<UI-TERM key="oms-community.Migration.constants.NotStarted">未启动</UI-TERM>** 和 **<UI-TERM key="oms-community.Migration.constants.Released">已释放</UI-TERM>** 状态的数据同步任务进行 **<UI-TERM key="oms-community.pages.EndpointPublic.BatchDelete">批量删除</UI-TERM>** 操作。

1. 在 **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">同步任务列表</UI-TERM>** 页面，选择需要批量删除的数据同步任务。

2. 单击页面下方的 **<UI-TERM key="oms-community.components.BatchSelect.MoreBatchOperations">更多批量操作</UI-TERM>** \> **<UI-TERM key="oms-community.pages.EndpointPublic.BatchDelete">批量删除</UI-TERM>**。

3. 在弹出对话框中，单击 **<UI-TERM key="oms-community.Components.ReplicationInstance.Ok">确定</UI-TERM>**。

   该对话框会提示您可以进行批量删除的任务个数、任务名称和最新位点。

4. 待批量删除成功后，页面会进行提示并告知您批量删除成功的任务个数。

   如果有操作失败的任务，请根据页面提示进行排查。

## 批量修改告警配置

OMS 社区版支持处于 **<UI-TERM key="oms-community.Sync.constants.NotStarted.5">未启动</UI-TERM>**、**<UI-TERM key="oms-community.Operator.constants.Running">运行中</UI-TERM>**、**<UI-TERM key="oms-community.Sync.constants.Paused">已暂停</UI-TERM>** 和 **<UI-TERM key="oms-community.src.constants.Failed">失败</UI-TERM>** 状态的数据同步任务进行 **<UI-TERM key="oms-community.Migration.model.migration.vm.ModifyAlertConfigurationsInBatches">批量修改告警配置</UI-TERM>** 操作。

1. 在 **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">同步任务列表</UI-TERM>** 页面，选择需要批量修改告警配置的数据同步任务。

2. 单击页面下方的 **<UI-TERM key="oms-community.components.BatchSelect.MoreBatchOperations">更多批量操作</UI-TERM>** \> **<UI-TERM key="oms-community.Migration.constants.ModifyAlertConfigurationsInBatches">批量修改告警配置</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.utils.hooks.useOMSWarn.ConfigureMultipleAlerts">批量设置告警</UI-TERM>** 对话框，修改告警级别。

   ![batch-modify-alert-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/batch-modify-alert-zh.png)

   OMS 社区版支持的告警级别包括 **<UI-TERM key="oms-community.components.WarnLevel.Unprotected">无保护</UI-TERM>**、**<UI-TERM key="oms-community.components.WarnLevel.HighProtection">高保护</UI-TERM>**、**<UI-TERM key="oms-community.components.WarnLevel.MediumProtection">中保护</UI-TERM>** 和 **<UI-TERM key="oms-community.components.WarnLevel.DiBaoHu">低保护</UI-TERM>**，详情请参见 [告警设置](../../1000.system-management/200.alert-center/300.manage-alert-settings.md)。

4. 单击 **<UI-TERM key="oms-community.User.New.Submitted">提交</UI-TERM>**。

   如果您需要查看数据迁移或数据同步任务的告警监控消息，请参见 [查看任务告警信息](../../1000.system-management/200.alert-center/100.view-project-alerts.md)。

5. 批量修改告警设置成功后，页面会进行提示。如果有操作失败的任务，请根据页面提示进行排查。
