# 修改数据同步任务的名称

本文为您介绍如何修改 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版数据同步任务的名称。

## 使用限制

* OMS 社区版支持处于 **<UI-TERM key="oms-community.Sync.constants.NotStarted.5">未启动</UI-TERM>**、**<UI-TERM key="oms-community.Operation.Overview.constants.Running">运行中</UI-TERM>**、**<UI-TERM key="oms-community.Sync.constants.Paused">已暂停</UI-TERM>** 和 **<UI-TERM key="oms-community.Audit.constants.Failed">失败</UI-TERM>** 状态的任务修改任务名称。

* 数据同步任务运行过程中创建的修改同步对象子任务不支持编辑任务名称。修改同步对象的详情请参见 [查看和修改同步对象](../1100.manage-a-data-synchronization-projects/200.view-and-modify-objects-to-be-synchronized.md)。

* 任务名称为用户维度内的唯一标记。

## 操作步骤

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.Sync.New.DataSynchronization">数据同步</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">同步任务列表</UI-TERM>** 页面，单击任务名称右侧的 **<UI-TERM key="oms-community.Endpoint.constants.Editing">编辑</UI-TERM>** 图标。

   ![rename-sync-1-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/rename-sync-1-zh.png)

   您也可以单击目标任务的名称，进入任务详情页面，单击任务名称右侧的 **<UI-TERM key="oms-community.pages.User.Editing">编辑</UI-TERM>** 图标。

   ![rename-sync-2-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/rename-sync-2-zh.png)

4. 在 **<UI-TERM key="oms-community.Migration.model.migration.vm.EditProjectName">编辑任务名称</UI-TERM>** 对话框，输入修改后的任务名称。

5. 单击 **<UI-TERM key="oms-community.components.ImportTransferObj.Determine">确定</UI-TERM>**。
