# 启动和暂停数据同步任务

本文为您介绍如何启动、暂停和恢复数据同步任务。

## 启动数据同步任务

创建数据同步任务时，如果在预检查完成后仅保存该数据同步任务，未进行启动，则需要在同步任务列表中手动启动数据同步任务。

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.layout.constants.DataSynchronization">数据同步</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">同步任务列表</UI-TERM>** 页面，单击目标任务后的 **<UI-TERM key="oms-community.constants.dist.Start">启动</UI-TERM>**。

   您也可以在 **<UI-TERM key="oms-community.Sync.Detail.DataSynchronization">数据同步</UI-TERM>** 页面，单击任务名称进入详情页面，单击右上角的 **<UI-TERM key="oms-community.Migration.constants.Start">启动</UI-TERM>**。

4. 在对话框中，单击 **<UI-TERM key="oms-community.Migration.hooks.useMigrationObject.Determine">确定</UI-TERM>**。

## 暂停数据同步任务

仅支持暂停 **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.Running">运行中</UI-TERM>** 的数据同步任务。暂停数据同步任务后，OMS 社区版会中止数据同步任务调度，此时延迟会实时增长。

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.components.CustomizedTable.DataSynchronization">数据同步</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">同步任务列表</UI-TERM>** 中找到指定的同步任务，单击其右侧的 **<UI-TERM key="oms-community.Operator.constants.Pause">暂停</UI-TERM>**。

   您也可以在 **<UI-TERM key="oms-community.pages.Sync.DataSynchronization">数据同步</UI-TERM>** 页面，单击任务名称进入详情页面，单击右上角的 **<UI-TERM key="oms-community.Operation.constants.Pause">暂停</UI-TERM>**。

4. 在对话框中，单击 **<UI-TERM key="oms-community.Operator.Connector.StartConnectorModal.StartConfirm">确定</UI-TERM>**。

   <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>本操作将暂停同步写入组件，且同步任务暂停时间超过 12 小时，任务无法被恢复。</p>
   </main>

## 恢复数据同步任务

您可以手动恢复 **<UI-TERM key="oms-community.Overview.constants.Pause">暂停</UI-TERM>** 或 **<UI-TERM key="oms-community.src.constants.Failed">失败</UI-TERM>** 的数据同步任务，OMS 社区版会继续运行数据同步任务，尽快缩短同步延迟。

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.src.constants.DataSynchronization">数据同步</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">同步任务列表</UI-TERM>** 中找到指定的同步任务，单击其右侧的 **<UI-TERM key="oms-community.Operator.constants.Restore">恢复</UI-TERM>**。

   您也可以在 **<UI-TERM key="oms-community.layout.constants.DataSynchronization">数据同步</UI-TERM>** 页面，单击任务名称进入详情页面，单击右上角的 **<UI-TERM key="oms-community.Sync.constants.Recovery">恢复</UI-TERM>**。

4. 在对话框中，单击 **<UI-TERM key="oms-community.Migration.hooks.useMigrationParams.Determine">确定</UI-TERM>**。
