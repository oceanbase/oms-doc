# 启动和暂停数据同步任务

本文为您介绍如何启动、暂停和恢复数据同步任务。

## 启动数据同步任务

创建数据同步任务时，如果在预检查完成后仅保存该数据同步任务，未进行启动，则需要在同步任务列表中手动启动数据同步任务。

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **数据同步**。

3. 在 **同步任务列表** 页面，单击目标任务后的 **启动**。

   您也可以在 **数据同步** 页面，单击任务名称进入详情页面，单击右上角的 **启动**。

4. 在对话框中，单击 **确定**。

## 暂停数据同步任务

仅支持暂停 **运行中** 的数据同步任务。暂停数据同步任务后，OMS 社区版会中止数据同步任务调度，此时延迟会实时增长。

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **数据同步**。

3. 在 **同步任务列表** 中找到指定的同步任务，单击其右侧的 **暂停**。

   您也可以在 **数据同步** 页面，单击任务名称进入详情页面，单击右上角的 **暂停**。

4. 在对话框中，单击 **确定**。

   <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>本操作将暂停同步写入组件，且同步任务暂停时间超过 12 小时，任务无法被恢复。</p>
   </main>

## 恢复数据同步任务

您可以手动恢复 **暂停** 或 **失败** 的数据同步任务，OMS 社区版会继续运行数据同步任务，尽快缩短同步延迟。

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **数据同步**。

3. 在 **同步任务列表** 中找到指定的同步任务，单击其右侧的 **恢复**。

   您也可以在 **数据同步** 页面，单击任务名称进入详情页面，单击右上角的 **恢复**。

4. 在对话框中，单击 **确定**。
