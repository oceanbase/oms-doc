# 部门管理

OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版以部门为维度对角色进行隔离管理。即同一个部门的 ADMIN 角色的用户仅具备本部门下所有任务的读写权限，对其它部门的任务不具备读写权限。本文为您介绍 root 用户如何新建、修改和删除部门。

## 使用限制

* 仅 root 用户支持进入 **<UI-TERM key="oms-community.pages.User.DepartmentManagement">部门管理</UI-TERM>** 页面。

* 默认存在一个 default 部门，且该部门不允许被修改和删除。

* 当部门存在成员时，该部门不允许被删除。

* 为了兼容前 ADMIN 角色，OMS 社区版未对部分系统维度的能力进行限制。例如，机器维度的组件数量限制，以及组件内以 IP 为维度进行批量操作等。

## 新建部门

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.SystemManagement">系统管理</UI-TERM>** \> **<UI-TERM key="oms-community.pages.User.PermissionManagement">权限管理</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.PermissionManagement">权限管理</UI-TERM>** 页面，单击 **<UI-TERM key="oms-community.pages.User.DepartmentManagement">部门管理</UI-TERM>** 页签。

4. 在 **<UI-TERM key="oms-community.pages.User.DepartmentManagement">部门管理</UI-TERM>** 页面的右上角，单击 **<UI-TERM key="oms-community.User.New.CreateANewDepartment">新建部门</UI-TERM>**。

5. 在 **<UI-TERM key="oms-community.User.New.CreateANewDepartment">新建部门</UI-TERM>** 对话框，输入 **<UI-TERM key="oms-community.pages.User.DepartmentName">部门名称</UI-TERM>**。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>部门名称的长度不能超过 40 个字符。</p>
    </main>

6. 单击 **<UI-TERM key="oms-community.Migration.New.Confirmation">确定</UI-TERM>**。

## 修改部门名称

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.SystemManagement">系统管理</UI-TERM>** \> **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.PermissionManagement">权限管理</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.PermissionManagement">权限管理</UI-TERM>** 页面，单击 **<UI-TERM key="oms-community.pages.User.DepartmentManagement">部门管理</UI-TERM>** 页签。

4. 在 **<UI-TERM key="oms-community.pages.User.DepartmentManagement">部门管理</UI-TERM>** 页面，单击目标部门后的 **<UI-TERM key="oms-community.components.BanchView.ModifyName">修改名称</UI-TERM>**。

5. 在文本框中输入修改后的部门名称，单击 **<UI-TERM key="oms-community.Migration.New.Save">保存</UI-TERM>**。

## 删除部门

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="transmit.terminal.notification">系统管理</UI-TERM>** \> **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.PermissionManagement">权限管理</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.PermissionManagement">权限管理</UI-TERM>** 页面，单击 **<UI-TERM key="oms-community.pages.User.DepartmentManagement">部门管理</UI-TERM>** 页签。

4. 在 **<UI-TERM key="oms-community.pages.User.DepartmentManagement">部门管理</UI-TERM>** 页面，单击没有成员的目标部门后的 **<UI-TERM key="oms-community.components.ProjectLabel.LabelManager.Delete">删除</UI-TERM>**。

5. 单击对话框中的 **<UI-TERM key="oms-community.Operator.JDBCWriter.useJDBCWriterAction.Update">确定</UI-TERM>**。
