# 新建 SSO 集成

OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版内置了账号体系，您可以根据本文的操作在 OMS 社区版中配置 SSO 集成，并通过 SSO 登录到 OMS 社区版控制台。本文为您介绍如何新建 SSO 集成。

## 前提条件

* 请确保当前登录 OMS 社区版的用户为 ADMIN 角色。

* 请确保用户已部署授权服务。

## 使用限制

* OAuth2 或 OIDC 集成仅支持授权码模式。

* OAuth2 或 OIDC 退出登录时，仅清除 OMS 社区版应用的登录态，不会清理 SSO 系统的登录态。

## 操作步骤

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM>系统管理</UI-TERM>** > **<UI-TERM>SSO 管理</UI-TERM>**。

3. 在 **<UI-TERM>SSO 管理</UI-TERM>** 页面，单击右上角的 **<UI-TERM>创建 SSO 集成</UI-TERM>**。

4. 在 **<UI-TERM>新建 SSO 集成</UI-TERM>** 对话框，配置各项参数。

    * 基本信息

      |  参数   |  描述  |
      |--------------|---------------|
      | 配置名称  |  用于自定义登录名，以英文字母开头、英文或数字结尾，支持英文、数字和下划线（_），长度限制为 2 ~ 32 个字符。 |
      | 类型  | 支持 **OAuth2** 和 **OIDC**，请根据实际需求进行选择。|

    * OAUTH 信息

      |  参数   |  描述  |
      |--------------|---------------|
      | Client ID | 应用标识，请和授权服务器注册时的配置保持一致。|
      | Client Secret | 应用密钥，请和授权服务器注册时的配置保持一致。|
      | Auth URL |授权服务器提供的获取 grant-code 地址。|
      | Token URL | 授权服务器提供的获取 access-token 地址。 |
      | User Info URL（可选）| 授权服务器提供的获取 user-info 地址。|
      | Redirect URL |授权服务器回调 OMS 社区版服务的地址。 <main id="notice" type='notice'><h4>注意</h4><p>如果 SSO 存在回调白名单，则需要进行加白。</p></main>  |
      | Scope | 应用授权作用域。您可以自行输入并支持输入多个，建议设置为 `profile`。<main id="notice" type='notice'><h4>注意</h4><p>通过第三方应用配置 SSO 时，Scope 参数为必填。</p></main>  |

    * 高级选项

      您可以根据实际情况判断是否开启 **<UI-TERM>高级选项</UI-TERM>**。开启后，请配置下述参数。

      |  参数   |  描述  |
      |--------------|---------------|
      | jwkSet Url（可选）| 授权服务器提供的公钥地址，使用公钥进行鉴权。 |
      | Issue URL（可选）| 设置认证服务的 Issue 地址。<main id="notice" type='notice'><h4>注意</h4><p>仅选择 <b>类型</b> 为 <b>OIDC</b> 时，会显示该参数。</p></main>  |
      | Client Authentication Method | 通过授权服务器对客户端进行身份验证时使用的身份验证方法。 |
      | Authorization Grant Type | OAUTH2 的授权方式。 |
      | User Info Authentication Method | 在向资源服务器发送资源请求中的承载访问令牌时使用的身份验证方法。|

    * 用户字段映射

      用户字段映射用于标识与 OAuth2 登录关联的 OMS 社区版账号的标识符。为了将第三方用户的用户信息映射到 OMS 社区版用户字段，请填写下述参数。

      |  参数   |  描述  |
      |--------------|---------------|
      | 用户信息数据结构类型 | 请选择用户信息数据结构类型。|
      | 用户名字段 | 请输入用户名字段。|
      | 邮箱字段（可选）| 请输入邮箱字段。|

5. 配置完成后，请将鼠标悬停至 **<UI-TERM>测试连接</UI-TERM>** 右侧的图标，根据提示信息手动添加白名单后，单击 **<UI-TERM>测试连接</UI-TERM>**。

6. 测试通过后，单击 **<UI-TERM>保存</UI-TERM>**。

## 后续步骤

在 **<UI-TERM>SSO 管理</UI-TERM>** 页面，启用新建的 SSO 集成。详情请参见 [启用或停用 SSO 集成](../500.sso-management/300.enable-and-disenable-sso.md)。
