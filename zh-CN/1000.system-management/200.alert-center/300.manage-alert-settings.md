# 告警设置

OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版支持通过管理控制台页面，配置告警内置监控项、告警阈值和告警频率，并支持新建、编辑和删除告警通道。

## 背景信息

目前，OMS 社区版长期同步任务状态等监控任务的告警通道，通过 OCP 对接到客户环境。您可以通过 OMS 社区版的 **<UI-TERM key="oms-community.Notification.Setting.AlertSettings">告警设置</UI-TERM>** 页面，对数据迁移和数据同步任务进行不同保护级别对应的阈值设置。

OMS 社区版支持的告警级别包括 **<UI-TERM key="oms-community.components.WarnLevel.Unprotected">无保护</UI-TERM>**、**<UI-TERM key="oms-community.components.WarnLevel.HighProtection">高保护</UI-TERM>**、**<UI-TERM key="oms-community.components.WarnLevel.MediumProtection">中保护</UI-TERM>** 和 **<UI-TERM key="oms-community.components.WarnLevel.DiBaoHu">低保护</UI-TERM>**：

* 无保护：无需告警，适用于短期迁移或实时性要求较低的业务场景。

* 高保护：适用于延迟要求极高的业务场景。

  高保护的触发条件如下：

  * 同步延迟大于设定的阈值。
  
  * 结构迁移或全量任务中断的时长大于设定的阈值。

* 中保护：适用于延迟要求较高的业务场景，其设定的阈值需要大于、等于高保护设置的阈值。

* 低保护：适用于延迟要求不高的业务场景，其设定的阈值需要大于、等于中保护设置的阈值。

Admin 用户可以修改各个保护级别的 **<UI-TERM key="oms-community.Notification.Setting.Card.AlertThreshold">告警阈值</UI-TERM>** 和 **<UI-TERM key="oms-community.components.WarnContent.AlertFrequency">告警频率</UI-TERM>**，普通用户可以为自己的数据同步任务标记告警级别，但仅支持查看各个保护级别的 **<UI-TERM key="oms-community.Notification.Setting.Card.AlertThreshold">告警阈值</UI-TERM>** 和 **<UI-TERM key="oms-community.Notification.Setting.Card.AlertFrequency">告警频率</UI-TERM>**。

## 操作步骤

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="transmit.terminal.notification">系统管理</UI-TERM>** \> **<UI-TERM>告警</UI-TERM>**。

3. 在 **<UI-TERM>告警</UI-TERM>** 页面，单击 **<UI-TERM key="oms-community.Audit.constants.AlarmSettings">告警设置</UI-TERM>** 页签。

4. 在 **<UI-TERM key="oms-community.Notification.Setting.AlertSettings">告警设置</UI-TERM>** 页面，根据业务需求，设置 **<UI-TERM key="oms-community.components.WarnLevel.HighProtection">高保护</UI-TERM>**、**<UI-TERM key="oms-community.components.WarnLevel.MediumProtection">中保护</UI-TERM>**、**<UI-TERM key="oms-community.components.WarnLevel.DiBaoHu">低保护</UI-TERM>** 的 **<UI-TERM key="oms-community.Notification.Setting.Card.AlertThreshold">告警阈值</UI-TERM>** 和 **<UI-TERM key="oms-community.Notification.Setting.Card.AlertFrequency">告警频率</UI-TERM>**。

   | 保护级别 |  参数  |                        描述                        |
   |------|------|--------------------------------------------------|
   | 高保护  | 同步延迟 | 设定范围为 1 秒 \~ 5 分钟。                               |
   | 高保护  | 中断时间 | 设定范围为 1 秒 \~ 5 分钟。                               |
   | 中保护  | 同步延迟 | 设定范围为 30 秒 \~ 10 分钟。                             |
   | 中保护  | 中断时间 | 设定范围为 30 秒 \~ 10 分钟。                             |
   | 低保护  | 同步延迟 | 设定范围为 5 分钟 \~ 3 小时。                              |
   | 低保护  | 中断时间 | 设定范围为 5 分钟 \~ 3 小时。                              |
   | 告警频率       || 默认每 3 分钟发送一次。您可以根据业务需求进行设置，设定范围为 1 分钟 \~ 600 分钟。 |

5. 设置成功后，您可以在 **<UI-TERM key="oms-community.components.CustomizedTable.DataMigration">数据迁移</UI-TERM>** 和 **<UI-TERM key="oms-community.Sync.New.DataSynchronization">数据同步</UI-TERM>** 页面，查看和修改告警等级。

   以 **<UI-TERM key="oms-community.components.CustomizedTable.DataMigration">数据迁移</UI-TERM>** 页面为例，操作如下：

   1. 在左侧导航栏，单击 **<UI-TERM key="oms-community.New.components.EndpointForm.DataMigration">数据迁移</UI-TERM>**。

   2. 在 **<UI-TERM key="oms-community.pages.Migration.MigrationProject">迁移任务列表</UI-TERM>** 页面，单击目标迁移任务后的 **<UI-TERM key="oms-community.project.cloudweb.MoreOperations">更多操作</UI-TERM>** \> **<UI-TERM key="oms-community.Detail.components.MigrationInfos.ModifyAlertLevels">修改告警等级</UI-TERM>**。

   3. 在 **<UI-TERM key="oms-community.pages.Migration.TableRowCard.ModifyAlertLevels">修改告警等级</UI-TERM>** 对话框，选中需要的告警等级。

   4. 单击 **<UI-TERM key="oms-community.components.WarnContent.Submitted">提交</UI-TERM>**。

## 新建告警通道

1. 在 OMS 社区版控制台的左侧导航栏，单击 **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.SystemManagement">系统管理</UI-TERM>** \> **<UI-TERM>告警</UI-TERM>**。

2. 在 **<UI-TERM>告警</UI-TERM>** 页面，单击 **<UI-TERM key="oms-community.Audit.constants.AlarmSettings">告警设置</UI-TERM>** 页签。

3. 在 **<UI-TERM key="oms-community.Notification.Setting.AlarmChannel.AlertChannels">告警通道列表</UI-TERM>** 区域，单击右上角的 **<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.CreateAnAlertChannel">新建告警通道</UI-TERM>**。

   ![新建](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4980175261/p291330.png)

4. 在 **<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.CreateAnAlertChannel">新建告警通道</UI-TERM>** 对话框，配置各项参数。

   |  参数  |  描述  |
   |------|----------|
   | 通道名称 | 自定义输入通道的名称，仅支持中文、英文、数字和下划线（_），且不能超过 50 个字符。<br>**注意：**<br>通道名称在 OMS 系统内全局唯一。   |
   | 通道类型 | 包括 **<UI-TERM>OCP 告警</UI-TERM>** 和 **<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.DingtalkAlarm">钉钉告警</UI-TERM>**。            |
   | 配置信息 | 根据选择的通道类型，填写配置信息： <ul><li> 当选择 **<UI-TERM>OCP 告警</UI-TERM>** 时，从关联的 OCP 列表中选择一个 OCP。   <li> 当选择 **<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.DingtalkAlarm">钉钉告警</UI-TERM>** 时，请输入钉钉机器人 Webhook 地址的 access_token 信息，并且钉钉机器人需要设置关键词 “OMS 告警”。详情请参见下文的《获取钉钉机器人的 access_token 信息》。<br> 设置钉钉告警后，您可以通过指定的钉钉群接收告警通知。</ul>    |

5. 单击 **<UI-TERM key="oms-community.EndpointPublic.components.FormContent.TestConnection">测试连接</UI-TERM>**。

6. 测试通过后，单击 **<UI-TERM key="oms-community.JDBCWriter.New.Submitted">提交</UI-TERM>**。

新建成功后，您可以进行 **<UI-TERM key="oms-community.Notification.Setting.AlarmChannel.Editing">编辑</UI-TERM>** 和 **<UI-TERM key="oms-community.Sync.constants.Delete">删除</UI-TERM>** 操作：

* 编辑告警通道

  1. 单击目标告警通道后的 **<UI-TERM key="oms-community.EndpointPublic.constants.Editing">编辑</UI-TERM>**。

  2. 在 **<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.ModifyAnAlertChannel">修改告警通道</UI-TERM>** 对话框，修改各项参数。

     您可以修改告警通道的 **<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.ChannelName">通道名称</UI-TERM>**、**<UI-TERM key="oms-community.Notification.Setting.AlarmChannel.ChannelType">通道类型</UI-TERM>** 和 **<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.PeiZhiXinXi">配置信息</UI-TERM>**。
  
  3. 单击 **<UI-TERM key="oms-community.EndpointPublic.constants.TestConnection">测试连接</UI-TERM>**。
  
  4. 测试通过后，单击 **<UI-TERM key="oms-community.Detail.components.MigrationInfos.Submitted">提交</UI-TERM>**。

* 删除告警通道

  1. 单击目标告警通道后的 **<UI-TERM key="oms-community.Operator.constants.Destruction">删除</UI-TERM>**。
  
  2. 在弹出的对话框中，单击 **<UI-TERM key="oms-community.migration.full.constants.Delete">删除</UI-TERM>**。

## 获取钉钉机器人的 access_token 信息

1. 打开目标钉钉群，单击右上角的 **<UI-TERM>群设置</UI-TERM>** 图标。

2. 单击 **<UI-TERM>智能群助手</UI-TERM>**。

3. 在 **<UI-TERM>智能群助手</UI-TERM>** 页面，单击 **<UI-TERM>添加机器人</UI-TERM>**。

4. 在 **<UI-TERM>群机器人</UI-TERM>** 页面，单击 **+** 图标。

5. 在 **<UI-TERM>选择要添加的机器人</UI-TERM>** 页面，单击 **<UI-TERM key="oms-community.New.components.ParameterForm.Custom">自定义</UI-TERM>**。

6. 在 **<UI-TERM>机器人详情</UI-TERM>** 页面，单击 **<UI-TERM key="oms-community.components.EndpointSelect.Add">添加</UI-TERM>**。

7. 在 **<UI-TERM>添加机器人</UI-TERM>** 页面，配置各项参数。

   |  参数   |描述  |
   |-------|----------|
   | 机器人名字 | 自定义机器人的名称。  |
   | 添加到群组 | 添加机器人的钉钉群，不支持修改。  |
   | 安全设置  | 包括 **<UI-TERM>自定义关键词</UI-TERM>**、**<UI-TERM>加签</UI-TERM>** 和 **<UI-TERM>IP 地址（段）</UI-TERM>**。请至少选择一种安全设置，保障自定义机器人安全。详情请参见钉钉官方文档 [自定义机器人安全设置](https://open.dingtalk.com/document/robots/customize-robot-security-settings)。 |

8. 选中 **我已阅读并同意《自定义机器人服务及免责条款》**，单击 **<UI-TERM key="oms-community.Sync.constants.Complete">完成</UI-TERM>**。

9. 单击 **<UI-TERM key="oms-community.components.FullValidation.UpdateValidatingSqlDrawer.Copy">复制</UI-TERM>**，获取 Webhook 地址，截取 `access_token=` 之后的 token 信息。您也可以直接复制机器人 Webhook 中的 access_token 信息。

   <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>请妥善保管 Webhook 地址，一旦泄露会有安全风险。</p>
   </main>

   ![token信息](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7617297461/p392777.png)

10. 单击 **<UI-TERM key="oms-community.src.constants.Complete">完成</UI-TERM>**。
