# 查看数据源信息

创建数据源后，您可以在数据源列表查看所有已创建数据源的基本信息、详情和网络连接等信息，也可以根据数据源类型进行筛选、根据数据源的创建时间进行排序，以及模糊搜索指定数据源。

## 操作步骤

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.pages.Endpoint.DataSourceManagement">数据源管理</UI-TERM>**。

   **<UI-TERM key="oms-community.pages.Endpoint.DataSources">数据源列表</UI-TERM>** 页面为您展示所有已创建的数据源及其基本信息，包括 **<UI-TERM key="oms-community.EndpointPublic.components.form.DataSourceId">数据源标识</UI-TERM>**、**<UI-TERM key="oms-community.pages.EndpointPublic.DataSourceType">数据源类型</UI-TERM>**、**主机 IP:端口**、**<UI-TERM key="oms-community.endpoints.MySqlForm.FormItem.DatabaseUsername">数据库用户名</UI-TERM>** 和数据源的 **<UI-TERM key="oms-community.pages.Endpoint.AddTime">添加时间</UI-TERM>**。

   如果是多地域场景，您可以在 **<UI-TERM key="oms-community.Endpoint.New.Geographical">地域</UI-TERM>** 列进行筛选，查看目标地域下的数据源。

   您可以在操作列进行下述操作：

   1. 测试连接：单击 **<UI-TERM key="oms-community.pages.OCP.constant.TestConnection">测试连接</UI-TERM>**，检查数据库的网络连接情况。

   2. 复制数据源：单击 **<UI-TERM key="oms-community.components.FullValidation.UpdateValidatingSqlDrawer.Copy">复制</UI-TERM>**，在 **<UI-TERM key="oms-community.Endpoint.New.CopyDataSources">复制数据源</UI-TERM>** 对话框中，配置各项参数。详情请参见 [复制数据源](../200.manage-data-sources/300.copy-data-source.md)。

   3. 编辑数据源：单击 **<UI-TERM key="oms-community.Notification.Setting.AlarmChannel.Editing">编辑</UI-TERM>**，在 **<UI-TERM key="oms-community.Endpoint.New.EditDataSource">编辑数据源</UI-TERM>** 对话框中，编辑需要修改的参数。

   4. 删除数据源：单击 **<UI-TERM key="oms-community.Sync.Detail.Delete">删除</UI-TERM>**，在对话框中，单击 **<UI-TERM key="oms-community.Notification.Setting.AlarmChannel.Delete">删除</UI-TERM>**。详情请参见 [删除数据源](../200.manage-data-sources/500.delete-a-data-source.md)。

   5. 缓存系统视图：单击 **<UI-TERM key="oms-community.Migration.Detail.MoreOperations">更多操作</UI-TERM>** > **<UI-TERM key="oms-community.pages.Endpoint.CacheSystemView">缓存系统视图</UI-TERM>**。详情请参见 [缓存系统视图](../200.manage-data-sources/600.cache-system-view.md)。

      <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>目前仅 OceanBase 数据库 V3.x 支持缓存系统视图。</p>
      </main>

3. 在 **<UI-TERM key="oms-community.pages.Endpoint.DataSources">数据源列表</UI-TERM>** 页面，查看指定的数据源。

   您可以根据数据源的类型进行筛选，快速查找指定类型的数据源，也可以通过右上角的搜索框模糊搜索指定数据源。

4. 单击指定数据源的 **<UI-TERM key="oms-community.Endpoint.New.DataSourceId">数据源标识</UI-TERM>**，查看该数据源的详细信息。
