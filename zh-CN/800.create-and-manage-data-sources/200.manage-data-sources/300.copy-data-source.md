# 复制数据源

OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版提供复制数据源功能，您可以通过复制已有数据源的方式快速创建数据源。该功能适用于需要快速创建相似数据源的场景，本文为您介绍如何复制数据源。

## 操作步骤

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.DataSourceManagement">数据源管理</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.pages.EndpointPublic.DataSources">数据源列表</UI-TERM>** 页面，单击目标数据源后的 **<UI-TERM key="oms-community.Endpoint.constants.Copy">复制</UI-TERM>**。

   如果是多地域场景，您可以在 **<UI-TERM key="oms-community.Endpoint.constants.Geographical">地域</UI-TERM>** 列进行筛选，复制目标地域下的数据源。

4. 在 **<UI-TERM key="oms-community.Endpoint.New.CopyDataSources">复制数据源</UI-TERM>** 对话框中，配置各项参数。

   配置参数详情请参见对应数据源的创建文档。

5. 单击 **<UI-TERM key="oms-community.Endpoint.New.TestConnection">测试连接</UI-TERM>**，测试数据源的连通性。

6. 测试连接通过后，单击 **<UI-TERM key="oms-community.EndpointPublic.constants.Copy">复制</UI-TERM>**。
