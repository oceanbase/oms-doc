# 编辑数据源

OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版提供编辑数据源功能，您可以修改已有数据源的各项参数。本文为您介绍如何编辑数据源。

## 操作步骤

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.pages.Endpoint.DataSourceManagement">数据源管理</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.pages.EndpointPublic.DataSources">数据源列表</UI-TERM>** 页面，单击目标数据源后的 **<UI-TERM key="oms-community.Endpoint.constants.Editing">编辑</UI-TERM>**。

   如果是多地域场景，您可以在 **<UI-TERM key="oms-community.Endpoint.constants.Geographical">地域</UI-TERM>** 列进行筛选，编辑目标地域下的数据源。

4. 在 **<UI-TERM key="oms-community.pages.EndpointPublic.EditDataSource">编辑数据源</UI-TERM>** 对话框中，编辑需要修改的参数。

   配置参数详情请参见对应数据源的创建文档。

5. 单击 **<UI-TERM key="oms-community.EndpointPublic.constants.TestConnection">测试连接</UI-TERM>**，测试 OMS 社区版和源数据库的网络连接。

6. 测试连接通过后，单击 **<UI-TERM key="oms-community.Sync.New.Save">保存</UI-TERM>**。
