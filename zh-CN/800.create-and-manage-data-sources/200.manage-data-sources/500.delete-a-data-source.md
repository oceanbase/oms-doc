# 删除数据源

OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版支持删除已创建的数据源。该操作不会影响您的数据库，也不会影响正在使用该数据库进行数据迁移、数据同步的任务。

## 操作步骤

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.layout.constants.DataSourceManagement">数据源管理</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.pages.EndpointPublic.DataSources">数据源列表</UI-TERM>** 页面，单击需要删除的数据源后的 **<UI-TERM key="oms-community.EndpointPublic.constants.Delete">删除</UI-TERM>**。

   如果是多地域场景，您可以在 **<UI-TERM key="oms-community.Endpoint.constants.Geographical">地域</UI-TERM>** 列进行筛选，删除目标地域下的数据源。

4. 在对话框中，单击 **<UI-TERM key="oms-community.Sync.Detail.Delete">删除</UI-TERM>**。
