# 缓存系统视图

本文为您介绍缓存系统视图的背景信息及其操作。

## 背景信息

迁移 OceanBase 数据库 V3.x 大量表数据至 OceanBase 数据库 V4.x 时，如果源端表的数量过多，information_schema 下的 STATISTICS、TABLES 和 COLUMNS 等主要的系统视图在 OceanBase 数据库 V3.x 中没有索引，每次查询都是全表扫描，然后在结构迁移、全量迁移中大量使用，并且很多查询是每一张表都需要查询一次，导致创建数据迁移任务失败。

因此，OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版 V4.2.5 新增支持本地实现对 OceanBase 数据库 V3.x 中使用到的系统元数据视图进行缓存，您可以在缓存系统视图后再创建数据迁移任务，OMS 社区版会自动使用缓存数据。缓存成功后，缓存文件本地根目录为 `/home/ds/run/sysmetacache/{endpointId}`。

## 使用限制

目前仅 OceanBase 数据库 V3.x 支持缓存系统视图。

## 操作步骤

单击 **<UI-TERM key="oms-community.Detail.components.FullMigration.MoreOperations">更多操作</UI-TERM>** > **<UI-TERM key="oms-community.pages.Endpoint.CacheSystemView">缓存系统视图</UI-TERM>**，

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.layout.constants.DataSourceManagement">数据源管理</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.pages.EndpointPublic.DataSources">数据源列表</UI-TERM>** 页面，单击 OceanBase 数据库 V3.x 目标数据源后的 **<UI-TERM key="oms-community.Migration.Detail.MoreOperations">更多操作</UI-TERM>** > **<UI-TERM key="oms-community.pages.Endpoint.CacheSystemView">缓存系统视图</UI-TERM>**。

    ![omsce1-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-ce/omsce1-zh.png)

4. 跳转至 **<UI-TERM key="oms-community.Migration.Detail.OMTicket">运维任务</UI-TERM>** 页面，等待运维任务完成，即缓存完成。
