# 新建 OceanBase-CE 数据源

配置好数据源是创建数据迁移或数据同步任务的前提。本文为您介绍如何在 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版中新建 OceanBase-CE 数据源。

## 前提条件

* 已获取相关数据库的 IP 地址和端口号。

* 已存在用于数据迁移或数据同步的数据库用户。

   建议您为数据迁移或数据同步任务创建一个专属的数据库用户，该用户必须具备相关的数据操作权限。详情请参见 [创建数据库用户](../300.create-a-database-user.md)。

## 操作步骤

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.pages.Endpoint.DataSourceManagement">数据源管理</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.pages.Endpoint.DataSources">数据源列表</UI-TERM>** 页面，单击右上角的 **<UI-TERM key="oms-community.EndpointPublic.Empty.AddADataSource">新建数据源</UI-TERM>**。

4. 在 **<UI-TERM key="oms-community.pages.EndpointPublic.AddADataSource">新建数据源</UI-TERM>** 对话框，配置各项参数。**<UI-TERM key="oms-community.EndpointPublic.components.form.TerminalType">数据源类型</UI-TERM>** 默认为 **OceanBase-CE**。

    |   参数    |    描述       |
   |-------------|-------------|
   | 数据源标识       | 建议使用中文、数字和字母的组合。名称中不能包含空格，长度不能超过 32 个字符。              |
   | 地域              | 从下拉列表中选择数据源所属的地域。 <br>**<UI-TERM key="oms-community.New.components.MigrationObjectForm.Small">注意</UI-TERM>**  <ul><li> 仅多地域场景下会显示该参数。   <li> 请确保数据源与地域的映射关系保持一致，否则可能导致迁移同步性能较差。  </ul>        |
   | 租户类型        | OceanBase 社区版租户的类型，目前仅支持 MySQL 租户。           |
   | 所属 OCP（可选）      | 从下拉列表中选择已关联的所属 OCP。<ul><li>请自行判断，当前数据源和所选 OCP 是否为被管理关系。<li>设置所属 OCP 是为了 OMS 社区版正常获取 OceanBase 社区版的增量日志，空置本选项会造成增量同步和反向增量选项无法被选择。</ul>如果列表中无目标 OCP，请单击 **<UI-TERM key="oms-community.components.OCPSelect.AddOcp">添加 OCP</UI-TERM>**，在 **<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.AddAnAssociatedOcp">添加关联 OCP</UI-TERM>** 中配置各项参数。详情请参见 [关联 OCP](../../1000.system-management/300.associate-with-ocp.md)。                           |
   | 输入方式        | 包括 **<UI-TERM key="oms-community.Endpoint.components.ObForm.ManualInput">手动输入</UI-TERM>** 和 **<UI-TERM key="oms-community.Endpoint.components.ObForm.CommandLineConnectionString">命令行连接串</UI-TERM>**。<ul><li>**<UI-TERM key="oms-community.Endpoint.components.ObForm.ManualInput">手动输入</UI-TERM>**：请手动输入 OceanBase 社区版的公网地址和端口。   <li>**<UI-TERM key="oms-community.Endpoint.components.ObForm.CommandLineConnectionString">命令行连接串</UI-TERM>**：请输入命令行连接串。    |
   | 主机 IP       | 数据库宿主机的 IP。      |
   | 端口          | 数据库宿主机 IP 的端口号。|
   | 租户名（可选）        | OceanBase 社区版租户的名称。<br>如果您需要创建的是社区版 OceanBase 数据源，则需要填写租户名。如果您需要创建的是公有云 OceanBase 数据源，则无需填写租户名。                                                 |
   | 集群名（可选）         | OceanBase 社区版租户所在集群的名称。                             |
   | Service Name（可选） | 服务名称，详情请参见 [SERVICE_NAME](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002016878)。|
   |  数据库用户名         | 用于数据迁移或数据同步的 OceanBase 社区版的用户名称。建议您为数据迁移任务创建单独的数据库用户。    |
   | 数据库密码          | 数据库用户的密码。     |
   | DB Name（可选）  | 数据库的名称。<br>**<UI-TERM key="oms-community.User.Personal.Description">说明</UI-TERM>**<br>如果您配置了 DB Name，当数据源作为源端时，数据迁移或数据同步任务仅支持选择指定 DB Name 下的迁移或同步对象。    |
   | 备注（可选）          | 数据源的备注信息。  |

5. （可选）在 **<UI-TERM key="oms-community.components.EndpointSelect.AddADataSource">新建数据源</UI-TERM>** 对话框，单击 **<UI-TERM key="oms-community.endpoints.ObForm.Senior.AdvancedOptions">高级选项</UI-TERM>** 右侧的 **<UI-TERM key="oms-community.components.Paragraph.EllipsisParagraph.Expand">展开</UI-TERM>**，根据业务需求配置相应参数。

   |参数|描述|
   |---|---|
   |DRC 用户用户名（可选）|该用户主要用于读取 OceanBase 社区版增量日志和数据库对象结构信息，请在业务集群 `sys` 租户下创建该用户。|
   |Configurl 或者 rootservice（可选）|Configurl 主要用于获取 OceanBase 社区版底层服务器的真实地址。<ul><li>如果您已选择 **<UI-TERM key="oms-community.Endpoint.components.ObForm.Ocp">所属 OCP</UI-TERM>**，OMS 社区版默认会从 OCP 获取 Configurl，该选项不显示。</li><li>如果您未选择 **<UI-TERM key="oms-community.Endpoint.constants.Ocp">所属 OCP</UI-TERM>**，可以填写 **<UI-TERM key="oms-community.EndpointPublic.components.ADBForm.UserName">用户名</UI-TERM>** 和 **<UI-TERM key="oms-community.Endpoint.components.DB2Form.Password">密码</UI-TERM>** 后，单击 Configurl 或者 rootservice 文本框右侧的 **在 OceanBase Server 中查询**，通过 OceanBase Server 获取 Configurl 或者 rootservice。<br>如果查询失败，则可以在 OceanBase 社区版 sys 租户下，执行 `show parameters like 'obconfig_url'` 命令，查询的值即 Configurl；执行 `show parameters like 'rootservice_list';` 命令，查询的值即 rootservice。</li></ul>|
   |密码（可选）|drc_user 用户对应的密码。|
   |__oceanbase_inner_drc_user 密码（可选）|该用户主要用于 OceanBase 数据库内无唯一键表的数据迁移。<br>**<UI-TERM key="oms-community.New.components.MigrationObjectForm.Small">注意</UI-TERM>**<br>您需要在当前数据源所在的租户下创建该用户。 |
   | 启用 SSL | 根据业务需求，选择是否启用 SSL。如果启用，可根据业务需求选择是否 **<UI-TERM>禁用主机名验证</UI-TERM>**，以及单击 **<UI-TERM>上传文件</UI-TERM>**，上传 **<UI-TERM>CA 证书</UI-TERM>**、**<UI-TERM>客户端证书</UI-TERM>** 和 **<UI-TERM>客户端密钥</UI-TERM>**。|

   * 创建以 OceanBase-CE 数据源为源端的数据迁移或数据同步任务时：

     * 结构迁移/结构同步、增量同步需要输入用户名和密码。如果您未选择 **<UI-TERM key="oms-community.Endpoint.components.ObForm.Ocp">所属 OCP</UI-TERM>**，还需要输入 Configurl 或者 rootservice。

     * 迁移无唯一键表时，需要输入 `_OCEANBASE_INNER_DRC_USER` 用户的密码。

   * 创建以 OceanBase-CE 数据源为目标端的数据迁移任务时，反向增量需要输入用户名和密码。如果您未选择 **<UI-TERM key="oms-community.Endpoint.constants.Ocp">所属 OCP</UI-TERM>**，还需要输入 Configurl 或者 rootservice。
  
6. 单击 **<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.TestConnection">测试连接</UI-TERM>**，验证 OMS 社区版和数据库的网络连接，以及用户名和密码的有效性。

7. 测试连接通过后，单击 **<UI-TERM key="oms-community.Migration.New.Determine">确定</UI-TERM>**。
