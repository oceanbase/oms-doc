# 新建 HBase 数据源

配置好数据源是创建数据迁移或数据同步任务的前提。本文为您介绍如何在 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版中新建 HBase 数据源。

## 前提条件

* 已获取下表中新建 HBase 数据源的必填配置项。

   | 参数  |  描述    |
   |--------------|--------------------|
   |hbase.zookeeper.quorum | zookeeper 链接。|
   |fs.default.name | HBase HDFS 配置，格式为 `hdfs://<ip>:<port>`。例如，`hdfs://xxx.xxx.xxx.1:29000`。|
   |zookeeper.znode.parent | HBase zookeeper path 配置。例如，`/hbase`。|
   |hbase.rootdir | HBase HDFS 根目录。例如，`hdfs://xxx.xxx.xxx.1:29000/habse`。|

* 如果 HBase 集群使用 Kerberos 进行安全认证，您需要在 OMS 社区版配置 Kerberos 后，再新建数据源。

   1. 登录 Kerberos 服务器，复制凭证至 OMS 社区版容器中。

      ```shell
      # root 用户的密码由用户进入 OMS 社区版容器使用 passwd 命令进行设置
      scp -P 2023  /etc/krb5.conf root@<OMS 社区版容器 IP>:/etc/

      #在用户配置环境需要注释掉 /etc/krb5.conf 中的 renew_lifetime = 60480
      ```

   2. 复制 Kerberos keytab 文件至 OMS 社区版容器的目录下，并设置权限。例如，存放路径为 `/home/ds/`。

      ```shell
      #keytab 文件中需要包含 oms.kerberos.principal 配置项配置的用户
      scp -P 2023 xxx.keytab root@<OMS 社区版容器 IP>:/home/ds/
      chmod 777 /home/ds/xxx.keytab
      ```

   3. 进入 OMS 社区版容器，执行以下命令，重新启动 Console 组件。

      ```bash
      supervisorctl restart oms_console
      ```

## 操作步骤

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **数据源管理**。

3. 在 **数据源管理** 页面，单击右上角的 **新建数据源**。

4. 在 **新建数据源** 对话框，选择 **数据源类型** 为 **HBase**。

5. 配置各项参数。

   |   **参数**    |                     **描述**                |
   |-------------|--------------------------------------------------------|
   | 数据源标识       | 建议使用中文、数字和字母的组合。名称中不能包含空格，长度不能超过 32 个字符。 <main id="notice" type='notice'><h4>注意</h4><p>数据源标识在 OMS 社区版系统内全局唯一。</p></main>                                                                                                                                                                                                                                                                                |
   | 地域          | 从下拉列表中选择数据源所属的地域（即部署 OMS 社区版时配置的 `cm_region` 参数）。<main id="notice" type='notice'><h4>注意</h4><ul><li> 仅多地域场景下会显示该参数。   <li>请确保数据源与地域的映射关系保持一致，否则可能导致迁移同步性能较差。    </ul> </main>                                                                                                                  |
   | 数据库属性       | 默认显示必填的配置参数，请参见《前提条件》的参数描述。如果还有其它需要添加的参数，您可以单击 **添加** 进行配置。kerberos 认证相关的参数请参见表格下方的说明。 |
   | 配置文件（可选）       |  HBase 集群的配置文件 `hbase-site.xml`。        |
   | 备注（可选）      | 数据源的备注信息。       |

   如果您选择的 HBase 数据库已配置 Kerberos 认证，请在 **数据库属性** 区域添加以下参数。

   | 参数  |  描述 |
   |---------------|---------------|
   | hbase.security.authentication | 此处配置为 `kerberos`，表示 HBase 集群将使用 Kerberos 进行安全认证。  |
   | hadoop.security.authentication | 此处配置为 `kerberos`，表示要求 Hadoop 相关服务也使用 Kerberos 进行安全认证。|
   | hbase.master.kerberos.principal | 表示 HBase 主节点（HMaster）的 Kerberos principal 名称，格式为 `primary/instance@REALM`。<ul><li>primary 表示服务名，例如 `hbase`。</li><li>instance 可以配置为主机 IP（例如 `xxx.xxx.xxx.1`），也可以配置为 `_HOST`（表示动态替换主机 IP）。</li><li>REALM 表示 Kerberos 领域，例如 `EXAMPLE.COM`。</li></ul> |
   | hbase.regionserver.kerberos.principal | 表示 HBase 区域服务器（RegionServer）的 Kerberos principal 名称，格式为 `primary/instance@REALM`。 |
   | oms.kerberos.principal | 用于 OMS 社区版连接。如果不填该参数，则使用 `hbase.master.kerberos.principal` 和 `hbase.regionserver.kerberos.principal` 的配置。 |
   | oms.kerberos.keytab.file |表示 Kerberos keytab 文件在 OMS 社区版容器中的目录位置，例如 `/home/ds/xxx.keytab`。 <br>如果数据迁移任务运行选择了 Flink，则该文件需要在 Flink 服务器上存放于相同位置。|

6. 单击 **测试连接**，验证 OMS 社区版和数据库的网络连接。

7. 测试连接通过后，单击 **确定**。
