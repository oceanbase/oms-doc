# 新建 MongoDB 数据源

配置好数据源是创建数据迁移任务的前提。本文为您介绍如何在 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版新建 MongoDB 数据源。

## 操作步骤

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.layout.constants.DataSourceManagement">数据源管理</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.pages.Endpoint.DataSourceManagement">数据源管理</UI-TERM>** 页面，单击右上角的 **<UI-TERM key="oms-community.pages.Endpoint.AddADataSource">新建数据源</UI-TERM>**。

4. 在 **<UI-TERM key="oms-community.pages.Endpoint.AddADataSource">新建数据源</UI-TERM>** 对话框，选择 **<UI-TERM key="oms-community.Endpoint.constants.DataSourceType">数据源类型</UI-TERM>** 为 **MongoDB**。

5. 配置各项参数。

    | 参数   |   描述  |
    |------------|-------------|
    | 数据源标识          | 建议使用中文、数字和字母的组合。名称中不能包含空格，长度不能超过 32 个字符。 <main id="notice" type='notice'><h4>注意</h4><p>数据源标识在 OMS 社区版系统内全局唯一。</p></main>         |
    | 地域             | 从下拉列表中选择数据源所属的地域（即部署 OMS 社区版时配置的 `cm_region` 参数）。 <main id="notice" type='notice'><h4>注意</h4><ul><li> 仅多地域场景下会显示该参数。   <li>请确保数据源与地域的映射关系保持一致，否则可能导致迁移同步性能较差。    </ul> </main>        |
    | MongoDB Address | MongoDB 数据库的地址，格式为 `IP 地址:端口号`。<br>MongoDB 数据源支持配置多个地址的信息，地址之间使用英文逗号（,）分隔。例如，`xxx.xxx.xxx.1:2883,xxx.xxx.xxx.2:2883`。  |
    | 数据库用户名（可选） | 用于数据迁移的数据库用户名称。|
    | 数据库密码（可选）| 用于数据迁移的数据库用户的密码。|
    | 认证数据库（可选）| 用户所属的数据库。|
    | 数据库属性/值 | 根据实际情况添加数据库属性及属性值。当 MongoDB 数据源开启了 TLS 时，您必须添加相应的配置项，详情请参见《MongoDB 数据源开启 TLS 的配置》模块的文档。|
    | 备注（可选） | 数据源的备注信息。|

6. 单击 **<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.TestConnection">测试连接</UI-TERM>**，验证 OMS 社区版和数据库的网络连接，以及用户名和密码的有效性。

7. 测试连接通过后，单击 **<UI-TERM key="oms-community.components.SyncSwitch.ConfirmStopSourceApp.Determine">确定</UI-TERM>**。

## MongoDB 数据源开启 TLS 的配置

如果 MongoDB 数据源开启了 TLS，您需要上传 CA 文件和客户端证书密钥文件至 OMS 社区版容器后，再新建数据源配置相关参数。

1. 登录部署 OMS 社区版的宿主机，复制 CA 文件和客户端证书密钥文件至 OMS 社区版容器中。

    ```shell
    # 进入 OMS 社区版容器，创建存放证书文件的目录
    sudo docker exec -it <OMS 社区版容器 ID> bash
    mkdir -p /home/ds/tls

    # 从宿主机复制 CA 文件到 OMS 社区版容器
    sudo docker cp /path/to/ca.crt <OMS 社区版容器 ID>:/home/ds/tls/

    # 从宿主机复制客户端证书文件到 OMS 社区版容器
    sudo docker cp /path/to/client.p12 <OMS 社区版容器 ID>:/home/ds/tls/client.p12

    # 进入 OMS 社区版容器，设置文件权限
    sudo docker exec -it <OMS 社区版容器 ID> bash
    chmod 777 /home/ds/tls/ca.crt
    chmod 777 /home/ds/tls/client.p12
    ```

2. 新建 MongoDB 数据源，添加下述数据库属性和值。

    | 数据库属性 | 值   |  描述 |
    |-------------|-------------|------------|
    | tlsCAFile | STRING | 表示 CA 文件在 OMS 社区版容器中的路径。|
    | tlsCertificateKeyFile |  STRING | 表示包含客户端证书和私钥的 PKCS#12 容器文件在 OMS 社区版容器中的路径。|
    | tlsCertificateKeyFilePassword | STRING | 表示客户端证书密钥文件的密码。如果客户端证书密钥文件已加密，则需要填写该参数。|
    | tlsAllowInvalidHostnames | BOOLEAN | 表示是否禁用 TLS 证书中的主机名验证。|
    | authenticationMechanism | STRING | 表示 MongoDB 数据源的身份验证机制。如果启用了 x509 认证，则需要填写 `MONGODB-X509`。|
