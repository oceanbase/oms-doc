# 新建 Hive 数据源

配置好数据源是创建数据迁移或数据同步任务的前提。本文为您介绍如何在 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版中新建 Hive 数据源。

## 前提条件

* 已获取相关数据库的 IP 地址和端口号。

* 已存在用于数据迁移的数据库用户。

  建议您为数据迁移任务创建一个专属的数据库用户，该用户必须具备相关的数据操作权限。详情请参见 [创建数据库用户](../300.create-a-database-user.md)。

## 操作步骤

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.DataSourceManagement">数据源管理</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.pages.Endpoint.DataSourceManagement">数据源管理</UI-TERM>** 页面，单击右上角的 **<UI-TERM key="oms-community.components.EndpointSelect.AddADataSource">新建数据源</UI-TERM>**。

4. 在 **<UI-TERM key="oms-community.pages.EndpointPublic.AddADataSource">新建数据源</UI-TERM>** 对话框，选择 **<UI-TERM key="oms-community.pages.EndpointPublic.DataSourceType">数据源类型</UI-TERM>** 为 **Hive**。

5. 配置各项参数。

   |   **参数**    |                **<UI-TERM key="oms-community.pages.SystemParam.Description">描述</UI-TERM>**                      |
   |-------------|--------------------------------------|
   | 数据源标识       | 建议使用中文、数字和字母的组合。名称中不能包含空格，长度不能超过 32 个字符。<main id="notice" type='notice'><h4>注意</h4><p>数据源标识在 OMS 社区版系统内全局唯一。</p></main>                                                                                                                                                                                                                                                                                            |
   | 地域          | 从下拉列表中选择数据源所属的地域即部署 OMS 社区版时配置的 `cm_region` 参数）。<main id="notice" type='notice'><h4>注意</h4><ul><li> 仅多地域场景下会显示该参数。   <li>请确保数据源与地域的映射关系保持一致，否则可能导致迁移同步性能较差。    </ul> </main>                                                                                                               |
   | 主机 IP       | 数据库宿主机的 IP。  |
   | 端口          | 数据库宿主机 IP 的端口号，默认值为 10000。           |
   | 数据库用户名       | 用于数据迁移或数据同步的 Hive 数据库的用户名称。                                                                                                                                                                                                                                                                                                                             |
   | 数据库密码（可选）          | 数据库用户的密码。                                                                                                                                                                                                                                                                                                    |
   | thrift 主机（可选） | Thrift 主机的地址。<ol><li>Metastore 启动元数据服务，提供 Thrift 协议链接服务 <p>```shell nohup bin/hive --service metastore > 1.log &```<li>启动元数据服务 HiveServer2 ，提供 JDBC 协议链接服务 <p>```shell nohup bin/hive --service hiveserver2 > 2.log&```</ol>|
   | thrift 端口（可选） | Thrift 主机的端口号，默认值为 9083。|
   | 备注（可选）      | 数据源的备注信息。                  |

6. 单击 **<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.TestConnection">测试连接</UI-TERM>**，验证 OMS 社区版和数据库的网络连接，以及用户名和密码的有效性。

7. 测试连接通过后，单击 **<UI-TERM key="oms-community.components.SyncSwitch.ConfirmStopSourceApp.Determine">确定</UI-TERM>**。
