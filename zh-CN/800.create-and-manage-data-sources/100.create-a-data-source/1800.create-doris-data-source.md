# 新建 Doris 数据源

配置好数据源是新建数据迁移任务的前提。本文为您介绍如何在 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版新建 Doris 数据源。

## 操作步骤

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.layout.constants.DataSourceManagement">数据源管理</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.pages.Endpoint.DataSourceManagement">数据源管理</UI-TERM>** 页面，单击右上角的 **<UI-TERM key="oms-community.pages.Endpoint.AddADataSource">新建数据源</UI-TERM>**。

4. 在 **<UI-TERM key="oms-community.pages.Endpoint.AddADataSource">新建数据源</UI-TERM>** 对话框，选择 **<UI-TERM key="oms-community.Endpoint.constants.DataSourceType">数据源类型</UI-TERM>** 为 **Doris**。

5. 配置各项参数。

    |   参数   |   描述   |
    |------------|--------------|
    | 数据源标识 | 建议使用中文、数字和字母的组合。名称中不能包含空格，长度不能超过 32 个字符。 <main id="notice" type='notice'><h4>注意</h4><p>数据源标识在 OMS 社区版系统内全局唯一。</p></main>         |
    | 地域  | 从下拉列表中选择数据源所属的地域（即部署 OMS 社区版时配置的 `cm_region` 参数）。 <main id="notice" type='notice'><h4>注意</h4><ul><li> 仅多地域场景下会显示该参数。   <li>请确保数据源与地域的映射关系保持一致，否则可能导致迁移同步性能较差。    </ul> </main>        |
    | 主机 IP | 数据库宿主机的 IP。|
    | 端口    | 数据库宿主机 IP 的端口号。|
    | 数据库用户名 | 用于数据迁移或数据同步的 Doris 数据库的用户名称。|
    | 数据库密码（可选） | 数据库用户的密码。|
    | DB Name（可选）| Doris 数据库的名称。<main id="notice" type='explain'><h4>说明</h4><p>如果您配置了 DB Name，当数据源作为源端时，数据迁移或数据同步任务仅支持选择指定 DB Name 下的迁移或同步对象。</p></main>   |
    | 备注（可选）| 数据源的备注信息。|

6. 单击 **<UI-TERM key="oms-community.Endpoint.New.TestConnection">测试连接</UI-TERM>**，验证 OMS 社区版和数据库的网络连接，以及用户名和密码的有效性。

7. 测试连接通过后，单击 **<UI-TERM key="oms-community.Detail.components.StructSync.Determine">确定</UI-TERM>**。
