# oms_host_threshold OMS 社区版机器阈值告警

## 对系统的影响

该告警可能影响部分项目的创建，以及其运行性能。

## 可能原因

CPU、内存或磁盘阈值过高。

目前 OMS 社区版对 CPU、内存和磁盘阈值的限制如下。

| 分类 | 描述   |  默认值  |
|-------|-----------|-------|
| `drcCfg.cpuUsedPercentThresHold` | OMS 社区版机器 CPU 百分比阈值上限。当已使用 CPU 超出机器 CPU 参数值的百分比时，会禁止再创建项目。 | 0.85 |
| `drcCfg.memUsedPercentThresHold`| OMS 社区版机器内存百分比阈值上限。当已使用内存超出机器内存参数值的百分比时，会禁止再创建项目。| 0.80 |
|`drcCfg.diskUsedPercentThresHold`|OMS 社区版机器磁盘百分比阈值上限。当已使用磁盘超出机器磁盘参数值的百分比时，会禁止再创建项目。| 0.90 |

## 处理方法

降低机器负载，释放不需要的迁移或者同步项目。您也可以进行 OMS 社区版集群扩容。

调整 CPU、内存和磁盘阈值的方法如下：

1. 登录 OMS 社区版容器。

    ```shell
    docker exec -it ${CONTAINER_NAME} bash
    ```

   <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><code>CONTAINER_NAME</code> 为创建容器的名称。</p>
   </main>

2. 在 `/home/admin/conf/cm/drc-cm.properties` 中添加 `drcCfg.cpuUsedPercentThresHold`（默认为 0.85）、`drcCfg.memUsedPercentThresHold`（默认为 0.80）和 `drcCfg.diskUsedPercentThresHold`（默认值为 0.90），根据业务需求设置阈值。

3. 重新启动 OMS 社区版的 oms_drc_cm 服务。

    ```shell
    supervisorctl restart oms_drc_cm
    ```
