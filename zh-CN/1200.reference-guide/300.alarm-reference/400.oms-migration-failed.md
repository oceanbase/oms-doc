# oms_migration_failed 迁移任务失败

## 可能原因

您需要进入迁移任务页面，查看具体的报错原因。

## 处理方法

* 通过查看当前任务的报错日志，以及查看组件监控识别具体状态异常组件，并查看相关日志等方式进行具体分析。

  如果是偶然现象，您可以单击 **<UI-TERM key="oms-community.Operation.constants.Recovery">恢复</UI-TERM>** 按钮进行重试。
  
* 您也可以同步告警信息至 OMS 社区版的技术服务人员，由我们的技术服务人员为您处理。
