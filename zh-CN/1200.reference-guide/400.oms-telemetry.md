# Telemetry 参数说明

OceanBase 迁移服务（OceanBase Migration Service，OMS）支持 Telemetry（遥测），本文为您介绍 Telemetry 采集数据的具体内容。

Telemetry 上报的内容如下：

```JSON
{
  "id": "OMS_UUID", 
  "reporter":"OMS",
  "reportTime":1676358401,
  "version":"4.2.3-CE",
  "regions":
  [
    {  
      "id":1,
      "nodes":1 
 }
  ],
  "projects":{
      "count":10,
      "RUNNING":6, 
      "FAILED":0,  
      "FINISHED":4,
      "switch2ob": 4, 
      "mysql2ob":10, 
      "ob2mysql":0
      ...
  }
}
```

| 参数  |  描述 |
|---------------|-----------------|
| id  |  OMS 社区版集群的 ID，部署时生成。|
| reporter |  上报者。 |
| reportTime | 上报的时间。|
| version | 当前 OMS 社区版的版本。|
| regions | OMS 社区版的地域信息。|
|  ├─ id  | 部署 OMS 社区版时的地域数字 ID。|
|  ├─ nodes | 当前地域的节点数量。|
| projects |  任务信息。|
|  ├─ count |  任务的总数量。 |
|  ├─ RUNNING | 运行中的任务数量。  |
|  ├─ FAILED  | 失败的任务数量。 |
|  ├─ FINISHED | 已完成的任务数量。  |
|  ├─ switch2ob | 完成切换至 OceanBase 社区版的任务数量。 |
|  ├─ mysql2ob  | 源端 MySQL 数据库至目标端 OceanBase 社区版的任务数量。   |
|  ├─ ob2mysql  | 源端 OceanBase 社区版至目标端 MySQL 数据库的任务数量。|
|  ...          | 参数格式为“源端2目标端”，您可以根据实际情况配置各种数据库类型，以统计源端至目标端的任务数量。|
