# 创建 Kafka 数据源

本文为您介绍 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版提供的 OpenAPI：创建 Kafka 数据源 CreateKafkaDataSource。

## 功能说明

本接口用于创还能 Kafka 数据源。

## 调用说明

### 接口约束

本接口适用于 OMS 社区版 V4.2.12-CE 及之后版本。

### 请求路径

`POST /api/v2?Action=CreateKafkaDataSource`

### 请求参数

|      参数    |    类型   |  描述  |
|---------------|-----------------|----------------|
| name  | string | 数据源标识。建议使用中文、数字和字母的组合，名称中不能包含空格，长度不能超过 32 个字符。|
| region | string | 数据源所属的地域。|
| description | string | 数据源的备注信息，不能超过 128 个字符。|
| endpoint | string | Kafka 数据源的地址，格式为 `kafka ip:port` 或者 `kafka ip:port,kafka ip:port,kafka ip:port`。|
| enableSSL | boolean | 是否启用 SSL。|
| certSSLId |string | 授信证书文件 ID。您可以通过上传文件 API 上传并获取文件 ID。|
| enableSASL | boolean | 是否开启认证。|
| saslMechanism | string | 认证方式，支持 GSSAPI、PLAIN、SCRAM_SHA_256 和 SCRAM_SHA_512。|
| username | string | 用户名。如果认证方式为 PLAIN、SCRAM_SHA_256 或 SCRAM_SHA_512，则需要提供该参数。|
| password | string | 密码。如果认证方式为 PLAIN、SCRAM_SHA_256 或 SCRAM_SHA_512，则需要提供该参数。|
| kdcPath | string | KDC 服务器地址。如果认证方式为 GSSAPI，则需要提供该参数。|
| saslKerberosPrincipal | string | 用户主体。如果认证方式为 GSSAPI，则需要提供该参数。|
| serviceName | string | Kafka 服务端的配置 `sasl.kerberos.service.name`，即 Kerberos 中配置的 Kafka 服务主体名称。如果认证方式为 GSSAPI，则需要提供该参数。|
| certSASLId | string | keytab 文件 ID。您可以通过上传文件 API 上传并获取文件 ID。|

### 返回结果

|     参数     |        类型        |           描述           |
|------------|------------------|------------------------|
| success    | boolean          | 是否调用成功。                |
| errorDetail | object | 错误详情。|
| code       | string           | 错误码。                   |
| message    | string           | 描述信息。                  |
| advice     | string           | 建议。                    |
| requestId  | string           | 请求 ID。                 |
| pageNumber | integer | 页序号，分页查询时生效。                  |
| pageSize   | integer | 页大小，分页查询时生效。                  |
| totalCount | integer | 总数，分页查询时生效。                  |
| cost       | string           | 请求耗时，单位为秒。                  |
| data       | string           | Kafka 数据源的 ID。 |
