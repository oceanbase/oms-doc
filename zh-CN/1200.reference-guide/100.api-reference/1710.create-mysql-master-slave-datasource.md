# 创建 MySQL 数据源（支持主备库）

本文为您介绍 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版提供的 OpenAPI：创建支持主备库的 MySQL 数据源 CreateMySQLMasterSlaveDataSource。

## 功能说明

本接口用于创建支持主库和备库等数据库类型的 MySQL 数据源。

## 调用说明

### 接口约束

本接口适用于 OMS 社区版 V4.2.4-CE 及之后版本。

### 请求路径

`POST /api/v2?Action=CreateMySQLMasterSlaveDataSource`

### 请求参数

|     参数     |        类型        |           描述           |
|------------|------------------|------------------------|
| master  |  object  |  MySQL 主库的数据源信息。|
|   ├─ name    | string          | 数据源标识。建议使用中文、数字和字母的组合。名称中不能包含空格，长度不能超过 32 个字符。<br>请注意主库和备库的 `name` 需要保持一致。                |
|   ├─ ip | string | 数据库宿主机的 IP。 |
|   ├─ port       | integer           | 数据库宿主机 IP 的端口号。                |
|   ├─ schema    | string           | 数据库的名称。填写后，仅对该数据库进行数据迁移或数据同步。   |
|   ├─ username     | string           | 用于数据迁移或数据同步的数据库用户的名称。               |
|   ├─ password  | string           | 数据库用户的密码，需要使用 Base64 编码。               |
|   ├─ tryKeepHb | boolean | 增量同步时，是否允许 OMS 自动向该实例写入心跳数据，以解决源端在无业务写入场景下的高延时问题。                  |
|   ├─ region   | string | 数据源所属的地域。                  |
|   ├─ description | string | 数据源的备注信息，不能超过 128 个字符。                |
|   ├─ role  | string | 用于区分数据库的类型，包括主库和备库。此处为固定值：`MASTER`。|
| slave |  object  | MySQL 备库的数据源信息。|
|   ├─ name    | string          | 数据源标识。建议使用中文、数字和字母的组合。名称中不能包含空格，长度不能超过 32 个字符。<br>请注意主库和备库的 `name` 需要保持一致。                |
|   ├─ ip | string | 数据库宿主机的 IP。 |
|   ├─ port       | integer           | 数据库宿主机 IP 的端口号。                |
|   ├─ schema    | string           | 数据库的名称。填写后，仅对该数据库进行数据迁移或数据同步。   |
|   ├─ username     | string           | 用于数据迁移或数据同步的数据库用户的名称。               |
|   ├─ password  | string           | 数据库用户的密码，需要使用 Base64 编码。               |
|   ├─ tryKeepHb | boolean | 增量同步时，是否允许 OMS 自动向该实例写入心跳数据，以解决源端在无业务写入场景下的高延时问题。                  |
|   ├─ region   | string | 数据源所属的地域。                  |
|   ├─ description | string | 数据源的备注信息，不能超过 128 个字符。                |
|   ├─ role  | string | 用于区分数据库的类型，包括主库和备库。此处为固定值：`SLAVE`。|

### 返回结果

|     参数     |        类型        |           描述           |
|------------|------------------|------------------------|
| success    | boolean          | 是否调用成功。                |
| errorDetail | object | 错误详情。|
| code       | string           | 错误码。                   |
| message    | string           | 描述信息。                  |
| advice     | string           | 建议。                    |
| requestId  | string           | 请求 ID。                 |
| pageNumber | integer | 页序号，分页查询时生效。                  |
| pageSize   | integer | 页大小，分页查询时生效。                  |
| totalCount | integer | 总数，分页查询时生效。                  |
| cost       | string           | 请求耗时，单位为秒。                  |
| data       | List<string>           | MySQL 数据源主备库 ID 的集合。 |
