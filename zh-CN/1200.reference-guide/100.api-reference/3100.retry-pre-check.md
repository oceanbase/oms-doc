# 重试预检查

本文为您介绍 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版提供的 OpenAPI：重试预检查 RetryPreCheck。

## 功能说明

本接口用于重试预检查。

## 调用说明

### 接口约束

本接口适用于 OMS 社区版 V4.2.12-CE 及之后版本。

### 请求路径

`POST /api/v2?Action=RetryPreCheck`

### 请求参数

|  参数 | 类型  | 描述 |
|-----------|------------|-----------|
| id  | string |  预检查任务的 ID。|
| skippedPreChecks| array| 需要跳过的预检查项。|
|  ├─ endpointType |string |预检查端点，包括 `SOURCE`（源端）/DEST（目标端）。|
|  ├─ checkType |string| 预检查任务的类型。|

### 返回结果

| 参数 |  类型 | 描述 |
|--------------|------------|------------|
| success | boolean | 是否调用成功。|
| errorDetail | object | 错误详情。|
| code | string | 错误码。|
| message | string | 描述信息。|
| advice | string | 建议。|
| requestId | string | 请求 ID。|
| pageNumber|  integer | 页序号，分页查询时生效。|
| pageSize | integer | 页大小，分页查询时生效。|
| totalCount | integer|  总数，分页查询时生效。|
| cost | string | 请求耗时，单位为秒。|
| data | string | 预检查任务的 ID。|

## 示例

### 请求示例

```JSON
{
    "id": "t_7di****",
    "skippedPreChecks": [
        {
            "endpointType": "DEST",
            "checkType": "RDB_TABLE_EXIST"
        }
    ]
}
```

### 返回示例

```JSON
{
    "success": true,
    "errorDetail": null,
    "code": null,
    "message": null,
    "advice": null,
    "requestId": "1af9fc****",
    "pageNumber": null,
    "pageSize": null,
    "totalCount": null,
    "cost": "111 ms",
    "data": "t_7d****"
}
```
