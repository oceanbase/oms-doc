# 查询预检查详情

本文为您介绍 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版提供的 OpenAPI：查询预检查详情 GetPreCheckResult。

## 功能说明

本接口用于查询预检查详情。

## 调用说明

### 接口约束

本接口适用于 OMS 社区版 V4.2.12-CE 及之后版本。

### 请求路径

`POST /api/v2?Action=GetPreCheckResult`

### 请求参数

|   参数 |   类型  | 描述 |
|------------|--------------|-----------|
|  id  | string | 预检查任务的 ID。|

### 返回结果

|  参数 | 类型 | 描述 |
|----------------|-------------|-------------|
| success | boolean | 是否调用成功。|
| errorDetail | object | 错误详情。|
| code | string | 错误码。|
| message | string | 描述信息。|
| advice | string | 建议。|
| requestId | string | 请求 ID。|
| pageNumber | integer | 页序号，分页查询时生效。|
| pageSize | integer | 页大小，分页查询时生效。|
| totalCount|  integer | 总数，分页查询时生效。|
| cost | string | 请求耗时，单位为秒。|
| data | object | 预检查的相关信息，具体包含的信息请参见《data 数据结构》。|

* data 数据结构

    |  参数 |  类型|   描述|  
    |----------------|-------------|-------------|
    |  preCheckId |  string |  预检查 ID|  
    |  preCheckStatus |  string |  预检查任务的状态，包括 `INIT`（初始化）、`PENDING`（未启动）、`RUNNING`（运行中）、`FAILED`（失败）和 `FINISHED`（已完成）。|
    |  progress |  double|   预检查任务的进度。 |
    |  preCheckResults |  array|   预检查任务列表。|
    |   ├─ name |  string |  预检查名称。|
    |   ├─ endpointType|   string |  预检查端点，包括 `SOURCE`（源端）/DEST（目标端）。|
    |   ├─ checkType|   string |  预检查任务的类型。|
    |   ├─ status |  string |  预检查任务的状态，包括 `PENDING`（未启动）、`RUNNING`（运行中）、`FAILED`（预检查任务执行期间由于各种异常导致失败）、`WARNING`（预检查任务执行成功但不通过，仅以警告形式提示）和 `PASSED`（预检查任务执行成功且通过）。|
