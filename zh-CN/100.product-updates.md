# 产品动态

本文为您介绍 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版 V4.2.11-CE 的功能。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>目前仅支持 OMS 社区版 V4.2.0-CE ~ V4.2.10-CE 升级至 V4.2.11-CE，不支持 V4.2.0-CE 之前版本升级至 V4.2.11-CE。</p>
</main>

## 新增功能

* 支持适配 OceanBase 社区版 V4.4.1。

* 支持迁移 StarRocks 数据库的全量数据至 OceanBase 社区版。

* 支持迁移 PostgreSQL 数据库 V17.x 的数据至 OceanBase 数据库。

* 支持 OMS k8s 环境下的部署。

* 适配统信系统 uos v20。

* 支持通配增量场景增加通配 DB 功能。本功能通过在 Store 和增量组件白名单中添加新增的通配 DB 实现支持正向切换时反向增量开始位点的选择功能。

* 支持正向切换时反向增量开始位点的选择功能，默认反向增量组件启动时间作为开始位点，用户也可选择反向 Store 启动时间作为反向增量组件的启动位点。

* 支持迁移 TiDB 数据库的数据至 OceanBase 社区版时的记录过滤功能。

* 支持 Store 数据保留时间提醒功能。当增量 Store 数据保留周期小于全量预计完成时间，任务显示告警提示增加 Store 数据保留时间。

* 支持 MongoDB 数据源 x509 认证。

* 支持迁移 Qdrant 数据源中的多个向量字段。

## 易用性提升

* OMS 支持不停任务的热更升级模式。

* OMS 多节点场景组件节点选择算法支持随机、磁盘空间、内存、CPU。

* 支持全量校验指定用于 JOIN 的字段，解决源端表和目标表主键、唯一建不相同的场景。

* 数据同步任务通配场景优化任务同步对象展示。

* 优化组件黑白名单配置功能。

* 支持 Postgres 自定义类型数据迁移。

* 进行 OceanBase 社区版之间的数据迁移时，自动屏蔽 __CTAS 内部表避免发生异常问题。
