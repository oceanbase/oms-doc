# 产品动态

本文为您介绍 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版 V4.2.10-CE 的功能。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>目前仅支持 OMS 社区版 V4.2.0-CE ~ V4.2.9-CE 升级至 V4.2.10-CE，不支持 V4.2.0-CE 之前版本升级至 V4.2.10-CE。</p>
</main>

## 新增功能

* 支持 OceanBase 社区版至 ElasticSearch 的结构迁移、全量迁移和增量同步。

* 迁移 Milvus 的数据至 OceanBase 社区版时，新增支持结构迁移和增量同步。

* 支持迁移 HBase 的 TTL 信息至 OBKV。

* 支持迁移 OceanBase 社区版的表 TTL 信息的结构迁移。

* 支持迁移 MongoDB 的全量数据至 OceanBase 社区版。

* 支持迁移 MariaDB V10.2 ~ V10.6.x 的数据至 OceanBase 社区版。

## 易用性提升

* 组件监控页面支持状态筛选。

* 数据同步 Canal 序列化方式支持 dateConvertFormat 配置时间类型输出格式。

* OMS 社区版释放任务时，清理任务所有组件目录。

* 迁移 TiDB 数据库的数据至 OceanBase 社区版时，增加 PROCESS 权限的预检查。

* 迁移 PostgreSQL 数据库的数据至 OceanBase 社区版时，增加迁移用户只读权限的预检查。

* Kafka GSSAPI 鉴权增加 serviceName 配置项。
