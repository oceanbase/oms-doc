# 产品动态

本文为您介绍 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版 V4.2.4-CE 的功能。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>目前仅支持 OMS 社区版 V4.2.3-CE 升级至 V4.2.4-CE，不支持 V4.2.3-CE 之前版本升级至 V4.2.4-CE。</p>
</main>

## 新增功能

* 迁移 OBKV 的增量数据至 HBase。

* 迁移 HBase 的数据至 OBKV 时，新增支持反向增量。

* 支持迁移 Kerberos 认证的 HBase 集群数据至 OBKV。

* 旁路写入支持多表汇聚场景。

* 全量校验新增两项功能

  * 新增支持字段不一致的校验场景，您可以通过配置来决定仅校验匹配字段。

  * 新增字段排除功能。您可以指定字段不参与校验，提高校验速度。例如，排除 LOB 类型的字段。

* 结构迁移新增支持 OceanBase 社区版至 OceanBase 社区版无主键表的视图。

* 新增创建 MySQL 主备库数据源的 API。
  
## 易用性提升

* OceanBase 社区版作为中间库时，提供自动检测功能，您可以自主选择是否需要过滤 OMS 写入的数据。

* OMS 社区版的安装系统支持 cgroup2 的适配。

* 增量同步阶段 DDL 在 OceanBase 社区版中可以配置并发执行。

  * 通过配置并发数来提高增量 DDL 执行速度。

  * 支持 session 阶段可以设置的数据库变量。

* 结构迁移新增 SQL 导出功能，您可以导出全部对象的结构信息保存至本地。
