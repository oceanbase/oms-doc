# 产品动态

本文为您介绍 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版 V4.2.9-CE 的功能。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>目前仅支持 OMS 社区版 V4.2.0-CE ~ V4.2.8-CE 升级至 V4.2.9-CE，不支持 V4.2.0-CE 之前版本升级至 V4.2.9-CE。</p>
</main>

## 新增功能

* 支持迁移 Elasticsearch 数据库的数据至 OceanBase 社区版。

* 支持迁移 PostgreSQL 数据库中向量和数组类型的数据至 OceanBase 社区版。

* 支持迁移 TiDB V8.x 的数据至 OceanBase 社区版。

* 支持迁移 Milvus 数据库的动态列至 OceanBase 社区版。

* 支持迁移 Hive V2.1.1 的数据至 OceanBase 社区版。

* OceanBase 社区版至 Kafka 的数据同步任务支持发送保序心跳数据，下游消费 Kafaka 数据可以依据心跳数据中的时间来判断某个时间点的数据是否全部消费完成。

* 支持 OceanBase 社区版 STRING 类型数据的迁移。

* 支持 OceanBase 数据源 service_name 配置方式。

* 支持 Kafka 数据源多个主机端口配置。

## 易用性提升

* 同步 OceanBase 社区版的数据至 Kafka 时，支持表名通配方式映射 Topic 的配置。

* 支持 OceanBase 数据源的数据库版本自动刷新，解决 OceanBase 数据库版本升级后，OMS 中的版本因未更新导致 OMS 增量同步使用错误 CDC 版本的问题。

* 优化 TiDB TICDC 模式下，表 UK 多个字段的 OMS 性能问题。

* 优化 OMS 修改组件参数功能页面。
