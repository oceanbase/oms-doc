# 产品动态

本文为您介绍 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版 V4.2.14-CE 的功能。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>目前仅支持 OMS 社区版 V4.2.0-CE ~ V4.2.13-CE 升级至 V4.2.14-CE，V4.2.0-CE 之前的版本不支持升级至 V4.2.14-CE。</p>
</main>

## 新增功能

* 支持 OceanBase 社区版 V4.6.0 数据迁移同步

* Elasticsearch 迁移 OceanBase 链路

  * 支持 Elasticsearch 结构迁移 OceanBase 社区版。
  * 支持 Elasticsearch 9.x 迁移。
  * 支持 Elasticsearch 迁移 OceanBase 全量校验功能。

* MongoDB 迁移 OceanBase 链路

  * 支持MongoDB迁移OceanBase的全量校验功能。
  * 支持MongoDB创建迁移链路时指定排查指定字段不迁移。

* TiDB 迁移 OceanBase 链路  

  * 支持 TiDB 的增量 TiCDC 的 Canal-Json 格式。

* 支持 MySQL 8.4 迁移 OceanBase 社区版。

* 迁移链路支持 OceanBase 增量 store 共享功能。

## 易用性提升

* HA 节点调度优化。

* 链路异常告警优化。

* OMS 部署脚本 python2 升级 python3 支持元数据库开启 TLSv1.3。

* 支持 API 创建 TiDB 数据源功能。

* 支持修改数据源密码功能。

* 支持空数据库同步 kakfa 功能。

* 支持 OceanBase 同步 kafka 无增量数据场景心跳保持功能。

* ClickHouse 分区表全量迁移优化。

* API CreateProject 支持 sink 参数设置。
