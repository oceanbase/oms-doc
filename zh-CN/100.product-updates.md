# 产品动态

本文为您介绍 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版 V4.2.6-CE 的功能。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>目前仅支持 OMS 社区版 V4.2.5-CE 升级至 V4.2.6-CE，不支持 V4.2.5-CE 之前版本升级至 V4.2.6-CE。</p>
</main>

## 新增功能

* 支持创建 Milvus 全量数据迁移至 OceanBase 向量库的数据迁移任务。

* 支持创建 Redis 全量数据迁移至 OBKV Redis 数据库的数据迁移任务。

## 易用性提升

* 新增 TiDB 至 OceanBase 的增量同步设置 Kafka 消费分组功能。

* 升级 OceanBase 社区版的旁路导入 API，提高并发场景下的旁路导入稳定性。

* OMS 社区版支持在数据迁移和数据同步任务新增对象前预检资源，避免出现任务运行中失败的情况。

* OMS 社区版支持适配 Ubuntu 系统。
