# 产品动态

本文为您介绍 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版 V4.2.3-CE 的功能。

<main id="notice" type='notice'>
<h4>注意</h4>
<ul>
<li>
<p>目前仅支持 OMS 社区版 V4.2.2-CE 升级至 V4.2.3-CE，不支持 V4.2.2-CE 之前版本升级至 V4.2.3-CE。</p>
</li>
<li>
<p>OMS 社区版 V4.1.0-CE 支持通过特殊升级步骤直接升级至 V4.2.3-CE。</p>
</li>
</ul>
</main>

## 新增功能

* 迁移 HBase 的数据至 OBKV 时，新增支持旁路写入方式。

* 迁移 HBase 的数据至 OBKV 时，新增支持社区版 HBase V2.x。

* 迁移 TiDB 数据库的数据至 OceanBase 社区版时，新增支持 TiDB V2.x 和 V3.x。

* 新增支持使用单点登录 SSO 的方式登录 OMS 社区版。

* 新增支持 GreenPlum V5.1。

* 迁移 PostgreSQL 数据库的数据至 OceanBase 社区版时，新增支持 PostgreSQL 数据库 V11.x、V13.x、V14.x、V15.x 和 V16.x。
  
## 易用性提升

* OMS 社区版部署：支持 V4.1.0-CE 直接升级至 V4.2.3-CE。

* 新增已存在的数据迁移任务更换数据源功能。

* 支持设置统一日志保留时间功能。

* 支持数据库通配功能，并且支持库名和表名中存在点号的通配问题。

* 支持字段转换函数 floor。

* 支持 MySQL 数据库地理位置类型的迁移和校验。

* 新增预检查 OMS 资源。

* 取消全量校验订正之后自动进行全量校验逻辑。

* root 和 admin 用户密码初始设置永不超期。

* 增量阶段 DDL 异常跳过优化。
