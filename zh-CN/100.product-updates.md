# 产品动态

本文为您介绍 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版 V4.2.13-CE 的功能。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>目前仅支持 OMS 社区版 V4.2.0-CE ~ V4.2.12-CE 升级至 V4.2.13-CE，不支持 V4.2.0-CE 之前版本升级至 V4.2.13-CE。</p>
</main>

## 新增功能

* 支持同步 ElasticSearch 数据库的增量数据至 OceanBase 社区版。

* 支持同步 MongoDB 数据库的增量数据至 OceanBase 社区版。

* 支持迁移 MongoDB 数据库 V3.x 的数据至 OceanBase 社区版。

* 支持迁移 ClickHouse 数据库的全量数据至 OceanBase 社区版。

* 支持迁移 PostgreSQL 数据库 sparsevec 类型的数据至 OceanBase 社区版。

* 支持 OceanBase 开启 TLS

  * 支持 OceanBase 数据源开启 TLS。

  * 支持安装 OMS 社区版使用开启 TLS 的 OceanBase 作为元数据库。

* 支持排除 TiDB 数据库指定字段，不迁移至 OceanBase 社区版。

## 易用性提升

* 支持 OceanBase CDC 纳秒。

* API 创建任务支持配置告警等级。
