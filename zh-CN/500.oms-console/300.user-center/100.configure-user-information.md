# 设置个人信息

您可以在个人中心设置您的联系方式、所属部门等个人信息。

## 操作步骤

1. 登录 OMS 社区版控制台。

2. 在 OMS 社区版系统界面的右上角，单击当前登录用户名，选择 **<UI-TERM key="oms-community.src.layout.BasicLayout.PersonalSettings">个人设置</UI-TERM>**。

   ![个人设置](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2096124461/p397785.png)

3. 在 **<UI-TERM key="oms-community.User.Personal.PersonalSettings">个人设置</UI-TERM>** 页面，设置您的 **<UI-TERM key="oms-community.User.Detail.Mailbox">邮箱</UI-TERM>**、**<UI-TERM key="oms-community.User.New.MobilePhoneNumber">手机号码</UI-TERM>**、**<UI-TERM key="oms-community.pages.User.Department">部门</UI-TERM>** 和个人说明信息。

4. 设置完成后，单击 **<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.Submitted">提交</UI-TERM>**。
