# 迁移 Hive 的数据至 OceanBase 社区版

本文为您介绍如何通过命令行执行 Hive 至 OceanBase 社区版的数据迁移。

## 背景信息

OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版对于 Hive 数据迁移实现了以下三种方式。

* Hive 外表模式：通过 Hive 外表实现 Hive 的数据迁移至 OceanBase 社区版。

* Spark 本地模式：使用 Spark OceanBase 插件，在 Spark 本地模式下读取 Hive 的数据写入至 OceanBase 社区版。数据从 Hive 读取至 OMS 社区版中，然后再写入 OceanBase 社区版。

* Spark 集群模式：使用 Spark OceanBase 插件，提交 Spark 集群。数据从 Hive 读取至 Spark 集群，然后再写入 OceanBase 社区版。

`hive2ob.sh` 配置文件包括 `condition.json`、`source.json`、`coordinator.json` 和 `sink.json`。

* 黑白名单配置文件 `condition.json`

  * 指定白名单配置

    ```Json

    {
    "blackCondition":[
        {
            "all":false,
            "sub":[
                {
                    "name":"filter_table_name"
                        }
                    ],
            "name":"src_schema",
            "map":"dst_schema"
            }
            ],
    "whiteCondition":[
        {
            "all":false,
            "sub":[
                {
                    "name":"hive_tabe_name",
                    "map":"ob_table_name"
                }
                    ],
            "name":"src_schema",
            "map":"dst_schema"
                }
            ]
        }
        ```

  * 通配方式

    ```Json
    {
        "blackCondition":[
            {
                "all":false,
                "sub":[
                    {
                        "func":"fn",
                        "name":"filter_table_name"
                    }
                ],
                "func":"fn",
                "name":"src_schema",
                "map":"dst_schema"
            }
        ],
        "whiteCondition":[
            {
                "all":false,
                "sub":[
                    {
                        "func":"fn",
                        "name":"*"
                    },
                    {
                        "name":"hive_table_name",
                        "map":"rename_hive_table_name"
                    }
                ],
                "func":"fn",
                "name":"src_schema",
                "map":"dst_schema"
            }
        ]
    }
    ```

* `source.json`

    ```Json
    {
        "boosterClass":"com.oceanbase.oms.connector.source.hive.OmsHiveRunner",
        "clients":[
            {
                "clientId":"np_6cm31nfy1d28",
                "instance":"jdbc:hive2://sqaobnoxdn011124009103:10000/default",
                "username":"hadoop",
                "password":" ",
                "hiveconf":{
                            "HADOOP_USER_NAME":"hadoop",
                            "oms.kerberos.principal":"",
                            "oms.kerberos.keytab.file":"",
                            //spark 才需要
                        "hive.metastore.uris":"thrift://sqaobnoxdn011124009103:9083"
                        },
        "fileconf":{
            "hive-site.xml":"hive-site.xml 文件内容，base64 编码"
        }
            }
        ],
    //您可以自定义读取 Hive 的 SQL 语句。此处的 select 字段顺序必须和目标端 OceanBase 社区版中的表字段顺序一致，并且数量一致。
    "hivesql":[
        {
        "table":"schema.table_name",
        "sql":"select f1,f2 from schema.table_name where f1='xx'"
        }
    ],
    "addjars": [
            "/data/1/hadoop/oms-hive-jdbc-handler.jar","/data/1/hive/lib/hive-jdbc-handler-2.3.9.jar","/data/1/hive/lib/commons-dbcp-1.4.jar","/data/1/hive/lib/commons-pool-1.5.4.jar"
        ],
    "jar":"connector-hive.jar:connector-dataflow.jar",
        "dbVersion":"1.2.0-cdh5.15.2",
        "timezone":"+08:00",
        "taskResume":"false",
        "type":"HIVE_SOURCE",
    "sliceWorkerNum":"4",
    "dbType":"HIVE"
    }
    ```

    |    参数   |   描述   |
    |-----------------|------------------|
    | hiveconf | hiveconf 中的配置可以使用 hive set 设置的配置参数。|
    | hivesql | 该参数适用于需要自定义查询 Hive 表 SQL 语句的情况。从 Hive 向 OceanBase 社区版写入数据时，OMS 社区版会使用 OceanBase 社区版目标表中的所有字段名和顺序来组装查询 Hive 表的 SQL 语句。如果存在以下两种情况，则需要您自定义查询 Hive SQL，并且自定义 SQL 的 SELECT 字段顺序必须和目标端 OceanBase 社区版中的字段顺序保持一致。<ul><li>Hive 表的字段名称和目标端 OceanBase 社区版中的字段名称不一致。<li>目标端 OceanBase 社区版中的字段在 Hive 表中不存在。该情况可以使用常量替换字段应该出现的位置。</ul>
    | addjars | 该参数用于添加外表相关的 JAR 包，包括 Hive Server2 本地模式和 HTTP 模式。<ul><li>Hive Server2 本地模式：JAR 复制到 Hive Server2 服务器的特定目录，此处直接配置 JAR 目录。<li>HTTP 模式：对于 Hive 支持 HTTP 方式添加 JAR 包的情况，您可以直接使用 OMS 社区版的 HTTP 服务添加 JAR 包（http://{OMS_IP}:{OMS_PORT}/jars/oms-hive-jdbc-handler.jar）。<main id="notice" type='notice'><h4>注意</h4><p>oms-hive-jdbc-handler.jar 为必填项。对于部分 Hive，还需要添加 Hive 自带的 JAR 包：hive-jdbc-handler-x.x.x.jar,commons-dbcp-x.x.jar,commons-pool-x.x.x.jar。</p></main></ul>|
    | sliceWorkerNum | 该参数用于控制读取 Hive 表的并发，表示同时有几张 Hive 表在进行读写。默认值为 4。|

* `sink.json`

    ```Json
    {
        "boosterClass":"com.oceanbase.oms.connector.jdbc.sink.obmysql.OBMySQLJDBCSinkBooster",
        "type":"JDBC_SINK_OB_MYSQL/JDBC_SINK_OB_MYSQL_DIRECT_LOAD",
        "insertMode":"INSERT",
        "jdbcUrl":"jdbc:mysql://xxx.xxx.xxx.xxx:2883?useUnicode=true&allowMultiQueries=true&socketTimeout=50000&characterEncoding=utf8&readOnlyPropagatesToServer=false",
        "username":"xxx@xxx#xxx",
        "password":"xxx",
            "jar":"jdbc-sink-ob-mysql.jar",
        // 如果您不设置，则结果表名按照目标表名来自动创建 oms_result_xxx
        "saveResult":"true",
        "resultTable":{"schema":"hive","table":"oms_result_migrate"},
        "dbVersion":"4.3.4.0",
            "timezone":"+08:00",
            "workerNum":"4"
        }
    ```

    结果表结构如下：

    ```SQL
    create table if not exists oms_result_migrate (
    id bigint not null auto_increment,
    schema_name varchar(128) not null,
    table_name varchar(128) not null,
    result_type varchar(1) not null comment 'i-insert,d-delete,u-update,e-error',
    rows bigint not null,
    gmt_create timestamp(6) default current_timestamp(6),
    data longtext,
    message text,
    primary key(id),
    index idx_schema_table(schema_name,table_name,result_type)
    );
    ```

## 操作步骤

1. 登录 OMS 社区版容器。

    ```shell
    docker exec -it ${CONTAINER_NAME} bash
    ```

   <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><code>CONTAINER_NAME</code> 为创建容器的名称。</p>
   </main>

2. 切换至 ds 用户。

    ```shell
    su ds
    ```

3. 执行初始化任务配置脚本。

    ```shell
    /home/ds/plugins/jdbc_connector/tools/hive2ob.sh init <任务名称> <参数...>
    ```

    * hive2ob.sh `init` 表示初始化，创建任务运行目录、复制需要的 JAR 包、生成配置文件模板等。配置文件的格式和 Connector 全量配置文件保持一致。

        hive2ob.sh `run` 表示运行，进程会在后端运行。

    * 任务名称由字母和数字组成，不支持特殊字符。

        任务名称主要是用户创建任务运行工作目录 `/home/ds/run/<任务名称>`。`/home/ds/run` 是 OMS 社区版作业根目录，您可以使用 `OMS_RUN_PATH` 环境变量进行修改。

    * 下表为您介绍 `hive2ob.sh` 支持的参数配置。

        |  参数              |                    描述            |
        |--------------------|-----------------------------------|
        | --mode | 运行模式，包括 `local` 和 `spark`。该参数仅在 hive2ob.sh `init` 时生效。<ul><li>`local`：默认值，表示使用本地连接 Hive Server2，通过外表方式进行数据迁移。<li>`spark`：表示通过 Spark 框架进行数据迁移。</ul>|
        | --whitelist | 白名单，该参数仅在 hive2ob.sh `init` 时生效。格式为 `schema.table_name`，多个配置之间使用竖线（\|）分隔。如果 `schema` 或 `table_name` 中包含英文句号（.），则使用 {DOT} 分隔 `schema` 和 `table_name`。 |
        | --blacklist | 黑名单，该参数仅在 hive2ob.sh `init` 时生效。格式为 `schema.table_name`，多个配置之间使用竖线（\|）分隔。如果 `schema` 或 `table_name` 中包含英文句号（.），则使用 {DOT} 分隔 `schema` 和 `table_name`。 |
        | --hiveurl   | Hive Server2 的 JDBC 链接，该参数仅在 hive2ob.sh `init` 时生效。例如，`jdbc:hive2://host:10000/default`。|
        | --hiveuser  | 用户名，默认值为 hadoop。该参数仅在 hive2ob.sh `init` 时生效。|
        | --hivepassword | 用户密码，默认值为空。该参数仅在 hive2ob.sh `init` 时生效。|
        | --hivethrift  | 用于访问 Hive 的 Thrift 服务的 URL。例如，`thrift://xxx:9083`。该参数仅在 hive2ob.sh `init` 并且 mode 为 spark 时生效。|
        | --hiveconf   | hive-site.xml 配置文件，多个 xml 配置文件之间使用英文逗号（,）分隔。该参数仅在 hive2ob.sh `init` 时生效。|
        | --hivejars | 当 mode 为 local 时，外表需要用到的 JAR。请注意此处 JAR 的路径是 `--hiveurl` 指定服务器上的 JAR 路径，多个 JAR 之间使用英文逗号（,）分隔。该参数该参数仅在 hive2ob.sh `init` 时生效。<br>`oms-hive-jdbc-handler.jar` 必须复制到 Hive Server2 的机器上。Hive V2.x 需要根据实际情况加入 JAR，Hive V3.x 则无需加入 JAR。<ul><li>hive-jdbc-handler-2.3.9.jar<li>commons-dbcp-1.4.jar<li>commons-pool-1.5.4.jar</ul>例如，`/data/1/hadoop/oms-hive-jdbc-handler.jar,/data/1/hadoop/hive-jdbc-handler-2.3.9.jar,...`。|
        | --oburl | OceanBase JDBC URL，该参数仅在 hive2ob.sh `init` 时生效。例如，`jdbc:mysql://x.x.x.x:2883?useUnicode=true&allowMultiQueries=true&socketTimeout=50000&characterEncoding=utf8&readOnlyPropagatesToServer=false`。|
        | --obuser | 目标端 OceanBase 社区版的用户名。该参数仅在 hive2ob.sh `init` 时生效。|
        | --obpassword | 目标端 OceanBase 社区版的用户密码。该参数仅在 hive2ob.sh `init` 时生效。|
        | --writetype  | 写入模式，包括 `sql` 和 `direct`。该参数仅在 hive2ob.sh `init` 时生效。<ul><li>`sql`：默认值，表示 SQL 模式，使用 INSERT SQL 写入数据至 OceanBase 社区版。<li>`direct`：表示旁路写入模式，使用 OceanBase 旁路导入 API 写入数据。|
        | --sparkmaster | 该参数仅在 hive2ob.sh `init` 并且 mode 为 spark 时生效。例如，spark://host:7077，默认 local[*]。|
        | --sparksqlwhdir| 该参数仅在 hive2ob.sh `init` 并且 mode 为 spark 时生效。例如，hdfs://host:9000/user/hive/warehouse。|

4. 修改任务个性化配置。例如，目标 Schema 和表名重命，则需要修改 `conf/condition.json` 文件。

5. 执行下述命令，运行数据迁移任务。

    ```shell
    /home/ds/plugins/jdbc_connector/tools/hive2ob.sh init <任务名称>
    ```

6. 查看任务进程。

    ```shell
    ps -ef|grep <任务名称>
    ```

7. 查看任务日志。

    ```shell
    /home/ds/run/<任务名称>/logs
    ```

## 数据迁移示例

### Hive 外表模式示例

```shell
# hiveexternal 是任务名称
# 初始化之后会在 /home/ds/run 下面新建 hiveexternal 子目录
# 如果 hiveexternal 已经存在，初始化会报错
# --writetype direct 表示旁路写入

/home/ds/plugins/jdbc_connector/tools/hive2ob.sh init hiveexternal \
--mode local --whitelist "default.hive_data" \
--hiveurl "jdbc:hive2://xxx.xxx.xxx.xxx:10000" --hiveuser hadoop \
--oburl "jdbc:mysql://xxx.xxx.xxx.xxx:2883?useUnicode=true&allowMultiQueries=true&socketTimeout=50000&characterEncoding=utf8&readOnlyPropagatesToServer=false" \
--obuser "root@obmysql#xxxxxx" --obpassword "xxxxxxx" \
--writetype direct

# 根据需要修改配置，配置文件在 /home/ds/run/任务名/conf 中
# 运行数据迁移任务
/home/ds/plugins/jdbc_connector/tools/hive2ob.sh init run
```

### Spark 本地模式示例

```shell
# sparklocal 是任务名称
/home/ds/plugins/jdbc_connector/tools/hive2ob.sh init sparklocal \
--mode spark --whitelist "default.hive_data" \
--hivethrift "thrift://xxx.xxx.xxx.xxx:9083" \
--hiveuser hadoop --oburl "jdbc:mysql://xxx.xxx.xxx.xxx:2883?useUnicode=true&allowMultiQueries=true&socketTimeout=50000&characterEncoding=utf8&readOnlyPropagatesToServer=false" \
--obuser "root@obmysql#xxxxxx" --obpassword "xxxxxxs" \
--writetype direct --sparksqlwhdir "hdfs://xxx.xxx.xxx.xxx:29000/user/hive/warehouse"

/home/ds/plugins/jdbc_connector/tools/hive2ob.sh run sparklocal
```

### Spark 集群模式示例

```shell
# sparkcluster 是任务名称
/home/ds/plugins/jdbc_connector/tools/hive2ob.sh init sparkcluster \
--mode spark --whitelist "default.hive_data" \
--hivethrift "thrift://xxx.xxx.xxx.xxx:9083" \
--hiveuser hadoop --oburl "jdbc:mysql://xxx.xxx.xxx.xxx:2883?useUnicode=true&allowMultiQueries=true&socketTimeout=50000&characterEncoding=utf8&readOnlyPropagatesToServer=false" \
--obuser "root@obmysql#xxxxxx" --obpassword "xxxxxx" \
--sparkmaster "spark://sqaxxxxx086.sa128:7077" \
--writetype direct --sparksqlwhdir "hdfs://xxx.xxx.xxx.xxx:29000/user/hive/warehouse"

/home/ds/plugins/jdbc_connector/tools/hive2ob.sh run sparkcluster
```
