# 数据库库表重命名

本文为您介绍如何使用 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版提供的重命名迁移对象的功能。

## 适用场景

默认情况下，被迁移的对象（例如数据库、表等）在源端和目标端的名称相同，您可以通过 OMS 社区版提供的对象名称重命名功能，设置被迁移的对象在目标端的名称，实现源端和目标端之间数据库的库名、表名的映射。该功能常用于测试环境和生产环境命名不一致、多表聚合功能等场景。

<main id="notice" type='explain'>
<h4>说明</h4>
<p>多表聚合功能主要用于将 DRDS、MyCat 等分库分表的数据同步至目标端的同一张表。</p>
</main>

## 使用限制

* OMS 社区版仅支持配置数据迁移任务时，在设置选择迁移对象步骤执行重命名操作。

* 一旦启动数据迁移任务，请勿再执行重命名操作。否则可能导致数据迁移任务失败。

## 指定对象重命名

1. 新建数据迁移任务，并配置至 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.SelectObjectsToBeMigrated">选择迁移对象</UI-TERM>** 步骤。

    详情请参见 [数据迁移](../100.data-migration-overview.md) 模块相应类型的创建数据迁移任务文档。

2. 使用 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.SpecifiedObject">指定对象</UI-TERM>** 方式选择迁移对象后，在 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.SelectAMigrationRange">选择迁移范围</UI-TERM>** 区域右侧的 **<UI-TERM key="oms-community.common.Transfer.TargetObject">目标端对象</UI-TERM>** 列表中，鼠标悬停至目标表对象。

3. 单击显示的 **<UI-TERM key="oms-community.components.TreeTransfer.TargetNode.Rename">重命名</UI-TERM>**。

    ![rename-1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/rename-1.png)

4. 输入目标端对象重命名后的名称。

    ![rename-2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/rename-2.png)

5. 单击 **<UI-TERM key="oms-community.components.ViewObj.AddObject.Ok">确定</UI-TERM>**。

    ![rename-3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/rename-3.png)

6. 根据提示完成后续的任务配置。

## 匹配规则重命名

1. 新建数据迁移任务，并配置至 **<UI-TERM key="oms-community.Migration.New.SelectObject">选择迁移对象</UI-TERM>** 步骤。

    详情请参见 [数据迁移](../100.data-migration-overview.md) 模块相应类型的创建数据迁移任务文档。

2. 使用 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.MatchRules">匹配规则</UI-TERM>** 方式选择迁移对象后，您可以使用以下两种方式进行库表重命名。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <ul>
    <li>
    <p>您在左侧通过迁移对象规则重命名目标对象后，右侧将不允许对已操作的对象再次进行重命名。</p>
    </li>
    <li>
    <p>重命名后，不会改变行过滤条件等设置。</p>
    </li>
    <li>
    <p><code><源库>.*=<目标库>.<表名></code> 表示将源库的所有表映射至目标库的一张表中。即 <code>a.b=c.d</code> 中，只有 b 的部分支持规则，a、c、d 均为具体的库名和表名。</p>
    </li>
    </ul>
    </main>

    * 在 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.SelectAMigrationRange">选择迁移范围</UI-TERM>** 区域左侧，通过配置迁移对象规则进行重命名。

        您可以在 **<UI-TERM key="oms-community.components.Rules2destination.ObjectMigrationRules">迁移对象规则</UI-TERM>** 中，通过等号（=）来清除源端和目标端的映射关系，对其进行重命名。例如，源端的库名为 e，表名为 f，您可以输入 `e.f=m.n`，修改源端的库名为 m，表名为 n。

        1. 在 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.SelectAMigrationRange">选择迁移范围</UI-TERM>** 区域，输入重命名后的 **<UI-TERM key="oms-community.components.ViewObject.ObjectMigrationRules">迁移对象规则</UI-TERM>**。

        2. 单击 **<UI-TERM key="oms-community.biz.Rules2destination.Verification">校验</UI-TERM>**。

        3. 在弹出框中，单击 **<UI-TERM key="oms-community.Detail.components.MigrationSteps.Determine">确定</UI-TERM>**。

        4. 校验成功后，单击 **<UI-TERM key="oms-community.biz.Rules2destination.PreviewObjects">预览对象</UI-TERM>**，即可查看重命名后的库名和表名。

            ![rename-4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/rename-4.png)

    * 在 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.SelectAMigrationRange">选择迁移范围</UI-TERM>** 区域右侧，直接对匹配对象进行重命名。

        1. 在 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.SelectAMigrationRange">选择迁移范围</UI-TERM>** 区域，输入 **<UI-TERM key="oms-community.components.Rules2destination.ObjectMigrationRules">迁移对象规则</UI-TERM>** 和 **<UI-TERM key="oms-community.biz.Rules2destination.ExcludeObjectRules">排除对象规则</UI-TERM>**（可选）。

        2. 单击 **<UI-TERM key="oms-community.biz.Rules2destination.Verification">校验</UI-TERM>**。校验成功后，单击 **<UI-TERM key="oms-community.biz.Rules2destination.PreviewObjects">预览对象</UI-TERM>**。

        3. 在右侧的 **<UI-TERM key="oms-community.components.Rules2destination.MatchingResult">匹配结果</UI-TERM>** 页面，鼠标悬停至目标数据库或数据表对象，单击 **<UI-TERM key="oms-community.components.Rules2destination.Node.Rename">重命名</UI-TERM>**。

        4. 输入目标端对象重命名后的名称。

            ![rename-5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/rename-5.png)

        5. 单击 **<UI-TERM key="oms-community.pages.User.Confirmation">确定</UI-TERM>**。

3. 根据提示完成后续的任务配置。
