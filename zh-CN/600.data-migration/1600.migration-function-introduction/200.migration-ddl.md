# 同步 DDL

本文为您介绍创建数据迁移任务时，同步 DDL 选项的适用场景、使用限制和操作步骤。

## 适用场景

创建数据迁移任务时，您可以设置是否同步 DDL。只有设置同步 DDL 后，Create/Alter/Drop/Truncate Table 等 DDL 语句才会被同步至目标端。该功能常用于长期的数据迁移、数据同步任务，可以显著降低任务运维的成本。

## 使用限制

* 除支持的同步 DDL 类型外，其它类型均不支持。具体 DDL 范围请参见 [同步 DDL 支持的范围和限制](../1700.supported-ddl-operations-for-incremental-migration-and-limits/100.mysql-to-obmysql/100.mysql-to-obmysql-overview.md)。

* 如果需要同步的表涉及其它类型的 DDL，数据迁移任务可能会中断并造成数据问题，且无法恢复。

* 请勿在结构迁移和全量迁移阶段执行库或者表结构变更的 DDL 操作，否则可能导致数据迁移任务中断。

## 操作步骤

1. 新建数据迁移任务，并配置至 **<UI-TERM key="oms-community.Migration.New.SelectMigrationType">选择迁移类型</UI-TERM>** 步骤。

    详情请参见 [数据迁移](../100.data-migration-overview.md) 模块相应类型的创建数据迁移任务文档。

2. 在 **<UI-TERM key="oms-community.Migration.New.SelectMigrationType">选择迁移类型</UI-TERM>** 页面，勾选 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.IncrementalMigration">增量同步</UI-TERM>** > **<UI-TERM key="oms-community.components.SyncOption.CheckSyncKind.SynchronousDdl">同步 DDL</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.components.MigrationParamsConfig.MigrationParamsDetail.SchemaChangeDdl">同步 DDL</UI-TERM>** 区域选择 **<UI-TERM key="oms-community.components.MigrationTypeParams.SourceSideExecution">源端执行</UI-TERM>** 或 **<UI-TERM key="oms-community.components.MigrationTypeParams.TargetSideExecution">目标端执行</UI-TERM>**。

   * 源端执行：表示 DDL 操作仅在源端执行，并增量同步至目标端。

   * 目标端执行：表示 DDL 操作仅在目标端执行，并增量同步至源端。

4. 根据提示完成后续的任务配置。
