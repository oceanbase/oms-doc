# 查看和修改迁移对象

本文为您介绍如何在 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版中查看和修改已配置的数据迁移任务的迁移对象。

## 背景信息

数据迁移任务在迁移过程中，满足限制条件的情况下，您可以增加或减少迁移对象。每一次运行的修改行为都会被记录。当增加对象任务执行完成后，会与关联的原任务合并。合并成功后，原任务正常运行，增加对象任务会自动释放。

## 使用限制

* 通过 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.SpecifiedObject">指定对象</UI-TERM>** 方式选择迁移对象的数据迁移任务，支持增加和减少迁移对象。

   通过 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.MatchRules">匹配规则</UI-TERM>** 方式选择迁移对象的数据迁移任务，支持减少迁移对象。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>容灾双活场景的数据迁移任务，不支持增加和减少迁移对象。</p>
    </main>

* 数据迁移任务处于 **<UI-TERM key="oms-community.Sync.constants.NotStarted.5">未启动</UI-TERM>**、**<UI-TERM key="oms-community.Operation.Overview.constants.Running">运行中</UI-TERM>** 或 **<UI-TERM key="oms-community.Migration.constants.Paused">已暂停</UI-TERM>** 状态时，支持增加和减少迁移对象。

   <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>对于处于 <b>已暂停</b> 状态的数据迁移任务，如果 <b>全量迁移</b> 或 <b>增量同步</b> 步骤处于 <b>已暂停</b> 状态，则不支持增加迁移对象。</p>
    </main>

* 数据迁移任务处于 **<UI-TERM key="oms-community.Audit.Deatil.Failed">失败</UI-TERM>** 状态时，不支持增加迁移对象。

* 数据迁移任务处于 **<UI-TERM key="oms-community.Migration.constants.Modifying">修改中</UI-TERM>** 或 **<UI-TERM key="oms-community.Migration.constants.Merging">合并中</UI-TERM>** 状态时，不支持再次修改迁移对象。

* 数据迁移任务的 **<UI-TERM key="oms-community.Operation.constants.FullMigration">全量迁移</UI-TERM>**、**<UI-TERM key="oms-community.New.components.MigrationObjectForm.IncrementalMigration">增量同步</UI-TERM>** 步骤处于 **<UI-TERM key="oms-community.Sync.constants.Paused">已暂停</UI-TERM>** 或 **<UI-TERM key="oms-community.src.constants.Failed">失败</UI-TERM>** 状态时，不支持增加迁移对象。

* 数据迁移任务处于 **<UI-TERM key="oms-community.Migration.constants.ReverseIncrement">反向增量</UI-TERM>** 步骤时，不支持增加迁移对象。

## 查看迁移对象

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.Migration.New.DataMigration">数据迁移</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.New.components.EndpointForm.DataMigration">数据迁移</UI-TERM>** 页面，单击目标任务的名称，进入该任务的详情页面。

4. 单击页面右上角的 **<UI-TERM key="oms-community.Detail.components.SyncObject.ViewObjectsToBeSynchronized">查看对象</UI-TERM>**，查看 **<UI-TERM key="oms-community.components.ImportTransferObj.ObjectsToBeMigrated">迁移对象</UI-TERM>** 和 **<UI-TERM key="oms-community.Detail.components.SyncObject.ModifyObjectRecords">修改对象记录</UI-TERM>**。

   * **<UI-TERM key="oms-community.components.ImportTransferObj.ObjectsToBeMigrated">迁移对象</UI-TERM>** 页签为您展示当前任务的迁移对象，您还可以单击 **<UI-TERM key="oms-community.components.ViewObject.ModifyObjects">修改对象</UI-TERM>**，进行 **<UI-TERM key="oms-community.Detail.components.SyncObject.AddObjects">增加对象</UI-TERM>** 和 **<UI-TERM key="oms-community.components.ViewObject.ReduceObjects">减少对象</UI-TERM>** 操作。

   * **<UI-TERM key="oms-community.Detail.components.SyncObject.ModifyObjectRecords">修改对象记录</UI-TERM>** 页签为您展示所有修改对象操作的 ID、修改类型、状态和修改时间等信息。

## 增加迁移对象

1. 在目标任务的详情页面，单击右上角的 **<UI-TERM key="oms-community.Migration.hooks.useMigrationObject.ViewObjectsToBeMigrated">查看对象</UI-TERM>**。

2. 在 **<UI-TERM key="oms-community.Detail.components.SyncObject.ViewObjectsToBeSynchronized">查看对象</UI-TERM>** 对话框，单击 **<UI-TERM key="oms-community.components.ViewObject.ModifyObjects">修改对象</UI-TERM>** \> **<UI-TERM key="oms-community.Detail.components.SyncObject.AddObjects">增加对象</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.components.ViewObj.AddObject.AddObjects">增加对象</UI-TERM>** 对话框的左侧 **<UI-TERM key="oms-community.common.Transfer.SourceObject">源端对象</UI-TERM>** 区域，选中需要迁移的对象，单击 **\>**，将其添加至右侧列表中。您可以选择一个或多个库的表、视图作为迁移对象。

   选择增加的迁移对象后，您可以进行重命名对象名称、设置行过滤和查看列信息等操作。

   <main id="notice" type='notice'>
    <h4>注意</h4>
    <ul>
    <li>
    <p>增加对象将默认继承原数据迁移任务的全部配置选项。如果增加对象的过程中终止了操作，您需要手动删除目标库中已增加的对象。</p>
    </li>
    <li>
    <p>如果源端数据源配置了 Schema Name 或 DB Name，则仅支持增加指定 Schema Name 或 DB Name 下的迁移对象。</p>
    </li>
    </ul>
   </main>

4. 选择完成后，单击 **<UI-TERM key="oms-community.Migration.New.Next">下一步</UI-TERM>**。

5. 系统会自动对增加对象执行预检查。全部检查任务均通过后，单击 **<UI-TERM key="oms-community.Sync.New.Save">保存</UI-TERM>**。

6. 确认无误后，在弹出框单击 **<UI-TERM key="oms-community.components.Rules2destination.Node.Determine">确定</UI-TERM>**。

   * 如果任务处于已暂停或失败状态，您可以取消后重新进行修改。修改后，请先恢复数据迁移任务，才能够执行增加对象操作。

   * 如果任务处于运行中状态，单击保存后，将立即执行增加任务操作。
  
   增加对象操作开始执行后，会在 **<UI-TERM key="oms-community.Migration.constants.ViewObjectsToBeMigrated">查看对象</UI-TERM>** \> **<UI-TERM key="oms-community.components.ViewObject.ModifyObjectRecords">修改对象记录</UI-TERM>** 页面生成记录，您可以进入该页面查看记录的详情。增加对象记录的状态包括 **<UI-TERM key="oms-community.ModifyRecordTable.constants.PendingExecution">待执行</UI-TERM>**、**<UI-TERM key="oms-community.SystemManage.Authorization.contants.Canceled">已取消</UI-TERM>**、**<UI-TERM key="oms-community.ModifyRecordTable.constants.Modifying">修改中</UI-TERM>**、**<UI-TERM key="oms-community.ModifyRecordTable.constants.Running">运行中</UI-TERM>**、**<UI-TERM key="oms-community.ModifyRecordTable.constants.Terminated">已终止</UI-TERM>**、**<UI-TERM key="oms-community.ModifyRecordTable.constants.Merging">合并中</UI-TERM>**、**<UI-TERM key="oms-community.PreCheck.constants.Success">成功</UI-TERM>** 和 **<UI-TERM key="oms-community.PreCheck.constants.Failed">失败</UI-TERM>**，不同状态的增加对象记录支持的操作，以及处于运行中状态的原任务对应的状态也不同。

    <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>原任务处于 <strong>未启动</strong> 状态时，增加对象会生成一条 <strong>成功</strong> 状态的修改记录。原任务处于 <strong>已暂停</strong> 状态时，增加对象会生成一条 <strong>待执行</strong> 状态的修改记录。</p>
    </main>

   只有原任务处于运行中的状态，增加对象记录的状态才会被推进。增加对象记录的状态推进后，原任务状态也随之更新。详情请参见下表。

   | **增加对象记录的状态** | **支持的操作**                                                    | **原任务对应的状态** |
   |---------------|--------------------------------------------------------------|------------|
   | 待执行           | 查看详情、取消                                                      | 运行中        |
   | 已取消           |  无                                                            |  运行中  |
   | 修改中           | 无                                                          | 修改中       |
   | 运行中           | 查看详情、终止                                                      | 修改中        |
   | 已终止           | 查看详情                                                         | 运行中        |
   | 合并中           | 查看详情                                                         | 合并中        |
   | 成功            | 查看详情                         | 运行中        |
   | 失败            | 查看详情、重试 <br>您还可以单击 **<UI-TERM key="oms-community.components.ModifyRecordTable.ViewReason">查看原因</UI-TERM>**，跳转至任务的详情页面，查看失败的原因。 | 修改中/合并中       |

## 减少迁移对象

### 指定对象方式的数据迁移任务

1. 在目标任务的详情页面，单击右上角的 **<UI-TERM key="oms-community.Migration.constants.ViewObjectsToBeMigrated">查看对象</UI-TERM>**。

2. 在 **<UI-TERM key="oms-community.Migration.constants.ViewObjectsToBeMigrated">查看对象</UI-TERM>** 对话框，单击 **<UI-TERM key="oms-community.components.ViewObject.ModifyObjects">修改对象</UI-TERM>** > **<UI-TERM key="oms-community.ModifyRecordTable.constants.ReduceObjects">减少对象</UI-TERM>**。

   ![oms-doc-1-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-ce/oms-doc-1-zh.png)

3. 在 **<UI-TERM key="oms-community.ModifyRecordTable.constants.ReduceObjects">减少对象</UI-TERM>** 对话框的右侧 **<UI-TERM key="oms-community.common.Transfer.TargetObject">目标端对象</UI-TERM>** 区域，鼠标悬停至需要减少迁移的对象，单击 **<UI-TERM key="oms-community.components.PreCheck.PreCheckTable.Remove">移除</UI-TERM>**。

   ![oms-doc-2-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-ce/oms-doc-2-zh.png)

4. 在 **<UI-TERM key="oms-community.components.ViewObject.ReduceObjects">减少对象</UI-TERM>** 对话框，单击 **<UI-TERM key="oms-community.Migration.constants.Remove">移除</UI-TERM>**。

5. 在弹出框中确认需要移除的对象无误后，单击 **<UI-TERM key="oms-community.Modal.DangerousConfirm.Delete">确定</UI-TERM>**。

   如果任务处于已暂停、失败或运行中状态，单击确定后，将立即执行减少对象操作。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <ul>
    <li>
    <p>对象减少后不可恢复，请谨慎操作。</p>
    </li>
    <li>
    <p>减少对象操作最终是全部成功或全部失败。</p>
    </li>
    </ul>
    </main>

   减少对象操作开始执行后，会在 **<UI-TERM key="oms-community.Sync.constants.ViewObjectsToBeSynchronized">查看对象</UI-TERM>** \> **<UI-TERM key="oms-community.Migration.Detail.ModifyObjectRecords">修改对象记录</UI-TERM>** 页面生成记录，您可以进入该页面查看记录的详情。减少对象记录的状态包括 **<UI-TERM key="oms-community.ModifyRecordTable.constants.PendingExecution">待执行</UI-TERM>**、**<UI-TERM key="oms-community.SystemManage.Authorization.contants.Canceled">已取消</UI-TERM>**、**<UI-TERM key="oms-community.Sync.constants.Modifying">修改中</UI-TERM>**、**<UI-TERM key="oms-community.ModifyRecordTable.constants.Success">成功</UI-TERM>** 和 **<UI-TERM key="oms-community.Audit.constants.Failed">失败</UI-TERM>**，不同状态的修改对象记录支持的操作，以及处于运行中状态的原任务对应的状态也不同。

   | **减少对象记录的状态** | **支持的操作**                                                    | **原任务对应的状态** |
   |---------------|--------------------------------------------------------------|------------|
   | 待执行           | 查看详情、取消                                                      | 运行中        |
   | 已取消           |  无                                                            |  运行中  |
   | 修改中           | 无                                                          | 修改中       |
   | 成功            | 查看详情                         | 运行中        |
   | 失败            | 查看详情、重试 <br>您还可以单击 **<UI-TERM key="oms-community.components.ModifyRecordTable.ViewReason">查看原因</UI-TERM>**，跳转至任务的详情页面，查看失败的原因。 | 修改中      |

### 匹配规则方式的数据迁移任务

1. 在目标任务的详情页面，单击右上角的 **<UI-TERM key="oms-community.Sync.constants.ViewObjectsToBeSynchronized">查看对象</UI-TERM>**。

2. 在 **<UI-TERM key="oms-community.Detail.components.SyncObject.ViewObjectsToBeSynchronized">查看对象</UI-TERM>** 对话框，单击 **<UI-TERM key="oms-community.common.Transfer.SourceObject">源端对象</UI-TERM>** > **<UI-TERM key="oms-community.ModifyRecordTable.constants.ReduceObjects">减少对象</UI-TERM>**。

   ![oms-doc-3-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-ce/oms-doc-3-zh.png)

3. 在 **<UI-TERM key="oms-community.components.ViewObj.DelObject.ReduceObjects">减少对象</UI-TERM>** 对话框左侧的 **<UI-TERM key="oms-community.biz.Rules2destination.ExcludeObjectRules">排除对象规则</UI-TERM>** 区域，输入需要移除的表对象的通配规则，单击 **<UI-TERM key="oms-community.components.Rules2destination.VerifyAndPreviewObjects">校验并预览对象</UI-TERM>**。

4. 在 **<UI-TERM key="oms-community.components.ViewObject.ReduceObjects">减少对象</UI-TERM>** 对话框右侧确认待迁移的全部对象无误后，单击 **<UI-TERM key="oms-community.common.TreeSearch.TargetNode.Remove">移除</UI-TERM>**。

5. 单击弹出框中的 **<UI-TERM key="oms-community.pages.EndpointPublic.Confirmation">确定</UI-TERM>**。
