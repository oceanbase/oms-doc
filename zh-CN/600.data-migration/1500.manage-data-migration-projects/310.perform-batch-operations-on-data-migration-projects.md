# 批量操作数据迁移任务

本文为您介绍如何使用 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版对数据迁移任务进行批量操作。

## 背景信息

OMS 社区版支持在 **<UI-TERM key="oms-community.pages.Migration.MigrationProject">迁移任务列表</UI-TERM>** 页面，对数据迁移任务进行批量操作。不同状态的数据迁移任务支持不同的批量操作。

| 数据迁移任务的状态 | 支持的批量操作                                               |
|---------------|---------------------------------------------------------------------------|
| 未启动           | 批量启动、批量删除、批量修改告警配置                                                     |
| 运行中           | 运行中的任务在不同场景下，支持的批量操作也不同。<ul><li> 批量暂停、批量修改告警配置：所有场景。 </li><li> 批量进入正向切换 <br>场景：所选任务处于 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.FullVerification">全量校验</UI-TERM>** 已完成阶段。</li><li>批量正向切换 <br>场景：所选任务的迁移类型相同，并且均处于正向切换的同一卡点步骤（除切换预检查步骤外）。 </li> <li>批量跳过全量校验 <br>场景：所选任务处于已进入全量校验阶段。 |
| 已暂停           | 批量恢复、批量释放、批量修改告警配置、批量跳过全量校验（处于已进入全量校验阶段）。                                             |
| 失败            | 批量恢复、批量释放、批量修改告警配置、批量跳过全量校验（处于已进入全量校验阶段）。                                             |
| 已释放           | 批量删除                                          |
| 释放中           | 无                               |
| 已完成           | 批量释放                         |

如果您在选择多个任务进行某项批量操作时，遇到并非所有任务都符合该项批量操作适用的场景。OMS 社区版会在弹出对话框中提示您可以进行该项批量操作的任务。

![batch-pause-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/batch-pause-zh.png)

## 进入迁移任务列表页面

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.Migration.Detail.DataMigration">数据迁移</UI-TERM>**，即可进入 **<UI-TERM key="oms-community.pages.Migration.MigrationProject">迁移任务列表</UI-TERM>** 页面。

   您可以在该页面选择需要进行批量操作的数据迁移任务，进行相关批量操作。

   ![migrate-batch-operation-zh.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/migrate-batch-operation-zh.png)

## 批量暂停

OMS 社区版支持处于 **<UI-TERM key="oms-community.Sync.constants.YunXingZhong">运行中</UI-TERM>** 状态的数据迁移任务进行 **<UI-TERM key="oms-community.Migration.constants.BatchPause">批量暂停</UI-TERM>** 操作。

1. 在 **<UI-TERM key="oms-community.pages.Migration.MigrationProject">迁移任务列表</UI-TERM>** 页面，选择需要暂停的数据迁移任务。

2. 单击页面下方的 **<UI-TERM key="oms-community.Migration.constants.BatchPause">批量暂停</UI-TERM>**。

3. 在弹出对话框中，单击 **<UI-TERM key="oms-community.biz.AccountAuthorization.Ok">确定</UI-TERM>**。

   该对话框会提示您可以进行批量暂停的任务个数、任务名称和最新位点。

4. 待批量暂停成功后，页面会进行提示并告知您批量暂停成功的任务个数。

   如果有操作失败的任务，请根据页面提示进行排查。

## 批量恢复

OMS 社区版支持处于 **<UI-TERM key="oms-community.Migration.constants.Paused">已暂停</UI-TERM>** 和 **<UI-TERM key="oms-community.Sync.constants.Failed">失败</UI-TERM>** 状态的数据迁移任务进行 **<UI-TERM key="oms-community.Migration.constants.BatchRecovery">批量恢复</UI-TERM>** 操作。

1. 在 **<UI-TERM key="oms-community.pages.Migration.MigrationProject">迁移任务列表</UI-TERM>** 页面，选择需要恢复的数据迁移任务。

2. 单击页面下方的 **<UI-TERM key="oms-community.Migration.constants.BatchRecovery">批量恢复</UI-TERM>**。

3. 在弹出对话框中，单击 **<UI-TERM key="oms-community.pages.Endpoint.Confirmation">确定</UI-TERM>**。

   该对话框会提示您可以进行批量恢复的任务个数、任务名称和最新位点。

4. 待批量恢复成功后，页面会进行提示并告知您批量恢复成功的任务个数。

   如果有操作失败的任务，请根据页面提示进行排查。

## 批量释放

OMS 社区版支持处于 **<UI-TERM key="oms-community.Migration.constants.Paused">已暂停</UI-TERM>**、**<UI-TERM key="oms-community.Overview.constants.Failed">失败</UI-TERM>** 和 **<UI-TERM key="oms-community.Operation.constants.Completed">已完成</UI-TERM>** 状态的数据迁移任务进行 **<UI-TERM key="oms-community.Migration.constants.BatchRelease">批量释放</UI-TERM>** 操作。

1. 在 **<UI-TERM key="oms-community.pages.Migration.MigrationProject">迁移任务列表</UI-TERM>** 页面，选择需要释放的数据迁移任务。

2. 单击页面下方的 **<UI-TERM key="oms-community.Migration.constants.BatchRelease">批量释放</UI-TERM>**。

3. 在弹出对话框中，单击 **<UI-TERM key="oms-community.pages.EndpointPublic.Add">确定</UI-TERM>**。

   该对话框会提示您可以进行批量释放的任务个数、任务名称和最新位点。

4. 待批量释放成功后，页面会进行提示并告知您批量释放成功的任务个数。

   如果有操作失败的任务，请根据页面提示进行排查。

## 批量正向切换

OMS 社区版支持处于 **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.Running">运行中</UI-TERM>** 状态，且处于正向切换的同一卡点步骤（除切换预检查步骤外）的数据迁移任务进行 **<UI-TERM key="oms-community.BatchSelect.model.batchAction.vm.BatchForwardSwitching">批量正向切换</UI-TERM>** 操作。

处于正向切换的同一卡点步骤是指所选任务处于正向切换的同一个子步骤。正向切换的子步骤包括启动正向切换、切换预检查、启动目标端 Store、确认源端停写、确认同步追平停写位点、停止正向同步、执行数据库对象处理和启动反向增量。

<main id="notice" type='explain'>
 <h4>说明</h4>
 <p>正向切换的子步骤会根据创建任务时选择的迁移类型而变化。</p>
</main>

1. 在 **<UI-TERM key="oms-community.pages.Migration.MigrationProject">迁移任务列表</UI-TERM>** 页面，选择需要批量正向切换的数据迁移任务。

2. 单击页面下方的 **<UI-TERM key="oms-community.Migration.constants.BatchForwardSwitching.1">批量正向切换</UI-TERM>**。

   ![batch-forward0-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/batch-forward0-zh.png)

3. 在弹出对话框中，单击 **<UI-TERM key="oms-community.biz.AccountAuthorization.Ok">确定</UI-TERM>**。

   该对话框会提示您可以批量正向切换的任务个数、任务名称和最新位点。

   ![batch-forward1-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/batch-forward1-zh.png)

4. 在 **<UI-TERM key="oms-community.Migration.constants.BatchForwardSwitching.1">批量正向切换</UI-TERM>** 对话框，根据界面提示依次进行操作。

   1. 启动正向切换

      单击 **<UI-TERM key="oms-community.components.SyncSwitch.ConfirmStartSwitch.StartAForwardSwitch">启动正向切换</UI-TERM>** 区域右上角的 **<UI-TERM key="oms-community.BatchSelect.constants.ConfirmStartup">确认启动</UI-TERM>**，即可批量启动正向切换。您也可以单击任务后的 **<UI-TERM key="oms-community.BatchSelect.constants.Start">启动</UI-TERM>**，进行单个任务启动。

      ![batch-forward2-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/batch-forward2-zh.png)

   2. 切换预检查

      该步骤用于检查当前任务状态是否具备切换条件。如果预检查通过，会自动执行下一步操作。如果预检查未通过，会提示报错详情。

      ![batch-forward3-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/batch-forward3-zh.png)

      如果预检查未通过，您可以进行 **<UI-TERM key="oms-community.components.SyncSwitch.ConfirmReverseSync.TryAgain">重试</UI-TERM>** 或 **<UI-TERM key="oms-community.Migration.constants.Skip">跳过</UI-TERM>** 操作。如果单击 **<UI-TERM key="oms-community.components.SyncSwitch.PreCheckSubStep.Skip">跳过</UI-TERM>**，您需要在弹出的对话框中，再次单击 **<UI-TERM key="oms-community.Sync.constants.Skip">跳过</UI-TERM>**。

   3. 启动目标端 Store

      启动目标端增量拉取，创建并启动目标端 Store。如果启动失败，您可以进行 **<UI-TERM key="oms-community.Migration.constants.TryAgain">重试</UI-TERM>** 或 **<UI-TERM key="oms-community.Sync.constants.Skip">跳过</UI-TERM>** 操作。

      ![batch-forward4-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/batch-forward4-zh.png)

   4. 确认源端停写

      单击 **确认源端停写** 区域右上角的 **<UI-TERM key="oms-community.constants.dist.Confirm">确认</UI-TERM>**，即可批量运行该子步骤。您也可以依次单击任务后的 **<UI-TERM key="oms-community.constants.dist.Confirm">确认</UI-TERM>**，进行单个任务运行。

      ![batch-forward5-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/batch-forward5-zh.png)

   5. 确认同步追平停写位点

      OMS 社区版自动检查源端和目标端处于一致位点。检查完成后，展示当前增量同步延迟时间和增量同步位点。在同步追平停写位点失败的场景下，您可以进行 **<UI-TERM key="oms-community.components.BatchSelect.BatchActions.Retry">重试</UI-TERM>** 或 **<UI-TERM key="oms-community.components.SyncSwitch.PreCheckSubStep.Skip">跳过</UI-TERM>** 操作。

      ![batch-forward6-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/batch-forward6-zh.png)

   6. 停止正向同步

      停止源端到目标端的增量同步。如果停止失败，您可以进行 **<UI-TERM key="oms-community.ModifyRecordTable.constants.Retry">重试</UI-TERM>** 或 **<UI-TERM key="oms-community.Operation.components.operationDetail.Skip">跳过</UI-TERM>** 操作。

       ![batch-forward7-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/batch-forward7-zh.png)

   7. 执行数据库对象处理

      单击 **执行数据库对象处理** 区域右上角的 **<UI-TERM key="oms-community.constants.dist.MarkComplete">标记完成</UI-TERM>**，即可批量执行数据库对象。您也可以依次单击执行任务后的 **<UI-TERM key="oms-community.constants.dist.MarkComplete">标记完成</UI-TERM>**，进行单个任务运行。待全部标记完成后，进行下一步。

        ![batch-forward8-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/batch-forward8-zh.png)

   8. 启动反向增量

      单击 **<UI-TERM key="oms-community.components.SyncSwitch.ConfirmReverseSync.StartReverseIncremental">启动反向增量</UI-TERM>** 区域右上角的 **<UI-TERM key="oms-community.BatchSelect.constants.ConfirmStartup">确认启动</UI-TERM>**，即可批量启动目标端到源端的增量写入。您也可以依次单击任务后的 **<UI-TERM key="oms-community.Migration.constants.Start">启动</UI-TERM>**，进行单个任务启动。等待页面提示 **反向增量启动成功** 即可。

       ![batch-forward9-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/batch-forward9-zh.png)

## 批量修改告警配置

OMS 社区版支持处于 **<UI-TERM key="oms-community.Sync.constants.NotStarted.5">未启动</UI-TERM>**、**<UI-TERM key="oms-community.src.constants.Running">运行中</UI-TERM>**、**<UI-TERM key="oms-community.Sync.constants.Paused">已暂停</UI-TERM>** 和 **<UI-TERM key="oms-community.components.BatchSelect.BatchSwitch.Failed">失败</UI-TERM>** 状态的数据迁移任务进行 **<UI-TERM key="oms-community.Migration.model.migration.vm.ModifyAlertConfigurationsInBatches">批量修改告警配置</UI-TERM>** 操作。

1. 在 **<UI-TERM key="oms-community.pages.Migration.MigrationProject">迁移任务列表</UI-TERM>** 页面，选择需要批量修改告警配置的数据迁移任务。

2. 单击页面下方的 **<UI-TERM key="oms-community.components.BatchSelect.MoreBatchOperations">更多批量操作</UI-TERM>** \> **<UI-TERM key="oms-community.Migration.model.migration.vm.ModifyAlertConfigurationsInBatches">批量修改告警配置</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.utils.hooks.useOMSWarn.ConfigureMultipleAlerts">批量设置告警</UI-TERM>** 对话框，修改告警级别。

   ![batch-modify-alert-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/batch-modify-alert-zh.png)

   OMS 社区版支持的告警级别包括 **<UI-TERM key="oms-community.components.WarnLevel.Unprotected">无保护</UI-TERM>**、**<UI-TERM key="oms-community.components.WarnLevel.HighProtection">高保护</UI-TERM>**、**<UI-TERM key="oms-community.components.WarnLevel.MediumProtection">中保护</UI-TERM>** 和 **<UI-TERM key="oms-community.components.WarnLevel.DiBaoHu">低保护</UI-TERM>**，详情请参见 [告警设置](../../1000.system-management/200.alert-center/300.manage-alert-settings.md)。

4. 单击 **<UI-TERM key="oms-community.OCP.components.OCPForm.Submitted">提交</UI-TERM>**。

   如果您需要查看数据迁移或数据同步任务的告警监控消息，请参见 [查看任务告警信息](../../1000.system-management/200.alert-center/100.view-project-alerts.md)。

5. 批量修改告警设置成功后，页面会进行提示。如果有操作失败的任务，请根据页面提示进行排查。

![batch-skip-verification-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/batch-skip-verification-zh.png)

1. 在 **<UI-TERM key="oms-community.pages.Migration.MigrationProject">迁移任务列表</UI-TERM>** 页面，选择需要批量跳过全量校验的数据迁移任务。

2. 单击页面下方的 **<UI-TERM key="oms-community.components.BatchSelect.MoreBatchOperations">更多批量操作</UI-TERM>** \> **<UI-TERM key="oms-community.Migration.constants.SkipFullVerificationInBatches">批量跳过全量校验</UI-TERM>**。

3. 在弹出对话框中，单击 **<UI-TERM key="oms-community.pages.User.Confirmation">确定</UI-TERM>**。

   该对话框会提示您可以批量跳过全量校验的任务个数、任务名称和最新位点。

4. 待批量跳过全量校验成功后，页面会进行提示并告知您批量操作成功的任务个数。

   如果有操作失败的任务，请根据页面提示进行排查。
