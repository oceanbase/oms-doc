# 管理计算平台

使用 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版迁移 HBase 数据库的数据至 OBKV 时，全量迁移和增量同步组件支持在计算平台运行。本文为您介绍如何新建、编辑和删除计算平台。

## 前提条件

* 使用 FLINK 计算平台类型时，已获取下表中 FLINK 计算平台的必填配置项。

    ![omsce5-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-ce/omsce5-zh.png)

    | 参数  |  描述    |
    |--------------|--------------------|
    |jobmanager.rpc.address| `jobmanager` 地址。|
    |jobmanager.rpc.port | `jobmanager` 端口。|
    |rest.port | `rest` 服务端口。|

* 使用 SPARK 计算平台类型时，已获取 SPARK 计算平台的必填配置项 `master`。

     ![omsce6-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-ce/omsce6-zh.png)

    `master` 是指 Spark URL，您可以以通过 Spark Web UI 页面获取。

    ![omsce4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-ce/omsce4.png)

## 新建计算平台

1. 新建 HBase 数据库至 OBKV 或 Hive 数据库至 OceanBase 社区版的数据迁移任务，并配置至 **<UI-TERM key="oms-community.Migration.New.MigrationOptions">迁移选项</UI-TERM>** 步骤。

    详情请参见 [迁移 HBase 数据库的数据至 OBKV](../400.create-a-project-to-migrate-data-from-hbase-to-obkv.md) 或 [迁移 Hive 的数据至 OceanBase 社区版](../1401.create-a-task-to-migrate-data-from-hive-to-ob.md)。

2. 在 **<UI-TERM key="oms-community.Operation.constants.FullMigration">全量迁移</UI-TERM>** 或 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.IncrementalMigration">增量同步</UI-TERM>** 区域，单击 **<UI-TERM key="oms-community.migration.new.components.communityForm.platform">计算平台</UI-TERM>** 下拉列表中的 **<UI-TERM key="oms-community.migration.new.components.communityForm.managePlatform">管理计算平台</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.migration.new.components.communityForm.managePlatform">管理计算平台</UI-TERM>** 对话框，单击右上角的 **<UI-TERM key="oms-community.migration.new.components.communityForm.createPlatform">新建计算平台</UI-TERM>**。

4. 在 **<UI-TERM key="oms-community.migration.new.components.communityForm.createPlatform">新建计算平台</UI-TERM>** 对话框，配置各项参数。

    | 参数  | 描述 |
    |-------------|-------------------|
    | 计算平台名称 | 自定义计算平台的名称。  |
    | 计算平台类型 | 目前支持 **FLINK** 和 **SPARK**。  |
    | 参数配置  | 默认显示必填的配置参数，请参见《前提条件》的参数描述。 |
    | 配置文件 | <ul><li>HBase 集群的配置文件 `hbase-site.xml`。  <li>Hive 集群的配置文件 `hive-site.xml`。</ul> |
    | 备注（可选） | 计算平台的备注信息。  |

5. 单击 **<UI-TERM key="oms-community.pages.OCP.constant.TestConnection">测试连接</UI-TERM>**。

6. 测试连接成功后，单击 **<UI-TERM key="oms-community.Audit.constants.Create">新建</UI-TERM>**。

## 编辑计算平台

1. 进入 **<UI-TERM key="oms-community.migration.new.components.communityForm.managePlatform">管理计算平台</UI-TERM>** 对话框，单击目标计算平台后的 **<UI-TERM key="oms-community.Endpoint.constants.Editing">编辑</UI-TERM>**。

2. 在 **<UI-TERM key="oms-community.migration.new.components.communityForm.editPlatform">编辑计算平台</UI-TERM>** 对话框，编辑需要修改的参数。

3. 单击 **<UI-TERM key="oms-community.EndpointPublic.components.FormContent.TestConnection">测试连接</UI-TERM>**。

4. 测试连接成功后，单击 **<UI-TERM key="oms-community.Audit.constants.Create">修改</UI-TERM>**。

## 删除计算平台

进入 **<UI-TERM key="oms-community.migration.new.components.communityForm.managePlatform">管理计算平台</UI-TERM>** 对话框，单击目标计算平台后的 **<UI-TERM key="oms-community.Sync.Detail.Delete">删除</UI-TERM>**，即可删除不再使用的计算平台。
