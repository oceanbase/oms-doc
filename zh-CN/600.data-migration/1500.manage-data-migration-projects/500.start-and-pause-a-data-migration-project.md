# 启动和暂停数据迁移任务

本文为您介绍如何启动、暂停和恢复数据迁移任务。

## 启动数据迁移任务

创建数据迁移任务时，如果在预检查完成后仅保存该数据迁移任务，未进行启动，则需要在迁移任务列表中手动启动数据迁移任务。

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.New.components.EndpointForm.DataMigration">数据迁移</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.Migration.Detail.DataMigration">数据迁移</UI-TERM>** 页面，单击目标任务后的 **<UI-TERM key="oms-community.BatchSelect.constants.Start">启动</UI-TERM>**。

   您也可以在 **<UI-TERM key="oms-community.Migration.Detail.DataMigration">数据迁移</UI-TERM>** 页面，单击任务名称进入详情页面，单击右上角的 **<UI-TERM key="oms-community.Sync.constants.Start">启动</UI-TERM>**。

## 暂停数据迁移任务

仅运行中的数据迁移任务支持暂停操作。暂停数据迁移任务后，OMS 社区版会中止编排任务列表中正在运行状态的子任务，并自动终止其后面所有子任务的调度。

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.src.constants.DataMigration">数据迁移</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.src.constants.DataMigration">数据迁移</UI-TERM>** 页面，单击目标任务后的 **<UI-TERM key="oms-community.Operator.constants.Pause">暂停</UI-TERM>**。

   您也可以在 **<UI-TERM key="oms-community.Migration.New.DataMigration">数据迁移</UI-TERM>** 页面，单击任务名称进入详情页面，单击右上角的 **<UI-TERM key="oms-community.src.constants.Pause">暂停</UI-TERM>**。

4. 在对话框中，单击 **<UI-TERM key="oms-community.Endpoint.New.Add">确定</UI-TERM>**。

   <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>本操作将暂停实时同步组件，全量校验组件（如有）、全量迁移组件（如有），且任务暂停时长超过 12 小时，任务无法被恢复。</p>
   </main>

## 恢复数据迁移任务

您可以手动恢复暂停或失败的数据迁移任务的运行。OMS 社区版会从编排任务列表中，第一个待执行状态的任务开始依次执行各个子任务。

1. 登录 OMS 社区版控制台。

2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.New.components.EndpointForm.DataMigration">数据迁移</UI-TERM>**。

3. 在 **<UI-TERM key="oms-community.components.CustomizedTable.DataMigration">数据迁移</UI-TERM>** 页面，单击目标任务后的 **<UI-TERM key="oms-community.Sync.constants.Recovery">恢复</UI-TERM>**。

   您也可以在 **<UI-TERM key="oms-community.New.components.EndpointForm.DataMigration">数据迁移</UI-TERM>** 列表页面，单击任务名称进入详情页面，单击右上角的 **<UI-TERM key="oms-community.Sync.constants.Recovery">恢复</UI-TERM>**。
