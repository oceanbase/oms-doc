# 迁移 OBKV 的增量数据至 HBase 数据库

本文为您介绍如何使用 OceanBase 迁移服务（OceanBase Migration Service，OMS）社区版迁移 OBKV 的增量数据至 HBase 数据库。

## 背景信息

在 OMS 社区版控制台创建从 OBKV 迁移数据至 HBase 数据库的数据迁移任务，您可以迁移源端数据库中的增量数据至 OBKV。OBKV 的详情请参见 [OBKV 简介](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000000900468)。

## 使用限制

* 目前支持 HBase 数据库 V1.2.0-cdh5.15.2 和 V2.4.13。

* OBKV 表名的格式为 `表名$列族名`，增量同步任务仅支持迁移该格式的表。

* OMS 社区版仅支持迁移库名、表名和列名为 ASCII 码且不包含特殊字符（包括换行、空格，以及 |"'`()=;/&）的对象。

* 建议您一次性迁移的表数量不超过 1000 张，避免影响数据迁移任务的运行。

## 操作步骤

1. 新建数据迁移任务。

   1. 登录 OMS 社区版控制台。

   2. 在左侧导航栏，单击 **<UI-TERM key="oms-community.layout.constants.DataMigration">数据迁移</UI-TERM>**。

   3. 在 **<UI-TERM key="oms-community.layout.constants.DataMigration">数据迁移</UI-TERM>** 页面，单击右上角的 **<UI-TERM key="oms-community.Migration.Empty.CreateAMigrationProject">新建迁移任务</UI-TERM>**。

2. 在 **<UI-TERM key="oms-community.Sync.New.SelectSourceAndDestination">选择源和目标</UI-TERM>** 页面，配置各项参数。

   |   参数   |                  描述                          |
   |--------|------------------------------------------------|
   | 迁移任务名称 | 建议使用中文、数字和字母的组合。名称中不能包含空格，长度不能超过 64 个字符。                                                                                                                                                 |
   | 标签     | 单击文本框，在下拉列表中选择目标标签。您也可以单击 **<UI-TERM key="oms-community.components.ProjectLabel.LabelSelect.ManageTags">管理标签</UI-TERM>**，进行新建、修改和删除。详情请参见 [通过标签管理数据迁移任务](1500.manage-data-migration-projects/300.use-tags-to-manage-data-migration-projects.md)。                                                                            |
   | 源端     | 如果您已创建 OceanBase 社区版数据源，请从下拉列表中进行选择。如果未创建，请单击下拉列表中的 **<UI-TERM key="oms-community.pages.Endpoint.AddADataSource">新建数据源</UI-TERM>**，在右侧对话框进行新建。参数详情请参见 [新建 OceanBase-CE 数据源](../800.create-and-manage-data-sources/100.create-a-data-source/100.add-an-oceanbase-ce-data-source.md)。   <br>当您选择的源端数据源已在其他数据迁移任务中作为目标端数据源，请配置是否需要过滤 OMS 写入数据。选择过滤时，如果该数据源已被多个任务使用，OMS 社区版将会默认获取最新创建的数据迁移任务。                                                               |
   | 目标端    |  如果您已创建 HBase 数据源，请从下拉列表中进行选择。如果未创建，请单击下拉列表中的 **<UI-TERM key="oms-community.EndpointPublic.Empty.AddADataSource">新建数据源</UI-TERM>**，在右侧对话框进行新建。参数详情请参见 [新建 HBase 数据源](../800.create-and-manage-data-sources/100.create-a-data-source/1000.create-a-hbase-data-source.md)。   |
   | 使用场景  | 目前仅支持 **<UI-TERM key="oms-community.Migration.Detail.DataMigration">数据迁移</UI-TERM>**。|

3. 单击 **<UI-TERM key="oms-community.Sync.New.Next">下一步</UI-TERM>**。在 **<UI-TERM key="oms-community.Migration.New.SelectMigrationType">选择迁移类型</UI-TERM>** 页面，选择当前迁移任务的迁移类型。

    目前仅支持 **<UI-TERM key="oms-community.components.SyncOption.CheckSyncKind.IncrementalSynchronization">增量同步</UI-TERM>** 中的 **<UI-TERM key="oms-community.components.SyncOption.CheckSyncKind.DataChangeDml">同步 DML</UI-TERM>**，详情请参见 [DML 过滤](../600.data-migration/1600.migration-function-introduction/100.migration-dml.md)。

4. 单击 **<UI-TERM key="oms-community.Sync.New.Next">下一步</UI-TERM>**。在 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.SelectObjectsToBeMigrated">选择迁移对象</UI-TERM>** 页面，选择迁移对象和迁移范围。

   您可以通过 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.SpecifiedObject">指定对象</UI-TERM>** 和 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.MatchRules">匹配规则</UI-TERM>** 两个入口选择迁移对象。本文为您介绍通过 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.SpecifiedObject">指定对象</UI-TERM>** 方式选择迁移对象的具体操作，配置匹配规则的详情请参见 [配置迁移对象的匹配规则](../600.data-migration/1600.migration-function-introduction/300.configure-matching-rules-for-migration-objects.md)。

      <main id="notice" type='notice'>
      <h4>注意</h4>
      <ul>
      <li>
      <p>待迁移的表名和其中的列名不能包含中文字符。</p>
      </li>
      <li>
      <p>当数据库的库名或表名存在 &quot;$$&quot; 字符时，会影响数据迁移任务的创建。</p>
      </li>
      </ul>
      </main>

    ![migration-5-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/migration-5-zh.png)

     OMS 社区版支持通过文本导入对象、重命名对象名称、设置行过滤、查看列信息，以及移除单个或全部迁移对象。

     |   操作    |                                   步骤                                                                          |
     |---------|---------------------------------------------------------------------------------------------------|
     | 导入对象    | <ol><li> 在 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.SelectAMigrationRange">选择迁移范围</UI-TERM>** 区域的右侧列表中，单击右上角的 **<UI-TERM key="oms-community.components.Transfer.ImportObjects">导入对象</UI-TERM>**。   <li>在对话框中，单击 **<UI-TERM key="oms-community.Migration.hooks.useMigrationObject.Determine">确定</UI-TERM>**。<br> **注意：**<br> 导入会覆盖之前的操作选择，请谨慎操作。  <li>在 **导入迁移对象** 对话框中，导入需要迁移的对象。<br>您可以通过导入 CSV 文件的方式进行库表重命名、设置行过滤条件等操作。详情请参见 [下载和导入迁移对象配置](../600.data-migration/1500.manage-data-migration-projects/400.download-and-import-the-settings-of-migration-objects.md)。   <li> 单击 **<UI-TERM key="oms-community.components.ImportTransferObj.TestLegality">检验合法性</UI-TERM>**。   <li> 通过合法性的检验后，单击 **<UI-TERM key="oms-community.Detail.components.MigrationSteps.Determine">确定</UI-TERM>**。</ol>    |
     | 重命名     | OMS 社区版支持重命名迁移对象的名称，详情请参见 [数据库库表重命名](../600.data-migration/1600.migration-function-introduction/500.db-table-rename.md)。  <br>请注意重命名的表名也需要符合 OBKV 表名的格式 `表名$列族名`。                     |
     | 设置      | OMS 社区版支持 `WHERE` 条件实现行过滤，详情请参见 [SQL 条件过滤数据](../600.data-migration/1600.migration-function-introduction/600.migration-row-filters.md)。<br>您还可以在 **<UI-TERM key="oms-community.biz.ETL.ETLDescription.ViewColumns">查看列</UI-TERM>** 区域，查看迁移对象的列信息。                      |
     | 移除/全部移除 | OMS 社区版支持在数据映射时，对暂时选中到目标端的单个或多个对象进行移除操作。 <ul><li>移除单个迁移对象 <br>在 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.SelectAMigrationRange">选择迁移范围</UI-TERM>** 区域的右侧列表中，鼠标悬停至目标对象，单击显示的 **<UI-TERM key="oms-community.common.TreeSearch.TargetNode.Remove">移除</UI-TERM>**，即可移除该迁移对象。  <li> 移除全部迁移对象 <br>在 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.SelectAMigrationRange">选择迁移范围</UI-TERM>** 区域的右侧列表中，单击右上角的 **<UI-TERM key="oms-community.Transfer.target.RemoveAll">全部移除</UI-TERM>**。在对话框中，单击 **<UI-TERM key="oms-community.Operator.Connector.useConnectorAction.MigrationConfirm">确定</UI-TERM>**，即可移除全部迁移对象。  </ul>   |

5. 单击 **<UI-TERM key="oms-community.Sync.New.Next">下一步</UI-TERM>**。在 **<UI-TERM key="oms-community.Migration.New.MigrationOptions">迁移选项</UI-TERM>** 页面，配置增量同步的各项参数。

   如果您需要查看或修改增量同步组件参数，请单击 **<UI-TERM key="oms-community.New.components.MigrationObjectForm.IncrementalMigration">增量同步</UI-TERM>** 区域右上角的 **<UI-TERM>Store 配置详情</UI-TERM>** 或 **<UI-TERM>incr 增量配置详情</UI-TERM>**。参数说明请参见 [组件参数说明](../900.o-m-manual/400.components/500.component-parameters/100.coordinator.md) 模块的文档。

    |参数|描述|
    |----|----------------------------------|
    | 并发速度 | 包括 **<UI-TERM key="oms-community.New.components.ParameterForm.Smooth">平稳</UI-TERM>**、**<UI-TERM key="oms-community.Notification.Setting.AlarmChannel.Normal">正常</UI-TERM>**、**<UI-TERM key="oms-community.components.MigrationParamsConfig.MigrationParamsForm.Quick">快速</UI-TERM>** 和 **<UI-TERM key="oms-community.New.components.ParameterForm.Custom">自定义</UI-TERM>**。增量同步的性能不同，增量同步任务所需要的资源也不同。当您选择 **<UI-TERM key="oms-community.New.components.ParameterForm.Custom">自定义</UI-TERM>** 时，可以根据实际情况设置 **<UI-TERM key="oms-community.migration.new.components.communityForm.readConcurrency">读取并发</UI-TERM>**、**<UI-TERM key="oms-community.migration.new.components.communityForm.writeConcurrency">写入并发</UI-TERM>** 和 **<UI-TERM key="oms-community.migration.new.components.communityForm.jvmMemory">JVM 内存</UI-TERM>**。|
    |增量同步起始位点| 请在此处指定迁移某个时间节点之后的数据，默认为当前系统时间。详情请参见 [设置增量同步位点](../600.data-migration/1600.migration-function-introduction/1000.incremental-synchronization-timestamp.md)。  |
    |增量记录保存时间| OMS 社区版中增量解析文件缓存的时长。配置的保存时间越长，OMS 社区版 Store 组件需要消耗的磁盘空间越大。  |

6. 单击 **<UI-TERM key="oms-community.SystemParam.contants.Precheck">预检查</UI-TERM>**，系统对数据迁移任务进行预检查。

   在 **<UI-TERM key="oms-community.SystemParam.contants.Precheck">预检查</UI-TERM>** 环节，OMS 社区版会检查数据库用户的读写权限、数据库的网络连接等是否符合要求。全部检查任务均通过后才能启动数据迁移任务。如果预检查报错：

   * 您可以排查并处理问题后，重新执行预检查，直至预检查成功。

   * 您也可以单击错误预检查项操作列中的 **<UI-TERM key="oms-community.components.SyncSwitch.StopSync.Skip">跳过</UI-TERM>**，会弹出对话框提示您跳过本操作的具体影响，确认可以跳过后，请单击对话框中的 **<UI-TERM key="oms-community.components.ViewObj.AddObject.Ok">确定</UI-TERM>**。

7. 单击 **<UI-TERM key="oms-community.components.MigrationPreTable.StartAProject">启动任务</UI-TERM>**。如果您暂时无需启动任务，请单击 **<UI-TERM key="oms-community.components.ViewObj.AddObject.Save">保存</UI-TERM>**，跳转至数据迁移任务的详情页面，您可以根据需要进行手动启动。

      OMS 社区版支持在数据迁移任务运行过程中修改迁移对象，详情请参见 [查看和修改迁移对象](../600.data-migration/1500.manage-data-migration-projects/200.view-and-modify-migration-objects.md)。数据迁移任务启动后，会根据选择的迁移类型依次执行，详情请参见 [查看数据迁移任务的详情](../600.data-migration/1500.manage-data-migration-projects/100.view-details-of-a-data-migration-project.md) 中《查看迁移详情》模块的内容。
