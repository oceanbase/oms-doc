# Product updates

This topic describes the features of OceanBase Migration Service (OMS) Community Edition V4.2.5-CE.

<main id="notice" type='notice'>
<h4>Note</h4>
<p>Only OMS Community Edition V4.2.4-CE can be upgraded to V4.2.5-CE. Versions earlier than V4.2.4-CE cannot be upgraded to V4.2.5-CE.</p>
</main>

## New features

* Supports full data migration from Qdrant to an OceanBase vector store.

* Supports incremental synchronization of DDL operations in data migration tasks when MariaDB is the source database.

* Supports the migration of tables without primary keys from PostgreSQL databases.

## Usability improvements

* Adds a local cache for OceanBase Database V3.x metadata and allows OMS Community Edition to query the cached metadata directly when you create a task. This resolves failures to create data migration tasks when an OceanBase Database V3.x source contains a large number of tables.

* Supports one-click forward switchover.

* Supports role-based authorization for MySQL and OceanBase Database migration users.

* Supports the migration of MySQL databases whose names contain Chinese characters.

* Supports Debian 12.

* On the **OPS & Monitoring** > **Components** > **Store** page, provides links from Store components to their associated data migration or data synchronization tasks.

* Displays a warning and provides a link to the performance tuning documentation when the estimated full migration time exceeds two days.
