# What's New

This topic describes the features of OceanBase Migration Service (OMS) Community Edition V4.2.14-CE.

<main id="notice" type='notice'>
<h4>Notice</h4>
<p>Currently, only OMS Community Edition V4.2.0-CE through V4.2.13-CE can be upgraded to V4.2.14-CE. Versions earlier than V4.2.0-CE cannot be upgraded directly to V4.2.14-CE.</p>
</main>

## New features

* Supports data migration and synchronization for OceanBase Database Community Edition V4.6.0.

* Elasticsearch migration to OceanBase link

  * Supports schema migration from Elasticsearch to OceanBase Database Community Edition.
  * Supports migration from Elasticsearch V9.x.
  * Supports full verification for Elasticsearch migration to OceanBase.

* MongoDB migration to OceanBase link

  * Supports full verification for MongoDB migration to OceanBase.
  * Supports specifying fields to exclude during migration when creating a migration link in MongoDB.

* TiDB migration to OceanBase link  

  * Supports incremental TiCDC in Canal-Json format for TiDB.

* Supports migration from MySQL 8.4 to OceanBase Database Community Edition.

* Migration links support the incremental store sharing feature of OceanBase Database.

## Usability improvements

* HA node scheduling optimization.

* Link exception alert optimization.

* The OMS deployment script now uses Python 3 instead of Python 2 and supports TLS 1.3 for the metadata database.

* Supports creating a TiDB data source via API.

* Supports changing the data source password.

* Supports synchronizing an empty database to Kafka.

* Supports maintaining heartbeats when no incremental data is generated during synchronization from OceanBase Database to Kafka.

* Optimization for full migration of partitioned tables in ClickHouse.

* API CreateProject supports setting sink parameters.
