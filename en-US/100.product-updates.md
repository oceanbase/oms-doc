# What's New

This topic describes the features of OceanBase Migration Service (OMS) Community Edition V4.2.6.

<main id="notice" type='notice'>
<h4>Notice</h4>
<p>Only OMS Community Edition V4.2.5 can be upgraded to OMS Community Edition V4.2.6. </p>
</main>

## New features

* OMS Community Edition supports full data migration from a Milvus database to an OceanBase vector store.

* OMS Community Edition supports full data migration from a Redis database to an OBKV Redis database.

## Usability improvements

* OMS Community Edition allows you to configure Kafka consumer groups when you synchronize incremental data from a TiDB database to OceanBase Database.

* OMS Community Edition supports upgraded direct load API operations for OceanBase Database Community Edition. This improves the stability of direct load in concurrency scenarios.

* OMS Community Edition supports resource precheck before you add objects to a data migration or synchronization task. This avoids failures during task execution.

* OMS Community Edition supports Ubuntu.
