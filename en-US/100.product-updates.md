# What's New

This topic describes the features of OceanBase Migration Service (OMS) Community Edition V4.2.10.

<main id="notice" type='notice'>
<h4>Notice</h4>
<p>Only OMS Community Edition V4.2.0 to V4.2.9 can be upgraded to OMS Community Edition V4.2.10. </p>
</main>

## New features

* OMS Community Edition V4.2.10 supports schema migration, full migration, and incremental synchronization from OceanBase Database Community Edition to an Elasticsearch database.

* OMS Community Edition V4.2.10 supports schema migration and incremental synchronization when you migrate data from Milvus to OceanBase Database Community Edition.

* OMS Community Edition V4.2.10 supports migrating the TTL information of HBase to OceanBase Key-Value (OBKV).

* OMS Community Edition V4.2.10 supports schema migration of the table TTL information of OceanBase Database Community Edition.

* OMS Community Edition V4.2.10 supports full migration from a MongoDB database to OceanBase Database Community Edition.

* OMS Community Edition V4.2.10 supports data migration from MariaDB V10.2 to V10.6.x to OceanBase Database Community Edition.

## Usability improvements

* The component monitoring page supports status filtering.

* The Canal serialization method supports the dateConvertFormat parameter for configuring the output format of time types.

* When you release a task of OMS Community Edition, all component directories of the task are deleted.

* When you migrate data from a TiDB database to OceanBase Database Community Edition, the PROCESS privilege is pre-checked.

* When you migrate data from a PostgreSQL database to OceanBase Database Community Edition, the read-only privilege of the migration user is pre-checked.

* The serviceName parameter is added for the GSSAPI authentication of Kafka.
