# What's New

This topic describes the features of OceanBase Migration Service (OMS) Community Edition V4.2.13-CE.

<main id="notice" type='notice'>
<h4>Notice</h4>
<p>Currently, you can upgrade OMS Community Edition V4.2.0-CE  ~ V4.2.12-CE to V4.2.13-CE. You cannot upgrade OMS Community Edition V4.2.0-CE or earlier versions to V4.2.13-CE.</p>
</main>

## New features

* Supports incremental data synchronization from an ElasticSearch database to OceanBase Database Community Edition.

* Supports incremental data synchronization from a MongoDB database to OceanBase Database Community Edition.

* Supports migration of data from a MongoDB database V3.x to OceanBase Database Community Edition.

* Supports full data migration from a ClickHouse database to OceanBase Database Community Edition.

* Supports migration of data of the sparsevec type from a PostgreSQL database to OceanBase Database Community Edition.

* Supports OceanBase Database with TLS enabled.

  * Supports OceanBase Database data sources with TLS enabled.

  * Supports installing OMS Community Edition with OceanBase Database with TLS enabled as the metadata database.

* Supports excluding specified fields from a TiDB database during migration to OceanBase Database Community Edition.

## Usability improvements

* Supports OceanBase CDC nanoseconds.

* API task creation supports alert level configuration.
