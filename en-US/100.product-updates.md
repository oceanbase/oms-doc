# What's New

This topic describes the features of OceanBase Migration Service (OMS) Community Edition V4.2.8.

<main id="notice" type='notice'>
<h4>Notice</h4>
<p>Only OMS Community Edition V4.2.0 to V4.2.7 can be upgraded to OMS Community Edition V4.2.8. </p>
</main>

## New features

* OMS Community Edition V4.2.8 supports schema migration for columnstore data.

* OMS Community Edition V4.2.8 supports data migration from a Hive database to OceanBase Database Community Edition.

* OMS Community Edition V4.2.8 supports data writing from OceanBase Database Community Edition to MyCat.

## Usability improvements

* OMS Community Edition V4.2.8 supports manual schema adjustments before schema migration to meet special user needs.

* OMS Community Edition V4.2.8 supports special characters in a username used for login from a third-party system.

* OMS Community Edition V4.2.8 supports automatic refresh of the incremental synchronization performance page and reverse increment performance page for real-time performance monitoring.
