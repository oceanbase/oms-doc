# Delete a server

In the console of OceanBase Migration Service (OMS) Community Edition, you can delete a server on the **<UI-TERM>Servers</UI-TERM>** page under **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.OMMonitoring">OPS & Monitoring</UI-TERM>**. After a server is deleted, it will no longer be displayed on the console and OMS Community Edition will no longer issue tasks or schedule components on the server.

## Considerations

* Before you delete a server, make sure that the Store, Full-Import, Incr-Sync, and Full-Verification components on the server are removed and the associated tasks are released. If components exist on the server, you cannot delete the server.

* Deleting a server does not delete the OMS Community Edition container on the server. If you want to delete the container, you must do so manually.

* You can delete a server only in the Down or Unknown state.

## Procedure

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.OMMonitoring">OPS & Monitoring</UI-TERM>** > **<UI-TERM>Servers</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.Operation.Machine.MachineList">Servers</UI-TERM>** page of the target region, find the server that you want to delete.

    You can also search for the server by IP address in the search box in the upper-right corner.

4. In the Actions column of the target server, click **<UI-TERM key="oms-community.pages.User.Delete">Delete</UI-TERM>**.

5. In the dialog box that appears, click **<UI-TERM key="oms-community.components.TreeTransfer.TargetNode.Determine">OK</UI-TERM>**.
