# View server logs

If you encounter a fault or a high latency during a data migration or synchronization task, you can view the logs of the specific server components for troubleshooting. OceanBase Migration Service (OMS) Community Edition allows you to securely and conveniently view server logs without logging on to the specific server.

## Prerequisites

You have identified the components that are in error and obtained the IP address of the corresponding server. The underlying component name of the task resource contains the IP address of the server to which it belongs.

## Procedure

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.OMMonitoring">OPS & Monitoring</UI-TERM>** > **<UI-TERM key="oms-community.Operation.Machine.Machine">Server</UI-TERM>**.

3. Click **<UI-TERM key="oms-community.Operation.Machine.ViewLogs">View Logs</UI-TERM>** in the Actions column of the target server.

   * For single-region deployment, the region information is displayed on the right of **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Machine">Server</UI-TERM>**, and the region column is not displayed.

   * For multi-region deployment, you can filter servers by region and view the logs of servers in the target region.

4. Specify **<UI-TERM key="oms-community.Operation.Machine.logDrawer.LogLocation">Log Position</UI-TERM>**.

   By default, logs are stored in the `/home/admin/xxx` directory.

   ![View](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/view-en.png)

   * You can enter the name of the folder where the logs are stored to view all log files in the folder.

   * You can enter the path and the name of a log file to view its details.

5. Click **<UI-TERM key="oms-community.Operation.Machine.logDrawer.Search">Search</UI-TERM>**.

   The latest 1000 log entries are displayed. To refresh the logs, click **<UI-TERM key="oms-community.Operation.Machine.logDrawer.Search">Search</UI-TERM>** again.

   You can also download and copy logs.
