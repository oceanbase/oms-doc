# ElasticSearch Store

|  Parameter  |  Required  | Default value  | Description  |
|--------------|-------------|--------------|------------|
| es.host | Yes | N/A | The connection address of ElasticSearch. For example, `<http://10.10.10.1:9200>`. |
| es.port | Yes | N/A | The port of ElasticSearch. |
| es.username | No | N/A | The username of ElasticSearch. |
| es.password | No | N/A | The password of ElasticSearch. |
| es.pullThreadPoolSize | No | 16 | The size of the CCR pull thread pool. All index shards share the same pull thread pool. |
| es.whitelist | Yes | N/A | The allowlist. The wildcard expressions are separated by pipes (\|). The wildcard expressions can be `*.*`, `dbName.*`, or `dbName.tableName`. |
| es.blacklist | No | N/A | The blocklist. The wildcard expressions are separated by pipes (\|). The wildcard expressions can be `*.*`, `dbName.*`, or `dbName.tableName`. |
| es.usePluginApi | Yes | true | Specifies whether to use the plugin mode (install the OMS plugin for ElasticSearch). |
| es.startFromCurrentMaxSeqNo | Yes | false | Specifies whether to start from the maximum seqno. By default, it starts from the minimum seqno. |
| es_retentionLeaseEnabled | Yes | true | Specifies whether to enable the lease. If you disable this parameter, data may be lost. After the lease is enabled, the ElasticSearch server retains data for a period of time. The ES server parameter `index.soft_deletes.retention_lease.period` controls how long a retention lease remains valid. |
| es_retentionLeaseRenewIntervalSeconds | Yes | 30 | The lease renewal interval. |
| es.skipOnHistoryGap | Yes | false | Specifies whether to skip when encountering a seqno gap. By default, an error is returned if a gap is encountered. |
| es_retentionLeaseRemoveOnStop | Yes | false | Specifies whether to remove the lease when the Store component stops. By default, the lease is not removed. The ES server parameter `index.soft_deletes.retention_lease.period` controls how long a retention lease remains valid. |
