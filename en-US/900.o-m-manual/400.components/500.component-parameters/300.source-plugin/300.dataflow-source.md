# DataFlowSource

## Bootstrap class

connector-dataflow.jar

com.oceanbase.oms.connector.source.dataflow.DataFlowSourceBooster

## 【Metadata】clients

* Function: Data source information

* Default value: None, required

* Value selection range:

    ```JSON
    {
      "clientId": "clientId, unique identifier",
      "cluster": "OB cluster",
      "tenant": "OB tenant",
      "instance": "ip:port/[schema]", // The schema must exist in a PostgreSQL, DB2 LUW, or Oracle database.
      "tableWhiteLists": { // This configuration only applies to logical tables. Physical tables depend on the Conditions configuration, which is not effective.
        "db": ["tab", "tab2"]
      },
      "username": "Username",
      "password": "Password",
      "weakRead": "false", // Optional, default false
      "sysInstance": "System tenant instance, ip:port/[schema]", // Optional, default empty
      "sysTenantUsername": "System tenant name", // Optional, default empty
      "sysTenantPassword": "System tenant password" // Optional, default empty
    }
    ```

* Supported versions: OMS Community Edition V3.3.1-CE and later

## 【Connection】extConfig

* Function: Additional configuration for the source connection. The format is `map<string,string>`. The following configuration parameters are included:

  * useSSL: Specifies whether to enable SSL.

  * trustStore: Specifies the path of the trusted certificate.

  * trustStorePassword: Specifies the password of the trusted certificate.

  * keyStore: Specifies the path of the client key store.

  * keyStorePassword: Specifies the password of the client key store file.

  * disableSslHostnameVerification: Specifies whether to disable hostname verification.

* Supported versions: OMS Community Edition V4.2.13-CE and later

## 【Data Extraction】nullReplaceEnable

* Function: When the value of an Oracle GB18030 field is `chr(129)-chr(254)` and the field is NOT NULL, the JDBC driver reads it as NULL. This parameter specifies whether to enable character replacement in such cases.

* Default value: false

* Value range: true or false

* Supported versions: OMS Community Edition V3.3.1-CE and later

## 【Data Extraction】nullReplaceString

* Function: When the value of an Oracle GB18030 field is `chr(129)-chr(254)` and the field is NOT NULL, the JDBC driver reads it as NULL. This parameter specifies the replacement character to use when `nullReplaceEnable=true`.

* Default value: " "

* Value range: characters and strings

* Supported versions: OMS Community Edition V3.3.1-CE and later

## 【Data Extraction】ncharCharsetMap

* Function: For Oracle NVARCHAR2/NCCHAR types, the Oracle database reads these types with the NLS_NCHAR_CHARACTERSET configuration. This parameter maps the Oracle database's NLS_NCHAR_CHARACTERSET configuration to the character set encoding in Java.

* Default value: {"AL16UTF16":"UTF16"}

* Value range: JSON string

* Supported versions: OMS Community Edition V3.3.1-CE and later

## 【Data Extraction】rtrimOracleChar

* Function: When the source type is CHAR, whether to perform right-trimming. If all characters are spaces, one space is retained. The maximum length of a CHAR type is 2000. If the character set encoding of the source and target is inconsistent, the data may exceed the maximum length and fail to write to the target.

* Default value: false

* Value range: true or false

* Supported versions: OMS Community Edition V3.3.1-CE and later

## 【Data Extraction】intervalTypeFmt

* Function: Configure the formatting parameters for Oracle INTERVAL types.

  * When the source is an Oracle database and the target is not an Oracle or OceanBase database in Oracle-compatible mode.

  * When the target is an Oracle database and the source is not an Oracle or OceanBase database in Oracle-compatible mode.

    {"intervalDayDef":1,"intervalToSecondDef":1,"intervalYearDef":1,"intervalToMonthDef":2,"intervalSign":true,"intervalDayFmttime":2}

  * When the source is an OceanBase database in Oracle-compatible mode and the target is not an Oracle or OceanBase database in Oracle-compatible mode.

  * When the target is an OceanBase database in Oracle-compatible mode and the source is not an Oracle or OceanBase database in Oracle-compatible mode.

    {"intervalDayDef":2,"intervalToSecondDef":6,"intervalYearDef":1,"intervalToMonthDef":2,"intervalSign":true,"intervalDayFmttime":2}

* Default value: None

* Value range: JSON string

* Supported versions: OMS Community Edition V3.3.1-CE and later
