# View details of a Full-Verification component

The OPS & Monitoring module of OceanBase Migration Service (OMS) Community Edition allows you to view the basic information about a Full-Verification component, including the component name, task name, task type, and status. You can determine the running status of a Full-Verification component based on the basic information.

## Procedure

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.Welcome.constants.OMMonitoring">OPS & Monitoring</UI-TERM>** > **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Components">Component</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Components">Component</UI-TERM>** page, click the **<UI-TERM>Full-Verification</UI-TERM>** tab.

4. On the **<UI-TERM>Full-Verification</UI-TERM>** tab, view information about the target Full-Verification component.

   You can search for a Full-Verification component by component name, Migration Task Name, or server IP address.

5. View the basic information about the target Full-Verification component.
