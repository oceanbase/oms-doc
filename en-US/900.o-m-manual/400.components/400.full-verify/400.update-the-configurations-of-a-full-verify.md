# Update the configurations of a Full-Verification component

OceanBase Migration Service (OMS) Community Edition allows you to view and update the configurations of a specified Full-Verification component. When you update the configurations, the current configurations of the Full-Verification component are automatically displayed. You can view or modify the configurations of the Full-Verification component.

## Limits

OMS Community Edition allows you to update the configurations of a Full-Verification component in the **<UI-TERM key="oms-community.Operation.Overview.constants.Running">Running</UI-TERM>**, **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.Stopped">Stopped</UI-TERM>**, or **<UI-TERM>Exception</UI-TERM>** state.

## Procedure

1. Log on to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.SystemParam.contants.OMMonitoring">OPS & Monitoring</UI-TERM>** > **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Components">Component</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Components">Component</UI-TERM>** page, click the **<UI-TERM>Full-Verification</UI-TERM>** tab.

4. On the Full-Verification tab, you can search for a Full-Verification component by component name, server IP address, or data migration task name or ID.

   You can filter Full-Verification components by region and update the configurations of the Full-Verification components in the target region.

5. Click **<UI-TERM key="oms-community.Operation.components.machineCom.Update">Update</UI-TERM>** in the **<UI-TERM key="oms-community.components.MigrationPreTable.Operation">Actions</UI-TERM>** column of the target Full-Verification component.

6. In the **<UI-TERM key="oms-community.Operator.Checker.useCheckerAction.UpdateConfigurations">Update Configuration</UI-TERM>** dialog box, add a parameter or update the configurations. For more information, see [Component parameters](../500.component-parameters/100.coordinator.md).

To add a Full-Verification parameter, perform the following operations:

1. In the **<UI-TERM>Update Configuration</UI-TERM>** dialog box, move the pointer over the blank area next to the root parameter and click the add icon that appears.

2. Specify **Key Name** and click the check icon.

3. In the **</UI-TERM>Update Configuration</UI-TERM>** dialog box, find the new key name. Its default value is NULL.

4. Move the pointer over the new parameter and click the Edit icon that appears. Modify the parameter value and click the check icon.

To update the configurations of a Full-Verification component, perform the following operations:

   5. In the **<UI-TERM key="oms-community.Operator.Store.useStoreAction.UpdateConfigurations">Update Configuration</UI-TERM>** dialog box, move the pointer over the parameter to be modified and click the Edit icon that appears.

6. Modify the value in the text box and then click the confirm icon.

The green tick specifies to update the value and the red cross specifies to cancel the modification.

7. In the **<UI-TERM>Update Configuration</UI-TERM>** dialog box, click **<UI-TERM key="oms-community.components.ETL.ETLFormDrawer.Determine">OK</UI-TERM>**.

   3. On the **<UI-TERM key="oms-community.Operation.OperationComponent.Component">Component</UI-TERM>** page, click the **<UI-TERM>Full-Verification</UI-TERM>** tab.

4. On the Full-Verification tab, you can search for a Full-Verification component by component name, server IP address, or data migration task name or ID.

You can filter Full-Verification components by region and update the configurations of the Full-Verification components in the target region.

5. Click **<UI-TERM key="oms-community.Operation.Machine.Update">Update</UI-TERM>** in the **<UI-TERM key="oms-community.Notification.Setting.AlarmChannel.Operation">Actions</UI-TERM>** column of the target Full-Verification component.

6. In the **<UI-TERM key="oms-community.Operator.JDBCWriter.useJDBCWriterAction.UpdateConfigurations">Update Configuration</UI-TERM>** dialog box, add a parameter or update the configurations. For more information, see [Component parameters](../500.component-parameters/100.coordinator.md).

## Add a parameter or update the configurations on the Configuration List tab

### Add a parameter

1. Go to the **<UI-TERM>Configuration List</UI-TERM>** tab of the **<UI-TERM key="oms-community.Operator.Connector.useConnectorAction.UpdateConfigurations">Update Configuration</UI-TERM>** dialog box.

2. Click **<UI-TERM>+ Add</UI-TERM>** at the bottom of the page.

3. Enter the name of the parameter to be added in the first column and the value in the second column.

4. After the parameter is added, click **<UI-TERM key="oms-community.components.ImportTransferObj.Determine">OK</UI-TERM>** on the **<UI-TERM>Configuration List</UI-TERM>** tab.

You can click the delete icon next to the name of a parameter to delete the parameter.

### Update the configurations

1. Go to the **<UI-TERM>Configuration List</UI-TERM>** tab of the **<UI-TERM key="oms-community.Operator.Connector.useConnectorAction.UpdateConfigurations">Update Configuration</UI-TERM>** dialog box.

   2. Find the parameter to be modified and enter a new value in the second column.

3. You can also click the delete icon next to the name of a parameter to delete the parameter. You can also modify the value of **<UI-TERM key="oms-community.migration.new.components.communityForm.concurrencySpeed">Concurrency Speed</UI-TERM>** as needed.
