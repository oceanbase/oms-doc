# Delete a Full-Verification component

This topic describes how to delete a Full-Verification component to save running resources.

## Limitations

OceanBase Migration Service (OMS) Community Edition allows you to delete a Full-Verification component in the **<UI-TERM key="oms-community.Operation.constants.Stopped">Stopped</UI-TERM>**, **<UI-TERM>Exception**</UI-TERM>, or **<UI-TERM key="oms-community.Operation.Overview.constants.Completed">Completed</UI-TERM>** state.

## Procedure

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.OMMonitoring">OPS & Monitoring</UI-TERM>** > **<UI-TERM key="oms-community.Audit.constants.Component">Component</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Components">Component</UI-TERM>** page, click the **<UI-TERM>Full-Verification</UI-TERM>** tab.

4. On the Full-Verification page, you can search for a Full-Verification component by component name, server IP address, or Migration Task Name or ID.

   You can filter Full-Verification components by region and delete the Full-Verification components in the target region.

5. Click **<UI-TERM key="oms-community.components.ModifyRecordTable.MoreOperations">More</UI-TERM>** in the **<UI-TERM key="oms-community.pages.Audit.Operation">Actions</UI-TERM>** column of the target Full-Verification component and select **<UI-TERM key="oms-community.EndpointPublic.constants.Delete">Delete</UI-TERM>** from the drop-down list.

6. In the dialog box that appears, enter the name of the Full-Verification component and click **<UI-TERM key="oms-community.biz.AccountAuthorization.Ok">OK</UI-TERM>**.
