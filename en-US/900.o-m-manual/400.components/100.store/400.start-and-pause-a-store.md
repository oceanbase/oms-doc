# Start and pause a store

If the store corresponding to a data synchronization task fails, you can pause the store for troubleshooting and then restart the store. You can also stop and restart the store when an operational error occurs.

## Start a store

OceanBase Migration Service (OMS) Community Edition allows you to start a store in the **<UI-TERM key="oms-community.Operation.Overview.constants.Stopped">Stopped</UI-TERM>**, **Abnormal**, or **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.UnexpectedExit">Unexpected Exit</UI-TERM>** state.

1. Log on to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.Welcome.constants.OMMonitoring">OPS & Monitoring</UI-TERM>** **>** **<UI-TERM key="oms-community.Audit.constants.Component">Component</UI-TERM>**. The **<UI-TERM key="oms-community.components.MonitorDrawer.LogPullComponent">Store</UI-TERM>** tab automatically appears.

3. On the **<UI-TERM>Stores</UI-TERM>** page, click **<UI-TERM key="oms-community.Sync.constants.Start">Start</UI-TERM>** on the right of the target store, which must be in the **<UI-TERM>Exception</UI-TERM>** or **<UI-TERM key="oms-community.Operator.constants.Stopped">Stopped</UI-TERM>** state.

   You can filter stores by region and start the stores that are not running in the target region.

4. In the dialog box that appears, click **<UI-TERM key="oms-community.Operator.Store.useStoreAction.Update">OK</UI-TERM>**.

## Pause a store

OMS Community Edition allows you to pause a store in the **<UI-TERM key="oms-community.src.constants.Running">Running</UI-TERM>** state.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>Pausing a store may interrupt the data synchronization task and data migration task. Proceed with caution. </p>
  </main>

1. Log on to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.SystemParam.contants.OMMonitoring">OPS & Monitoring</UI-TERM>** **>** **<UI-TERM key="oms-community.components.MonitorDrawer.LogPullComponent">Store</UI-TERM>**. The **Stores** page automatically appears.

3. On the **<UI-TERM key="oms-community.components.MonitorDrawer.LogPullComponent">Store</UI-TERM>** tab, click **<UI-TERM key="oms-community.Operation.constants.Pause">Pause</UI-TERM>** in the Actions column of the target store.

   You can filter stores by region and pause the stores that are running in the target region.

4. In the dialog box that appears, click **<UI-TERM key="oms-community.components.ETL.ETLFormDrawer.Determine">OK</UI-TERM>**.
