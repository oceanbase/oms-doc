# View details of a store

The OPS & Monitoring module of OceanBase Migration Service (OMS) Community Edition allows you to view the basic information about a store, including the name, type, latency, and status. You can determine the running status of a store based on the basic information.

## Procedure

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.OMMonitoring">OPS & Monitoring</UI-TERM>** **>** **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Components">Component</UI-TERM>**. The **<UI-TERM key="oms-community.components.MonitorDrawer.LogPullComponent">Store</UI-TERM>** tab automatically appears.

3. On the **<UI-TERM key="oms-community.components.MonitorDrawer.LogPullComponent">Store</UI-TERM>** tab, view the basic information about the target store.

   You can search for a target store by store name, topic, subtopic, or task ID.

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>Fuzzy query is not supported on the Store tab. </p>
    </main>

   | **Parameter** | **<UI-TERM key="oms-community.User.New.DescriptionOptional">Description</UI-TERM>** |
   |------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   | Name | The name of the store.  |
   | Region | <ul><li>For single-region deployment, the region information is displayed on the right of **<UI-TERM key="oms-community.components.MonitorDrawer.LogPullComponent">Store</UI-TERM>**, and the region column is not displayed.    <li> For multi-region deployment, you can filter stores by region and view the stores in the target region. </ul> |
   | Type | The type of the source database.  |
   | RPS | The number of transactions handled by the server per second. It is used to measure the system throughput.  |
   | Latency | The difference between the time when data is written to the source database and the time when data is written to the target database.  |
   | Status | The status of the store. Valid values: **<UI-TERM key="oms-community.Migration.constants.Running">Running</UI-TERM>**, **<UI-TERM>Exception</UI-TERM>**, and **<UI-TERM key="oms-community.Operator.constants.Stopped">Stopped</UI-TERM>**.  |
   | Start Timestamp | The earliest event time of all LogRecords in the current store. The store saves a series of LogRecords (transaction log records) and each LogRecord corresponds to an event time, which indicates the time when this record is changed in the database or the time when the corresponding transaction is committed.   |
   | Current Timestamp | The latest event time of all LogRecords in the current store.  |
   | Connections | The number of downstream nodes during data processing of the store.  |
   | Actions | <ul><li>You can perform the following operations on a store in the **<UI-TERM key="oms-community.src.constants.Running">Running</UI-TERM>** state: **<UI-TERM key="oms-community.Operation.constants.Pause">Pause</UI-TERM>**, **<UI-TERM key="oms-community.Operator.Checker.DisableUpdateBtn.Update">Update</UI-TERM>**, and **<UI-TERM key="oms-community.components.SyncSwitch.DbObjectTable.ViewLogs">View Logs</UI-TERM>**. <li>You can perform the following operations on a store in the **<UI-TERM key="oms-community.Operation.constants.Stopped">Stopped</UI-TERM>**, **<UI-TERM>Exception</UI-TERM>**, or **<UI-TERM key="oms-community.Migration.constants.UnexpectedExit">Unexpected Exit</UI-TERM>** state: **<UI-TERM key="oms-community.IncrSync.New.Start">Start</UI-TERM>**, **<UI-TERM key="oms-community.Operator.Checker.DisableUpdateBtn.Update">Update</UI-TERM>**, **<UI-TERM key="oms-community.pages.OCP.constant.Delete">Delete</UI-TERM>**, and **<UI-TERM key="oms-community.Operation.Machine.ViewLogs">View Logs</UI-TERM>**. </ul> |

4. You can click **<UI-TERM key="oms-community.Operator.constants.ViewLogs">View Logs</UI-TERM>** in the Actions column of the target store to view the logs of the store. You can also download and copy the logs.
