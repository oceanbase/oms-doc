# View details of a Store component

The Store page of OceanBase Migration Service (OMS) Community Edition allows you to view the basic information of a Store, such as the name, type, latency, and status of the Store. This helps you assess the running status of the Store.

## Procedure

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.OMMonitoring">OPS & Monitoring</UI-TERM>** > **<UI-TERM key="oms-community.Audit.constants.Component">Component</UI-TERM>**. The **<UI-TERM>Store</UI-TERM>** tab automatically appears.

3. On the **<UI-TERM>Store</UI-TERM>** tab, view the basic information of the target Store.

   You can also search for the Store by name, topic, subtopic, or task ID, or filter the Store by type and status.

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>In OMS Community Edition, you cannot perform fuzzy queries on the <strong>Store</strong> page. </p>
    </main>

   |   **Parameter**   | **Description**                                                                                   |
   |------------|----------------|
   | Name         | The name of the Store.  |
   | Region         |<ul><li> If the Store is deployed in a single region, the region information is displayed on the right side of the **<UI-TERM>Store</UI-TERM>** page, and this column is no longer displayed.   <li> If the Store is deployed in multiple regions, you can filter the Store by region to view the Store information in the target region.</ul>    |
   | Task Name      | The name of the data migration or synchronization task associated with the Store component. You can click the task name to go to the details page of the task.|
   | Type         | The type of the database source.   |
   | RPS        | The number of transactions processed per second by the server, which measures the system throughput.   |
   | Latency         | The latency of the Store component is the time difference between the current time and the time when the Store fetches the change records. The latency calculation involves polling, and it is usually between 10 and 30 seconds.     |
   | Status         | The status of the Store component, which can be **<UI-TERM key="oms-community.Sync.constants.YunXingZhong">Running</UI-TERM>**, **<UI-TERM key="oms-community.Operation.constants.Exception">Exception</UI-TERM>**, or **<UI-TERM key="oms-community.Operator.constants.Stopped">Stopped</UI-TERM>**.  |
   | Start Timestamp  |  A Store component stores a series of LogRecords (transaction log records). Each LogRecord corresponds to an event time, which is the time when the record is changed in the database or the transaction is committed. The start timestamp is the minimum event time of all LogRecords in the current Store component.   |
   | Current Timestamp  | The maximum event time of all LogRecords in the current Store component.   |
   | Connections        | The number of downstream nodes during data processing of the Store.   |
   | Actions   |  <ul><li> For a Store component in the **<UI-TERM key="oms-community.Operator.constants.Running">Running</UI-TERM>** state, you can perform the **<UI-TERM key="oms-community.Overview.constants.Pause">Pause</UI-TERM>**, **<UI-TERM key="oms-community.Operation.constants.Update">Update</UI-TERM>**, and **<UI-TERM key="oms-community.components.SyncSwitch.DbObjectTable.ViewLogs">View Logs</UI-TERM>** actions. <li> For a Store component in the **<UI-TERM key="oms-community.Operation.constants.Stopped">Stopped</UI-TERM>**, **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.Exception">Exception</UI-TERM>**, or **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.UnexpectedExit">Unexpected Exit</UI-TERM>** state, you can perform the **<UI-TERM key="oms-community.JDBCWriter.New.Start">Start</UI-TERM>**, **<UI-TERM key="oms-community.Connector.New.Update">Update</UI-TERM>**, **<UI-TERM key="oms-community.OperationComponent.Connector.Delete">Delete</UI-TERM>**, and **<UI-TERM key="oms-community.Operator.constants.ViewLogs">View Logs</UI-TERM>** actions.</ul>|

4. You can also click **<UI-TERM key="oms-community.components.Operator.openLog.ViewLogs">View Logs</UI-TERM>** next to the name of the target Store to view its logs and perform the **Download** and **<UI-TERM key="oms-community.Endpoint.constants.Copy">Copy</UI-TERM>** actions.
