# Rerun and resume a Full-Import component

The OPS & Monitoring module of OceanBase Migration Service (OMS) Community Edition allows you to rerun and resume a Full-Import component.

## Limits

OMS Community Edition allows you to rerun and resume a Full-Import component in the **Abnormal** or **<UI-TERM key="oms-community.Operator.constants.Stopped">Stopped</UI-TERM>** state.

## Rerun a Full-Import component

1. Log on to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.SystemParam.contants.OMMonitoring">OPS & Monitoring</UI-TERM>** > **<UI-TERM key="oms-community.Audit.constants.Component">Component</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.Operation.OperationComponent.Component">Component</UI-TERM>** page, click the **Full-Import** tab.

4. On the **Full-Import** tab, you can search for a Full-Import component by component name or server IP address. Fuzzy match by task name or task ID is supported.

   You can filter Full-Import components by region and start the Full-Import components in the target region.

5. Click **<UI-TERM key="oms-community.Migration.constants.Rerun">Rerun</UI-TERM>** in the **<UI-TERM key="oms-community.Operation.Checker.Operation">Actions</UI-TERM>** column of the target Full-Import component.

6. In the dialog box that appears, confirm **<UI-TERM key="oms-community.Operator.IncrSync.MigrateIncrSyncModal.OperationObject">Object</UI-TERM>** and click **<UI-TERM key="oms-community.components.SyncSwitch.ConfirmStopSourceApp.Determine">OK</UI-TERM>**.

## Resume a Full-Import component

1. Log on to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.layout.constants.OMMonitoring">OPS & Monitoring</UI-TERM>** > **<UI-TERM key="oms-community.Audit.constants.Component">Component</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.Operation.OperationComponent.Component">Component</UI-TERM>** page, click the **Full-Import** tab.

4. On the **Full-Import** tab, you can search for a Full-Import component by component name or server IP address. Fuzzy match by task name or task ID is supported.

   You can filter Full-Import components by region and pause the Full-Import components in the target region.

5. Click **<UI-TERM key="oms-community.Sync.constants.Recovery">Resume</UI-TERM>** in the **<UI-TERM key="oms-community.Operation.components.operationDetail.Operation">Actions</UI-TERM>** column of the target Full-Import component.

6. In the dialog box that appears, confirm **<UI-TERM key="oms-community.Operator.IncrSync.MigrateIncrSyncModal.OperationObject">Object</UI-TERM>** and click **<UI-TERM key="oms-community.Operator.Store.useStoreAction.Update">OK</UI-TERM>**.
