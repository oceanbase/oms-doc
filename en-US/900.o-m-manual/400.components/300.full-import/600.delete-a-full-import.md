# Delete a Full-Import component

This topic describes how to delete a Full-Import component to save running resources.

## Limitations

OceanBase Migration Service (OMS) Community Edition allows you to delete a Full-Import component in the **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.Stopped">Stopped</UI-TERM>**, **<UI-TERM>Exception</UI-TERM>**, or **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.Completed">Completed</UI-TERM>** state.

## Procedure

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.SystemParam.contants.OMMonitoring">OPS & Monitoring</UI-TERM>** > **<UI-TERM key="oms-community.Audit.constants.Component">Component</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.Audit.constants.Component">Component</UI-TERM>** page, click the **<UI-TERM>Full-Import</UI-TERM>** tab.

4. On the **<UI-TERM>Full-Import</UI-TERM>** tab, you can search for a Full-Import component by component name or server IP address. Fuzzy match by task name or task ID is supported.

   You can filter Full-Import components by region and delete the Full-Import components in the target region.

5. Click **<UI-TERM key="oms-community.Migration.Detail.MoreOperations">More</UI-TERM>** in the **<UI-TERM key="oms-community.pages.EndpointPublic.Operation">Actions</UI-TERM>** column of the target Incr-Sync component and select **<UI-TERM key="oms-community.Migration.constants.Delete">Delete</UI-TERM>** from the drop-down list.

6. In the dialog box that appears, enter **delete** and click OK.
