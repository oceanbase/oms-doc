# View details of a Full-Import component

The Full-Import component migrates the inventory data and synchronizes part of the incremental data of the source database tables. The OPS & Monitoring module of OceanBase Migration Service (OMS) Community Edition allows you to perform O&M operations on a Full-Import component and view the basic information about a Full-Import component on the Full-Import page.

## Procedure

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.layout.constants.OMMonitoring">OPS & Monitoring</UI-TERM>** > **<UI-TERM key="oms-community.Audit.constants.Component">Component</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.Operation.OperationComponent.Component">Component</UI-TERM>** page, click the **<UI-TERM>Full-Import</UI-TERM>** tab.

4. On the **<UI-TERM>Full-Import</UI-TERM>** tab, you can search for a Full-Import component by component name or server IP address. Fuzzy match by task name or task ID is supported.

5. View the basic information about the target Full-Import component.

   | **Parameter** | **<UI-TERM key="oms-community.User.New.Description">Description</UI-TERM>**    |
   |-----------------------|--------------------|
   | Name | The name of the Full-Import component.  Move the pointer over the name of the Full-Import component and click the copy icon to copy the component name.    |
   | Region | You can filter Full-Import components by region and view information about the Full-Import components in the target region.    |
   | Task Name | The name of the data migration or synchronization task. You can click the name to go to the details page of the task.   |
   | Task Type | The type of the task. Supported options: **<UI-TERM key="oms-community.src.constants.DataMigration">Data Migration</UI-TERM>** and **<UI-TERM key="oms-community.components.CustomizedTable.DataSynchronization">Data Synchronization</UI-TERM>**.  |
   | Status | The status of the Full-Import component. Valid values: **<UI-TERM key="oms-community.ModifyRecordTable.constants.Running">Running</UI-TERM>**, **<UI-TERM key="oms-community.Migration.constants.Stopped">Stopped</UI-TERM>**, **<UI-TERM>Exception</UI-TERM>**, and **<UI-TERM key="oms-community.Migration.constants.Completed">Completed</UI-TERM>**.    |
   | Actions | <ul><li>You can perform the following operations on a Full-Import component in the **<UI-TERM key="oms-community.Operator.constants.Running">Running</UI-TERM>** state: **<UI-TERM key="oms-community.Operator.constants.Pause">Pause</UI-TERM>**, **<UI-TERM key="oms-community.Operator.Checker.DisableUpdateBtn.Update">Update</UI-TERM>**, and **<UI-TERM key="oms-community.components.Operator.openLog.ViewLogs">View Logs</UI-TERM>**.  <li>You can perform the following operations on a Full-Import component in the **<UI-TERM key="oms-community.Migration.constants.Stopped">Stopped</UI-TERM>** or **<UI-TERM>Exception</UI-TERM>** state: **<UI-TERM key="oms-community.Migration.constants.Rerun">Rerun</UI-TERM>**, **<UI-TERM key="oms-community.Operation.constants.Recovery">Resume</UI-TERM>**, **<UI-TERM key="oms-community.Operation.constants.Update">Update</UI-TERM>**, **<UI-TERM key="oms-community.Operator.constants.Delete">Delete</UI-TERM>**, and **<UI-TERM key="oms-community.Operation.Machine.ViewLogs">View Logs</UI-TERM>**. <li>You can perform the following operations on a Full-Import component in the **<UI-TERM key="oms-community.Operator.constants.Finished">Completed</UI-TERM>** state: **<UI-TERM key="oms-community.Sync.constants.Delete">Delete</UI-TERM>** and **<UI-TERM key="oms-community.components.Operator.openLog.ViewLogs">View Logs</UI-TERM>**. </ul> |
