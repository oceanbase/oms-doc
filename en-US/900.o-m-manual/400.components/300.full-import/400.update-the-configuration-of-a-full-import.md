# Update the configurations of a Full-Import component

OceanBase Migration Service (OMS) Community Edition allows you to view and update the configurations of a specified Full-Import component. When you update the configurations, the current configurations of the Full-Import component are automatically displayed. You can view or modify the configurations of the Full-Import component.

## Limitations

* OMS Community Edition allows you to update the configurations of a Full-Import component in the **<UI-TERM key="oms-community.src.constants.Running">Running</UI-TERM>**, **<UI-TERM key="oms-community.Operation.Overview.constants.Stopped">Stopped</UI-TERM>**, or **<UI-TERM>Exception</UI-TERM>** state.

* After you update the configurations of a Full-Import component, the system will restart the Full-Import component for the update to take effect. Proceed with caution.

  When a data migration or synchronization task fails, check the configurations of the task first, such as the basic information and user privileges of the source and destination databases.

## Scenarios

You can update Full-Import configurations in the following scenarios:

* A data migration task fails due to incorrect configuration information.

* A data migration task needs to be optimized.

## Enter the update configuration dialog box

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.SystemParam.contants.OMMonitoring">OPS & Monitoring</UI-TERM>** > **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Components">Component</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.Audit.constants.Component">Component</UI-TERM>** page, click the **<UI-TERM>Full-Import</UI-TERM>** tab.

4. On the **<UI-TERM>Full-Import</UI-TERM>** tab, you can search for a Full-Import component by component name, server IP address, or task name.

   You can filter Full-Import components by region and update the configurations of the Full-Import components in the target region.

5. Click **<UI-TERM key="oms-community.components.UpdateCompCfgDrawer.UpdateCompCfgDrawer.Update">Update</UI-TERM>** in the **<UI-TERM key="oms-community.Operation.components.operationDetail.Operation">Actions</UI-TERM>** column of the target Full-Import component.

6. In the **<UI-TERM key="oms-community.Operator.JDBCWriter.useJDBCWriterAction.UpdateConfigurations">Update Configuration</UI-TERM>** dialog box, add a parameter or update the configurations in the **Configuration List** or **Configuration Details** tab. For more information, see [Component parameters](../500.component-parameters/100.coordinator.md).

## Add or update configurations on the configuration list tab

### Add configurations

1. In the **<UI-TERM>Update Configuration</UI-TERM>** dialog box, click the **Configuration List** tab.

2. Click **+ Add** at the bottom of the page.

3. Enter the name of the parameter to be added in the first column and the value of the parameter in the second column.

4. Click **OK** in the **Configuration List** tab.

   If you need to delete a parameter, click the delete icon to the right of the target parameter value.

### Update configurations

1. In the **<UI-TERM>Update Configuration</UI-TERM>** dialog box, click the **Configuration List** tab.

2. Find the target parameter that needs to be modified and enter its new value in the second column.

   If you need to delete a parameter, click the delete icon to the right of the target parameter value. You can also modify the **<UI-TERM>Concurrency Speed</UI-TERM>** according to actual needs.

4. Click **OK** in the **Configuration List** tab.

## Add or update configuration on the configuration details tab

### Add configurations

1. In the **<UI-TERM>Update Configuration</UI-TERM>** dialog box, click the **Configuration List** tab.

2. Move the pointer over the blank area next to the `condition`, `coordinator`, `sink`, or `source` parameter and click the Add icon.

3. Specify **Key Name** and click the check icon.

4. In the **</UI-TERM>Update Configuration</UI-TERM>** dialog box, find the new key name. Its default value is NULL.

5. Move the pointer over the new parameter and click the Edit icon that appears. Modify the parameter value and click the check icon.

6. Click **OK** in the **Configuration Details** tab.

### Update configurations

1. In the **<UI-TERM>Update Configuration</UI-TERM>** dialog box, click the **Configuration Details** tab.

2. Move the pointer over the target configuration and click the edit icon that appears.

3. Modify the value in the text box and then click the confirm icon.

   The green tick specifies to update the value and the red cross specifies to cancel the modification.

4. Click **OK** in the **Configuration Details** tab.
