# Pause a Full-Import component

The OPS & Monitoring module of OceanBase Migration Service (OMS) Community Edition allows you to pause a Full-Import component in the Running state.

## Procedure

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.OMMonitoring">OPS & Monitoring</UI-TERM>** > **<UI-TERM key="oms-community.Operation.OperationComponent.Component">Component</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.Audit.constants.Component">Component</UI-TERM>** page, click the **<UI-TERM>Full-Import</UI-TERM>** tab.

4. On the **<UI-TERM>Full-Import</UI-TERM>** tab, you can search for a Full-Import component by component name or server IP address. Fuzzy match by task name or task ID is supported.

   You can filter Full-Import components by region and start the Full-Import components in the target region.

5. Click **<UI-TERM key="oms-community.Sync.constants.Pause">Pause</UI-TERM>** in the **<UI-TERM key="oms-community.components.MonitorDrawer.Operation">Actions</UI-TERM>** column of the target Full-Import component.

6. In the dialog box that appears, click **<UI-TERM key="oms-community.Operator.Connector.useConnectorAction.MigrationConfirm">OK</UI-TERM>**.
