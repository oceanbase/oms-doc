# Batch O&M

To perform common O&M operations such as start and delete operations on the Incr-Sync components of a server or a specific task, you can run batch O&M tasks. Batch O&M allows you to modify the configurations of multiple Incr-Sync components at a time, improving O&M efficiency.

## Usage notes

You can perform batch O&M for Incr-Sync components only when multiple servers are available in a high availability scenario.

## Procedure

1. Log in to the OceanBase Migration Service (OMS) Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.SystemParam.contants.OMMonitoring">OPS & Monitoring</UI-TERM>** > **<UI-TERM key="oms-community.Audit.constants.Component">Component</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Components">Component</UI-TERM>** page, click the **<UI-TERM>Incr-Sync</UI-TERM>** tab.

4. On the **<UI-TERM>Incr-Sync</UI-TERM>** page, click **<UI-TERM key="oms-community.Operation.JDBCWriter.BatchOM">Batch O&M</UI-TERM>** in the upper-right corner.

5. Select an operation type. The following options are available: **<UI-TERM key="oms-community.IncrSync.New.Stop">Stop</UI-TERM>**, **<UI-TERM key="oms-community.Detail.components.StartConnectorModal.Start">Start</UI-TERM>**, **<UI-TERM key="oms-community.Operator.IncrSync.MigrateIncrSyncModal.Migration">Migrate</UI-TERM>**, **<UI-TERM key="oms-community.components.UpdateCompCfgDrawer.UpdateCompCfgDrawer.Update">Update</UI-TERM>**, and **<UI-TERM key="oms-community.Migration.constants.Destruction">Delete</UI-TERM>**.

6. Select a dimension for batch O&M.

   You can perform batch O&M by server IP address or task name. For multi-region deployment, region information is displayed in the IP address drop-down list.

7. Click **<UI-TERM key="oms-community.OCP.components.OCPForm.Submitted">Submit</UI-TERM>**.
