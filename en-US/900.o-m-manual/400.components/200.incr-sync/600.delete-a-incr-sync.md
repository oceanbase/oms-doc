# Delete an Incr-Sync component

This topic describes how to delete an Incr-Sync component to save running resources.

## Limits

* OceanBase Migration Service (OMS) Community Edition allows you to delete an Incr-Sync component in the **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.Stopped">Stopped</UI-TERM>** or **Abnormal** state.

* You cannot delete Incr-Sync components corresponding to tasks in the Running state.

* If an error is returned when a data migration or synchronization task is running, the task and corresponding Incr-Sync components need to be deleted before a new task is created.

## Prerequisites

The Incr-Sync component to be deleted is stopped. For more information, see [Start and pause an Incr-Sync component](../200.incr-sync/200.start-and-pause-a-incr-sync.md).

## Procedure

1. Log on to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.layout.constants.OMMonitoring">OPS & Monitoring</UI-TERM>** > **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Components">Component</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Components">Component</UI-TERM>** page, click the **Incr-Sync** tab.

4. On the **Incr-Sync** page, you can search for an Incr-Sync component by component name, server IP address, or task name.

   You can filter Incr-Sync components by region and delete the Incr-Sync components in the target region.

5. Click **<UI-TERM key="oms-community.Detail.components.StructMigration.MoreOperations">More</UI-TERM>** in the **<UI-TERM key="oms-community.Operation.Machine.Operation">Actions</UI-TERM>** column of the target Incr-Sync component and select **<UI-TERM key="oms-community.OperationComponent.Connector.Delete">Delete</UI-TERM>** from the drop-down list.

6. In the dialog box that appears, enter **delete** and click **<UI-TERM key="oms-community.Detail.components.StructSync.Determine">OK</UI-TERM>**.
