# Start and pause an Incr-Sync component

The O&M monitoring module of OceanBase Migration Service (OMS) Community Edition allows you to start and pause an Incr-Sync component. You can pause an Incr-Sync component for troubleshooting and then automatically or manually start it after the issue is fixed.

## Limitations

* OMS Community Edition allows you to start an Incr-Sync component in the **<UI-TERM key="oms-community.Operator.constants.Stopped">Stopped</UI-TERM>** or **<UI-TERM>Exception</UI-TERM>** state.

* OMS Community Edition allows you to pause an Incr-Sync component in the **<UI-TERM key="oms-community.Operation.constants.Running">Running</UI-TERM>** state.

## Start an Incr-Sync component

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.layout.constants.OMMonitoring">OPS & Monitoring</UI-TERM>** > **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Components">Component</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Components">Component</UI-TERM>** page, click the **<UI-TERM>Incr-Sync</UI-TERM>** tab.

4. On the **<UI-TERM>Incr-Sync</UI-TERM>** page, you can search for an Incr-Sync component by component name, server IP address, or task name.

   You can filter Incr-Sync components by region and start the Incr-Sync components that are not running in the target region.

5. Click **<UI-TERM key="oms-community.Sync.Detail.Start">Start</UI-TERM>** in the **<UI-TERM key="oms-community.Operation.components.operationDetail.Operation">Actions</UI-TERM>** column of the target Incr-Sync component.

6. In the dialog box that appears, confirm **<UI-TERM key="oms-community.Operator.Connector.useConnectorAction.OperationObject">Object</UI-TERM>** and **<UI-TERM key="oms-community.Operator.Connector.StartConnectorModal.PullBack">Whether Reset Synchronization Timestamp</UI-TERM>** and then click **<UI-TERM key="oms-community.pages.User.Confirmation">OK</UI-TERM>**.

## Pause an Incr-Sync component

When you find an Incr-Sync component with a running exception such as high latency, we recommend that you promptly stop the Incr-Sync component for troubleshooting.

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.OMMonitoring">OPS & Monitoring</UI-TERM>** > **<UI-TERM key="oms-community.Operation.OperationComponent.Component">Component</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.Audit.constants.Component">Component</UI-TERM>** page, click the **<UI-TERM>Incr-Sync</UI-TERM>** tab.

4. On the **<UI-TERM>Incr-Sync</UI-TERM>** page, you can search for an Incr-Sync component by component name, server IP address, or task name.

   You can filter Incr-Sync components by region and pause the Incr-Sync components in the target region.

5. Click **<UI-TERM key="oms-community.Operation.constants.Pause">Pause</UI-TERM>** in the **<UI-TERM key="oms-community.SystemManage.Authorization.Operation">Actions</UI-TERM>** column of the target Incr-Sync component.

6. In the dialog box that appears, click **<UI-TERM key="oms-community.Migration.hooks.useMigrationObject.Determine">OK</UI-TERM>**.
