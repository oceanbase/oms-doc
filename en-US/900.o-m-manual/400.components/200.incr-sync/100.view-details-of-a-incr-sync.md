# View details of an Incr-Sync component

The OPS & Monitoring module of OceanBase Migration Service (OMS) Community Edition allows you to perform O&M operations on an Incr-Sync component on the Incr-Sync page, such as monitoring the running status of the Incr-Sync component, to facilitate rapid troubleshooting.

## Procedure

1. Log on to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.OMMonitoring">OPS & Monitoring</UI-TERM>** > **<UI-TERM key="oms-community.Operation.OperationComponent.Component">Component</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Components">Component</UI-TERM>** page, click the **Incr-Sync** tab.

4. On the **Incr-Sync** page, you can search for an Incr-Sync component by component name, server IP address, or task name.

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>OMS Community Edition does not support fuzzy queries on the <strong>Incr-Sync</strong> page. </p>
    </main>

5. View the basic information about an Incr-Sync component.

   | **Parameter** | **<UI-TERM key="oms-community.User.Detail.Description">Description</UI-TERM>** |
   |--------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   | Name | The name of the Incr-Sync component. Move the pointer over the name of the Incr-Sync component and then click the copy icon to copy the component name.  |
   | Region | You can filter Incr-Sync components by region and view information about the Incr-Sync components in the target region.  |
   | Task Name | The name of the data migration or synchronization task. You can click the name to go to the details page of the task.  |
   | Task Type | The type of the task. Supported options: **<UI-TERM key="oms-community.src.constants.DataMigration">Data Migration</UI-TERM>** and **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.DataSynchronization">Data Synchronization</UI-TERM>**.  |
   | Type | The migration or synchronization type of the data migration or synchronization task.  |
   | RPS | The number of transactions handled by the server per second. It is used to measure the system throughput.  |
   | Latency (s) | The difference between the time when data is written to the source database and the time when data is written to the destination database. It is usually used to determine the task status.  |
   | Delay refresh timestamp | The time interval since the last delay update of the task.  |
   | Status | The status of the Incr-Sync component. Valid values: **<UI-TERM key="oms-community.Operation.Overview.constants.Running">Running</UI-TERM>**, **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.Stopped">Stopped</UI-TERM>**, and **Abnormal**.  |
   | Actions | <ul><li>You can perform the following operations on an Incr-Sync component in the **<UI-TERM key="oms-community.src.constants.Running">Running</UI-TERM>** state: **<UI-TERM key="oms-community.Sync.constants.Pause">Pause</UI-TERM>**, **<UI-TERM key="oms-community.Operator.Checker.DisableUpdateBtn.Update">Update</UI-TERM>**, and **<UI-TERM key="oms-community.Migration.constants.ViewLogs">View Logs</UI-TERM>**. <li>You can perform the following operations on an Incr-Sync component in the **<UI-TERM key="oms-community.Operation.constants.Stopped">Stopped</UI-TERM>** or **Abnormal** state: **<UI-TERM key="oms-community.Audit.constants.Start">Start</UI-TERM>**, **<UI-TERM key="oms-community.Operator.constants.Update">Update</UI-TERM>**, **<UI-TERM key="oms-community.migration.full.constants.Delete">Delete</UI-TERM>**, **<UI-TERM key="oms-community.Operator.IncrSync.MigrateIncrSyncModal.Migration">Migrate</UI-TERM>**, and **<UI-TERM key="oms-community.components.SyncSwitch.DbObjectTable.ViewLogs">View Logs</UI-TERM>**.  |
