# Overview of OMS Community Edition

## Introduction

The community edition of OceanBase Migration Service (OMS) is a service that supports interaction between homogeneous and heterogeneous data sources and the community edition of OceanBase Database. This service enables online migration of existing data and real-time synchronization of incremental data.

OMS Community Edition provides a visualized centralized management platform that allows you to perform data migration with simple configurations. OMS Community Edition helps you achieve low-risk, cost-effective, and high-efficiency real-time data migration and synchronization between homogeneous or heterogeneous databases to OceanBase Community Edition.

## Features

The OpenStack Monitoring Service (OMS) community edition supports data migration and synchronization:

* Data migration: Data migration is a one-time task, and resources are released once the task is completed. The Data Migration feature allows you to migrate data between homogeneous or heterogeneous data sources, such as databases, instances, or split databases. It is applicable to scenarios such as database upgrades, cross-instance data migration, database splitting, and scaling out.

    A data migration task is the basic unit of the data migration feature in the OMS Community Edition. When you create a migration task, you can specify a database as the maximum migration scope and a table as the minimum migration scope. For more information about supported task types and migration types, see the Data Migration module.

* Data Synchronization: Data synchronization is a continuous process that keeps the source data in sync with the destination data. It maintains data consistency between the source and destination, ensuring real-time data flow for critical business operations. Using the data synchronization feature, you can achieve real-time data synchronization between data sources. This feature is applicable to scenarios such as multi-active data centers, disaster recovery at remote locations, data aggregation, and real-time data warehouses. For more information, please refer to the [Data Synchronization](../700.data-synchronization/100.data-synchronization-overview.md) module.

## Features and Benefits

* Support multiple data sources.

  The OMS Community Edition supports real-time data synchronization between the OceanBase Community Edition and OceanBase Database in MySQL mode and other databases including MySQL, PostgreSQL, TiDB, Kafka, and RocketMQ. The specific functions vary depending on the types of source and target databases.

* Seamless migration with no impact on services

  In a zero-downtime manner, you can seamlessly migrate data to OceanBase Database Community Edition in the OMS Community Edition. After the application is switched over to OceanBase Database Community Edition, all change data on OceanBase Database Community Edition will be synchronized in real time to the source database before the switch.

  OMS Community Edition helps you reduce the risks in business migration and build a highly available and reliable data system.

* High-performance, secure, and reliable data migration

  OMS Community Edition can replicate large-scale data between IT infrastructures with sub-second delay. This sub-second delay allows OMS Community Edition to be applied to data migration, standby system, real-time data synchronization, and database upgrade and migration.

  The OMS Community Edition enables you to complete data migration and synchronization tasks without interrupting business applications and without affecting the business processes. It can also ensure data integrity and transaction consistency. OMS can achieve 100 MB/s of full migration performance and 200,000 TPS, and 50,000 RPS of real-time data synchronization. At the same time, OMS provides a high-availability deployment architecture to ensure the stability and reliability of data transmission tasks.

* One-stop interactive service

  DTS supports data migration life cycle management. You can easily create, configure, and monitor data migration tasks in the DTS console.

* Real-time data synchronization decouples business processes

  OceanBase Database Community Edition supports data synchronization from the OceanBase Database Community Edition and self-managed Kafka or RocketMQ. This allows for real-time data synchronization that can be used for building real-time data warehouses, data queries, and report distribution.

* Data validity check

  Provide multiple data consistency checking methods, which ensure the quality of the data more comprehensively, efficiently, and promptly. The method also displays the inconsistent data to facilitate quick corrections.

* Easily migrate data to OceanBase Database Community Edition.

  It fully supports the features of various versions of OceanBase Database Community Edition, can intelligently collect and convert database objects, and supports migration without shutting down the source database.

## Scenarios

### Database migration without downtime

![architecture1-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/architecture1-zh.png)

In traditional database migration scenarios, to ensure the stability of the migration process and data consistency, stop-the-world migration is typically used. During migration, you need to temporarily stop writing data to the source database. After the migration is complete and data consistency is verified, the business database is switched.

The time spent on stopping migration is related to the amount of business data and the network conditions. If the business data volume is large, database downtime during migration may be as long as several days and have a significant impact on the business.

The OMS Community Edition provides non-service-interruptive data migration that ensures that the source database continues to provide services during the migration process. This minimizes the impact of data migration on services. After the structure migration, full data migration, and incremental data migration are completed, all data from the source database is real-time synchronized to the destination database. If the data verification is successful, services can be switched from the source database to the destination database.

### Real-time data synchronization

OMS Community Edition's data synchronization feature supports real-time synchronization of incremental data from databases such as OceanBase Database Community Edition to self-hosted message queues like Kafka and RocketMQ, thereby enhancing message processing capabilities and enabling comprehensive applications in the big data domain, including monitoring data aggregation, stream processing, and online and offline analysis.

OceanBase Database is a time series database that allows you to store data and perform real-time queries on the data. It can also process large-scale data with high performance.

### Highly available and easy to deploy

* Single-node support for high availability (HA) is provided by Store and Incr-Sync components. If a Store or Incr-Sync component fails, restart the faulty process.

  ![architecture2-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/architecture2-zh.png)

* Disaster recovery support based on IDC.

  ![architecture3-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/architecture3-zh.png)

  * If the local node fails, the components are migrated to another node.

  * When the resources of the machine are insufficient, attempt to perform load balancing for some components.

  * When a store fails, restart the store if there are sufficient resources. If resources are insufficient, perform load balancing or delete redundant stores.

  * Restart the exception process when a fault occurs in Incr-Sync.

* Support for disaster recovery in region-based data centers.

  OMS Community Edition supports separate deployment for incremental log reading and incremental synchronous writing. This feature allows for parallel transmission, data compression, and data encryption via multiple Transmission Control Protocol (TCP) connections. It overcomes challenges like long-distance communication, poor network conditions, and data security. However, cross-regional task scheduling is not supported.
