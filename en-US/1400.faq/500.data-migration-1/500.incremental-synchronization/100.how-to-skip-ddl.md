# How do I skip DDL statements?

This topic describes how to skip specified DDL statements in the JDBCWriter component.

## Applicable versions

OceanBase Migration Service (OMS) V3.2.2 and later

## Procedure

1. Find the DDL statements received on the source end.

   1. Log in to the OMS console.

   2. In the left-side navigation pane, click **<UI-TERM key="oms-community.components.UserGuidance.DataMigration">Data Migration</UI-TERM>**.

   3. On the **<UI-TERM key="oms-community.Migration.New.DataMigration">Data Migration</UI-TERM>** page, click the name of the target data migration task to go to its details page.

   4. Click **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.ViewComponentMonitoring">View Component Monitoring</UI-TERM>** in the upper-right corner.

   5. In the **<UI-TERM key="oms-community.Migration.constants.ViewComponentMonitoring">View Component Monitoring</UI-TERM>** dialog box, click the More icon after  and choose **<UI-TERM key="oms-community.components.SyncSwitch.DbObjectTable.ViewLogs">View Logs</UI-TERM>** from the context menu.

   6. Click the `msg/ddl_msg.log` tab and copy the DDL statement that follows the colon after the `receive ddl` keyword. The statement is received from the source.

      ![ddl_msg](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/ddl_msg1.png)

2. Update the configurations of the JDBCWriter component.

   1. Return to the **<UI-TERM key="oms-community.Migration.constants.ViewComponentMonitoring">View Component Monitoring</UI-TERM>** dialog box.

   2. Click **<UI-TERM key="oms-community.Connector.New.Update">Update</UI-TERM>** in the **<UI-TERM key="oms-community.pages.OCP.Operation">Actions</UI-TERM>** column of the JDBCWriter component.

   3. In the **<UI-TERM>Update Configuration</UI-TERM>** dialog box, hover the pointer over the blank area next to the root parameter and click the add icon that appears.

   4. Enter  for `Key Name` and click the check icon.

   5. In the **<UI-TERM>Update Configuration</UI-TERM>** dialog box, find the new key name. The default value is NULL.

   6. Hover the pointer over the new parameter, click the edit icon that appears, and change the value of the parameter to the DDL statement that follows the colon after the `receive ddl` keyword and that you copied in the foregoing step.

      ```sql
      DROP TABLE IF EXISTS `t_alter` /* generated by server */
      ```

      If you want to skip multiple DDL statements, separate them with a dollar sign (&), for example:

      ```sql
      DROP TABLE IF EXISTS `t_alter` /* generated by server */&DROP TABLE IF EXISTS `t1_alter`
      ```

3. Restart the JDBCWriter component.
