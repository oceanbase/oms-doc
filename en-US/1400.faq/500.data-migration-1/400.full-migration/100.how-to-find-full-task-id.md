# How do I query the ID of a checker?

This topic describes how to use a data migration task on OceanBase Migration Service (OMS) to query the ID of a checker.

1. Log in to the OMS console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.layout.constants.DataMigration">Data Migration</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.DataMigration">Data Migration</UI-TERM>** page, click the name of the target data migration task to go to its details page.

4. Click **<UI-TERM key="oms-community.Migration.Detail.ViewComponentMonitoring">View Component Monitoring</UI-TERM>** in the upper-right corner.

5. In the **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.ViewComponentMonitoring">View Component Monitoring</UI-TERM>** dialog box, check the component ID of a checker.
