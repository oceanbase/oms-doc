# Clear files in the Store component

This topic describes how to clear data files in the Store component to ensure sufficient disk space.

## Limitations

OceanBase Migration Service (OMS) Community Edition allows you to update the configurations of a Score component in the **<UI-TERM key="oms-community.Operation.constants.Running">Running</UI-TERM>**, **<UI-TERM key="oms-community.Migration.constants.Stopped">Stopped</UI-TERM>**, **<UI-TERM key="oms-community.Operation.constants.Exception">Exception</UI-TERM>**, or **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.UnexpectedExit">Unexpected Exit</UI-TERM>** state.

## Considerations

Clearing files in a store component will cause the following risks:

* If latency exists during incremental synchronization, the data in the Store component may be cleared.

* Data beyond the retention period cannot be pulled.

## Procedure

1. Log in to the console of OMS Community Edition.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.Migration.Detail.DataMigration">Data Migration</UI-TERM>**.

3. In the **<UI-TERM key="oms-community.pages.Migration.MigrationProject">Migration Tasks</UI-TERM>**  list, click the name of the target task to go to its details page.

4. Click **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.ViewComponentMonitoring">View Component Monitoring</UI-TERM>** in the upper-right corner.

5. In the **<UI-TERM key="oms-community.Migration.constants.ViewComponentMonitoring">View Component Monitoring</UI-TERM>** dialog box, click **<UI-TERM key="oms-community.Operation.Machine.Update">Update</UI-TERM>** next to the Store component.

6. In the **<UI-TERM key="oms-community.Operator.JDBCWriter.useJDBCWriterAction.UpdateConfigurations">Update Configuration</UI-TERM>** dialog box, update the value of the `store.clearer.outdated` parameter that specifies the retention period of incremental data, in seconds.

   1. Move the pointer over the `store.clearer.outdated` parameter and click the Edit icon.

   2. Modify the value in the text box and then click the OK icon.

      The green tick specifies to update the value and the red cross specifies to cancel the modification.

7. In the **<UI-TERM key="oms-community.Operator.Store.useStoreAction.UpdateConfigurations">Update Configuration</UI-TERM>** dialog box, click **<UI-TERM key="oms-community.pages.Endpoint.Confirmation">OK</UI-TERM>**.
