# Clear files in the Store component

This topic describes how to clear data files in the Store component to ensure sufficient disk space.

## Limitations

OceanBase Migration Service (OMS) Community Edition allows you to update the configurations of a Score component in the **Running**, **Stopped**, **Exception**, or **Unexpected Exit** state.

## Considerations

Clearing files in a store component will cause the following risks:

* If latency exists during incremental synchronization, the data in the Store component may be cleared.

* Data beyond the retention period cannot be pulled.

## Procedure

1. Log on to the console of OMS Community Edition.

2. In the left-side navigation pane, click **Data Migration**.

3. In the **Migration Projects** list, click the name of the target project to go to its details page.

4. Click **View Component Monitoring** in the upper-right corner.

5. In the **View Component Monitoring** dialog box, click **Update** next to the Store component.

6. In the **Update Configuration** dialog box, update the value of the `store.clearer.outdated` parameter that specifies the retention period of incremental data, in seconds.

   1. Move the pointer over the `store.clearer.outdated` parameter and click the Edit icon.

   2. Modify the value in the text box and then click the OK icon.

      The green tick specifies to update the value and the red cross specifies to cancel the modification.

7. In the **Update Configuration** dialog box, click **OK**.
