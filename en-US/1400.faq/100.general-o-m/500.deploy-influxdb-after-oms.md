# Deploy InfluxDB for OMS

This topic describes how to deploy InfluxDB after you deploy OceanBase Migration Service (OMS) Community Edition.

## Limitations

* You can deploy only one InfluxDB instance for OMS Community Edition, regardless of whether you deploy OMS Community Edition in one or multiple regions.

* If OMS Community Edition is deployed on multiple nodes, you must deploy the same InfluxDB instance on all nodes.

## Procedure

1. Deploy InfluxDB.

   Deploy InfluxDB and verify that the service is available. For more information, see [Deploy a time-series database](../../400.deployment-guide/500.docker-deploy/600.deploy-a-time-series-database.md).

2. Configure OMS Community Edition.

   Run the following command to go to the container of OMS Community Edition:

   ```bash
   cat /home/admin/conf/config.yaml
   ```

   Modify the configuration file. Here is an example:

   ```bash
    "tsdb_enabled": !!bool "true"
    "tsdb_password": "XXXXXX"
    "tsdb_service": "INFLUXDB"
    "tsdb_url": "influxdb_ip:influxdb_port"
    "tsdb_username": "XXXXX"
   ```

   You must replace the `influxdb_ip` and `influxdb_port` fields with the actual IP address and port number of your InfluxDB instance.

3. Run the `sh /root/docker_init.sh` command to synchronize the configurations of InfluxDB to the configuration files of components of OMS Community Edition.

   You can modify the configurations of InfluxDB in the `application-oms.properties` file in the `/home/ds/supervisor/config/drc.properties` and `/home/ds/ghana/config/` directories.

   ```shell
   # Configurations of the time-series database
   metrics.service.impl=INFLUXDB
   metrics.enable=true
   metrics.url=xxx.xxx.xxx.xxx:8086
   metrics.user=username
   metrics.password=xxxxxxx
   ```
