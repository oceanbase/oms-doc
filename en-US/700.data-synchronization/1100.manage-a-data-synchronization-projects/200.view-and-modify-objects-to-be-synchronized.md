# View and modify synchronization objects

This topic describes how to view and modify the synchronization objects of a data synchronization task in OceanBase Migration Service (OMS).

## Background

If the limits are met, you can add or remove synchronization objects during synchronization. The changes made during the running of the task will be recorded. After an object addition task is completed, it will be integrated with the original task that is associated. After the task is integrated with the original task, the original task runs normally and the object addition task is automatically released.

## Limits

* For a data synchronization task in the **<UI-TERM key="oms-community.Sync.constants.NotStarted.5">Not Started</UI-TERM>**, **<UI-TERM key="oms-community.Sync.constants.YunXingZhong">Running</UI-TERM>**, or **Paused** state, you can add or remove its synchronization objects.

* For a data synchronization task in the **<UI-TERM key="oms-community.Audit.Deatil.Failed">Failed</UI-TERM>** state, you can only remove its synchronization objects.

* For a data synchronization task in the **<UI-TERM key="oms-community.Migration.constants.Modifying">Modifying</UI-TERM>** or **<UI-TERM key="oms-community.ModifyRecordTable.constants.Merging">Integrating</UI-TERM>** state, you cannot modify its synchronization objects again.

* When the **<UI-TERM key="oms-community.Sync.constants.IncrementalSynchronization">Incremental Synchronization</UI-TERM>** step of a data synchronization task is in the **Paused** or **<UI-TERM key="oms-community.Home.Toolbar.Failed">Failed</UI-TERM>** state, you can only remove its synchronization objects.

* When you synchronize data from an IDB logical table to a MySQL-compatible tenant of OceanBase Database or to a DataHub instance, you can only add synchronization objects.

## View synchronization objects

1. Log on to the OMS console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.layout.constants.DataSynchronization">Data Synchronization</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.components.CustomizedTable.DataSynchronization">Data Synchronization</UI-TERM>** page, click the name of the target task to go to its details page.

4. Click **<UI-TERM key="oms-community.Sync.constants.ViewObjectsToBeSynchronized">View Objects</UI-TERM>** in the upper-right corner and view information on the **<UI-TERM key="oms-community.Detail.components.SyncObject.SynchronizeObjects">Synchronization Objects</UI-TERM>** and **<UI-TERM key="oms-community.components.ViewObject.ModifyObjectRecords">Object Modifications</UI-TERM>** tabs.

   * The **<UI-TERM key="oms-community.Detail.components.SyncObject.SynchronizeObjects">Synchronization Objects</UI-TERM>** tab displays the synchronization objects of the current task. You can click **Modify Object** and then select **Add Object** or **<UI-TERM key="oms-community.Detail.components.SyncObject.ReduceObjects">Remove Objects</UI-TERM>**.

   * The **<UI-TERM key="oms-community.Detail.components.SyncObject.ModifyObjectRecords">Object Modifications</UI-TERM>** tab displays the IDs, types, statuses, and occurrence time of all object modifications.

## Add synchronization objects

1. On the details page of the target task, click **<UI-TERM key="oms-community.Migration.hooks.useMigrationObject.ViewObjectsToBeMigrated">View Objects</UI-TERM>** in the upper-right corner.

2. In the **<UI-TERM key="oms-community.Migration.hooks.useMigrationObject.ViewObjectsToBeMigrated">View Objects</UI-TERM>** dialog box, choose **<UI-TERM>Modify Objects</UI-TERM>** > **<UI-TERM>Add Objects</UI-TERM>**.

3. In the **<UI-TERM>Add Objects</UI-TERM>** dialog box that appears, select the objects to be synchronized in the left-side pane and click **>**. In the **<UI-TERM key="oms-community.Transfer.sync.MapObjectsToTopics">Map Object to Topic</UI-TERM>** dialog box that appears, select a mapping method.

   After you select the synchronization objects to add, you can perform operations such as changing the topic and setting row filters.

   <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>By default, the newly added synchronization objects will inherit all configuration options of the original data synchronization task. If you abort the object addition operation, you must manually delete the objects that have been added to the destination database. </p>
   </main>

4. Then, click **<UI-TERM key="oms-community.Migration.New.Next">Next</UI-TERM>**.

5. The system automatically performs a precheck on the added migration objects. After the added migration objects pass all check items, click **<UI-TERM key="oms-community.pages.EndpointPublic.Save">Save</UI-TERM>**.

6. Confirm the information and click **<UI-TERM key="oms-community.components.SyncSwitch.ConfirmStopSourceApp.Determine">OK</UI-TERM>** in the dialog box that appears.

   * For a paused or failed data migration task, you can cancel the operation and modify the migration objects again. The added migration objects will be migrated to the destination database only after the data migration task returns to normal.

   * If you add synchronization objects for a running data synchronization task, after you click Save, the added synchronization objects will be immediately synchronized to the destination database.

   After the object addition operation begins, records will be generated on the page that appears after you choose **<UI-TERM key="oms-community.Sync.constants.ViewObjectsToBeSynchronized">View Objects</UI-TERM>** > **<UI-TERM key="oms-community.Migration.Detail.ModifyObjectRecords">Object Modifications</UI-TERM>**. You can view details of the records on this page. The status of object addition records can be **<UI-TERM key="oms-community.ModifyRecordTable.constants.PendingExecution">Pending</UI-TERM>**, **<UI-TERM key="oms-community.Operation.constants.Canceled">Canceled</UI-TERM>**, **<UI-TERM key="oms-community.Sync.constants.Modifying">Modifying</UI-TERM>**, **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.Running">Running</UI-TERM>**, **<UI-TERM key="oms-community.ModifyRecordTable.constants.Terminated">Aborted</UI-TERM>**, **<UI-TERM key="oms-community.Migration.constants.Merging">Integrating</UI-TERM>**, **<UI-TERM key="oms-community.PreCheck.constants.Success">Succeeded</UI-TERM>**, or **<UI-TERM key="oms-community.components.BatchSelect.BatchSwitch.Failed">Failed</UI-TERM>**. The operations that you can perform on an object addition record and the status of the original task vary with the status of the object addition record.

   <main id="notice" type='explain'>

    <h4>Description</h4>

    <p>If the original data synchronization task is in the <strong>Not Started</strong> state, a modification record in the <strong>Successful</strong> state will be generated for an object addition operation. If the original data synchronization task is in the <strong>Paused</strong> state, a modification record in the <strong>Pending</strong> state will be generated for an object addition operation. </p>

   </main>

   The status of an object addition record changes only when the original data synchronization task is in the Running state, and the status of the original task changes along with the status of the object addition record. The following table describes more information.

   | Status of an object addition record | Supported operations | Status of the original task |
   |---------------|--------------------------------------------------------------|------------|
   | Pending | View details and cancel. | Running |
   | Canceled | None | Running |
   | Modifying | None | Modifying |
   | Running | View details and abort. | Modifying |
   | Aborted | View details. | Running |
   | Integrating | View details. | Integrating |
   | Succeeded | View details. | Running |
   | Failed | View details and retry.<br>You can also click **<UI-TERM>View Cause</UI-TERM>** to go to the details page of the task and view the cause of the failure.  | Modifying/Integrating |

## Remove synchronization objects

1. On the details page of the target task, click **<UI-TERM key="oms-community.Detail.components.SyncObject.ViewObjectsToBeSynchronized">View Objects</UI-TERM>** in the upper-right corner.

2. In the **<UI-TERM key="oms-community.Detail.components.SyncObject.ViewObjectsToBeSynchronized">View Objects</UI-TERM>** dialog box, choose **<UI-TERM>Modify Objects</UI-TERM>** > **<UI-TERM key="oms-community.components.ViewObject.ReduceObjects">Remove Objects</UI-TERM>**.

3. In the **<UI-TERM key="oms-community.components.ViewObject.ReduceObjects">Remove Objects</UI-TERM>** dialog box, move the pointer over a migration object that you want to remove in the **<UI-TERM>Target Object</UI-TERM>** section on the right and click **<UI-TERM key="oms-community.common.TreeSearch.TargetNode.Remove">Remove</UI-TERM>**.

   You can select multiple synchronization objects and then click **<UI-TERM key="oms-community.Detail.components.StructMigration.BatchRemoval">Batch Remove</UI-TERM>**. In the dialog box that appears, click **<UI-TERM key="oms-community.pages.Sync.TableRow.Confirmation">OK</UI-TERM>**.

4. In the **<UI-TERM key="oms-community.components.ViewObj.DelObject.ReduceObjects">Remove Objects</UI-TERM>** dialog box, click **<UI-TERM key="oms-community.common.TreeSearch.TargetNode.Remove">Remove</UI-TERM>**.

5. In the confirmation dialog box that appears, confirm the migration object to remove and click **<UI-TERM key="oms-community.Operator.JDBCWriter.useJDBCWriterAction.Start">OK</UI-TERM>**.

   If the task is in the paused, failed, or running state, after you click OK, the migration object is immediately removed from the destination database.

   <main id="notice" type='notice'>
    <h4>Notice</h4>
    <ul>
    <li>
    <p>A removed migration object cannot be recovered, so proceed with caution. </p>
    </li>
    <li>
    <p>The final result of the object removal operation is either succeeded or failed for all migration objects. </p>
    </li>
    </ul>
   </main>

   After the object removal operation begins, records will be generated on the page displayed after you choose **<UI-TERM key="oms-community.Detail.components.SyncObject.ViewObjectsToBeSynchronized">View Objects</UI-TERM>** \> **<UI-TERM key="oms-community.Detail.components.SyncObject.ModifyObjectRecords">Object Modifications</UI-TERM>**. You can view the details of the records on this page. The status of object removal records can be **<UI-TERM key="oms-community.ModifyRecordTable.constants.PendingExecution">Pending</UI-TERM>**, **<UI-TERM key="oms-community.SystemManage.Authorization.contants.Canceled">Canceled</UI-TERM>**, **<UI-TERM>Modifying, Succeeded</UI-TERM>**, or **<UI-TERM key="oms-community.Home.Toolbar.Failed">Failed</UI-TERM>**. The operations that you can perform on an object removal record and the status of the original task vary with the status of the object removal record.

   | Status of an object removal record | Supported operations | Status of the original task |
   |---------------|--------------------------------------------------------------|------------|
   | Pending | View details and cancel. | Running |
   | Canceled | None | Running |
   | Modifying | None | Modifying |
   | Succeeded | View details. | Running |
   | Failed | View details and retry.<br>You can also click **<UI-TERM>View Cause</UI-TERM>** to go to the details page of the task and view the cause of the failure.  | Modifying |
