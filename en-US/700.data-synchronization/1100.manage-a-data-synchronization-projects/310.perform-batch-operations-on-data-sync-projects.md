# Perform batch operations on data synchronization tasks

This topic describes how to perform batch operations on data synchronization tasks by using OceanBase Migration Service (OMS).

## Background

OMS allows you to perform operations on multiple data synchronization tasks at a time on the **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">Synchronization Tasks</UI-TERM>** page. Supported batch operations on data synchronization tasks vary based on the task states.

| Task status | Supported batch operation |
|--------------------|--------------------|
| Not Started        | Batch start, batch delete, and batch modify alert configuration |
| Running            | Batch pause and batch modify alert configuration |
| Paused             | Batch restore, batch release, and batch modify alert configuration |
| Failed             | Batch restore, batch release, and batch modify alert configuration |
| Released           | Batch delete |
| Releasing          | N/A |
| Completed          | Batch release |

If you select multiple tasks for a batch operation, but not all tasks support this batch operation, a dialog box appears and displays the tasks that support this batch operation.

![batch-pause-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/batch-pause-en.png)

## Go to the Synchronization Tasks page

1. Log in to the OMS console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.layout.constants.DataSynchronization">Data Synchronization</UI-TERM>**. The **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">Synchronization Tasks</UI-TERM>** page automatically appears.

   You can select data synchronization tasks for a batch operation.

## Batch pause

OMS allows you to batch pause data synchronization tasks in the **<UI-TERM key="oms-community.Operator.constants.Running">Running</UI-TERM>** state.

1. On the **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">Synchronization Tasks</UI-TERM>** page, select the data synchronization tasks to be paused.

2. Click **<UI-TERM key="oms-community.Migration.constants.BatchPause">Batch Pause</UI-TERM>** in the lower part of the page.

3. In the dialog box that appears, click **<UI-TERM key="oms-community.components.ResetPassword.ResetUserPassword.Determine">OK</UI-TERM>**.

   This dialog box will display the number of tasks that support batch pausing, the task names, and the latest timestamps.

4. After the operation succeeds, the number of tasks that are successfully paused is displayed.

   For any task that failed the batch operation, troubleshoot the issue as prompted.

## Batch restore

OMS allows you to batch restore data synchronization tasks in the **<UI-TERM>Stopped</UI-TERM>** or **<UI-TERM key="oms-community.src.constants.Failed">Failed</UI-TERM>** state.

1. On the **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">Synchronization Tasks</UI-TERM>** page, select the data synchronization tasks to be restored.

2. Click **<UI-TERM key="oms-community.Migration.constants.BatchRecovery">Batch Restore</UI-TERM>** in the lower part of the page.

3. In the dialog box that appears, click **<UI-TERM key="oms-community.Operator.Store.useStoreAction.Update">OK</UI-TERM>**.

   This dialog box will display the number of tasks that support batch restoration, the task names, and the latest timestamps.

4. After the operation succeeds, the number of tasks that are successfully restored is displayed.

   For any task that failed the batch operation, troubleshoot the issue as prompted.

## Batch release

OMS allows you to batch release data synchronization tasks in the **<UI-TERM>Stopped</UI-TERM>**, **<UI-TERM key="oms-community.Migration.constants.Failed">Failed</UI-TERM>**, or **<UI-TERM key="oms-community.components.SyncSwitch.DbObjectTable.Completed">Completed</UI-TERM>** state.

1. On the **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">Synchronization Tasks</UI-TERM>** page, select the data synchronization tasks to be released.

2. Click **<UI-TERM key="oms-community.Migration.constants.BatchRelease">Batch Release</UI-TERM>** in the lower part of the page.

3. In the dialog box that appears, click **<UI-TERM key="oms-community.components.SyncSwitch.ConfirmStopSourceApp.Determine">OK</UI-TERM>**.

   This dialog box will display the number of tasks that support batch release, the task names, and the latest timestamps.

4. After the operation succeeds, the number of tasks that are successfully released is displayed.

   For any task that failed the batch operation, troubleshoot the issue as prompted.

## Batch start

OMS allows you to batch start data synchronization tasks in the **<UI-TERM key="oms-community.src.constants.NotStarted">Not Started</UI-TERM>** state.

1. On the **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">Synchronization Tasks</UI-TERM>** page, select the data synchronization tasks for batch start.

2. Click **<UI-TERM key="oms-community.Migration.constants.BatchStart">Batch Start</UI-TERM>** in the lower part of the page.

3. In the dialog box that appears, click **<UI-TERM key="oms-community.pages.User.Confirmation">OK</UI-TERM>**.

   This dialog box will display the number of tasks that support batch start, the task names, and the latest timestamps.

4. After the operation succeeds, the number of tasks that are successfully started is displayed.

   For any task that failed the batch operation, troubleshoot the issue as prompted.

## Batch delete

OMS allows you to batch delete data synchronization tasks in the **<UI-TERM key="oms-community.Sync.constants.NotStarted.5">Not Started</UI-TERM>** or **<UI-TERM key="oms-community.Sync.constants.Released">Released</UI-TERM>** state.

1. On the **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">Synchronization Tasks</UI-TERM>** page, select the data synchronization tasks for batch deletion.

2. Choose **<UI-TERM key="oms-community.components.BatchSelect.MoreBatchOperations">More Batch Operations</UI-TERM>** > **<UI-TERM key="oms-community.pages.Endpoint.BatchDelete">Batch Delete</UI-TERM>** in the lower part of the page.

3. In the dialog box that appears, click **<UI-TERM key="oms-community.pages.Endpoint.Confirmation">OK</UI-TERM>**.

   This dialog box will display the number of tasks that support batch deletion, the task names, and the latest timestamps.

4. After the operation succeeds, the number of tasks that are successfully deleted is displayed.

   For any task that failed the batch operation, troubleshoot the issue as prompted.

## Batch modify alert configuration

OMS allows you to batch modify alert configuration of data synchronization tasks in the **<UI-TERM key="oms-community.Migration.constants.NotStarted">Not Started</UI-TERM>**, **<UI-TERM key="oms-community.Operation.Overview.constants.Running">Running</UI-TERM>**, **<UI-TERM>Stopped</UI-TERM>**, or **<UI-TERM key="oms-community.Migration.constants.Failed">Failed</UI-TERM>** state.

1. On the **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">Synchronization Tasks</UI-TERM>** page, select the data synchronization tasks whose alert settings are to be modified.

2. Choose **<UI-TERM key="oms-community.components.BatchSelect.MoreBatchOperations">More Batch Operations</UI-TERM>** > **<UI-TERM key="oms-community.Migration.constants.ModifyAlertConfigurationsInBatches">Batch Modify Alert Configuration</UI-TERM>** in the lower part of the page.

3. In the **<UI-TERM key="oms-community.utils.hooks.useOMSWarn.ConfigureMultipleAlerts">Batch Configure Alerts</UI-TERM>** dialog box, specify the related parameters.

   ![batch-modify-alert-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/batch-modify-alert-en.png)

   OMS supports the following alert levels: **<UI-TERM key="oms-community.components.WarnLevel.Unprotected">No Protection</UI-TERM>**, **<UI-TERM key="oms-community.components.WarnLevel.HighProtection">High Protection</UI-TERM>**, **<UI-TERM key="oms-community.components.WarnLevel.MediumProtection">Medium Protection</UI-TERM>**, and **<UI-TERM key="oms-community.components.WarnLevel.DiBaoHu">Low Protection</UI-TERM>**. For more information, see [Alert settings](../../1000.system-management/200.alert-center/300.manage-alert-settings.md).

4. Click **<UI-TERM key="oms-community.JDBCWriter.New.Submitted">Submit</UI-TERM>**.

   To view the alerts generated for a data migration or synchronization task, see [View task alerts](../../1000.system-management/200.alert-center/100.view-project-alerts.md).

5. After the alert settings are modified for the selected tasks, a prompt is displayed on the page. For any task that failed the batch operation, troubleshoot the issue as prompted.
