# Release and delete a data synchronization task

If a data synchronization task is no longer required, you can pause and release it. After a data synchronization task is released, you can delete the task to release resources.

## Release a data synchronization task

After the data synchronization task is released, OceanBase Migration Service (OMS) terminates the task. This operation is irreversible. Proceed with caution. However, OMS does not delete the task. You can still view details about the task.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>You can release a data synchronization task in the <strong>Paused</strong>, <strong>Failed</strong>, or <strong>Completed</strong> state. </p>
  </main>

1. Log in to the OMS console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.components.CustomizedTable.DataSynchronization">Data Synchronization</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">Synchronization Tasks</UI-TERM>** page, click **<UI-TERM key="oms-community.Sync.constants.Release">Release</UI-TERM>** in the Actions column of the task that you want to release.

   You can also click the task name to go to the details page, and click **<UI-TERM key="oms-community.Migration.constants.Release">Release</UI-TERM>** in the upper-right corner.

4. In the dialog box that appears, click **<UI-TERM key="oms-community.components.ViewObj.AddObject.Ok">OK</UI-TERM>**.

## Delete a data synchronization task

After you delete a data synchronization task, data of the task cannot be recovered. Proceed with caution.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>You can delete only a data synchronization task in the <strong>Not Started</strong> or <strong>Released</strong> state. </p>
  </main>

1. Log in to the OMS console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.SystemParam.contants.DataSynchronization">Data Synchronization</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">Synchronization Tasks</UI-TERM>** page, click **<UI-TERM key="oms-community.Endpoint.constants.Delete">Delete</UI-TERM>** in the Actions column of the task that you want to delete.

   You can also click the task name to go to the details page, and click **<UI-TERM key="oms-community.migration.full.constants.Delete">Delete</UI-TERM>** in the upper-right corner.

4. In the dialog box that appears, click **<UI-TERM key="oms-community.components.ProjectLabel.LabelManager.Delete">Delete</UI-TERM>**.
