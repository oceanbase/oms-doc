# View details of a data synchronization task

After you start a data synchronization task, you can go to its details page to view its basic information, synchronization details, component monitoring, and synchronization objects.

## Access the details page

1. Log in to the OMS console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.SystemParam.contants.DataSynchronization">Data Synchronization</UI-TERM>**.

3. Click the name of the data synchronization task whose details you want to view to go to the details page.

   On the **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.DataSynchronization">Data Synchronization</UI-TERM>** page, you can search for data synchronization tasks by tag, status, type, and keyword. The status of a data synchronization task can be:

   * **<UI-TERM key="oms-community.src.constants.NotStarted">Not Started</UI-TERM><UI-TERM key="oms-community.BatchSelect.constants.Start">Start</UI-TERM>** in the Actions column to start the task.

   * **<UI-TERM key="oms-community.Migration.constants.Running">Running</UI-TERM>**: The data synchronization task is in progress. You can view the data synchronization plan and current progress on the right.

   * **<UI-TERM key="oms-community.Sync.constants.Modifying">Modifying</UI-TERM>**: The synchronization objects of the data synchronization task are being modified.

   * **<UI-TERM key="oms-community.ModifyRecordTable.constants.Merging">Integrating</UI-TERM>**: The data synchronization task is being integrated with the synchronization object modification task.

   * **<UI-TERM>Stopped</UI-TERM>**: The data synchronization task is manually paused. You can click **<UI-TERM key="oms-community.Operation.constants.Recovery">Resume</UI-TERM>** in the Actions column to resume the task.

   * **<UI-TERM key="oms-community.Migration.constants.Failed">Failed</UI-TERM>**: The data synchronization task has failed. You can view where the failure occurred on the right. To view the error messages, click the task name to go to the task details page.

   * **<UI-TERM key="oms-community.Operation.Overview.constants.Completed">Completed</UI-TERM>**: The data synchronization task is completed and OMS has synchronized the specified data to the target database in the configured synchronization mode.

   * **<UI-TERM key="oms-community.Overview.constants.Releasing">Releasing</UI-TERM>**: The data synchronization task is being released. You cannot edit a data synchronization task in this state.

   * **<UI-TERM key="oms-community.Overview.constants.Released">Released</UI-TERM>**: The data synchronization task is released. After the synchronization task is released, OMS terminates the task.

## View basic information

The **<UI-TERM key="oms-community.Operation.components.operationDetail.BasicInformation">Basic Information</UI-TERM>** section displays the basic information of the current data synchronization task.

| **Parameter** | **<UI-TERM key="oms-community.User.New.Description">Description</UI-TERM>** |
|--------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID | The unique ID of the data synchronization task.  |
| Synchronization Type | The synchronization type specified when the data synchronization task was created.  |
| Alert Level | The alert level of the data synchronization task. OMS supports the following alert levels: **<UI-TERM key="oms-community.components.WarnLevel.Unprotected">No Protection</UI-TERM>**, **<UI-TERM key="oms-community.components.WarnLevel.HighProtection">High Protection</UI-TERM>**, **<UI-TERM key="oms-community.components.WarnLevel.MediumProtection">Medium Protection</UI-TERM>**, and **<UI-TERM key="oms-community.components.WarnLevel.DiBaoHu">Low Protection</UI-TERM>**. For more information, see [Alert settings](../../1000.system-management/200.alert-center/300.manage-alert-settings.md).  |
| Created By | The user who created the data synchronization task.  |
| Creation At | The time when the data synchronization task was created.  |
| Incremental Synchronization Start Timestamp | The synchronization start timestamp specified when the data synchronization task was created.  |
| Connection Details | Click **<UI-TERM>Connection Details</UI-TERM>** to view information about the connection between the source and target databases of the data synchronization task.  |

You can perform the following operations:

* View the component monitoring metrics

   Click **<UI-TERM key="oms-community.Migration.constants.ViewComponentMonitoring">View Component Monitoring</UI-TERM>** in the upper-right corner to view information about the Store, Full-Import, and Incr-Sync components.

* View and modify synchronization objects

   Click **<UI-TERM key="oms-community.Sync.constants.ViewObjectsToBeSynchronized">View Objects</UI-TERM>** in the upper-right corner. The synchronization objects of the current data synchronization task are displayed. You can modify the synchronization objects during the running of a synchronization task. For more information, see [View and modify synchronization objects](../1100.manage-a-data-synchronization-projects/200.view-and-modify-objects-to-be-synchronized.md).

* Clone a data synchronization task

   Click **<UI-TERM key="oms-community.pages.Endpoint.MoreOperations">More</UI-TERM>** in the upper-right corner and select **<UI-TERM key="oms-community.Sync.constants.Clone">Clone</UI-TERM>** from the drop-down list to clone the current data synchronization task. During the cloning process, you can modify the task settings as needed.

* View parameters

   Click **<UI-TERM key="oms-community.components.MonitorDrawer.MoreOperations">More</UI-TERM>** in the upper-right corner and select **<UI-TERM key="oms-community.components.Transfer.ConfigureEtl">Settings</UI-TERM>** from the drop-down list. On the page that appears, you can view the parameters specified when the data synchronization task was created.

* Modify the alert level

  OMS Community Edition allows you to modify the alert level of a data synchronization task. For more information, see [Alert settings](../../1000.system-management/200.alert-center/300.manage-alert-settings.md).

* Download object settings

   OMS Community Edition allows you to download the configuration information of data synchronization tasks and import task settings in batches. For more information, see [Download and import the settings of synchronization objects](../1100.manage-a-data-synchronization-projects/400.download-and-import-the-settings-of-synchronization-objects.md).

* Modify the data source

  The **<UI-TERM key="oms-community.Migration.constants.ModifyEndpoint">Modify Data Source</UI-TERM>** feature of OMS Community Edition applies to the following scenarios. If you use this feature in any other scenarios, the data synchronization task will run abnormally and cannot be recovered.

  * When the primary and standby databases of the source database are switched, the IP address of the original primary database is specified as the data source. After the primary and standby databases are switched, you need to change the IP address to that of the new primary database.

  * When the IP address of the data source is changed to a domain name or the port is modified, but the database itself remains unchanged.

  * When the username or password of the data source is modified.

  To modify the data source, perform the following steps:

  1. Go to the details page of the data synchronization task.

  2. Click **<UI-TERM key="oms-community.components.ModifyRecordTable.MoreOperations">More</UI-TERM>** > **<UI-TERM key="oms-community.Migration.constants.ModifyEndpoint">Modify Data Source</UI-TERM>**.

  3. In the **<UI-TERM key="oms-community.src.oms-models.project.ModifyEndpoint.ApplicationScenario">Scenarios</UI-TERM>** dialog box, click **<UI-TERM key="oms-community.Operator.Connector.useConnectorAction.MigrationConfirm">OK</UI-TERM>** after confirming the prompt.

  4. In the **<UI-TERM key="oms-community.Migration.constants.ModifyEndpoint">Modify Data Source</UI-TERM>** dialog box, select the data source for **<UI-TERM key="oms-community.components.MonitorDrawer.Source">Source</UI-TERM>** and the data source for **<UI-TERM key="oms-community.biz.EndpointSelect.Group.TargetNode">Target</UI-TERM>**.

     <main id="notice" type='notice'>
     <h4>Notice</h4>
     <p>You can modify only data sources of the same type as the data source of the current task. </p>
     </main>

  5. Click **<UI-TERM key="oms-community.components.ViewObj.AddObject.Ok">OK</UI-TERM>**.

## View synchronization details

In the **<UI-TERM key="oms-community.Sync.Detail.SynchronizationDetails">Synchronization Details</UI-TERM>** section, you can view information about **<UI-TERM>Schema Synchronization</UI-TERM>**, **<UI-TERM>Incremental Synchronization Log Pull</UI-TERM>**, **<UI-TERM key="oms-community.SyncParameter.components.FullSyncForm.FullSynchronization">Full Synchronization</UI-TERM>**, and **<UI-TERM key="oms-community.New.components.MigrationObjectForm.IncrementalMigration">Incremental Synchronization</UI-TERM>**.

### Schema synchronization

   Schema synchronization creates a topic. After a schema synchronization task is completed, you can query the new topic.

   On the **<UI-TERM>Schema Synchronization</UI-TERM>** page, you can view the status, start time, end time, total duration, and progress of the schema synchronization task.

### Incremental synchronization log pulling

   On the **<UI-TERM>Incremental Synchronization Log Pulling</UI-TERM>** page, you can view the status, start time, end time, total duration, and progress of log pulling for incremental synchronization.

### Full synchronization

   A full synchronization migrates the existing data in the source database to the target database. On the **<UI-TERM key="oms-community.SyncParameter.components.FullSyncForm.FullSynchronization">Full Synchronization</UI-TERM>** page, you can view the status, start time, end time, total duration, and progress of a full synchronization task and the estimated total number of rows, completed number of rows, requests per second (RPS), and real-time traffic.

   On the **<UI-TERM key="oms-community.Migration.constants.FullSyncPerformance">Full Synchronization Performance</UI-TERM>** tab, you can view performance metrics in charts such as source RPS, target RPS, synchronization traffic at the source and target databases, average read time and sharding time at the source database, and average write time at the target database. These metrics can help you identify performance issues effectively.

### Incremental synchronization

   On the **<UI-TERM key="oms-community.Migration.constants.IncrementalMigration">Incremental Synchronization</UI-TERM>** page, you can view the status, latency, and the current timestamp of the incremental synchronization task. Based on this information, you can learn about the running status and performance of the data synchronization task.

   When you create a data synchronization task, we recommend that you set the alert level and alert frequency to learn about the task running status in time. OMS provides low-level protection by default. You can modify the alert level based on your business requirements. For more information, see [Alert settings](../../1000.system-management/200.alert-center/300.manage-alert-settings.md).

  * When the incremental synchronization latency exceeds the specified alert threshold, the incremental synchronization task remains Running and the system does not trigger any alerts.

  * When the incremental synchronization latency is less than or equal to the specified alert threshold, the incremental synchronization status changes from Running to Monitoring. After the incremental synchronization status changes to Monitoring, it will not change back to Running when the latency exceeds the specified alert threshold.

   The **<UI-TERM key="oms-community.Detail.components.IncrSyncMonitor.IncrementalSynchronizationPerformance">Incremental Synchronization Performance</UI-TERM>** section displays the incremental synchronization information in real time. In the upper-right corner of the **<UI-TERM key="oms-community.Detail.components.MonitorCard.IncrementalMigrationPerformance">Incremental Synchronization Performance</UI-TERM>** section, you can filter the incremental synchronization data of the last hour, last day, last week, or a custom period to view the changes in the synchronization performance in real time.

   | Parameter | Description |
   |---------|-------|
   | Latency | The latency in synchronizing incremental data from the source database to the target database, in seconds.  |
   | Synchronization Traffic | When incremental synchronization starts, the traffic may contain full-phase data traffic information.  |
   | Average Write Duration | The average write time during data synchronization.  |
   | RPS | The number of rows written to the target database per second.  |

## View the component monitoring metrics

On the details page of the data synchronization task, click **<UI-TERM key="oms-community.Sync.constants.ViewComponentMonitoring">View Component Monitoring</UI-TERM>** in the upper-right corner to view information about the Store, Full-Import, and Incr-Sync components.

* You can view the component ID, earliest pull timestamp, current pull timestamp, and status of the **Store component**. You can perform the following operations:

  * Start the component: Click **<UI-TERM key="oms-community.Detail.components.StartConnectorModal.Start">Start</UI-TERM>** in the Actions column of the component that you want to start. In the dialog box that appears, click **<UI-TERM key="oms-community.Migration.New.Confirmation">OK</UI-TERM>**. You can start only the component in the Stopped, Abnormal, or Unexpected Exit state.

  * Pause the component: Click **<UI-TERM key="oms-community.src.constants.Pause">Pause</UI-TERM>** in the Actions column of the component that you want to pause. In the dialog box that appears, click **<UI-TERM key="oms-community.Migration.hooks.useMigrationParams.Determine">OK</UI-TERM>**.

  * Update the component: Click **<UI-TERM key="oms-community.IncrSync.New.Update">Update</UI-TERM>** in the Actions column of the component that you want to update. On the **<UI-TERM key="oms-community.components.UpdateCompCfgDrawer.UpdateCompCfgDrawer.UpdateConfigurations">Update Configuration</UI-TERM>** page, modify the configurations and then click **<UI-TERM key="oms-community.Operation.components.machineCom.Update">Update</UI-TERM>**.

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>The system restarts after you update the component. Proceed with caution. </p>
    </main>

  * View logs: Click **<UI-TERM key="oms-community.components.SyncSwitch.DbObjectTable.ViewLogs">View Logs</UI-TERM>** in the Actions column for the component. The **<UI-TERM key="oms-community.Operator.constants.ViewLogs">View Logs</UI-TERM>** page displays the latest logs. Archived logs will not be displayed. You can search for, download, and copy the logs.

* You can view the component ID, current pull timestamp, latency, and status of the **Incr-Sync component**. You can perform the following operations:

  * Start the component: Click **<UI-TERM key="oms-community.Sync.constants.Start">Start</UI-TERM>** in the Actions column of the component that you want to start. In the dialog box that appears, select **<UI-TERM key="oms-community.Detail.components.StartConnectorModal.PullBack">Whether Reset Synchronization Timestamp</UI-TERM>** and click **<UI-TERM key="oms-community.components.ResetPassword.ResetUserPassword.Determine">OK</UI-TERM>**. You can start only the component in the Stopped or Abnormal state.

  * Pause the component: Click **<UI-TERM key="oms-community.Operator.constants.Pause">Pause</UI-TERM>** in the Actions column of the component that you want to pause. In the dialog box that appears, click **<UI-TERM key="oms-community.Operator.Connector.useConnectorAction.Update">OK</UI-TERM>**.

  * Update the component: Click **<UI-TERM key="oms-community.Operation.constants.Update">Update</UI-TERM>** in the Actions column of the component that you want to update. On the **<UI-TERM key="oms-community.Operator.Checker.useCheckerAction.UpdateConfigurations">Update Configuration</UI-TERM>** page, modify the configurations and then click **<UI-TERM key="oms-community.Operation.components.machineCom.Update">Update</UI-TERM>**.

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>The system restarts after you update the component. Proceed with caution. </p>
    </main>

  * Migrate the component: Click **<UI-TERM key="oms-community.IncrSync.New.Migration">Migrate</UI-TERM>** after the target component in the **Stopped** state. In the dialog box that appears, select **Node** and click **<UI-TERM key="oms-community.pages.EndpointPublic.Add">OK</UI-TERM>**.

  * View logs: Click **<UI-TERM key="oms-community.Migration.constants.ViewLogs">View Logs</UI-TERM>** in the Actions column for the component. The **<UI-TERM key="oms-community.Migration.constants.ViewLogs">View Logs</UI-TERM>** page displays the latest logs. Archived logs will not be displayed. You can search for, download, and copy the logs.

  * Delete the component: Click **<UI-TERM key="oms-community.Endpoint.constants.Delete">Delete</UI-TERM>** in the Actions column of the component that you want to delete. In the dialog box that appears, enter **delete** to confirm your operation and then click **<UI-TERM key="oms-community.Operator.Store.useStoreAction.Update">OK</UI-TERM>**. You can delete only the component in the Stopped or Abnormal state.

* You can view the component ID, current progress, and status of the **Full-Import component**. You can perform the following operations:

  * Pause the component: Click **<UI-TERM key="oms-community.Operator.constants.Pause">Pause</UI-TERM>** next to the component in the running state. In the dialog box that appears, click **<UI-TERM key="oms-community.Components.ReplicationInstance.Ok">OK</UI-TERM>**.

  * Rerun the component: Click **<UI-TERM key="oms-community.Migration.constants.Rerun">Rerun</UI-TERM>** next to the component in the stopped or abnormal state. In the dialog box that appears, click **<UI-TERM key="oms-community.pages.EndpointPublic.Add">OK</UI-TERM>**.

  * Resume the component: Click **<UI-TERM key="oms-community.Operation.constants.Recovery">Resume</UI-TERM>** next to the component in the stopped or abnormal state. In the dialog box that appears, click **<UI-TERM key="oms-community.Operator.JDBCWriter.useJDBCWriterAction.Start">OK</UI-TERM>**.

  * Update the component: Click **<UI-TERM key="oms-community.Operator.Checker.DisableUpdateBtn.Update">Update</UI-TERM>** next to the component. In the dialog box that appears, click **<UI-TERM key="oms-community.components.FullValidation.UpdateValidatingSqlDrawer.Determine">OK</UI-TERM>**.

  * Delete the component: Click **<UI-TERM key="oms-community.Notification.Setting.AlarmChannel.Delete">Delete</UI-TERM>** next to the component in the stopped or abnormal state. In the dialog box that appears, enter **delete** to confirm the operation, and then click **<UI-TERM key="oms-community.components.ImportTransferObj.Determine">OK</UI-TERM>**.

  * View logs: Click **<UI-TERM key="oms-community.Migration.constants.ViewLogs">View Logs</UI-TERM>** next to the component. On the **<UI-TERM key="oms-community.components.SyncSwitch.DbObjectTable.ViewLogs">View Logs</UI-TERM>** page, you can view the latest logs generated during the running of the component. Archived logs are not displayed. You can perform the **Search**, **Download**, and **<UI-TERM key="oms-community.components.Paragraph.Copy">Copy</UI-TERM>** operations.
