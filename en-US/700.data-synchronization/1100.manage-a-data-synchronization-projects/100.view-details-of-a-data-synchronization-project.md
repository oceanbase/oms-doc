# View details of a data synchronization task

After you start a data synchronization task, you can view the basic information, synchronization details, component monitoring, and synchronization objects of the task on the details page.

## Access the details page

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.components.CustomizedTable.DataSynchronization">Data Synchronization</UI-TERM>**.

3. Click the name of the target data synchronization task to go to the details page.

   On the **<UI-TERM key="oms-community.pages.Sync.DataSynchronization">Data Synchronization</UI-TERM>** page, you can search for the target data synchronization task by using the tags, status, type, and keywords. The status of a data synchronization task can be one of the following:

   * **<UI-TERM key="oms-community.components.StepsCard.StepCard.NotStarted">Not Started</UI-TERM>**: The data synchronization task has not been started. You can click **<UI-TERM key="oms-community.Migration.constants.Start">Start</UI-TERM>** in the Actions column to start the task.

   * **<UI-TERM key="oms-community.Sync.constants.YunXingZhong">Running</UI-TERM>**: The data synchronization task is running. The plan and current progress of the task are displayed on the right.

   * **<UI-TERM key="oms-community.Sync.constants.Modifying">Modifying</UI-TERM>**: The data synchronization task is being modified.

   * **<UI-TERM key="oms-community.Migration.constants.Merging">Integrating</UI-TERM>**: The data synchronization task of the modified synchronization object is being merged with the task of the synchronization object being modified.

   * **<UI-TERM key="oms-community.Migration.constants.Paused">Stopped</UI-TERM>**: The data synchronization task has been manually paused. You can click **<UI-TERM key="oms-community.Operation.constants.Recovery">Resume</UI-TERM>** in the Actions column to resume the task from the paused subtask.

   * **<UI-TERM key="oms-community.Overview.constants.Failed">Failed</UI-TERM>**: The data synchronization task has failed. The specific failed link is displayed on the right. You can click the task name to view the error message on the details page.

   * **<UI-TERM key="oms-community.Operation.Overview.constants.Completed">Completed</UI-TERM>**: The data synchronization task has been successfully executed. OMS has synchronized the specified data to the target database in the preset synchronization mode.

   * **<UI-TERM key="oms-community.Overview.constants.Releasing">Releasing</UI-TERM>**: The data synchronization task is being released. No operation can be performed on a data synchronization task in the Releasing state.

   * **<UI-TERM key="oms-community.src.constants.Released">Released</UI-TERM>**: The data synchronization task has been successfully released. After a data synchronization task is released, OMS terminates the current synchronization task.

## View basic information

The **<UI-TERM key="oms-community.Migration.Detail.BasicInformation">Basic Information</UI-TERM>** section displays the basic information of the current data synchronization task.

| **Parameter** |                                                                                      **<UI-TERM key="oms-community.pages.SystemParam.Description">Description</UI-TERM>**                                                                                       |
|--------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID     | The unique ID of the data synchronization task.             |
| Synchronization Type   | The synchronization type selected when the data synchronization task was created.                                                                    |
| Alert Level   | The alert level of the current task. OMS supports the following alert levels: **<UI-TERM key="oms-community.components.WarnLevel.Unprotected">No Protection</UI-TERM>**, **<UI-TERM key="oms-community.components.WarnLevel.HighProtection">High Protection</UI-TERM>**, **<UI-TERM key="oms-community.components.WarnLevel.MediumProtection">Medium Protection</UI-TERM>**, and **<UI-TERM key="oms-community.components.WarnLevel.DiBaoHu">Low Protection</UI-TERM>**. For more information, see [Alert settings](../../1000.system-management/200.alert-center/300.manage-alert-settings.md). |
| Creator    | The creator of the current data synchronization task.                          |
| Creation Time   | The creation time of the current data synchronization task.                         |
| Incremental Synchronization Start Point | The time node specified when the data synchronization task was created.                 |
|Connection Details|Click **<UI-TERM key="oms-community.Detail.components.MigrationInfos.ConnectionDetails">View Details</UI-TERM>** to view the connection information of the source and destination of the data synchronization task.|

You can perform the following operations:

* View component monitoring

  Click **<UI-TERM key="oms-community.Migration.constants.ViewComponentMonitoring">View Component Monitoring</UI-TERM>** in the upper-right corner of the page to view information about components such as Store, Incr-Sync, and Full-Import, and perform related operations.

* View and modify synchronization objects

  Click **<UI-TERM key="oms-community.Migration.hooks.useMigrationObject.ViewObjectsToBeMigrated">View Objects</UI-TERM>** in the upper-right corner of the page to view the list of synchronization objects of the current data synchronization task. You can also modify the synchronization objects during the task execution. For more information, see [View and modify synchronization objects](../1100.manage-a-data-synchronization-projects/200.view-and-modify-objects-to-be-synchronized.md).

* Clone a data synchronization task

  Click **<UI-TERM key="oms-community.project.cloudweb.MoreOperations">More</UI-TERM>** \> **<UI-TERM key="oms-community.Migration.constants.Clone">Clone</UI-TERM>** in the upper-right corner of the page to clone the current data synchronization task. You can modify the related configurations during the cloning process based on your business requirements.

* View parameter configurations

  Click **<UI-TERM key="oms-community.Detail.components.FullMigration.MoreOperations">More</UI-TERM>** \> **<UI-TERM key="oms-community.Sync.constants.ViewParameterConfigurations">Settings</UI-TERM>** in the upper-right corner of the page to view the configurations of the data synchronization task.

* Modify the alert level

  OMS Community Edition allows you to modify the alert level of a data synchronization task. For more information, see [Alert settings](../../1000.system-management/200.alert-center/300.manage-alert-settings.md).

* Download object configurations

  OMS allows you to download the configurations of a data synchronization task in the batch import format. For more information, see [Download and import synchronization object configurations](../1100.manage-a-data-synchronization-projects/400.download-and-import-the-settings-of-synchronization-objects.md).

* Modify the data source

  The **<UI-TERM key="oms-community.Migration.constants.ModifyEndpoint">Modify Data Source</UI-TERM>** feature of OMS Community Edition applies to the following scenarios. If you use this feature in any other scenarios, the data synchronization task will run abnormally and cannot be recovered.

  * When the primary and standby databases of the source database are switched, the IP address of the original primary database is specified as the data source. After the primary and standby databases are switched, you need to change the IP address to that of the new primary database.

  * When the IP address of the data source is changed to a domain name or the port is modified, but the database itself remains unchanged.

  * When the username or password of the data source is modified.

  To modify the data source, perform the following steps:

  1. Go to the details page of the data synchronization task.

  2. Click **<UI-TERM key="oms-community.components.ModifyRecordTable.MoreOperations">More</UI-TERM>** > **<UI-TERM key="oms-community.Migration.constants.ModifyEndpoint">Modify Data Source</UI-TERM>**.

  3. In the **<UI-TERM key="oms-community.src.oms-models.project.ModifyEndpoint.ApplicationScenario">Scenarios</UI-TERM>** dialog box, click **<UI-TERM key="oms-community.Operator.Connector.useConnectorAction.MigrationConfirm">OK</UI-TERM>** after confirming the prompt.

  4. In the **<UI-TERM key="oms-community.Migration.constants.ModifyEndpoint">Modify Data Source</UI-TERM>** dialog box, select the data source for **<UI-TERM key="oms-community.components.MonitorDrawer.Source">Source</UI-TERM>** and the data source for **<UI-TERM key="oms-community.biz.EndpointSelect.Group.TargetNode">Target</UI-TERM>**.

     <main id="notice" type='notice'>
     <h4>Notice</h4>
     <p>You can modify only data sources of the same type as the data source of the current task. </p>
     </main>

  5. Click **<UI-TERM key="oms-community.components.ViewObj.AddObject.Ok">OK</UI-TERM>**.

## View synchronization details

You can view details about **<UI-TERM key="oms-community.components.SyncOption.CheckSyncKind.SchemaSynchronization">Schema synchronization</UI-TERM>**, **Incremental Log Pulling**, **<UI-TERM key="oms-community.components.SyncOption.CheckSyncKind.FullSynchronization">Full synchronization</UI-TERM>**, and **<UI-TERM key="oms-community.Migration.constants.IncrementalMigration">Incremental Synchronization</UI-TERM>** in the **<UI-TERM key="oms-community.Sync.Detail.SynchronizationDetails">Synchronization Details</UI-TERM>** section.

### Schema Synchronization

Schema Synchronization creates a topic. After the topic is created, you can query the topic.

You can view the status, start time, end time, total time consumed, and progress of Schema Synchronization on the **<UI-TERM key="oms-community.components.SyncOption.CheckSyncKind.SchemaSynchronization">Schema synchronization</UI-TERM>** page.

### Incremental Log Pulling

You can view the status, start time, end time, total time consumed, and progress of Incremental Log Pulling on the **Incremental Log Pulling** page.

### Full Synchronization

Full Synchronization synchronizes the existing data in the source to the destination. You can view the status, start time, end time, total time consumed, and progress of Full Synchronization on the **<UI-TERM key="oms-community.components.SyncOption.CheckSyncKind.FullSynchronization">Full synchronization</UI-TERM>** page. You can also view the estimated total number of rows, the number of rows synchronized, RPS, and real-time traffic.

In the **<UI-TERM key="oms-community.Migration.constants.FullSyncPerformance">Full Synchronization Performance</UI-TERM>** section, you can view the **<UI-TERM key="oms-community.components.FullMigrationPerformance.constants.SourceRps">Source RPS</UI-TERM>**, **<UI-TERM key="oms-community.components.FullMigrationPerformance.constants.TargetRps">Target RPS</UI-TERM>**, **<UI-TERM key="oms-community.components.FullMigrationPerformance.constants.SourceSyncTraffic">Source synchronous traffic</UI-TERM>**, **<UI-TERM key="oms-community.components.FullMigrationPerformance.constants.DestinationSyncTraffic">Target synchronous traffic</UI-TERM>**, **<UI-TERM key="must.components.FullMigrationPerformance.constants.AverageReadTimeAtSource">Average Read Time at Source</UI-TERM>**, **<UI-TERM key="must.components.FullMigrationPerformance.constants.AverageSlicingTimeAtSource">Average Slicing Time at Source</UI-TERM>**, and **<UI-TERM key="must.components.FullMigrationPerformance.constants.AverageDestinationWriteTime">Average Write Time at Target</UI-TERM>** in a chart to identify performance issues.

### Incremental Synchronization

You can view the status, delay, and current timestamp of Incremental Synchronization on the **<UI-TERM key="oms-community.New.components.MigrationObjectForm.IncrementalMigration">Incremental Synchronization</UI-TERM>** page. This helps you monitor the performance of data synchronization tasks.

When you create a data synchronization task, we recommend that you set the alert level and alert frequency to track the task status. By default, OMS provides low-level protection. You can modify the alert level based on your business requirements. For more information, see [Set alerts](../../1000.system-management/200.alert-center/300.manage-alert-settings.md).

* If the delay of Incremental Synchronization of a data synchronization task exceeds the configured alert time, the Incremental Synchronization step remains in the running state, and no alert is triggered.

* If the delay of Incremental Synchronization of a data synchronization task is less than or equal to the configured alert time, the Incremental Synchronization step switches from the running state to the monitoring state. After the delay exceeds the configured alert time, the Incremental Synchronization step does not switch back to the running state.

The **<UI-TERM key="oms-community.Detail.components.IncrSyncMonitor.IncrementalSynchronizationPerformance">Incremental Synchronization Performance</UI-TERM>** section displays real-time information about Incremental Synchronization. You can click the **<UI-TERM key="oms-community.Operation.components.MetricChart.NearlyHour">Last 1 Hour</UI-TERM>**, **<UI-TERM key="oms-community.Detail.components.MonitorCard.LastDay">Last 24 Hours</UI-TERM>**, or **<UI-TERM key="oms-community.Detail.components.IncrSyncMonitor.LastWeek">Last 7 Days</UI-TERM>** icon in the upper-right corner of the **Incremental Synchronization Monitoring** section to filter the incremental synchronization data in a specific time period and view the synchronization performance in segments or in real time.

| Parameter | Description |
|---------|-------|
| Delay | The time lag between when incremental changes in the source are synchronized to the destination, in seconds. |
| Synchronization Traffic | The traffic during incremental synchronization may include data traffic from the full synchronization phase. |
| Average Write Time | The average write time during data synchronization. |
| RPS | The number of rows written to the destination per second. |

## View component monitoring

On the details page of a data synchronization task, click **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.ViewComponentMonitoring">View Component Monitoring</UI-TERM>** in the upper-right corner. You can view information about the Store, Full-Import, and Incr-Sync components.

* The information about the **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.StoreLogPullComponents">Store</UI-TERM>** includes **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.ComponentId">Component ID</UI-TERM>**, **Earliest Pull Point**, **Current Pull Point**, and **<UI-TERM key="oms-community.Operation.constants.State">Status</UI-TERM>**. You can perform the following operations:

  * Start the component: Click **<UI-TERM key="oms-community.Audit.constants.Start">Start</UI-TERM>** after the target component in the **Stopped**, **Abnormal**, or **Unexpected Exit** state. In the dialog box that appears, click **<UI-TERM key="oms-community.components.SyncObjectForm.Determine">OK</UI-TERM>**.

  * Pause the component: Click **<UI-TERM key="oms-community.Operator.constants.Pause">Pause</UI-TERM>** after the target component in the **Running** state. In the dialog box that appears, click **<UI-TERM key="oms-community.Migration.hooks.useMigrationParams.Determine">OK</UI-TERM>**.

  * Update the component: Click **<UI-TERM key="oms-community.IncrSync.New.Update">Update</UI-TERM>** after the target component. On the **<UI-TERM key="oms-community.Operator.Connector.useConnectorAction.UpdateConfigurations">Update Configuration</UI-TERM>** page, modify the corresponding configurations and click **<UI-TERM key="oms-community.IncrSync.New.Update">Update</UI-TERM>**.

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>The update operation includes a restart. Proceed with caution. </p>
    </main>

  * View logs: Click **<UI-TERM key="oms-community.Operator.constants.ViewLogs">View Logs</UI-TERM>** after the target component. The **<UI-TERM key="oms-community.components.Operator.openLog.ViewLogs">View Logs</UI-TERM>** page displays the most recent logs generated during the running of the component. Archived logs are not displayed. You can perform the **Search**, **Download**, and **<UI-TERM key="oms-community.components.Paragraph.Copy">Copy</UI-TERM>** operations.

* The information about the **Incr-Sync Incremental Synchronization Component** includes **<UI-TERM key="oms-community.components.MonitorDrawer.ComponentId">Component ID</UI-TERM>**, **Current Point**, **<UI-TERM key="oms-community.Sync.constants.Latency">Latency</UI-TERM>**, and **<UI-TERM key="oms-community.Operation.Connector.State">Status</UI-TERM>**. You can perform the following operations:

  * Start the component: Click **<UI-TERM key="oms-community.Sync.constants.Start">Start</UI-TERM>** after the target component in the **Stopped** or **Abnormal** state. In the dialog box that appears, select **<UI-TERM key="oms-community.IncrSync.New.PullBack">Whether Reset Synchronization Timestamp</UI-TERM>**, and click **<UI-TERM key="oms-community.Operator.JDBCWriter.useJDBCWriterAction.Update">OK</UI-TERM>**.

  * Pause the component: Click **<UI-TERM key="oms-community.src.constants.Pause">Pause</UI-TERM>** after the target component in the **Running** state. In the dialog box that appears, click **<UI-TERM key="oms-community.Endpoint.New.Add">OK</UI-TERM>**.

  * Update the component: Click **<UI-TERM key="oms-community.Operation.Machine.Update">Update</UI-TERM>** after the target component. On the **<UI-TERM key="oms-community.components.UpdateCompCfgDrawer.UpdateCompCfgDrawer.UpdateConfigurations">Update Configuration</UI-TERM>** page, modify the corresponding configurations and click **<UI-TERM key="oms-community.Operation.components.machineCom.Update">Update</UI-TERM>**.

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>The update operation includes a restart. Proceed with caution. </p>
    </main>

  * Migrate the component: Click **<UI-TERM key="oms-community.IncrSync.New.Migration">Migrate</UI-TERM>** after the target component in the **Stopped** state. In the dialog box that appears, select **Node** and click **<UI-TERM key="oms-community.pages.EndpointPublic.Add">OK</UI-TERM>**.

  * View logs: Click **<UI-TERM key="oms-community.components.SyncSwitch.DbObjectTable.ViewLogs">View Logs</UI-TERM>** after the target component. The **<UI-TERM key="oms-community.components.SyncSwitch.DbObjectTable.ViewLogs">View Logs</UI-TERM>** page displays the most recent logs generated during the running of the component. Archived logs are not displayed. You can perform the **Search**, **Download**, and **<UI-TERM key="oms-community.components.FullValidation.UpdateValidatingSqlDrawer.Copy">Copy</UI-TERM>** operations.

  * Delete the component: Click **<UI-TERM key="oms-community.pages.User.Delete">Delete</UI-TERM>** after the target component in the **Stopped** or **Abnormal** state. In the dialog box that appears, enter **delete** to confirm the operation and click **<UI-TERM key="oms-community.Detail.components.SyncSteps.Determine">OK</UI-TERM>**.

* The information of a **Full-Import component** includes **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.ComponentId">Component ID</UI-TERM>**, **Current Progress**, and **<UI-TERM key="oms-community.Operation.Store.State">Status</UI-TERM>**. You can perform the following operations on the component:

  * Pause the component: In the **<UI-TERM key="oms-community.Operator.constants.Pause">Pause</UI-TERM>** column of the component in the running state, click **<UI-TERM key="oms-community.Operator.constants.Pause">Pause</UI-TERM>**. In the dialog box that appears, click **<UI-TERM key="oms-community.Components.ReplicationInstance.Ok">OK</UI-TERM>**.

  * Rerun the component: In the **<UI-TERM key="oms-community.Migration.constants.Rerun">Rerun</UI-TERM>** column of the component in the stopped or abnormal state, click **<UI-TERM key="oms-community.Migration.constants.Rerun">Rerun</UI-TERM>**. In the dialog box that appears, click **<UI-TERM key="oms-community.pages.EndpointPublic.Add">OK</UI-TERM>**.

  * Resume the component: In the **<UI-TERM key="oms-community.Operation.constants.Recovery">Resume</UI-TERM>** column of the component in the stopped or abnormal state, click **<UI-TERM key="oms-community.Operation.constants.Recovery">Resume</UI-TERM>**. In the dialog box that appears, click **<UI-TERM key="oms-community.Operator.JDBCWriter.useJDBCWriterAction.Start">OK</UI-TERM>**.

  * Update the component: In the **<UI-TERM key="oms-community.Operator.Checker.DisableUpdateBtn.Update">Update</UI-TERM>** column of the component, click **<UI-TERM key="oms-community.Operator.Checker.DisableUpdateBtn.Update">Update</UI-TERM>**. In the dialog box that appears, click **<UI-TERM key="oms-community.components.FullValidation.UpdateValidatingSqlDrawer.Determine">OK</UI-TERM>**.

  * Delete the component: In the **<UI-TERM key="oms-community.Notification.Setting.AlarmChannel.Delete">Delete</UI-TERM>** column of the component in the stopped or abnormal state, click **<UI-TERM key="oms-community.Notification.Setting.AlarmChannel.Delete">Delete</UI-TERM>**. In the dialog box that appears, enter **delete** to confirm the operation, and then click **<UI-TERM key="oms-community.components.ImportTransferObj.Determine">OK</UI-TERM>**.

  * View logs: In the **<UI-TERM key="oms-community.Migration.constants.ViewLogs">View Logs</UI-TERM>** column of the component, click **<UI-TERM key="oms-community.Migration.constants.ViewLogs">View Logs</UI-TERM>**. On the **<UI-TERM key="oms-community.components.SyncSwitch.DbObjectTable.ViewLogs">View Logs</UI-TERM>** page, you can view the latest logs generated during the running of the component. Archived logs are not displayed. You can perform the **Search**, **Download**, and **<UI-TERM key="oms-community.components.Paragraph.Copy">Copy</UI-TERM>** operations.
