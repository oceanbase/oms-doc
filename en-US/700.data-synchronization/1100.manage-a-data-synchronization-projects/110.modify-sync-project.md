# Change the name of a data synchronization task

This topic describes how to change the name of a data synchronization task when you use OceanBase Migration Service (OMS).

## Limits

* OMS allows you to change the name of a data migration task in the **<UI-TERM key="oms-community.components.StepsCard.StepCard.NotStarted">Not Started</UI-TERM>**, **<UI-TERM key="oms-community.Sync.constants.YunXingZhong">Running</UI-TERM>**, **<UI-TERM>Stopped</UI-TERM>**, or **<UI-TERM key="oms-community.src.constants.Failed">Failed</UI-TERM>** state.

* If you have created a sub-task to modify the synchronization objects during the running of a data synchronization task, you cannot change the task name. For more information about how to modify the synchronization objects, see [View and modify synchronization objects](../1100.manage-a-data-synchronization-projects/200.view-and-modify-objects-to-be-synchronized.md).

* The task name is a unique identifier for a task of a user.

## Procedure

1. Log on to the OMS console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.DataSynchronization">Data Synchronization</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">Synchronization Tasks</UI-TERM>** page, click the **<UI-TERM key="oms-community.EndpointPublic.constants.Editing">Edit</UI-TERM>** icon next to the name of the target task.

   ![rename-sync-1-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/rename-sync-1-en.png)

   You can also click the name of the target task to go to the details page of the task, and then click the **<UI-TERM key="oms-community.Endpoint.constants.Editing">Edit</UI-TERM>** icon next to the task name.

   ![rename-sync-2-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/rename-sync-2-en.png)

4. In the **<UI-TERM key="oms-community.MigretionOrSync.Edit.ProjectName.1">Edit Task Name</UI-TERM>** dialog box, enter a new task name.

5. Click **<UI-TERM key="oms-community.components.WorkerGradeSelect.Ok">OK</UI-TERM>**.
