# Start and pause a data synchronization task

This topic describes how to start, pause, or resume a data synchronization task.

## Start a data synchronization task

If you have created a data synchronization task but did not start it after it passed the pre-check, you can find the task in the list of synchronization tasks and start it.

1. Log on to the OceanBase Migration Service (OMS) console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.Sync.Detail.DataSynchronization">Data Synchronization</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">Synchronization Tasks</UI-TERM>** page, click **<UI-TERM key="oms-community.Audit.constants.Start">Start</UI-TERM>** in the Actions column of the task that you want to start.

   You can also click the task name on the **<UI-TERM key="oms-community.layout.constants.DataSynchronization">Data Synchronization</UI-TERM>** page to go to the details page, and click **<UI-TERM key="oms-community.JDBCWriter.New.Start">Start</UI-TERM>** in the upper-right corner.

4. In the dialog box that appears, click **<UI-TERM key="oms-community.pages.Sync.TableRow.Confirmation">OK</UI-TERM>**.

## Pause a data synchronization task

You can pause a data synchronization task only when it is in the **<UI-TERM key="oms-community.src.constants.Running">Running</UI-TERM>** state. After you pause a data synchronization task, OMS stops scheduling the data synchronization task, and the latency increases in real time.

1. Log on to the OMS console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.components.UserGuidance.DataSynchronization">Data Synchronization</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">Synchronization Tasks</UI-TERM>** page, click **<UI-TERM key="oms-community.src.constants.Pause">Pause</UI-TERM>** in the Actions column of the data synchronization task that you want to pause.

   You can also click the task name on the **<UI-TERM key="oms-community.layout.constants.DataSynchronization">Data Synchronization</UI-TERM>** page to go to the details page, and click **<UI-TERM key="oms-community.Operator.constants.Pause">Pause</UI-TERM>** in the upper-right corner.

4. In the dialog box that appears, click **<UI-TERM key="oms-community.Operator.Connector.useConnectorAction.MigrationConfirm">OK</UI-TERM>**.

   <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>This operation will pause the synchronization component. The task cannot be recovered if it is paused for more than 12 hours. </p>
   </main>

## Resume a data synchronization task

You can manually resume a data synchronization task that is in the **Paused** or **<UI-TERM key="oms-community.Audit.Deatil.Failed">Failed</UI-TERM>** state. After you resume the task, OMS continues to run the data synchronization task and reduces the synchronization latency as soon as possible.

1. Log on to the OMS console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.SystemParam.contants.DataSynchronization">Data Synchronization</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.pages.Sync.SynchronizationProjectList">Synchronization Tasks</UI-TERM>** page, click **Restore** in the Actions column of the data synchronization task that you want to resume.

   You can also click the task name on the **<UI-TERM key="oms-community.Sync.New.DataSynchronization">Data Synchronization</UI-TERM>** page to go to the details page, and click **Restore** in the upper-right corner.

4. In the dialog box that appears, click **<UI-TERM key="oms-community.pages.EndpointPublic.Confirmation">OK</UI-TERM>**.
