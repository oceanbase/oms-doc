# Use SQL conditions to filter data

This topic describes the application scenarios, limits, and procedure of data filtering by using SQL conditions after you select the synchronization objects when you create a data synchronization task.

## Scenarios

When you create a data synchronization task, you can specify SQL conditions to filter data. Only the data that meets the filter conditions will be synchronized to the destination database. This feature allows you to filter data in multiple scenarios, such as scheduled data synchronization or migration, data table sharding, and historical and dirty data filtering.

## Limits

* An SQL condition filters only fields of the current table. Cross-table filtering is not supported.

* SQL conditions are supported in full synchronization and incremental synchronization.

## Procedure

1. Create a data migration task and configure it to the **<UI-TERM key="oms-community.components.SyncObjectForm.SelectASynchronizationRange">Select Synchronization Objects</UI-TERM>** step.

   For more information, see the topic about creating a data synchronization task between the corresponding data sources in the [Data synchronization](../100.data-synchronization-overview.md) chapter.

2. Select the synchronization object, and then hover the pointer over the target object in the **<UI-TERM>Target Objects</UI-TERM>** list on the right of the **<UI-TERM>Specify Synchronization Scope</UI-TERM>** section.

3. Click **<UI-TERM key="oms-community.biz.ETL.ETLFormDrawer.Set">Settings</UI-TERM>**.

   ![row-filter-3-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/row-filter-3-en.png)

4. In the **<UI-TERM key="oms-community.biz.ETL.ETLDescription.Set">Settings</UI-TERM>** dialog box, specify a standard SQL `WHERE` clause to filter data by row.

   ![row-filter-1-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/row-filter-1-en.png)

5. Click **<UI-TERM key="oms-community.components.ETL.ETLFormDrawer.VerificationSyntax">Validate Syntax</UI-TERM>**.

   ![row-filter-2-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/row-filter-2-en.png)

6. Click **<UI-TERM key="oms-community.Components.ReplicationInstance.Ok">OK</UI-TERM>**.

7. Complete subsequent task settings as prompted.
