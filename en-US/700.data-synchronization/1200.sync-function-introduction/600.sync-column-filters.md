# Column filtering

This topic describes how to use the column filtering feature when you create a data synchronization task.

## Procedure

1. Create a data synchronization task and configure it to the **<UI-TERM key="oms-community.SyncObjectForm.ObjectSelect.SelectSynchronizationObjects">Select Synchronization Objects</UI-TERM>** step.

   For more information, see the topic about creating a data synchronization task between the corresponding data sources in the [Data synchronization](../100.data-synchronization-overview.md) chapter.

2. After you select the synchronization objects, hover the pointer over the target table object in the **<UI-TERM>Target Objects</UI-TERM>** list on the right side of the **<UI-TERM>Select Synchronization Scope</UI-TERM>** section.

3. Click **<UI-TERM key="oms-community.components.ViewObject.Set">Settings</UI-TERM>**.

   ![column-filter-1-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/column-filter-1-en.png)

4. In the **<UI-TERM key="oms-community.components.ViewObject.Set">Settings</UI-TERM>** dialog box, select the columns to be synchronized in the **<UI-TERM key="oms-community.components.ETL.ETLFormDrawer.SelectAColumn">Select Columns</UI-TERM>** section.

   ![column-filter-2-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/column-filter-2-en.png)

   <main id="notice" type='notice'>
   <h4>Notice</h4>
   <p>If you select all or no columns, the OMS feature will synchronize all columns. </p>
   </main>

5. Click **<UI-TERM key="oms-community.Endpoint.New.Add">OK</UI-TERM>**.
