# Upgrade OceanBase Incremental CDC

This topic describes how to upgrade OceanBase Incremental CDC by using a tool or manually.

## Background information

Different versions of OceanBase Database may require corresponding CDC libraries to pull incremental log data. The Store component of the OMS Community Edition pulls incremental data from OceanBase Database by loading CDC dynamic libraries.

The following table lists the directories related to the OMS Community Edition Store component and OceanBase CDC in `/home/ds/lib64/reader`.

| OMS Community Edition Store component and OceanBase CDC directory  | OceanBase Database version range |
|------------------------|-----------------------|
| ob-ce-reader | Not upgradable |
| ob-ce-4.x-reader | OceanBase Database V4.0.0 and later, V4.2.1 and earlier |
| ob-ce-4.2.2-reader | OceanBase Database V4.2.2 and later, V4.3.0 and earlier |
| ob-ce-4.3-reader | OceanBase Database V4.3.x and later, V4.4.x and earlier |
| ob-ce-4.4-reader | OceanBase Database V4.4.x and later |

## Upgrade by using a tool

1. [Download the CDC rpm package](https://en.oceanbase.com/softwarecenter): incremental data acquisition tool (OB CDC).

    Select the corresponding version of the CDC package based on the actual version of OceanBase Database.

    ![omsce2-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-ce/omsce2-zh.png)

2. After the rpm package is downloaded, copy it to the OMS Community Edition container and execute the CDC update script.

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>Before you update, back up the files in <code>/home/ds/lib64/reader/ob-ce-xxx-reader</code>.</p>
    </main>

    ```shell
    # Enter the container
    sudo docker exec -it [container name] bash

    # Execute the CDC update script
    cd /root
    bash obcdc_update.sh [rpm package path]

    # Example
    bash obcdc_update.sh /home/ds/oceanbase-ce-cdc-4.2.1.10-110000022024112010.el7.x86_64.rpm
    ```

3. Follow the prompts to complete the upgrade.

    1. The current CDC version to be updated is 4.x. Do you want to proceed? [y/n]

        Enter y to proceed. Enter n to exit.

    2. Start decompressing the rpm package.

    3. Start updating the CDC.

    4. The update is successful. Do you want to update the existing Store component's CDC? [y/n]

        Enter y to update the existing Store component's CDC. Enter n to end the update.

    5. If you choose to continue the update:

        Enter the Store components to be updated, separated by commas (,). The format is store{port}. Enter all to update all, or enter exit to exit. For example, store7100,store7101,store7102.

        * Enter all: update all CDCs in /home/ds/store/store{port}.

        * Enter a specific Store: update the CDC in the specified store directory.

        * Enter exit: end the update.

4. If you updated the existing Store component's CDC, restart the Store component and check whether the position is advanced.

## Manually upgrade

1. [Download the CDC rpm package](https://en.oceanbase.com/softwarecenter): the incremental data capture tool (OceanBase CDC).

    Click the version number in the upper-right corner to select the CDC package corresponding to the actual OceanBase Database version.

    ![omsce2-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-ce/omsce2-zh.png)

2. Decompress the rpm package: `rpm2cpio oceanbase-ce-cdc-x.x.x.x-xxxx.el7.x86_64.rpm|cpio -idmu --quiet`.

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>OMS Community Edition only supports <b>-el7</b>. </p>
    </main>

3. After decompression, the following files appear in the current directory `./home/admin/oceanbase/lib64`.

    ```shell
    libobcdc.so.x.x.x.x
    libobcdc.so.x -> libobcdc.so.x.x.x.x
    libobcdc.so -> libobcdc.so.x
    ```

4. Enter the OMS Community Edition container and use the `cd` command to go to the `/home/ds/lib64/reader` directory. Go to the `ob-ce-xxx-reader` directory corresponding to the OceanBase Database version in the directory.

5. Back up the original files in the `ob-ce-xxx-reader` directory.

6. Copy the files from `./home/admin/oceanbase/lib64` to the `ob-ce-xxx-reader` directory.

After the preceding steps are completed, the new Store components will use the upgraded CDC library. If existing Store components need to be upgraded, perform the following steps.

1. Go to the running directory of the Store component, `/home/ds/store/store{port}/lib64/reader`, which has the same directory structure as `/home/ds/lib64/reader`.

2. Copy the files from `./home/admin/oceanbase/lib64` to `/home/ds/store/store{port}/lib64/reader/ob-ce-xxx-reader`.

3. In the OMS Community Edition console, pause the Store component. For more information, see [Pause a Store component](../900.o-m-manual/400.components/100.store/400.start-and-pause-a-store.md).

4. Run the following command to confirm that the Store process has stopped. If the Store process is not stopped, you can run `kill -9`.

    ```shell
    ps -ef|grep store{port}
    ```

5. In the OMS Community Edition console, start the Store component.
