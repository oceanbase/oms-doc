# Upgrade the OceanBase CDC library

This topic describes how to upgrade the OceanBase CDC library.

## Background information

Different versions of OceanBase Database may require corresponding CDC libraries to pull incremental logs. The Store component of OMS Community Edition pulls incremental data from OceanBase Database by loading a CDC dynamic library.

The following table describes the OceanBase CDC library directories for the Store component of OMS Community Edition under `/home/ds/lib64/reader`.

| OceanBase CDC library directory for the Store component | OceanBase Database version range |
|------------------------|-----------------------|
| ob-ce-reader | Cannot be upgraded |
| ob-ce-4.x-reader | OceanBase Database V4.0.0 through V4.2.1 |
| ob-ce-4.2.2-reader | OceanBase Database V4.2.2 through V4.3.0 |
| ob-ce-4.3-reader | OceanBase Database V4.3.0 and later |

## Procedure

1. [Download the CDC RPM package](https://www.oceanbase.com/softwarecenter): Incremental Data Capture (OB CDC).

    Click the version number in the upper-right corner and select the CDC package that corresponds to your OceanBase Database version.

    ![omsce2-zh](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-ce/omsce2-zh.png)

2. Decompress the RPM package: `rpm2cpio oceanbase-ce-cdc-x.x.x.x-xxxx.el7.x86_64.rpm|cpio -idmu --quiet`.

    <main id="notice" type='notice'>
    <h4>Note</h4>
    <p>OMS Community Edition supports only the <b>x86 build for el7</b>.</p>
    </main>

3. After decompression, the following files appear in `./home/admin/oceanbase/lib64` under the current directory:

    ```shell
    libobcdc.so.x.x.x.x
    libobcdc.so.x -> libobcdc.so.x.x.x.x
    libobcdc.so -> libobcdc.so.x
    ```

4. Enter the OMS Community Edition container and run the `cd` command to go to `/home/ds/lib64/reader`. Then, based on the OceanBase Database version, enter the corresponding `ob-ce-xxx-reader` directory listed in the preceding table.

5. Back up the original files in the `ob-ce-xxx-reader` directory.

6. Copy the files from `./home/admin/oceanbase/lib64` in the decompressed RPM package to the `ob-ce-xxx-reader` directory.

After you complete the preceding steps, newly created Store components use the upgraded CDC library. To upgrade an existing Store component, perform the following steps:

1. Go to the runtime directory of the Store component, `/home/ds/store/store{port}/lib64/reader`. Its directory structure is the same as that of `/home/ds/lib64/reader`.

2. Copy the files from `./home/admin/oceanbase/lib64` in the decompressed RPM package to `/home/ds/store/store{port}/lib64/reader/ob-ce-xxx-reader`.

3. In the OMS Community Edition console, pause the Store component. For more information, see [Pause a Store component](../900.o-m-manual/400.components/100.store/400.start-and-pause-a-store.md).

4. Run the following command to confirm that the Store process has stopped. If it has not stopped, you can run `kill -9`.

    ```shell
    ps -ef|grep store{port}
    ```

5. In the OMS Community Edition console, start the Store component.
