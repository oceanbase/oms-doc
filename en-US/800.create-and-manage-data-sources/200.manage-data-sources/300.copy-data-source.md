# Copy a data source

OceanBase Migration Service (OMS) Community Edition allows you to create a data source by copying an existing one. This feature helps you create similar data sources. This topic describes how to copy a data source.

## Procedure

1. Log on to the OMS Community Edition console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.DataSourceManagement">Data Source Management</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.pages.EndpointPublic.DataSources">Data Sources</UI-TERM>** page, click the **<UI-TERM key="oms-community.EndpointPublic.constants.Copy">Copy</UI-TERM>** icon next to the data source that you want to copy.

   If your business system is deployed in multiple regions, you can use the **<UI-TERM key="oms-community.Operation.JDBCWriter.Geographical">Region</UI-TERM>** column to filter and copy a data source in a specific region.

4. In the **<UI-TERM key="oms-community.pages.EndpointPublic.CopyDataSources">Copy Data Source</UI-TERM>** dialog box, specify the parameters.

   For more information, see the corresponding procedure for creating a data source of the same terminal type.

5. Click **<UI-TERM key="oms-community.Endpoint.New.TestConnection">Test Connection</UI-TERM>** to test the network connection of the data source.

6. After the connection test succeeds, click **<UI-TERM key="oms-community.components.Paragraph.Copy">Copy</UI-TERM>**.
