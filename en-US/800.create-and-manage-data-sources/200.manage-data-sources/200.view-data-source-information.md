# View data source information

After creating a data source, you can view the basic information, details, and network connection information of the data source on the data source list page. You can also filter data sources by type, sort data sources by creation time, and search for a data source through fuzzy matching.

## Procedure

1. Log on to the OceanBase Migration Service (OMS) Community Edition console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.DataSourceManagement">Data Source Management</UI-TERM>**.

   The **<UI-TERM key="oms-community.pages.Endpoint.DataSources">Data Sources</UI-TERM>** page displays all existing data sources and their basic information in columns such as **Data Source ID**, **<UI-TERM key="oms-community.Endpoint.New.TerminalType">Data Source Type</UI-TERM>**, **<UI-TERM key="oms-community.EndpointPublic.components.ObForm.HostIp">Host IP Address</UI-TERM>**, **Port Number**, **<UI-TERM key="oms-community.EndpointPublic.components.ADBForm.UserName">Username</UI-TERM>**, and **<UI-TERM key="oms-community.pages.OCP.AddTime">Added At</UI-TERM>**.

   If your business system is deployed in multiple regions, you can use the **<UI-TERM key="oms-community.Operation.Checker.Geographical">Region</UI-TERM>** column to view the data sources in a specific region.

   The Actions column allows you to perform the following operations:

   1. Test connectivity: Click **<UI-TERM key="oms-community.pages.OCP.constant.TestConnection">Test Connection</UI-TERM>** to check the network connection of the database.

   2. Copy a data source: Click **<UI-TERM key="oms-community.Endpoint.constants.Copy">Copy</UI-TERM>**. In the **<UI-TERM key="oms-community.pages.EndpointPublic.CopyDataSources">Copy Data Source</UI-TERM>** dialog box, specify the parameters. For more information, see [Copy a data source](../200.manage-data-sources/300.copy-data-source.md).

   3. Edit a data source: Click **<UI-TERM key="oms-community.EndpointPublic.constants.Editing">Edit</UI-TERM>**. In the **<UI-TERM key="oms-community.Endpoint.New.EditDataSource">Edit Data Source</UI-TERM>** dialog box, modify the parameters as needed.

   4. Delete a data source: Click **<UI-TERM key="oms-community.Migration.constants.Destruction">Delete</UI-TERM>**. In the dialog box that appears, click **<UI-TERM key="oms-community.pages.User.Delete">Delete</UI-TERM>**. For more information, see [Delete a data source](../200.manage-data-sources/500.delete-a-data-source.md).

3. View data sources as needed on the **<UI-TERM key="oms-community.pages.EndpointPublic.DataSources">Data Sources</UI-TERM>** page.

   You can filter data sources by type to quickly find data sources of a specific type. You can also enter a keyword in the search box in the upper-right corner to search for a data source through fuzzy matching.

4. Click **<UI-TERM key="oms-community.pages.EndpointPublic.DataSourceId">Data Source Identifier</UI-TERM>** of a specific data source to view its details.
