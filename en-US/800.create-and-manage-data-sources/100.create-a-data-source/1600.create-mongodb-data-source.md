# Create a MongoDB data source

Before you create a data migration task, you must configure a data source. This topic describes how to create a MongoDB data source in OceanBase Migration Service (OMS) Community Edition.

## Procedure

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.layout.constants.DataSourceManagement">Data Source Management</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.pages.Endpoint.DataSourceManagement">Data Source Management</UI-TERM>** page, click **<UI-TERM key="oms-community.pages.Endpoint.AddADataSource">New Data Source</UI-TERM>** in the upper-right corner.

4. In the **<UI-TERM key="oms-community.pages.Endpoint.AddADataSource">New Data Source</UI-TERM>** dialog box, set **<UI-TERM key="oms-community.Endpoint.constants.DataSourceType">Data Source Type</UI-TERM>** to **MongoDB**.

5. Configure the parameters.

    | Parameter | Description |
    |------------|-------------|
    | Data Source Identifier | We recommend that you use Chinese, English, and numbers to name the data source. It must not contain any spaces and cannot exceed 32 characters in length. <main id="notice" type='notice'><h4>Notice</h4><p>The data source name is globally unique in OMS Community Edition. </p></main>         |
    | Region | Select the region where the data source resides from the drop-down list. The region is the value that you set for the `cm_region` parameter when you deployed OMS Community Edition. <main id="notice" type='notice'><h4>Notice</h4><ul><li>This parameter is displayed only when multiple regions are available.   <li>Make sure that the mappings between the data source and the region are consistent. Otherwise, the migration and synchronization performance can be poor. </ul> </main>        |
    | MongoDB Address | The address of the MongoDB database in the `IP address:port` format.<br>You can configure multiple addresses for a MongoDB data source. Separate the addresses with commas (,). For example, `xxx.xxx.xxx.1:2883,xxx.xxx.xxx.2:2883`.  |
    | Database User Name (Optional) | The username of the database user for data migration.|
    | Database Password (Optional) | The password of the database user for data migration.|
    | Authentication Database (Optional) | The database to which the user belongs.|
    | TLS Configuration | Select whether to upload **<UI-TERM key="oms-community.endpoints.MongoDBForm.CaCertificate">CA Certificate</UI-TERM>** and **<UI-TERM key="oms-community.endpoints.MongoDBForm.ClientCertificate">Client Certificate</UI-TERM>** based on your business requirements. <ul><li>**<UI-TERM key="oms-community.endpoints.MongoDBForm.CaCertificate">CA Certificate</UI-TERM>** (Optional): You can click **<UI-TERM key="oms-community.EndpointPublic.components.FileUploader.UploadObjects">Upload File</UI-TERM>** to upload a pem, crt, or cer file. <li>**<UI-TERM key="oms-community.endpoints.MongoDBForm.ClientCertificate">Client Certificate</UI-TERM>** (Optional): You can click **<UI-TERM key="oms-community.EndpointPublic.components.FileUploader.UploadObjects">Upload File</UI-TERM>** to upload a p12 or pfx file. <li>**<UI-TERM key="oms-community.endpoints.MongoDBForm.ClientCertificatePassword">Client Certificate Password</UI-TERM>** (Optional): Enter the password of the client certificate file. </ul> |
    | Database Properties/Values | You can add database properties and property values as needed. When TLS is enabled for a MongoDB data source, you must add the corresponding configuration items. For more information, see the "Configure TLS for a MongoDB data source" section.| |
    | Remarks (Optional) | Remarks about the data source.|

6. Click **<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.TestConnection">Test Connection</UI-TERM>** to verify the network connection between OMS Community Edition and the database, as well as the validity of the username and password.

7. After the test is successful, click **<UI-TERM key="oms-community.components.SyncSwitch.ConfirmStopSourceApp.Determine">OK</UI-TERM>**.
