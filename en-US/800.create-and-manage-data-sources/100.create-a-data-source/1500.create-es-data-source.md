# Create an ElasticSearch data source

Before you create a data migration or synchronization task, you must configure a data source. This topic describes how to create an ElasticSearch data source in OceanBase Migration Service (OMS) Community Edition.

## Prerequisites

* You have obtained the IP address and port number of the database.

* A database user for data migration exists.

  We recommend that you create a dedicated database user for each data migration task. This user must have the required privileges on the data. For more information, see [Create a database user](../300.create-a-database-user.md).

## Procedure

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.DataSourceManagement">Data Source Management</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.pages.Endpoint.DataSourceManagement">Data Source Management</UI-TERM>** page, click **<UI-TERM key="oms-community.components.EndpointSelect.AddADataSource">New Data Source</UI-TERM>** in the upper-right corner.

4. In the **<UI-TERM key="oms-community.pages.EndpointPublic.AddADataSource">New Data Source</UI-TERM>** dialog box, set **<UI-TERM key="oms-community.pages.EndpointPublic.DataSourceType">Data Source Type</UI-TERM>** to **ElasticSearch**.

5. Configure the parameters.

    |   **Parameter**    |                **Description**                      |
   |-------------|--------------------------------------|
   | Data Source Identifier | We recommend that you use Chinese, English, and numbers to name the data source. It must not contain any spaces and cannot exceed 32 characters in length. <main id="notice" type='notice'><h4>Notice</h4><p>The data source name is globally unique in OMS Community Edition. </p></main>    |
   | Region | The region to which the data source belongs, which is the value of the `cm_region` parameter when you deploy OMS Community Edition. <main id="notice" type='notice'><h4>Notice</h4><ul><li>The Region parameter is displayed only in multi-region environments.   <li>Make sure that the mappings between data sources and regions are consistent. Otherwise, the migration or synchronization performance may be poor.    </ul> </main>      |
   | Host IP Address | The IP address of the host where the database is located.|
   | Port | The port number of the host IP address.|
   | Database Username (Optional) | The name of the user for data migration in the ElasticSearch database.|
   | Database Password (Optional) | The password of the database user.|
   | Enable HTTPS | Specifies whether to enable HTTPS.|
   | Database Properties/Values (Optional) | The database properties and property values. This parameter is optional.|
   | Remarks (Optional) | Remarks about the data source. |

6. Click **<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.TestConnection">Test Connection</UI-TERM>** to verify the network connection between OMS Community Edition and the database as well as the validity of the username and password.

7. If the test connection is successful, click **<UI-TERM key="oms-community.components.SyncSwitch.ConfirmStopSourceApp.Determine">OK</UI-TERM>**.
