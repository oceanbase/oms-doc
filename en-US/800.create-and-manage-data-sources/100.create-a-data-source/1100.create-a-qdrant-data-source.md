# Create a Qdrant data source

Before you create a data migration or synchronization task, you must configure the data sources. This topic describes how to create a Qdrant data source in OceanBase Migration Service (OMS) Community Edition.

## Prerequisites

You have obtained the IP address and port number of the related database.

## Procedure

1. Log in to the console of OMS Community Edition.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.DataSourceManagement">Data Source Management</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.pages.Endpoint.DataSourceManagement">Data Source Management</UI-TERM>** page, click **<UI-TERM key="oms-community.EndpointPublic.Empty.AddADataSource">New Data Source</UI-TERM>** in the upper-right corner.

4. In the **<UI-TERM key="oms-community.pages.EndpointPublic.AddADataSource">New Data Source</UI-TERM>** dialog box, select **Qdrant** for **<UI-TERM key="oms-community.Endpoint.constants.DataSourceType">Data Source Type</UI-TERM>**.

5. Configure the following parameters.

   |    **Parameter**     | **<UI-TERM key="oms-community.User.Detail.Description">Description</UI-TERM>** |
   |-------------|--------------------------------------------------------|
   | Data Source Identifier       | We recommend that you set it to a combination of digits and letters. It must not contain any spaces and cannot exceed 32 characters in length. <main id="notice" type='notice'><h4>Notice</h4><p>The data source identifier must be globally unique in the system of OMS Community Edition. </p></main>                                                                                                                                                                                                                                                                                |
   | Region          | Select the region where the data source resides from the drop-down list. The region is the value that you set for the `cm_region` parameter when you deploy OMS Community Edition. <main id="notice" type='notice'><h4>Notice</h4><ul><li>This parameter is displayed only when multiple regions are available.   <li>Make sure that the mappings between the data source and the region are consistent. Otherwise, the migration and synchronization performance can be poor.    </ul> </main>                                                                                                                  |
   | Host IP Address         | The IP address of the host where the database is located.                                                                                                                                                                                                                                                                                 |
   | http port (http_port)         | The HTTP port of the Qdrant data source. Default value: `6333`.                                                                                                    |
   | rpc port (grpc_port)        | The RPC port of the Qdrant data source. Default value: `6334`.                              |
   | api-key (Optional)     | You can set an API key in the upper-right corner of the [Collections](http://11.124.9.86:6333/dashboard#/collections) page.                                                                                                                                                                                                                                                                                                                                      |
   | Remarks (Optional)      | Additional information about the data source.                                                                                                                                                                                                                                                                                                                                                |

6. Click **<UI-TERM key="oms-community.EndpointPublic.constants.TestConnection">Test Connection</UI-TERM>** to verify the network connection between OMS Community Edition and the data source.

7. After the test is passed, click **<UI-TERM key="oms-community.Sync.Detail.Confirmation">OK</UI-TERM>**.
