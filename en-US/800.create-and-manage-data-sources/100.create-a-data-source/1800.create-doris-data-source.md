# Create a Doris data source

Before you create a data migration task, you must configure a data source. This topic describes how to create a Doris data source in OceanBase Migration Service (OMS) Community Edition.

## Procedure

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.layout.constants.DataSourceManagement">Data Source Management</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.pages.Endpoint.DataSourceManagement">Data Source Management</UI-TERM>** page, click **<UI-TERM key="oms-community.pages.Endpoint.AddADataSource">New Data Source</UI-TERM>** in the upper-right corner.

4. In the **<UI-TERM key="oms-community.pages.Endpoint.AddADataSource">New Data Source</UI-TERM>** dialog box, select **<UI-TERM key="oms-community.Endpoint.constants.DataSourceType">Data Source Type</UI-TERM>** as **Doris**.

5. Configure the parameters.

    |   Parameter   |   Description   |
    |------------|--------------|
    | Data Source Identifier | We recommend that you use Chinese, English, and numbers to name the data source. It must not contain any spaces and cannot exceed 32 characters in length. <main id="notice" type='notice'><h4>Notice</h4><p>The data source name is globally unique in OMS Community Edition. </p></main>         |
    | Region | Select the region where the data source resides from the drop-down list. The region is the value that you set for the `cm_region` parameter when you deployed OMS Community Edition. <main id="notice" type='notice'><h4>Notice</h4><ul><li>This parameter is displayed only when multiple regions are available.   <li>Make sure that the mappings between the data source and the region are consistent. Otherwise, the migration and synchronization performance can be poor. </ul> </main>   |
    | Host IP | The IP address of the database host.|
    | Port    | The port number of the database host IP.|
    | Database Username | The username of the Doris database user for data migration or synchronization.|
    | Database Password (Optional) | The password of the database user.|
    | DB Name (Optional) | The name of the Doris database. <main id="notice" type='explain'><h4>Note</h4><p>If this parameter is specified, you can select migration or synchronization objects only in the specified database when the data source serves as the source. </p></main>   |
    | Remarks (Optional) | Remarks about the data source.|

6. Click **<UI-TERM key="oms-community.Endpoint.New.TestConnection">Test Connection</UI-TERM>** to verify the network connection between OMS Community Edition and the database, as well as the validity of the username and password.

7. After the test is successful, click **<UI-TERM key="oms-community.Detail.components.StructSync.Determine">OK</UI-TERM>**.
