# Create a StarRocks data source

Before you create a data migration task, you must configure a data source. This topic describes how to create a StarRocks data source in OceanBase Migration Service (OMS) Community Edition.

## Procedure

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.layout.constants.DataSourceManagement">Data Source Management</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.pages.Endpoint.DataSourceManagement">Data Source Management</UI-TERM>** page, click **<UI-TERM key="oms-community.pages.Endpoint.AddADataSource">New Data Source</UI-TERM>** in the upper-right corner.

4. In the **<UI-TERM key="oms-community.pages.Endpoint.AddADataSource">New Data Source</UI-TERM>** dialog box, set **<UI-TERM key="oms-community.Endpoint.constants.DataSourceType">Data Source Type</UI-TERM>** to **StarRocks**.

5. Configure the parameters.

    | Parameter | Description |
    |------------|-------------|
    | Data Source ID | The ID of the data source. The ID must be a combination of Chinese characters, digits, and letters. It cannot contain spaces, and its length must be less than 32 characters. <main id="notice" type='notice'><h4>Notice</h4><p>The data source ID must be unique in the OMS Community Edition system. </p></main>         |
   | Region | The region where the data source is located. This value is the `cm_region` parameter specified when OMS Community Edition is deployed. <main id="notice" type='notice'><h4>Notice</h4><ul><li> This parameter is displayed only in multi-region scenarios.   <li>Make sure that the mapping between the data source and the region is consistent. Otherwise, the migration and synchronization performance may be poor.    </ul> </main>        |
   | Host IP | The IP address of the database host.  |
   | Port | The port number of the database host.   |
   | Database User Name | The name of the user for data migration or synchronization.            |
   | Password | The password of the database user.      |
   | DB Name (Optional) | The name of the StarRocks database.<br>**<UI-TERM key="oms-community.User.New.DescriptionOptional">Description</UI-TERM>**<br>If you specify the DB Name, when the data source is the source, the data migration or synchronization task can select only the migration or synchronization object under the specified DB Name.  |
   | Remarks (Optional)      | Remarks about the data source.      |

6. Click **<UI-TERM key="oms-community.Endpoint.New.TestConnection">Test Connection</UI-TERM>** to verify the network connection between OMS Community Edition and the database, as well as the validity of the username and password. The database can be the source or destination.

7. After the test connection is successful, click **<UI-TERM key="oms-community.Detail.components.StructSync.Determine">OK</UI-TERM>**.
