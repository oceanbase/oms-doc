# Create a Redis data source

Before you create a data migration or synchronization task, you must configure the data sources. This topic describes how to create a Redis data source in OceanBase Migration Service (OMS) Community Edition.

## Prerequisites

* You have obtained the IP address and port number of the related database.

## Procedure

1. Log on to the console of OMS Community Edition.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.layout.constants.DataSourceManagement">Data Source Management</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.layout.constants.DataSourceManagement">Data Source Management</UI-TERM>** page, click **<UI-TERM key="oms-community.pages.EndpointPublic.AddADataSource">New Data Source</UI-TERM>** in the upper-right corner.

4. In the **<UI-TERM key="oms-community.Endpoint.New.AddADataSource">New Data Source</UI-TERM>** dialog box, select **Redis** for **<UI-TERM key="oms-community.Endpoint.New.TerminalType">Data Source Type</UI-TERM>**.

5. Configure the following parameters.

   | **Parameter** | **<UI-TERM key="oms-community.User.New.Description">Description</UI-TERM>** |
   |-------------|--------------------------------------|
   | Data Source Identifier       | We recommend that you set it to a combination of digits and letters. It must not contain any spaces and cannot exceed 32 characters in length. <main id="notice" type='notice'><h4>Notice</h4><p>The data source identifier must be globally unique in the system of OMS Community Edition. </p></main> |
   | Region          | Select the region where the data source resides from the drop-down list. The region is the value that you set for the `cm_region` parameter when you deployed OMS Community Edition. <main id="notice" type='notice'><h4>Notice</h4><ul><li>This parameter is displayed only when multiple regions are available.   <li>Make sure that the mappings between the data source and the region are consistent. Otherwise, the migration and synchronization performance can be poor.    </ul> </main> |
   | Host IP Address         | The IP address of the host where the database is located. You must specify the IP address of the physical server that hosts the Relational Database Service (RDS). Do not enter the IP address of any middleware.                                                                                                                                                                                                                                                                                                                   |
   | Port          | The port number of the host where the database is located. The default value is `6379`.                                                                                                                                                                                                                                                                                                                                          |
   | Database Username (Optional)        | The name of the Redis database user for data migration or synchronization.                                                                                                                                                                                                                                                                                                                             |
   | Database Password (Optional)          | The password of the database user.                                                                                                                                                                                                                                                                                                    |
   | Remarks (Optional)      | Additional information about the data source.                                                                                                                                                                                                                                                                                                                                                |

6. Click **<UI-TERM key="oms-community.EndpointPublic.components.FormContent.TestConnection">Test Connection</UI-TERM>** to verify the network connection between OMS Community Edition and the data source, as well as the validity of the username and password.

7. After the test is passed, click **<UI-TERM key="oms-community.src.layout.BasicLayout.Confirmation">OK</UI-TERM>**.
