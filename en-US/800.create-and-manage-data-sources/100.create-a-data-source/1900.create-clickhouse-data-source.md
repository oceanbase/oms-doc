# Create a ClickHouse data source

Before you create a data migration task, you must configure a data source. This topic describes how to create a ClickHouse data source in OceanBase Migration Service (OMS) Community Edition.

## Procedure

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.layout.constants.DataSourceManagement">Data Source Management</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.pages.Endpoint.DataSourceManagement">Data Source Management</UI-TERM>** page, click **<UI-TERM key="oms-community.pages.Endpoint.AddADataSource">New Data Source</UI-TERM>** in the upper-right corner.

4. In the **<UI-TERM key="oms-community.pages.Endpoint.AddADataSource">New Data Source</UI-TERM>** dialog box, select **<UI-TERM key="oms-community.Endpoint.constants.DataSourceType">Data Source Type</UI-TERM>** as **ClickHouse**.

5. Configure the parameters.

    |   Parameter   |   Description   |
    |------------|--------------|
    | Data Source ID | The ID of the data source. We recommend that you use a combination of Chinese characters, digits, and letters. The ID cannot contain spaces and must be 32 characters or shorter. <main id="notice" type='notice'><h4>Notice</h4><p>The data source ID must be unique in OMS Community Edition. </p></main>         |
    | Region  | The region where the data source is located. This parameter is the value of the `cm_region` parameter specified when OMS Community Edition is deployed. <main id="notice" type='notice'><h4>Notice</h4><ul><li> This parameter is displayed only in a multi-region scenario.   <li>Make sure that the mapping between the data source and the region is consistent. Otherwise, the performance of data migration or synchronization may be poor.    </ul> </main>        |
    | Host IP | The IP address of the database host.|
    | Port    | The port number of the database host.|
    | Database User Name | The username of the user for data migration or synchronization.|
    | Database Password | The password of the user for data migration or synchronization.|
    | DB Name (Optional) | The name of the ClickHouse database. <main id="notice" type='explain'><h4>Note</h4><p>If you specify the DB Name, when the data source is the source, a data migration or synchronization task can only select a migration or synchronization object under the specified DB Name. </p></main>   |
    | Remarks (Optional) | Remarks about the data source.|

6. Click **<UI-TERM key="oms-community.Endpoint.New.TestConnection">Test Connection</UI-TERM>** to verify the network connection between OMS Community Edition and the database, as well as the validity of the username and password.

7. After the test is successful, click **<UI-TERM key="oms-community.Detail.components.StructSync.Determine">OK</UI-TERM>**.
