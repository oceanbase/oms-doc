# oms_sync_status_inconsistent

## Description

The data synchronization task has stopped or failed or is being released, but data synchronization is still in progress. You can perceive that the data synchronization task has stopped, but the data synchronization link is still running.

## Impact on the system

This alert may cause inconsistency between the actual and expected results of the data synchronization task.

## Possible causes

* An improper operation is performed on the operations page.

* Other special circumstances have occurred.

## Solution

Suspend the connectors related to the data synchronization task or restore the data synchronization link.
