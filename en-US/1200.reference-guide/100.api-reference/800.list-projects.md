# ListProjects

This topic describes the `ListProjects` operation provided by OceanBase Migration Service (OMS) Community Edition.

## Description

You can call this operation to query a list of data migration or synchronization tasks in pagination mode.

## Call description

### Limitations

This operation is supported in OMS Community Edition V4.1.1 and later.

### Request path

`POST /api/v2?Action=ListProjects`

### Request parameters

| Parameter | Type | Description |
|--------|---------|------------|
| searchKey | string | The name or ID of the data migration or synchronization task. |
| type | string | The type of the task. Valid values: `MIGRATION` and `SYNC`.  |
| status | string | The status of the task.  |
| labelIds | array | The tag IDs. You can specify a maximum of five tag IDs.  |
| sourceEndpointTypes | array | The types of source data sources. |
| sinkEndpointTypes | array | The types of target data sources. |
| visibleSubProject | boolean | Specifies whether to show subtasks. Default value: `false`.  |
| sortField | string | The sorting field. Valid values: `gmtCreate` and `gmtModified`. Default value: `gmtCreate`.  |
| order | string | The sorting order. Valid values: `asc` and `descend`. Default value: `descend`.  |
| pageNumber | integer | The current page number. Default value: `1`.  |
| pageSize | integer | The number of records to return per page. Default value: `10`. Maximum value: `150`.  |
