# Create a TiDB data source

This topic describes the OpenAPI provided by OceanBase Migration Service (OMS) Community Edition: CreateTiDBDataSource.

## Overview

This API is used to create a TiDB data source.

## API details

### Constraints

This API applies to OMS Community Edition V4.2.14-CE and later.

### Request path

`POST /api/v2?Action=CreateTiDBDataSource`

### Request parameters

| Parameter | Type | Description |
| --------------- | ----------------- | ---------------- |
| name | string | Data source identifier. It is recommended to use a combination of Chinese characters, numbers, and letters. The name must not contain spaces and must not exceed 32 characters in length. |
| ip | string | The IP address of the TiDB database. |
| port | integer | The port of the TiDB database. |
| username | string | The username for the TiDB database. |
| password | string | The TiDB database password, which must be Base64-encoded. You can obtain it by running the command `echo -n "<original_password>" \| base64` to obtain it. |
| region | string | TiDB region. |
| kafkaId | string | The Kafka data source ID, which can be queried from the `oms_endpoint` table in the OMS metadata database. |
| kafkaTopic | string | The topic name for incremental data writes by TiCDC. |

### Response parameters

| Parameter | Type | Description |
| ------------ | ------------------ | ------------------------ |
| success | boolean | Whether the call was successful. |
| errorDetail | object | Error details. |
| code | string | Error code. |
| message | string | Description. |
| advice | string | Recommended. |
| requestId | string | Request ID. |
| pageNumber | integer | Page number, which takes effect during paginated queries. |
| pageSize | integer | Number of records returned per page. This parameter takes effect when you perform a paginated query. |
| totalCount | integer | Total number, which takes effect during paginated queries. |
| cost | string | Request time, in seconds. |
| data | string | The ID of the TiDB database. |
