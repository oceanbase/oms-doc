# Set an incremental synchronization timestamp

This topic describes the limitations, scenarios, and procedure of setting an incremental synchronization timestamp when you create a data migration or synchronization task.

## Limitations

* When you create a data migration or synchronization task, you can set an incremental synchronization timestamp only if you select **<UI-TERM key="oms-community.SyncParameter.components.IncrSyncForm.IncrementalSynchronization">Incremental Synchronization</UI-TERM>** for the migration or synchronization type and leave **Full Migration/Full Synchronization** unselected.

* The incremental synchronization timestamp must be the current time or a point in time earlier than the current time. It cannot be later than the expiration time of incremental logs in the source database.

## Scenarios

You can set an incremental synchronization timestamp in the following scenarios:

* You have verified data consistency between the source and target, and you want to create a data migration or synchronization task to obtain the incremental data generated after a specific point in time and synchronize the data to the target database.

* You no longer need the historical data in the source database, but want to synchronize only the incremental data generated after a specific point in time to the target database.
  
## Procedure

1. Configure a data migration or synchronization task as prompted to the **<UI-TERM key="oms-community.Migration.New.SelectMigrationType">Select Migration Type</UI-TERM>** or **<UI-TERM key="oms-community.Sync.New.SelectSynchronizationType">Select Synchronization Type</UI-TERM>** step.

    For more information, see the topics about [data migration](../100.data-migration-overview.md) or [data synchronization](../../700.data-synchronization/100.data-synchronization-overview.md) tasks of the corresponding data source types.

    ![function-36-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/function-36-en.png)

2. On the **<UI-TERM key="oms-community.Migration.New.SelectMigrationType">Select Migration Type</UI-TERM>** or **<UI-TERM key="oms-community.Sync.New.SelectSynchronizationType">Select Synchronization Type</UI-TERM>** page, select migration or synchronization types based on your business needs. You must select **<UI-TERM key="oms-community.New.components.MigrationObjectForm.IncrementalMigration">Incremental Synchronization</UI-TERM>** and leave **Full Migration/Full Synchronization** unselected.

    ![function-28-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/function-28-en.png)

3. Configure other parameters as prompted and proceed to the **Migration Options** or **<UI-TERM key="oms-community.Sync.New.SynchronizationOptions">Synchronization Options</UI-TERM>** step. In the **<UI-TERM key="oms-community.Detail.components.SyncDescriptions.SynchronizationStartPoint">Incremental Synchronization Start Timestamp</UI-TERM>** section on the **<UI-TERM key="oms-community.components.SyncOption.CheckSyncKind.IncrementalSynchronization">Incremental Synchronization</UI-TERM>** page, specify a point in time for synchronizing data. Data generated after this point in time will be synchronized. The default value is the current system time.

    ![function-39-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/function-39-en.png)

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>The parameters on this page vary with the migration or synchronization type that you selected. This topic describes how to configure the <strong>Incremental Synchronization Start Timestamp</strong> parameter. For information about other parameters, see the "Data migration" or "Data synchronization" chapter. </p>
    <p>You can select a point in time or enter a timestamp. The timestamp is related to the retention period of incremental logs in the source database. Generally, you can start data synchronization from the current timestamp. </p>
    </main>

4. Click **<UI-TERM key="oms-community.Sync.New.Precheck">Precheck</UI-TERM>**. After the precheck is passed, start the data migration task.
