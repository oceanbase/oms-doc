# Change the name of a data migration task

This topic describes how to change the name of a data migration task in OceanBase Migration Service (OMS) Community Edition.

## Limitations

* OMS Community Edition allows you to change the name of a data migration task in the **Not Started**, **Running**, **Paused**, or **Failed** state.

* If you have created a sub-project to modify the migration objects during the running of a data migration task, you cannot change the task name. For more information about how to modify the migration objects, see [View and modify migration objects](../1500.manage-data-migration-projects/200.view-and-modify-migration-objects.md).

* The task name is a unique identifier for a task of a user.

## Procedure

1. Log on to the OMS Community Edition console.

2. In the left-side navigation pane, click **Data Migration**.

3. On the **Migration Tasks**  page, click the **Edit** icon next to the name of the target task.

   ![rename-migrate-1-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/rename-migrate-1-en.png)

   You can also click the name of the target task to go to the details page of the task, and then click the **Edit** icon next to the task name.

   ![rename-migrate-2-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/rename-migrate-2-en.png)

4. In the **Edit Task Name** dialog box, enter a new task name.

5. Click **OK**.
