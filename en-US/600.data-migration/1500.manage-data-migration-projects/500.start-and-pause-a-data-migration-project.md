# Start and pause a data migration task

This topic describes how to start, pause, and resume a data migration task.

## Start a data migration task

If you have created a data migration task but did not start it after it passed the precheck, you can find the task in the list of migration tasks and start it.

1. Log in to the OceanBase Migration Service (OMS) Community Edition console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.components.CustomizedTable.DataMigration">Data Migration</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.Migration.Detail.DataMigration">Data Migration</UI-TERM>** page, click **<UI-TERM key="oms-community.Migration.constants.Start">Start</UI-TERM>** in the Actions column of the target task.

   You can also click the task name on the **<UI-TERM key="oms-community.Migration.New.DataMigration">Data Migration</UI-TERM>** page to go to the details page, and click **<UI-TERM key="oms-community.constants.dist.Start">Start</UI-TERM>** in the upper-right corner.

## Pause a migration task

You can pause a running data migration task. After a data migration task is paused, OMS Community Edition pauses the running subtasks in the orchestration task list and stops scheduling all subsequent subtasks.

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.SystemParam.contants.DataMigration">Data Migration</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.src.constants.DataMigration">Data Migration</UI-TERM>** page, click **<UI-TERM key="oms-community.Operator.constants.Pause">Pause</UI-TERM>** in the Actions column of the target task.

   You can also click the task name on the **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.DataMigration">Data Migration</UI-TERM>** page to go to the details page, and click **<UI-TERM key="oms-community.Operator.constants.Pause">Pause</UI-TERM>** in the upper-right corner.

4. In the dialog box that appears, click **<UI-TERM key="oms-community.pages.User.Confirmation">OK</UI-TERM>**.

   <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>This operation will pause the real-time synchronization component, full verification component (if any), and full migration component (if any). The task cannot be recovered if it is paused for more than 12 hours. </p>
   </main>

## Resume a migration task

You can manually resume a paused or failed migration task. OMS Community Edition runs the pending subtasks in the orchestration task list in sequence.

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.layout.constants.DataMigration">Data Migration</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.Migration.Detail.DataMigration">Data Migration</UI-TERM>** page, click **<UI-TERM>Resume</UI-TERM>** in the Actions column of the target task.

   You can also click the task name on the **<UI-TERM key="oms-community.components.UserGuidance.DataMigration">Data Migration</UI-TERM>** page to go to the details page, and click **<UI-TERM key="oms-community.Operator.constants.Restore">Resume</UI-TERM>** in the upper-right corner.
