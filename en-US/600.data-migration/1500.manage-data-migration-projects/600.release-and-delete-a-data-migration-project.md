# Release and delete a data migration task

If a data migration task is no longer required, you can pause and release it. After a data migration task is released, you can delete the task to release resources.

## Release a data migration task

After you release a data migration task, OceanBase Migration Service (OMS) Community Edition terminates the task. This operation is irreversible. Proceed with caution. However, OMS Community Edition does not delete the task. You can view details about the task or create similar data migration tasks based on the task.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>You can release a data migration task in the <strong>Paused</strong>, <strong>Failed</strong>, or <strong>Completed</strong> state. </p>
  </main>

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.DataMigration">Data Migration</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.pages.Migration.MigrationProject">Migration Tasks</UI-TERM>**  page, click **<UI-TERM key="oms-community.project.cloudweb.MoreOperations">More</UI-TERM>** in the Actions column of the target task and then select **<UI-TERM key="oms-community.Migration.constants.Release">Release</UI-TERM>** from the drop-down list.

   You can also click the task name to go to the details page. Then, click **<UI-TERM key="oms-community.components.SyncSwitch.DbObjectTable.MoreOperations">More</UI-TERM>** in the upper-right corner and select **<UI-TERM key="oms-community.Migration.constants.Release">Release</UI-TERM>** from the drop-down list.

4. In the dialog box that appears, click **<UI-TERM key="oms-community.components.ImportTransferObj.Determine">OK</UI-TERM>**.

## Delete a data migration task

After you delete a data migration task, data of the task cannot be recovered. Proceed with caution.

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>You can delete a data migration task in the <strong>Not Started</strong> or <strong>Released</strong> state. </p>
  </main>

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.SystemParam.contants.DataMigration">Data Migration</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.pages.Migration.MigrationProject">Migration Tasks</UI-TERM>**  page, click **<UI-TERM key="oms-community.Sync.Detail.Delete">Delete</UI-TERM>** in the Actions column of the target task.

   You can also click the task name to go to the details page, and click **<UI-TERM key="oms-community.Sync.Detail.Delete">Delete</UI-TERM>** in the upper-right corner.

4. In the dialog box that appears, enter the task name to confirm the operation.

5. Click **<UI-TERM key="oms-community.Operator.constants.Delete">Delete</UI-TERM>**.
