# Manage computing platforms

When you use OceanBase Migration Service (OMS) Community Edition to migrate data from HBase to OBKV, the Full-Import and Incr-Sync components can run on computing platforms. This topic describes how to create, edit, and delete computing platforms.

## Prerequisites

* You have obtained the values of the following parameters of Flink if you use a Flink computing platform.

    ![omsce5-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-ce/omsce5-en.png)

    | Parameter | Description |
    |--------------|--------------------|
    |jobmanager.rpc.address| The IP address of the JobManager. |
    |jobmanager.rpc.port | The port number of the JobManager. |
    |rest.port | The port number of the RESTful API. |

* You have obtained the value of the `master` parameter of Spark if you use a Spark computing platform.

     ![omsce6-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-ce/omsce6-en.png)

    The `master` parameter specifies the URL of the Spark master server. You can obtain the URL from the Spark web UI.

    ![omsce4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-ce/omsce4.png)

## Create a computing platform

1. Create a task to migrate data from HBase to OBKV, or from a Hive database to OceanBase Database Community Edition, and proceed to the **<UI-TERM>Migration Type</UI-TERM>** step.

    For more information, see [Migrate data from HBase to OBKV](../400.create-a-project-to-migrate-data-from-hbase-to-obkv.md) or [Migrate data from a Hive database to OceanBase Database Community Edition](../1401.create-a-task-to-migrate-data-from-hive-to-ob.md).

2. In the **<UI-TERM key="oms-community.Migration.constants.FullMigration">Full Migration</UI-TERM>** or **<UI-TERM key="oms-community.New.components.MigrationObjectForm.IncrementalMigration">Incremental Synchronization</UI-TERM>** section, click **<UI-TERM key="oms-community.migration.new.components.communityForm.managePlatform">Manage Computing Platform</UI-TERM>** in the **<UI-TERM key="oms-community.migration.new.components.communityForm.platform">Computing Platform</UI-TERM>** drop-down list.

3. In the **<UI-TERM key="oms-community.migration.new.components.communityForm.managePlatform">Manage Computing Platform</UI-TERM>** dialog box, click **<UI-TERM key="oms-community.migration.new.components.communityForm.createPlatform">New Computing Platform</UI-TERM>** in the upper-right corner.

4. In the **<UI-TERM key="oms-community.migration.new.components.communityForm.createPlatform">New Computing Platform</UI-TERM>** dialog box, configure the following parameters.

    | Parameter | Description |
    |-------------|-------------------|
    | Computing Platform Name | The name of the computing platform.  |
    | Computing Platform Type | The type of the computing platform. Valid values: **FLINK** and **SPARK**.  |
    | Parameter Configuration | By default, the required computing platform parameters are displayed. For more information, see the parameter description in the **Prerequisites** section. |
    | Config File | <ul><li>The configuration file of the source HBase cluster is named `hbase-site.xml`.<li>The configuration file of the source Hive cluster is named `hive-site.xml`. </ul> |
    | Remarks (Optional) | Additional information about the computing platform.  |

5. Click **<UI-TERM key="oms-community.EndpointPublic.constants.TestConnection">Test Connection</UI-TERM>**.

6. After the test succeeds, click **<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.Create">Create</UI-TERM>**.

## Edit a computing platform

1. Go to the **<UI-TERM key="oms-community.migration.new.components.communityForm.managePlatform">Manage Computing Platform</UI-TERM>** dialog box, find the target computing platform, and then click **<UI-TERM key="oms-community.EndpointPublic.constants.Editing">Edit</UI-TERM>** next to it.

2. In the **<UI-TERM key="oms-community.migration.new.components.communityForm.editPlatform">Edit Computing Platform</UI-TERM>** dialog box, modify parameters as needed.

3. Click **<UI-TERM key="oms-community.OCP.components.OCPForm.TestConnection">Test Connection</UI-TERM>**.

4. After the test succeeds, click **<UI-TERM key="oms-community.Audit.constants.Create">Create</UI-TERM>**.

## Delete a computing platform

Go to the **<UI-TERM key="oms-community.migration.new.components.communityForm.managePlatform">Manage Computing Platform</UI-TERM>** dialog box, find the target computing platform that is no longer required, and then click **<UI-TERM key="oms-community.OperationComponent.Connector.Delete">Delete</UI-TERM>** next to it.
