# Perform batch operations on data migration tasks

This topic describes how to perform batch operations on data migration tasks by using OceanBase Migration Service (OMS) Community Edition. 

## Background

OMS Community Edition allows you to perform operations on multiple data migration tasks at a time on the **<UI-TERM key="oms-community.pages.Migration.MigrationProject">Migration Tasks</UI-TERM>**  page. Supported batch operations on data migration tasks vary based on the task states.

| Task status | Supported batch operation   |
|--------------------|-------------------------|
| Not Started        | Batch start, batch delete, and batch modify alert configuration   |
| Running            | Supported batch operations on running tasks vary based on the scenarios. <ul><li> Batch pause and batch modify alert configuration: all scenarios  </li><li> Batch enter forward switchover stage<br>Scenario: Full verification is completed for the selected tasks. </li><li>Batch start forward switchover<br>Scenario: The selected tasks have the same migration type and are in the same step of the forward switchover stage (except for the switchover precheck step).  </li> <li>Batch skip full verification<br>Scenario: The selected tasks have entered the full verification stage. |
| Paused             | Batch restore, batch release, batch modify alert configuration, and batch skip full verification (in the full verification stage)  |
| Failed             | Batch restore, batch release, batch modify alert configuration, and batch skip full verification (in the full verification stage)    |
| Released           | Batch delete    |
| Releasing          | N/A |
| Completed          | Batch release   |

If you select multiple tasks for a batch operation, but not all tasks support this batch operation, a dialog box appears and displays the tasks that support this batch operation.

![batch-pause-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/batch-pause-en.png)

## Go to the Migration Tasks page

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.Migration.Detail.DataMigration">Data Migration</UI-TERM>**. The **<UI-TERM key="oms-community.pages.Migration.MigrationProject">Migration Tasks</UI-TERM>**  page automatically appears.

   You can select data migration tasks for a batch operation.

## Batch pause

OMS Community Edition allows you to batch pause data migration tasks in the **<UI-TERM key="oms-community.Operation.constants.Running">Running</UI-TERM>** state.

1. On the **<UI-TERM key="oms-community.pages.Migration.MigrationProject">Migration Tasks</UI-TERM>**  page, select the data migration tasks to be paused.

2. Click **<UI-TERM key="oms-community.Migration.constants.BatchPause">Batch Pause</UI-TERM>** in the lower part of the page.

3. In the dialog box that appears, click **<UI-TERM key="oms-community.pages.EndpointPublic.Add">OK</UI-TERM>**.

   This dialog box will display the number of tasks that support batch pausing, the task names, and the latest timestamps.

4. After the operation succeeds, the number of tasks that are successfully paused is displayed.

   For any task that failed the batch operation, troubleshoot the issue as prompted.

## Batch restore

OMS Community Edition allows you to batch restore data migration tasks in the **<UI-TERM>Stopped</UI-TERM>** or **<UI-TERM key="oms-community.Sync.constants.Failed">Failed</UI-TERM>** state.

1. On the **<UI-TERM key="oms-community.pages.Migration.MigrationProject">Migration Tasks</UI-TERM>**  page, select the data migration tasks to be restored.

2. Click **<UI-TERM key="oms-community.Migration.constants.BatchRecovery">Batch Restore</UI-TERM>** in the lower part of the page.

3. In the dialog box that appears, click **<UI-TERM key="oms-community.components.FullValidation.UpdateValidatingSqlDrawer.Confirmation">OK</UI-TERM>**.

   This dialog box will display the number of tasks that support batch restoration, the task names, and the latest timestamps.

4. After the operation succeeds, the number of tasks that are successfully restored is displayed.

   For any task that failed the batch operation, troubleshoot the issue as prompted.

## Batch release

OMS Community Edition allows you to batch release data migration tasks in the **<UI-TERM>Stopped</UI-TERM>**, **<UI-TERM key="oms-community.components.BatchSelect.BatchSwitch.Failed">Failed</UI-TERM>**, or **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.Completed">Completed</UI-TERM>** state.

1. On the **<UI-TERM key="oms-community.pages.Migration.MigrationProject">Migration Tasks</UI-TERM>**  page, select the data migration tasks to be released.

2. Click **<UI-TERM key="oms-community.Migration.constants.BatchRelease">Batch Release</UI-TERM>** in the lower part of the page.

3. In the dialog box that appears, click **<UI-TERM key="oms-community.Operator.Connector.StartConnectorModal.StartConfirm">OK</UI-TERM>**.

   This dialog box will display the number of tasks that support batch release, the task names, and the latest timestamps.

4. After the operation succeeds, the number of tasks that are successfully released is displayed.

   For any task that failed the batch operation, troubleshoot the issue as prompted.

## Batch start forward switchover

OMS Community Edition allows you to batch start forward switchover on data migration tasks that are in **<UI-TERM key="oms-community.Operation.Overview.constants.Running">Running</UI-TERM>** state and in the same step of the forward switchover stage, except for the switchover precheck step.

Forward switchover consists of the following steps: start forward switchover, perform switchover precheck, start the target Store, confirm that writing has stopped in the source, confirm the writing stop timestamp upon synchronization completion, stop forward synchronization, process database objects, and start reverse increment.

<main id="notice" type='explain'>
 <h4>Note</h4>
 <p>The steps of forward switchover vary based on the migration type specified when you created the task. </p>
</main>

1. On the **<UI-TERM key="oms-community.pages.Migration.MigrationProject">Migration Tasks</UI-TERM>**  page, select the data migration tasks to batch start forward switchover.

2. Click **<UI-TERM key="oms-community.Migration.constants.BatchForwardSwitching.1">Batch Start Forward Switchover</UI-TERM>** in the lower part of the page.

3. In the dialog box that appears, click **<UI-TERM key="oms-community.Migration.hooks.useMigrationParams.Determine">OK</UI-TERM>**.

   This dialog box will display the number of tasks that support this batch operation, the task names, and the latest timestamps.

4. In the **<UI-TERM key="oms-community.Migration.constants.BatchForwardSwitching.1">Batch Start Forward Switchover</UI-TERM>** dialog box, view the status of the forward switchover task.

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>You must manually confirm the following steps: start a forward switchover task, verify that writing is stopped at the source, process database objects, and start reverse increment. </p>
   </main>

5. After the operation succeeds, the number of tasks that succeeded in this batch operation is displayed.

   For any task that failed the batch operation, troubleshoot the issue as prompted.

## Batch start

OMS Community Edition allows you to batch start data migration tasks in the **<UI-TERM key="oms-community.Migration.constants.NotStarted">Not Started</UI-TERM>** state.

1. On the **<UI-TERM key="oms-community.pages.Migration.MigrationProject">Migration Tasks</UI-TERM>**  page, select the data migration tasks for batch start.

2. Choose **<UI-TERM key="oms-community.components.BatchSelect.MoreBatchOperations">More Batch Operations</UI-TERM>** > **<UI-TERM key="oms-community.Migration.constants.BatchStart">Batch Start</UI-TERM>** in the lower part of the page.

3. In the dialog box that appears, click **<UI-TERM key="oms-community.Operator.Checker.useCheckerAction.Update">OK</UI-TERM>**.

   This dialog box will display the number of tasks that support batch start, the task names, and the latest timestamps.

4. After the operation succeeds, the number of tasks that are successfully started is displayed.

   For any task that failed the batch operation, troubleshoot the issue as prompted.

## Batch delete

OMS Community Edition allows you to batch delete data migration tasks in the **<UI-TERM key="oms-community.Migration.constants.NotStarted">Not Started</UI-TERM>** or **<UI-TERM key="oms-community.Sync.constants.Released">Released</UI-TERM>** state.

1. On the **<UI-TERM key="oms-community.pages.Migration.MigrationProject">Migration Tasks</UI-TERM>**  page, select the data migration tasks for batch deletion.

2. Choose **<UI-TERM key="oms-community.components.BatchSelect.MoreBatchOperations">More Batch Operations</UI-TERM>** > **<UI-TERM key="oms-community.pages.EndpointPublic.BatchDelete">Batch Delete</UI-TERM>** in the lower part of the page.

3. In the dialog box that appears, click **<UI-TERM key="oms-community.components.Rules2destination.Node.Determine">OK</UI-TERM>**.

   This dialog box will display the number of tasks that support batch deletion, the task names, and the latest timestamps.

4. After the operation succeeds, the number of tasks that are successfully deleted is displayed.

   For any task that failed the batch operation, troubleshoot the issue as prompted.

## Batch enter forward switchover stage

OMS Community Edition allows you to enable multiple data migration tasks that are in the **<UI-TERM key="oms-community.Operator.constants.Running">Running</UI-TERM>** state and have completed full verification to enter the forward switchover stage.

![batch-enter-forward-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/batch-enter-forward-en.png)

1. On the **<UI-TERM key="oms-community.pages.Migration.MigrationProject">Migration Tasks</UI-TERM>**  page, select the data migration tasks to enter the forward switchover stage.

2. In the lower part of the page, choose **<UI-TERM key="oms-community.components.BatchSelect.MoreBatchOperations">More Batch Operations</UI-TERM>** > **<UI-TERM>Batch Enter Forward Switchover</UI-TERM>**.

3. In the dialog box that appears, click **<UI-TERM key="oms-community.components.SyncSwitch.ConfirmStopSourceApp.Determine">OK</UI-TERM>**.

   This dialog box will display the number of tasks that can enter the forward switchover stage, the task names, and the latest timestamps.

4. After the operation succeeds, the number of tasks that succeeded in the batch operation is displayed.

   For any task that failed the batch operation, troubleshoot the issue as prompted.

## Batch modify alert configuration

OMS Community Edition allows you to batch modify the alert configuration of data migration tasks in the **<UI-TERM key="oms-community.Sync.constants.NotStarted.5">Not Started</UI-TERM>**, **<UI-TERM key="oms-community.ModifyRecordTable.constants.Running">Running</UI-TERM>**, **<UI-TERM>Stopped</UI-TERM>**, or **<UI-TERM key="oms-community.Detail.components.FullMigration.Failed">Failed</UI-TERM>** state.

1. On the **<UI-TERM key="oms-community.pages.Migration.MigrationProject">Migration Tasks</UI-TERM>**  page, select the data migration tasks whose alert settings are to be modified.

2. Choose **<UI-TERM key="oms-community.components.BatchSelect.MoreBatchOperations">More Batch Operations</UI-TERM>** > **<UI-TERM key="oms-community.Migration.model.migration.vm.ModifyAlertConfigurationsInBatches">Batch Modify Alert Configuration</UI-TERM>** in the lower part of the page.

3. In the **<UI-TERM key="oms-community.utils.hooks.useOMSWarn.ConfigureMultipleAlerts">Batch Configure Alerts</UI-TERM>** dialog box, specify the related parameters.

   ![batch-modify-alert-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/batch-modify-alert-en.png)

   OMS Community Edition supports the following alert levels: **<UI-TERM key="oms-community.components.WarnLevel.Unprotected">No Protection</UI-TERM>**, **<UI-TERM key="oms-community.components.WarnLevel.HighProtection">High Protection</UI-TERM>**, **<UI-TERM key="oms-community.components.WarnLevel.MediumProtection">Medium Protection</UI-TERM>**, and **<UI-TERM key="oms-community.components.WarnLevel.DiBaoHu">Low Protection</UI-TERM>**. For more information, see [Alert settings](../../1000.system-management/200.alert-center/300.manage-alert-settings.md).

4. Click **<UI-TERM key="oms-community.components.WarnContent.Submitted">Submit</UI-TERM>**.

   To view the alerts generated for a data migration or synchronization task, see [View task alerts](../../1000.system-management/200.alert-center/100.view-project-alerts.md).

5. After the alert settings are modified for the selected tasks, a prompt is displayed on the page. For any task that failed the batch operation, troubleshoot the issue as prompted.

## Batch skip full verification

OMS Community Edition allows you to batch skip full verification for data migration tasks that are in the **<UI-TERM key="oms-community.Sync.constants.YunXingZhong">Running</UI-TERM>**, **<UI-TERM>Stopped</UI-TERM>**, or **<UI-TERM key="oms-community.pages.Audit.Failed">Failed</UI-TERM>** state during the full verification stage.

![batch-skip-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/batch-skip-en.png)

1. On the **<UI-TERM key="oms-community.pages.Migration.MigrationProject">Migration Tasks</UI-TERM>**  page, select the data migration tasks to skip full verification.

2. Choose **<UI-TERM key="oms-community.components.BatchSelect.MoreBatchOperations">More Batch Operations</UI-TERM>** > **<UI-TERM key="oms-community.Migration.constants.SkipFullVerificationInBatches">Batch Skip Full Verification</UI-TERM>** in the lower part of the page.

3. In the dialog box that appears, click **<UI-TERM key="oms-community.Migration.hooks.useMigrationObject.Determine">OK</UI-TERM>**.

   This dialog box will display the number of tasks that can skip full verification, the task names, and the latest timestamps.

4. After the operation succeeds, the number of tasks that succeeded in the batch operation is displayed.

   For any task that failed the batch operation, troubleshoot the issue as prompted.
