# Use tags to manage data migration tasks

OceanBase Migration Service (OMS) Community Edition allows you to manage data migration tasks by using tags.

## Background

After you create a data migration task, you can use tags to manage and filter the task. All tags can be shared. However, the admin user and general users have different privileges on tags:

* The admin user can create, query, modify, delete, and revoke tags.

* A general user can create, query, and revoke tags, and can modify and delete tags that are created by the user.

* A general user can use tags created by the admin user and other general users but can manage only tags created by themselves.

## Limitations

* You can add up to four tags to a data migration task.

* The total number of tags for all migration and synchronization tasks cannot exceed 100.

* The tag names must be unique in OMS Community Edition.

## Go to the Manage Tags dialog box

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, click **<UI-TERM key="oms-community.src.constants.DataMigration">Data Migration</UI-TERM>**.

3. Go to the **<UI-TERM key="oms-community.components.ProjectLabel.LabelSelect.ManageTags">Manage Tags</UI-TERM>** dialog box.

   You can use one of the following methods to go to the Manage Tags dialog box:

   * Use the Edit Tag icon in the Actions column of the task.

      1. On the **<UI-TERM key="oms-community.layout.constants.DataMigration">Data Migration</UI-TERM>** page, find the task.

      2. Click the Edit Tag icon in the Actions column of the task.

      3. In the **<UI-TERM key="oms-community.components.ProjectLabel.LabelManager.ModifyTags">Edit Tag</UI-TERM>** dialog box, click the field.

      4. In the drop-down list, click **<UI-TERM key="oms-community.components.ProjectLabel.LabelSelect.ManageTags">Manage Tags</UI-TERM>**.

   * Use the drop-down list on the Migration Tasks page.

      1. On the **<UI-TERM key="oms-community.Migration.New.DataMigration">Data Migration</UI-TERM>** page, click **<UI-TERM key="oms-community.components.ProjectLabel.Labels.Label">Tag</UI-TERM>** in the upper-right corner.

      2. In the drop-down list, click **<UI-TERM key="oms-community.components.ProjectLabel.LabelSelect.ManageTags">Manage Tags</UI-TERM>**.

## Create a tag

1. In the **<UI-TERM key="oms-community.components.ProjectLabel.LabelSelect.ManageTags">Manage Tags</UI-TERM>** dialog box, click **<UI-TERM key="oms-community.components.ProjectLabel.LabelManager.CreateTag">Create Tag</UI-TERM>**.

2. In the **<UI-TERM key="oms-community.components.ProjectLabel.LabelManager.CreateTag">Create Tag</UI-TERM>** dialog box, specify the tag name in the **<UI-TERM key="oms-community.components.ProjectLabel.LabelManager.TagName">Tag Name</UI-TERM>** field.

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>The tag name must be 1 to 20 characters in length and cannot contain a space. </p>
    </main>

3. Click **<UI-TERM key="oms-community.components.TreeTransfer.TargetNode.Determine">OK</UI-TERM>**.

## Modify a tag

1. In the **<UI-TERM key="oms-community.components.ProjectLabel.LabelSelect.ManageTags">Manage Tags</UI-TERM>** dialog box, click **<UI-TERM key="oms-community.oms-models.structMigration.constants.ModifyTheCreationSyntax">Modify</UI-TERM>** in the Actions column of the tag that you want to modify.

2. In the **<UI-TERM key="oms-community.components.ProjectLabel.LabelManager.ModifyTags">Edit Tag</UI-TERM>** dialog box, modify the tag name.

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>The tag name must be 1 to 20 characters in length and cannot contain a space. </p>
    </main>

3. Click **<UI-TERM key="oms-community.pages.EndpointPublic.Confirmation">OK</UI-TERM>**.

   * If no task uses the tag, the modification immediately takes effect.

   * If the tag is used by one or more tasks, a dialog box automatically appears, showing the number of tasks that use the tag. After you confirm the modification, click **<UI-TERM key="oms-community.components.FullValidation.UpdateValidatingSqlDrawer.Confirmation">OK</UI-TERM>**.

## Delete a tag

1. In the **<UI-TERM key="oms-community.components.ProjectLabel.LabelSelect.ManageTags">Manage Tags</UI-TERM>** dialog box, click **<UI-TERM key="oms-community.Sync.constants.Delete">Delete</UI-TERM>** in the Actions column of the tag that you want to delete.

2. In the dialog box that appears, click **<UI-TERM key="oms-community.Endpoint.constants.Delete">Delete</UI-TERM>**.

   * If no task uses the tag, the tag is deleted.

   * If the tag is used by one or more tasks, a dialog box automatically appears, showing the number of tasks that use the tag. After you confirm the operation, click **<UI-TERM key="oms-community.components.ETL.ETLFormDrawer.Determine">OK</UI-TERM>**.

    <main id="notice" type='explain'>
    <h4>Description</h4>
    <p>After the tag is deleted, it no longer appears in work items of the task. Proceed with caution. </p>
    </main>

## Revoke a tag

1. On the **<UI-TERM key="oms-community.components.UserGuidance.DataMigration">Data Migration</UI-TERM>** page, click the Edit Tag icon in the Actions column of the task whose tags you want to modify.

2. In the **<UI-TERM key="oms-community.components.ProjectLabel.LabelManager.ModifyTags">Edit Tag</UI-TERM>** dialog box, click the delete icon in the Actions column of the selected tag.

3. Click **<UI-TERM key="oms-community.pages.Endpoint.Confirmation">OK</UI-TERM>**.
