# (Optional) Deploy a time series database

To enable OMS Community Edition to collect and display historical monitoring data, deploy a time series database. This topic describes the limitations of time series databases and how to deploy them.

## Limitations

* Only InfluxDB V1.8 is supported as the time series database.

* When you deploy a time series database, use port 8086.

* Currently, only single-node deployment is supported for time series databases. Therefore, deploy only one time series database. You can deploy a time series database and OMS Community Edition on the same host. If the service is unavailable, the monitoring data is unavailable.

## Procedure

1. Log in to the host on which you want to deploy the time series database.

2. Load the InfluxDB V1.8 image.

   Download and upload the InfluxDB image to the host on which you want to deploy the time series database. [Click here](https://oms-images.oss-cn-shanghai.aliyuncs.com/current_branchs/influxdb_1.8.tar.gz) to download the InfluxDB image.

   ```shell
   sudo docker load -i ${influxdb_image}
   ```

3. Start the Docker container and ensure that the data mount disk has write permissions.

   ```shell
   sudo docker run  -dit -p 8086:8086 -p 14444:14444 \
   -v {mount data disk}:/var/lib/influxdb \
   --env INFLUXDB_BIND_ADDRESS=127.0.0.1:14444 \
   --env INFLUXDB_HTTP_AUTH_ENABLED=true \
   --env INFLUXDB_HTTP_PING_AUTH_ENABLED=true \
   --name=oms-influxdb \
   influxdb:1.8
   ```

4. If you need to enable authentication for the InfluxDB service, set the username and password.

   1. Enter the InfluxDB container.

      ```shell
      docker exec -it ${INFLUXDB_NAME} bash
      ```

   2. Open the InfluxDB console.

      ```shell
      cd /usr/bin
      ./influx
      ```

   3. Create a username and password and assign the admin privilege to the user.

      ```shell
      create user "${USER_NAME}" with password '${PASSWORD}' with all privileges
      ```

   4. Run the `auth` command to verify the username and password. The username and password must be assigned the admin privilege.

   5. Run the `show users` command to view the users.

      To view the databases, run the `show databases` command.

5. Exit the container where the time series database is located.
