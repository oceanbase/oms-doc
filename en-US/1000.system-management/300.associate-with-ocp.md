# Associate with OCP clusters

OceanBase Migration Service (OMS) Community Edition supports associating with OceanBase Cloud Platform (OCP). This topic describes how to add, modify, and delete an association with OCP clusters.

## Background information

OceanBase Cloud Platform (OCP) is the management console for OceanBase Database. You can use OCP to create, manage, and monitor OceanBase clusters. If you need to obtain incremental logs (Clogs) from OceanBase data sources or use OCP as an alert channel, you can associate OCP clusters with OMS Community Edition. OMS Community Edition will directly connect to the metadata database of OCP through JDBC to query the information required for data migration.

## Limitations

* OMS Community Edition supports OCP V3.1.1-CE, V3.3.0-CE, V4.0.0-CE, V4.0.3-CE, V4.2.0-CE, V4.2.1-CE, V4.2.2-CE, V4.3.0-CE, V4.3.1-CE, V4.3.2-CE, V4.3.3-CE, V4.3.4-CE, V4.3.5-CE, and V4.3.6-CE.

* The OCP user must have the `ALARM_MANAGER` or `ALARM_VIEWER` privilege.

## Associate an OCP cluster

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.SystemManagement">System Management</UI-TERM>** \> **<UI-TERM key="oms-community.Audit.constants.AssociateOcp">Associated OCP Clusters</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.Audit.constants.AssociateOcp">Associated OCP Clusters</UI-TERM>** page, click **<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.AddAnAssociatedOcp">Add Associated OCP Cluster</UI-TERM>** in the upper-right corner.

4. In the **<UI-TERM key="oms-community.OCP.components.OCPForm.AddAnAssociatedOcp">Add Associated OCP Cluster</UI-TERM>** dialog box, configure the parameters.

   | Parameter | Description |
   |---------|---------------------------------|
   | OCP Cluster Name | The name of the OCP cluster. The name must be 3 to 32 characters in length. <br>**Note:**<br>The OCP cluster name must be unique in the OMS system.    |
   | Service Address    | The login address of the OCP. The format is `http://IP:Port`, `http://DNS`, or `http://DNS:Port`. |
   | Username | The username used to log in to the OCP.          |
   | Password  | The password used to log in to the OCP.           |
   | Version (Optional)  | The version of the OCP.                       |

5. Click **<UI-TERM key="oms-community.EndpointPublic.components.FormContent.TestConnection">Test Connection</UI-TERM>**.

6. After the test is successful, click **<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.Submitted">Submit</UI-TERM>**.

   You can also click **<UI-TERM key="oms-community.Detail.components.StructMigration.Cancel">Cancel</UI-TERM>** to return to the **<UI-TERM key="oms-community.pages.OCP.OcpList">OCP Clusters</UI-TERM>** page.

## Modify the associated OCP cluster

1. On the **<UI-TERM key="oms-community.Audit.constants.AssociateOcp">Associated OCP Clusters</UI-TERM>** page, click **<UI-TERM key="oms-community.Audit.constants.Modify">Modify</UI-TERM>** next to the target OCP.

2. In the **<UI-TERM key="oms-community.OCP.components.OCPForm.ModifyAssociatedOcp">Modify Associated OCP Cluster</UI-TERM>** dialog box, modify the corresponding parameters.

   <main id="notice" type='notice'>
   <h4>Notice</h4>
   <p>You cannot modify the <strong>OCP cluster name</strong> and <strong>Service Address</strong> of the associated OCP cluster. </p>
   </main>

3. Click **<UI-TERM key="oms-community.OCP.components.OCPForm.TestConnection">Test Connection</UI-TERM>**.

4. After the test is successful, click **<UI-TERM key="oms-community.OCP.components.OCPForm.Submitted">Submit</UI-TERM>**.

   You can also click **<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.Cancel">Cancel</UI-TERM>** to return to the **<UI-TERM key="oms-community.pages.OCP.OcpList">OCP Clusters</UI-TERM>** page.

## Delete the associated OCP cluster

Before you delete the OCP information, you must stop the data migration or data synchronization task that is running on the associated data source.

1. On the **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.AssociateOcp">Associated OCP Clusters</UI-TERM>** page, click **<UI-TERM key="oms-community.migration.full.constants.Delete">Delete</UI-TERM>** next to the target OCP cluster.

2. In the dialog box that appears, click **<UI-TERM key="oms-community.Operator.JDBCWriter.useJDBCWriterAction.Update">OK</UI-TERM>**.
