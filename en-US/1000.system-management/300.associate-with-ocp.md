# Associate with OCP

You can associate OceanBase Migration Service (OMS) with OceanBase Cloud Platform (OCP) clusters. This topic describes how to add, modify, and delete an OCP cluster in the OMS console.

## Background information

OCP is the management platform of OceanBase Database. You can create OceanBase clusters and perform cluster O\&M and monitoring operations in the OCP console. When OMS needs to obtain the clogs of an OceanBase data source or use OCP as the alert channel, you must associate OMS with an OCP cluster. OMS uses the Java Database Connectivity (JDBC) connection URL to connect to the OCP MetaDB and query the information required for data migration.

## Limits

OMS Community Edition supports only OCP V3.1.1-CE, V3.3.0-CE, V4.0.0-CE, V4.0.3-CE, V4.2.0-CE and 4.2.1-CE.

## Add an OCP cluster

1. Log on to the OMS console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.SystemManagement">System Management</UI-TERM>** > **<UI-TERM>Associated OCP Cluster</UI-TERM>**.

3. On the **<UI-TERM>Associated OCP Cluster</UI-TERM>** page, click **<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.AddAnAssociatedOcp">Add Associated OCP Cluster</UI-TERM>**.

4. In the **<UI-TERM key="oms-community.OCP.components.OCPForm.AddAnAssociatedOcp">Add Associated OCP Cluster</UI-TERM>** dialog box, specify the following parameters.

   |    Parameter     |                                            Description                                            |
   |------------------|---------------------------------------------------------------------------------------------------|
   | OCP Cluster Name | The name of the OCP cluster. The name must be 3 to 32 characters in length.                       |
   | Endpoint         | The URL used by OMS to access the OCP cluster. The value is in the IP address:port number format. |
   | API Username     | The logon username used by OMS to access the OCP cluster.                                         |
   | API Password     | The logon password used by OMS to access the OCP cluster.                                         |
   | Version          | Optional. The version of OCP.                                                                     |

5. Click **<UI-TERM key="oms-community.EndpointPublic.components.FormContent.TestConnection">Test Connection</UI-TERM>**.

6. After the test succeeds, click **<UI-TERM key="oms-community.JDBCWriter.New.Submitted">Submit</UI-TERM>**.

   You can also click **<UI-TERM key="oms-community.Modal.DangerousConfirm.Cancel">Cancel</UI-TERM>** and return to the **<UI-TERM>OCP List</UI-TERM>** page.

## Modify an associated OCP

1. On the **<UI-TERM>Associated OCP Clusters</UI-TERM>** page, click **<UI-TERM key="oms-community.components.CommunityParameterForm.constant.Modification">Modify</UI-TERM>** in the Actions column of the OCP cluster that you want to modify.

2. In the **<UI-TERM>Modify Associated OCP</UI-TERM>** dialog box, modify parameters as needed.

   **Notice**

   You cannot modify the **<UI-TERM key="oms-community.pages.OCP.OcpName">OCP Cluster Name</UI-TERM>** and **<UI-TERM>Endpoint</UI-TERM>** parameters.

3. Click **<UI-TERM key="oms-community.pages.OCP.constant.TestConnection">Test Connection</UI-TERM>**.

4. After the test succeeds, click **<UI-TERM key="oms-community.Notification.Setting.AlarmChannelModal.Submitted">Submit</UI-TERM>**.

   You can also click **<UI-TERM key="oms-community.components.ViewObj.AddObject.Cancel">Cancel</UI-TERM>** and return to the **<UI-TERM>OCP List</UI-TERM>** page.

## Delete an associated OCP cluster

To delete an associated OCP cluster, you must release the running data migration or synchronization task that involves the associated data source.

1. On the **<UI-TERM>Associated OCP Clusters</UI-TERM>** page, click **<UI-TERM key="oms-community.OperationComponent.Connector.Delete">Delete</UI-TERM>** in the Actions column of the OCP cluster that you want to delete.

2. In the dialog box that appears, click **<UI-TERM key="oms-community.Detail.components.StructSync.Determine">OK</UI-TERM>**.
