# Manage users

This topic describes the operations you can perform on the User Management page after you log in to the OceanBase Migration Service (OMS) Community Edition console as different roles.

## Limitations

* Users with the USER role cannot view the **<UI-TERM key="oms-community.layout.constants.UserManagement">User Management</UI-TERM>** page.

* Users with the ROOT-VIEWER or ADMIN-VIEWER role can view the **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.UserManagement">User Management</UI-TERM>** page but cannot create, edit, or delete users.

## Create a user

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="transmit.terminal.notification">System Management</UI-TERM>** \> **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.UserManagement">User Management</UI-TERM>**.

   If you are a root user or a user with the ROOT-VIEWER role, first click **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.SystemManagement">System Management</UI-TERM>** \> **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.PermissionManagement">Permission Management</UI-TERM>** to go to the **<UI-TERM key="oms-community.pages.User.UserManagement">User Management</UI-TERM>** page. You can filter users by department on this page.

3. On the **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.UserManagement">User Management</UI-TERM>** page, click **<UI-TERM key="oms-community.pages.User.CreateUser">Create User</UI-TERM>** in the upper-right corner.

4. In the **<UI-TERM key="oms-community.User.New.CreateUser">Create User</UI-TERM>** dialog box, configure the parameters.

   |  Parameter  |                                    Description                                    |
   |------|--------------------------------------------------------------------------|
   | Account   | The account name that is customized, which must be 64 characters or less.                                  |
   | Role   | The role to be created. <ul><li>Root users can choose the ROOT-VIEWER, ADMIN, ADMIN-VIEWER, and USER roles. <li>ADMIN users can choose the ADMIN-VIEWER and USER roles. </ul>                                        |
   | Department  |  Root users can select a department. However, when you create a user with the ROOT-VIEWER role, the default department is selected. If you want to create a new department, you can click **<UI-TERM key="oms-community.pages.User.CreateANewDepartment">Create Department</UI-TERM>** in the drop-down list. For more information, see [Manage departments](../100.permission-management/300.department-management.md). |
   | Password   | The password must be more than 8 characters but less than 32 characters in length, and must contain at least 2 digits, 2 uppercase letters, 2 lowercase letters, and 2 special characters. Supported special characters are as follows:<br> ~!@#%^&*_-+=|(){}[]:;,.?/|
   | Email (Optional)   | The email address of the user.                                       |
   | Mobile Number (Optional) | The mobile number of the user.                               |
   | Note (Optional)   | The description of the user, which can be up to 256 characters.                    |

5. Click **<UI-TERM key="oms-community.JDBCWriter.New.Submitted">Submit</UI-TERM>**.

## Change the user password

1. On the **<UI-TERM key="oms-community.Audit.constants.UserManagement">User Management</UI-TERM>** page, click **<UI-TERM key="oms-community.components.ResetPassword.ResetUserPassword.ChangePassword">Change Password</UI-TERM>** in the Actions column of the target user.

2. In the **<UI-TERM key="oms-community.components.ResetPassword.ResetOwnPassword.ChangePassword">Change Password</UI-TERM>** dialog box, specify a new password in the **<UI-TERM key="oms-community.components.ResetPassword.ResetUserPassword.NewPassword">New Password</UI-TERM>** field.

3. Click **<UI-TERM key="oms-community.components.SyncObjectForm.Determine">OK</UI-TERM>**.

## Edit a user

1. On the **<UI-TERM key="oms-community.pages.User.UserManagement">User Management</UI-TERM>** page, click **<UI-TERM key="oms-community.pages.User.Editing">Edit</UI-TERM>** in the Actions column of the target user.

2. In the **<UI-TERM key="oms-community.User.New.EditUser">Edit User</UI-TERM>** dialog box, modify the user information as needed.

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>The <strong>Account</strong> field cannot be modified. </p>
    <p>The <strong>Account</strong> and <strong>Department</strong> fields cannot be modified for the admin user or a user with the ROOT-VIEWER role. </p>
    </main>

3. Click **<UI-TERM key="oms-community.JDBCWriter.New.Submitted">Submit</UI-TERM>**.

## Delete a user

  <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>The root and admin users created by the system cannot be deleted. </p>
  </main>

1. Click **<UI-TERM key="oms-community.Notification.Setting.AlarmChannel.Delete">Delete</UI-TERM>** in the Actions column of the target user.

2. In the dialog box that appears, click **<UI-TERM key="oms-community.Detail.components.UpdateSyncObj.Determine">OK</UI-TERM>**.
