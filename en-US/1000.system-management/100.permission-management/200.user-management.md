# Manage users

This topic describes the supported operations on the **<UI-TERM key="oms-community.layout.constants.UserManagement">User Management</UI-TERM>** page after you log on to the console of OceanBase Migration Service (OMS) as users with different roles.

## Limits

* The **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.UserManagement">User Management</UI-TERM>** page is not displayed for users with the USER role.

* Users with the ROOT-VIEWER or ADMIN-VIEWER role can view only the user information on the **<UI-TERM key="oms-community.SystemParam.contants.UserManagement">User Management</UI-TERM>** page, but cannot create, edit, or delete a user.

## Create a user

1. Log on to the console of OMS.

2. In the left-side navigation pane, choose **<UI-TERM key="transmit.terminal.notification">System Management</UI-TERM>** > **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.UserManagement">User Management</UI-TERM>**.

   If you log on as the root user or a user with the ROOT-VIEWER role, you can choose **<UI-TERM key="transmit.terminal.notification">System Management</UI-TERM>** > **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.PermissionManagement">Permission Management</UI-TERM>**, and filter users by department on the **<UI-TERM key="oms-community.pages.User.UserManagement">User Management</UI-TERM>** page.

3. On the **<UI-TERM key="oms-community.layout.constants.UserManagement">User Management</UI-TERM>** page, click **<UI-TERM key="oms-community.pages.User.CreateUser">Create User</UI-TERM>** in the upper-right corner.

4. In the **<UI-TERM key="oms-community.User.New.CreateUser">Create User</UI-TERM>** dialog box, specify the parameters.

   | Parameter | Description |
   |------|--------------------------------------------------------------------------|
   | Account | The name can contain letters and underscores (_) and cannot exceed 14 characters in length.  |
   | Role | Select a role from the drop-down list. <ul><li>The following roles are available for selection by the root user: ROOT-VIEWER, ADMIN, ADMIN-VIEWER, and USER.  <li>The following roles are available for selection by a user with the ADMIN role: ADMIN-VIEWER, and USER. </ul> |
   | Department | Only the root user can select a department. When you create a user with the ROOT-VIEWER role, `default` is used by default. To create a department, select **<UI-TERM key="oms-community.User.New.CreateANewDepartment">Create Department</UI-TERM>** from the drop-down list. For more information, see [Department management](../100.permission-management/300.department-management.md).  |
   | Password | The password must be a string of 8 to 32 characters and contains at least two digits, two upper-case letters, two lower-case letters, and two special characters. The following special characters are supported:<br>~ ! @ # % ^ & * _ - + = \ | ( ) { } : ; , . ? /[] |
   | Email (Optional) | The email address of the user.  |
   | Mobile Number (Optional) | The mobile phone number of the user.  |
   | Description (Optional) | The description of the user. The description can contain up to 256 characters in length.  |

5. Click **<UI-TERM key="oms-community.User.Personal.Submitted">Submit</UI-TERM>**.

## Change the password of a user

1. On the **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.UserManagement">User Management</UI-TERM>** page, click **<UI-TERM key="oms-community.pages.User.ChangePassword">Change Password</UI-TERM>** in the **<UI-TERM key="oms-community.pages.OCP.Operation">Actions</UI-TERM>** column of the user whose password you want to change.

2. In the **<UI-TERM key="oms-community.components.ResetPassword.ResetOwnPassword.ChangePassword">Change Password</UI-TERM>** dialog box, specify **<UI-TERM key="oms-community.components.ResetPassword.ResetOwnPassword.NewPassword">New Password</UI-TERM>**.

3. Click **<UI-TERM key="oms-community.Migration.hooks.useMigrationParams.Determine">OK</UI-TERM>**.

## Edit a user

1. On the **<UI-TERM key="oms-community.layout.constants.UserManagement">User Management</UI-TERM>** page, click **<UI-TERM key="oms-community.Notification.Setting.AlarmChannel.Editing">Edit</UI-TERM>** in the **<UI-TERM key="oms-community.pages.Endpoint.Operation">Actions</UI-TERM>** column of the user that you want to edit.

2. In the **<UI-TERM key="oms-community.User.New.EditUser">Edit User</UI-TERM>** dialog box, modify the user information as needed.

   > **Notice:**
   >
   > You cannot change the account of any user.
   >
   > You cannot change the account or department of an admin user or a user with the ROOT-VIEWER role.

3. Click **<UI-TERM key="oms-community.JDBCWriter.New.Submitted">Submit</UI-TERM>**.

## Delete a user

> **Notice:**
>
> You cannot delete the root user or admin users, which are created by the system.

1. On the **<UI-TERM key="oms-community.Audit.constants.UserManagement">User Management</UI-TERM>** page, click **<UI-TERM key="oms-community.components.BanchView.Delete">Delete</UI-TERM>** in the **<UI-TERM key="oms-community.pages.OCP.Operation">Actions</UI-TERM>** column of the user that you want to delete.

2. In the dialog box that appears, click **<UI-TERM key="oms-community.Detail.components.UpdateSyncObj.Determine">OK</UI-TERM>**.
