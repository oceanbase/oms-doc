# Edit an SSO integration

This topic describes how to modify the configuration of an existing SSO integration.

## Prerequisites

You have logged in to the OMS Community Edition console as an ADMIN user.

## Procedure

1. Log in to the OMS Community Edition console.

2. In the left-side navigation pane, choose **<UI-TERM key="transmit.terminal.notification">System Management</UI-TERM>** > **<UI-TERM key="oms-community.pages.ExternalSSO.SSOManagement">SSO Management</UI-TERM>**.

3. On the **<UI-TERM key="oms-community.pages.ExternalSSO.SSOManagement">SSO Management</UI-TERM>** page, click **<UI-TERM key="oms-community.EndpointPublic.constants.Editing">Edit</UI-TERM>** in the **<UI-TERM key="oms-community.pages.Audit.Operation">Actions</UI-TERM>** column of the SSO integration that you want to modify.

4. In the dialog box that appears, edit the configuration parameters.

5. Click **<UI-TERM key="oms-community.Detail.components.MigrationSteps.Determine">OK</UI-TERM>**.
