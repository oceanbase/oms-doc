# View task alerts

This topic describes the monitoring range supported by the task alert feature. This topic also describes how to view the alerts against migration and synchronization tasks created by all users.

## Background

OceanBase Migration Service (OMS) monitors events in migration and synchronization tasks, such as the migration task failure, migration task delay, synchronization task failure, inconsistent synchronization task status, and synchronization task delay, and sends alerts to corresponding channels.

## Procedure

1. Log on to the OMS console.

2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.SystemManagement">System Management</UI-TERM>** > **<UI-TERM>Alert Management</UI-TERM>**. The **<UI-TERM>Task Alert Messages</UI-TERM>** page appears.

   By default, this page displays alerts of the last 7 days. In the upper-right corner of the page, you can select **<UI-TERM key="oms-community.Notification.utils.LastWeek">Last 7 Days</UI-TERM>**, **<UI-TERM key="oms-community.Notification.utils.LastThreeWeeks">Last 3 Weeks</UI-TERM>**, **<UI-TERM key="oms-community.Notification.utils.LastMonth">Last Month</UI-TERM>**, or **<UI-TERM key="oms-community.Notification.utils.LastThreeMonths">Last 3 Months</UI-TERM>** from the drop-down list to view alerts within different ranges of time. You can also enter the alert ID or message content in the search box in the upper-right corner to search for an alert.

   You can filter alerts by using the **<UI-TERM key="oms-community.Notification.Group.AlertEvents">Alert Events</UI-TERM>** and **<UI-TERM key="oms-community.Notification.Group.SendingStatus">Sending Status</UI-TERM>** columns on the **<UI-TERM>Task Alert Messages</UI-TERM>** page. You can also click the name of the task to which an alert message belongs to go to the page of the corresponding data migration or synchronization task.

   * The following types of alert events are supported:

     * Migration task failure: For more information about how to handle this alert, see [oms_migration_failed](../../1200.reference-guide/300.alarm-reference/400.oms-migration-failed.md).

     * Migration task delay: For more information about how to handle this alert, see [oms_migration_delay](../../1200.reference-guide/300.alarm-reference/500.oms-migration-delay.md).

     * Synchronization task failure: For more information about how to handle this alert, see [oms_sync_failed](../../1200.reference-guide/300.alarm-reference/600.oms-sync-failed.md).

     * Inconsistent synchronization task status: For more information about how to handle this alert, see [oms_sync_status_inconsistent](../../1200.reference-guide/300.alarm-reference/700.oms-sync-status-inconsistent.md).

     * Synchronization task delay: For more information about how to handle this alert, see [oms_sync_delay](../../1200.reference-guide/300.alarm-reference/800.oms-sync-delay.md).

   * An alert can be found in one of the following states:

     * Pending: The alert is waiting for its sending to be scheduled.

     * Failed: The alert failed to be sent to the destination channel due to network issues or other unknown reasons.

     * Successful: The alert is sent to the destination channel, such as OceanBase Cloud Platform (OCP).

     * Completed: If the alert is not triggered within 3 hours, the alert status becomes Completed.

     * Sent again: The alert is sent again because the last sending failed.
