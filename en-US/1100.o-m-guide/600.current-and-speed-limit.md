# Set throttling

This topic describes how to modify parameter settings to set throttling to reduce the impact of data synchronization on the performance of the source or target database, thereby avoiding business loss.

## Background

In the `coordinator` section of the Full-Import or Incr-Sync component, the `throttleIOPS` parameter specifies the I/O operations per second (IOPS) in bytes and the `throttleRps` parameter specifies the records per second (RPS). The default values of both parameters are none, which specifies not to perform throttling. You can modify the `throttleIOPS` and `throttleRps` parameters of the Full-Import component based on business needs.

## Limitations

* OceanBase Migration Service (OMS)  allows you to update the configurations of a Full-Import or Incr-Sync component when it is in the **<UI-TERM key="oms-community.Operation.constants.Running">Running</UI-TERM>**, **<UI-TERM key="oms-community.Detail.components.SyncMonitorDrawer.Stopped">Stopped</UI-TERM>**, or **<UI-TERM>Abnormal</UI-TERM>** state.

* After you update the configurations of a Full-Import or Incr-Sync component, the system will restart the component for the updates to take effect. Proceed with caution.

## Procedure

1. Go to the **<UI-TERM>Full-Import</UI-TERM>** page.

   1. Log in to the OMS console.

   2. In the left-side navigation pane, choose **<UI-TERM key="oms-community.SystemParam.contants.OMMonitoring">OPS & Monitoring</UI-TERM>** > **<UI-TERM key="oms-community.utils.hooks.useLayoutMenus.Components">Component</UI-TERM>**.

   3. On the **<UI-TERM key="oms-community.Operation.OperationComponent.Component">Component</UI-TERM>** page, click the **<UI-TERM>Full-Import</UI-TERM>** tab.

2. On the **<UI-TERM>Full-Import</UI-TERM>** tab, search for the target Full-Import component by the component name, server IP address, or task name.

   You can filter the Full-Import components by region in the Region column and update the configurations of a Full-Import component in the target region.

3. Click **<UI-TERM key="oms-community.Migration.constants.Update">Update</UI-TERM>** in the **<UI-TERM key="oms-community.pages.OCP.Operation">Actions</UI-TERM>** column of the target Full-Import component.

4. In the **<UI-TERM key="oms-community.Operator.Checker.useCheckerAction.UpdateConfigurations">Update Configuration</UI-TERM>** dialog box, move the pointer over the blank area beside the `coordinator` parameter and then click the Add icon.

   If the required parameter already exists, click the Edit icon to change its value.

   ![coordinator-1-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/coordinator-1-en.png)

5. Enter the **key name** (`throttleRps` or `throttleIOPS`) to be added and the click the tick sign.

   ![coordinator-2-en](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/oms/oms-enterprise/coordinator-2-en.png)

6. In the **<UI-TERM key="oms-community.Operator.JDBCWriter.useJDBCWriterAction.UpdateConfigurations">Update Configuration</UI-TERM>** dialog box, find the added key name.

7. Hover the pointer over the new parameter and click the Edit icon that appears. Modify the parameter value and click the check icon.

8. In the **<UI-TERM key="oms-community.Operator.Store.useStoreAction.UpdateConfigurations">Update Configuration</UI-TERM>** dialog box, click **<UI-TERM key="oms-community.components.FullValidation.UpdateValidatingSqlDrawer.Confirmation">OK</UI-TERM>**.
